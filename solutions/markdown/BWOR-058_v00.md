# Operations Research Model: Yangtze General Shopping Mall Lease Optimization

## 1. Decision Variables

Let $x_i$ be the number of stores of type $i$ leased by the mall, where $i \in \{1, 2, 3, 4, 5\}$.

The variables are defined as follows:
*   $x_1$: Number of Jewelry stores
*   $x_2$: Number of Shoes & Hats stores
*   $x_3$: Number of Department Store units
*   $x_4$: Number of Bookstore units
*   $x_5$: Number of Catering stores

**Domain:** All $x_i$ are non-negative integers ($x_i \in \mathbb{Z}^+$).

## 2. Objective Function

The goal is to **Maximize** the total rental income.
The rent is calculated as 20% of the annual profit per store. The profit per store varies depending on the quantity of stores of that specific type opened (economies of scale or market saturation effects).

Let $P_{i,k}$ be the profit per store (in thousand Yuan) for store type $i$ when exactly $k$ stores of that type are opened.
Let $R_{i,k} = 0.20 \times P_{i,k}$ be the rent income per store for type $i$ at quantity $k$.

Based on the table, the rent coefficients ($R_{i,k}$) are:

*   **Jewelry ($i=1$):**
    *   If $x_1=1$: $R_{1,1} = 0.2 \times 9 = 1.8$
    *   If $x_1=2$: $R_{1,2} = 0.2 \times 8 = 1.6$
    *   If $x_1=3$: $R_{1,3} = 0.2 \times 7 = 1.4$
*   **Shoes & Hats ($i=2$):**
    *   If $x_2=1$: $R_{2,1} = 0.2 \times 10 = 2.0$
    *   If $x_2=2$: $R_{2,2} = 0.2 \times 9 = 1.8$
*   **Department Store ($i=3$):**
    *   If $x_3=1$: $R_{3,1} = 0.2 \times 27 = 5.4$
    *   If $x_3=2$: $R_{3,2} = 0.2 \times 21 = 4.2$
    *   If $x_3=3$: $R_{3,3} = 0.2 \times 20 = 4.0$
*   **Bookstore ($i=4$):**
    *   If $x_4=1$: $R_{4,1} = 0.2 \times 16 = 3.2$
    *   If $x_4=2$: $R_{4,2} = 0.2 \times 10 = 2.0$
*   **Catering ($i=5$):**
    *   If $x_5=1$: $R_{5,1} = 0.2 \times 17 = 3.4$
    *   If $x_5=2$: $R_{5,2} = 0.2 \times 15 = 3.0$
    *   If $x_5=3$: $R_{5,3} = 0.2 \times 12 = 2.4$

**Mathematical Objective Function:**
$$ \text{Maximize } Z = \sum_{i=1}^{5} x_i \cdot R_{i, x_i} $$

*Note: In a standard linear programming formulation, this non-linear (piecewise constant) objective would be linearized using binary variables $y_{i,k}$ indicating whether store type $i$ has exactly $k$ units. However, as an integer programming description, the function above accurately reflects the economic reality.*

## 3. Operational Constraints

### A. Area Constraint
The total area occupied by all stores must not exceed the available 5,000 m².
Area per store ($A_i$):
*   $A_1 = 250$
*   $A_2 = 350$
*   $A_3 = 800$
*   $A_4 = 400$
*   $A_5 = 500$

$$ 250x_1 + 350x_2 + 800x_3 + 400x_4 + 500x_5 \le 5000 $$

### B. Minimum and Maximum Store Count Constraints
Based on the "Min" and "Max" columns in Table 5-12:

1.  **Jewelry:**
    $$ 1 \le x_1 \le 3 $$
2.  **Shoes & Hats:**
    $$ 1 \le x_2 \le 2 $$
3.  **Department Store:**
    $$ 1 \le x_3 \le 3 $$
4.  **Bookstore:**
    $$ 0 \le x_4 \le 2 $$
5.  **Catering:**
    $$ 1 \le x_5 \le 3 $$

### C. Integer Constraints
$$ x_i \in \{0, 1, 2, 3\} \quad \forall i \in \{1, 2, 3, 4, 5\} $$
*(Specific domains are further restricted by the Min/Max bounds above.)*
