# Mathematical Model Formulation

## Model Type: MILP (Mixed Integer Linear Programming)

## MANDATORY COST INVENTORY (PRE-MODELING STEP)
| Entity | Setup Cost (Yuan) | Unit Cost (Yuan/unit) | Max Capacity (units) |
|--------|-------------------|----------------------|---------------------|
| Machine A | 1000 | 20 | 900 |
| Machine B | 920 | 24 | 1000 |
| Machine C | 800 | 16 | 1200 |
| Machine D | 700 | 28 | 1600 |

Total demand: 2000 units. All parameters are explicitly provided in Table 5-7.

## Index Sets & Parameters

**Index Set:**
- $I = \{A, B, C, D\}$: set of machines, indexed by $i$

**Parameters:**

| Symbol | Description | Values |
|--------|-------------|--------|
| $S_i$ | Setup cost for machine $i$ (Yuan) | $S_A=1000,\ S_B=920,\ S_C=800,\ S_D=700$ |
| $c_i$ | Unit production cost for machine $i$ (Yuan/unit) | $c_A=20,\ c_B=24,\ c_C=16,\ c_D=28$ |
| $U_i$ | Maximum production capacity of machine $i$ (units) | $U_A=900,\ U_B=1000,\ U_C=1200,\ U_D=1600$ |
| $D$ | Total required production (units) | $D = 2000$ |

## Decision Variables

| Symbol | Description | Domain |
|--------|-------------|--------|
| $x_i$ | Number of units produced on machine $i$ | Continuous, $x_i \geq 0,\quad \forall i \in I$ |
| $y_i$ | Binary variable: 1 if machine $i$ is used (setup incurred), 0 otherwise | Integer, $y_i \in \{0, 1\},\quad \forall i \in I$ |

**Domain Rationale:**
- $x_i$ is **continuous** (aggregate production quantity; no integrality constraint on individual units is stated).
- $y_i$ is **binary/integer** because the setup cost is a fixed charge incurred only if the machine is activated — this is a classic fixed-charge problem structure.

## Objective Function

$$\min \; Z = \sum_{i \in I} S_i \, y_i + \sum_{i \in I} c_i \, x_i$$

Explicitly:

$$\min \; Z = 1000\,y_A + 920\,y_B + 800\,y_C + 700\,y_D + 20\,x_A + 24\,x_B + 16\,x_C + 28\,x_D$$

**Objective Parameter Cross-Reference:**
- $S_A=1000$ ✓, $S_B=920$ ✓, $S_C=800$ ✓, $S_D=700$ ✓
- $c_A=20$ ✓, $c_B=24$ ✓, $c_C=16$ ✓, $c_D=28$ ✓

All objective parameters are matched to explicit values in Table 5-7.

## Operational Constraints

### 1. Demand Satisfaction (Equality)
The factory must produce exactly 2,000 units:

$$\sum_{i \in I} x_i = 2000$$

i.e.,
$$x_A + x_B + x_C + x_D = 2000$$

### 2. Capacity Constraints (Linked to Setup)
Machine $i$ can produce at most $U_i$ units **only if** it is activated. This is enforced by the standard big-$M$ linking constraint:

$$x_i \leq U_i \, y_i, \quad \forall i \in I$$

Explicitly:
$$x_A \leq 900 \, y_A$$
$$x_B \leq 1000 \, y_B$$
$$x_C \leq 1200 \, y_C$$
$$x_D \leq 1600 \, y_D$$

**Interpretation:**
- If $y_i = 0$: $x_i \leq 0 \Rightarrow x_i = 0$ (machine not used, no production, no setup cost).
- If $y_i = 1$: $x_i \leq U_i$ (machine active, production bounded by capacity, setup cost $S_i$ incurred).

### 3. Non-negativity and Domain Bounds
$$x_i \geq 0, \quad \forall i \in I$$
$$y_i \in \{0, 1\}, \quad \forall i \in I$$

## Feasibility Sanity Check

- **Total capacity if all machines used:** $900 + 1000 + 1200 + 1600 = 4700 \geq 2000$. ✓ Feasible.
- **Minimum machines needed:** Even the smallest single capacity is 900 < 2000, so at least 2 machines are required. The model naturally determines the optimal subset.
- **Trivial zero-solution test:** The demand constraint $\sum x_i = 2000$ is an **equality**, so $x_i = 0$ for all $i$ is **not** feasible. ✓ No trivial solution.

## Final Model Summary

$$\boxed{
\begin{aligned}
\min \quad & \sum_{i \in I} S_i \, y_i + \sum_{i \in I} c_i \, x_i \\
\text{s.t.} \quad & \sum_{i \in I} x_i = 2000 \\
& x_i \leq U_i \, y_i, \quad \forall i \in I \\
& x_i \geq 0, \quad \forall i \in I \\
& y_i \in \{0, 1\}, \quad \forall i \in I
\end{aligned}
}
$$

This is a standard **fixed-charge production allocation** MILP. The binary variables $y_i$ activate the fixed setup costs, while the continuous variables $x_i$ allocate production quantities subject to per-machine capacities. The solver will simultaneously determine which machines to run and how to split the 2,000-unit order among them to minimize total cost (setups + variable production).
