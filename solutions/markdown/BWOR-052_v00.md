# OR Model Formulation: Production Allocation with Fixed-Charge Costs

## 1. Decision Variables

To model the fixed setup costs and variable production costs, we define two sets of variables for each machine $i \in \{A, B, C, D\}$:

1.  **Continuous Variable**: $x_i$
    *   Definition: The number of units of the product produced on machine $i$.
    *   Domain: $x_i \ge 0$, $x_i \in \mathbb{R}$ (or $\mathbb{Z}$ if integer production is strictly required, though usually continuous is accepted for large batch sizes unless specified).

2.  **Binary Variable**: $y_i$
    *   Definition: An indicator variable that determines whether machine $i$ is used.
    *   Domain: $y_i \in \{0, 1\}$
    *   Logic: $y_i = 1$ if machine $i$ is turned on (setup cost incurred); $y_i = 0$ if machine $i$ is idle.

## 2. Objective Function

The goal is to **Minimize** the total production cost, which consists of the sum of fixed setup costs and variable unit production costs.

$$
\text{Minimize } Z = \sum_{i \in \{A,B,C,D\}} (f_i y_i + c_i x_i)
$$

Where:
*   $f_i$ is the setup cost for machine $i$.
*   $c_i$ is the unit production cost for machine $i$.

Explicitly:
$$
\text{Minimize } Z = 1000y_A + 20x_A + 920y_B + 24x_B + 800y_C + 16x_C + 700y_D + 28x_D
$$

## 3. Operational Constraints

### A. Demand Satisfaction
The total production across all machines must exactly meet the required demand of 2,000 units.
$$
x_A + x_B + x_C + x_D = 2000
$$

### B. Capacity Constraints
The production on any machine cannot exceed its maximum capacity.
$$
x_A \le 900
$$
$$
x_B \le 1000
$$
$$
x_C \le 1200
$$
$$
x_D \le 1600
$$

### C. Linking Constraints (Fixed-Charge Logic)
These constraints ensure that the setup cost ($f_i$) is incurred only if production ($x_i$) occurs on machine $i$, and that production is zero if the machine is not set up. We use the maximum capacity of each machine as the upper bound for the linking constraint.

$$
x_A \le 900 y_A
$$
$$
x_B \le 1000 y_B
$$
$$
x_C \le 1200 y_C
$$
$$
x_D \le 1600 y_D
$$

*(Note: If $y_i = 0$, then $x_i$ must be 0. If $x_i > 0$, then $y_i$ must be 1.)*

### D. Non-negativity and Integrality
$$
x_i \ge 0 \quad \forall i \in \{A, B, C, D\}
$$
$$
y_i \in \{0, 1\} \quad \forall i \in \{A, B, C, D\}
$$
