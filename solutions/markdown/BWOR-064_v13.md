To formulate this problem, we must recognize that for each factory, the investment options are **mutually exclusive** (you can only pick one plan per factory) and **binary** (you either pick a plan or not). This is a variation of the **Multiple-Choice Knapsack Problem**.

### 1. Index Sets & Parameters

**Sets:**
*   $I = \{1, 2, 3\}$: Set of factories.
*   $P_i$: Set of available plans for factory $i$.
    *   $P_1 = \{1, 2, 3\}$ (Plans with investment 0, 1, 2)
    *   $P_2 = \{1, 2, 3, 4\}$ (Plans with investment 0, 2, 3, 4)
    *   $P_3 = \{1, 2\}$ (Plans with investment 0, 1)
*   $P$: The set of all valid (Factory, Plan) pairs $(i, j)$ such that $j \in P_i$.

**Parameters:**
*   $C_{ij}$: Investment cost (in million yuan) for plan $j$ at factory $i$.
*   $R_{ij}$: Return (in million yuan) for plan $j$ at factory $i$.
*   $B$: Total available budget = 5 million yuan.

**Data Extraction from Table 7-4:**

| Factory ($i$) | Plan ($j$) | Investment $C_{ij}$ | Return $R_{ij}$ |
| :--- | :--- | :--- | :--- |
| 1 | 1 | 0 | 0 |
| 1 | 2 | 1 | 5 |
| 1 | 3 | 2 | 6 |
| 2 | 1 | 0 | 0 |
| 2 | 2 | 2 | 8 |
| 2 | 3 | 3 | 9 |
| 2 | 4 | 4 | 12 |
| 3 | 1 | 0 | 0 |
| 3 | 2 | 1 | 3 |

*(Note: "0 investment / 0 return" is included as a valid option to allow for the case where a factory receives no investment, though the "exactly one plan" constraint handles this naturally if we include the zero-option. Alternatively, we can enforce "at most one" and allow none, but including the zero plan in $P_i$ and forcing "exactly one" is the standard clean formulation.)*

### 2. Decision Variables

Let $x_{ij}$ be a binary decision variable for each factory $i \in I$ and plan $j \in P_i$:
$$
x_{ij} = 
\begin{cases} 
1 & \text{if plan } j \text{ is selected for factory } i \\
0 & \text{otherwise}
\end{cases}
$$

**Domain:** $x_{ij} \in \{0, 1\} \quad \forall i \in I, j \in P_i$

### 3. Objective Function

The goal is to **maximize** the total return.

$$
\text{Maximize } Z = \sum_{i \in I} \sum_{j \in P_i} R_{ij} x_{ij}
$$

Explicitly:
$$
Z = 5x_{1,2} + 6x_{1,3} + 8x_{2,2} + 9x_{2,3} + 12x_{2,4} + 3x_{3,2}
$$
*(Note: Terms with 0 return are omitted for brevity but are part of the sum structure.)*

### 4. Operational Constraints

**Constraint 1: Mutually Exclusive Plans (One plan per factory)**
For each factory $i$, exactly one plan must be chosen. Since we included the "0 investment" plan in our set $P_i$, this constraint ensures that if no profitable plan is chosen, the zero plan is selected instead.

$$
\sum_{j \in P_i} x_{ij} = 1 \quad \forall i \in I
$$

Explicitly:
1.  Factory 1: $x_{1,1} + x_{1,2} + x_{1,3} = 1$
2.  Factory 2: $x_{2,1} + x_{2,2} + x_{2,3} + x_{2,4} = 1$
3.  Factory 3: $x_{3,1} + x_{3,2} = 1$

**Constraint 2: Budget Constraint**
The total investment across all factories must not exceed the available budget of 5 million yuan.

$$
\sum_{i \in I} \sum_{j \in P_i} C_{ij} x_{ij} \le B
$$

Explicitly:
$$
1x_{1,2} + 2x_{1,3} + 2x_{2,2} + 3x_{2,3} + 4x_{2,4} + 1x_{3,2} \le 5
$$
*(Note: $C_{i,1}=0$ for all $i$, so those terms vanish.)*

**Constraint 3: Non-negativity / Binary Bounds**
Already defined in Decision Variables:
$$
x_{ij} \in \{0, 1\} \quad \forall (i,j) \in P
$$

### Summary of the Model

**Model Type:** MILP (Mixed Integer Linear Programming) - specifically a 0-1 Integer Program.

**Indices:**
*   $i \in \{1, 2, 3\}$
*   $j \in P_i$ where $P_1=\{1,2,3\}, P_2=\{1,2,3,4\}, P_3=\{1,2\}$

**Parameters:**
*   $C_{1,2}=1, C_{1,3}=2$
*   $C_{2,2}=2, C_{2,3}=3, C_{2,4}=4$
*   $C_{3,2}=1$
*   $R_{1,2}=5, R_{1,3}=6$
*   $R_{2,2}=8, R_{2,3}=9, R_{2,4}=12$
*   $R_{3,2}=3$
*   $B=5$

**Variables:**
*   $x_{ij} \in \{0,1\}$

**Objective:**
$$ \text{Maximize } Z = 5x_{1,2} + 6x_{1,3} + 8x_{2,2} + 9x_{2,3} + 12x_{2,4} + 3x_{3,2} $$

**Subject to:**
1.  $x_{1,1} + x_{1,2} + x_{1,3} = 1$
2.  $x_{2,1} + x_{2,2} + x_{2,3} + x_{2,4} = 1$
3.  $x_{3,1} + x_{3,2} = 1$
4.  $x_{1,2} + 2x_{1,3} + 2x_{2,2} + 3x_{2,3} + 4x_{2,4} + x_{3,2} \le 5$
5.  $x_{ij} \in \{0,1\}$ for all valid $i,j$.
