# OR Problem Analysis: Transshipment Transportation Model

## 1. Problem Interpretation
This is a **Transshipment Problem** (a generalized transportation problem).
*   **Sources:** X (Supply 70), Y (Supply 55).
*   **Destinations:** A (Demand 35), B (Demand 40), C (Demand 50).
*   **Transshipment Nodes:** In this specific network, destinations A, B, and C can also act as transshipment points to move goods between themselves. Sources X and Y can also send to each other (though usually, sources don't transship to each other in standard models unless specified, Table 3-23 implies X-Y connectivity).
*   **Key Feature:** Goods can flow directly from Source to Destination OR via other nodes (e.g., X $\to$ A $\to$ B).
*   **Objective:** Minimize Total Transport Distance (Cost).

## 2. Decision Variables
Let $x_{ij}$ be the quantity of goods shipped from node $i$ to node $j$.

**Nodes:**
*   Sources: $X, Y$
*   Transshipment/Destinations: $A, B, C$

**Variables:**
$x_{ij} \ge 0$ for all feasible arcs $(i, j)$ where $i \neq j$.

Based on the distance tables, the feasible arcs are:
*   Between Sources: $x_{XY}, x_{YX}$
*   From Sources to Destinations: $x_{XA}, x_{XB}, x_{XC}, x_{YA}, x_{YB}, x_{YC}$
*   Between Destinations (Transshipment): $x_{AB}, x_{AC}, x_{BA}, x_{BC}, x_{CA}, x_{CB}$

*(Note: In standard transshipment modeling, we treat all nodes as both supply and demand points to allow flow conservation.)*

## 3. Objective Function
Minimize the total transportation distance (cost).
Let $c_{ij}$ be the distance from node $i$ to node $j$.

$$
\text{Minimize } Z = \sum_{i \in \{X,Y\}} \sum_{j \in \{A,B,C\}} c_{ij} x_{ij} + \sum_{i \in \{A,B,C\}} \sum_{j \in \{A,B,C\}, j \neq i} c_{ij} x_{ij} + c_{XY} x_{XY} + c_{YX} x_{YX}
$$

Expanding with the given distances:

$$
\begin{aligned}
Z = & 10 x_{XA} + 14 x_{XB} + 12 x_{XC} + 15 x_{YA} + 12 x_{YB} + 18 x_{YC} \\
& + 12 x_{XY} + 10 x_{YX} \\
& + 14 x_{AB} + 11 x_{AC} + 10 x_{BA} + 4 x_{BC} + 8 x_{CA} + 12 x_{CB}
\end{aligned}
$$

*(Note: Distances from a node to itself, e.g., $c_{AA}$, are 0 and do not appear in the objective function as $x_{ii}=0$ typically, or they are omitted.)*

## 4. Operational Constraints

### A. Supply Constraints (Net Outflow = Supply)
For sources, the net outflow (Out - In) must equal the available supply. However, in transshipment models, it is often easier to define **Node Balance Constraints** for all nodes.

Let $S_i$ be supply and $D_i$ be demand.
*   $S_X = 70, S_Y = 55$
*   $D_A = 35, D_B = 40, D_C = 50$

Total Supply = $70 + 55 = 125$.
Total Demand = $35 + 40 + 50 = 125$.
The problem is balanced.

### B. Node Balance Constraints (Flow Conservation)
For each node $i$, $\text{Total Outflow} - \text{Total Inflow} = \text{Net Supply}_i$.
Where $\text{Net Supply}_i = S_i - D_i$.

1.  **Node X:**
    $$
    (x_{XY} + x_{XA} + x_{XB} + x_{XC}) - (x_{YX}) = 70
    $$
    *(Interpretation: Total leaving X minus Total entering X equals Supply at X)*

2.  **Node Y:**
    $$
    (x_{YX} + x_{YA} + x_{YB} + x_{YC}) - (x_{XY}) = 55
    $$

3.  **Node A (Transshipment/Destination):**
    Net Supply at A = $0 - 35 = -35$ (i.e., Inflow must exceed Outflow by 35).
    $$
    (x_{AB} + x_{AC}) - (x_{XA} + x_{YA} + x_{BA} + x_{CA}) = -35
    $$
    Or equivalently:
    $$
    x_{XA} + x_{YA} + x_{BA} + x_{CA} - x_{AB} - x_{AC} = 35
    $$

4.  **Node B (Transshipment/Destination):**
    Net Supply at B = $0 - 40 = -40$.
    $$
    x_{XB} + x_{YB} + x_{AB} + x_{CB} - x_{BA} - x_{BC} = 40
    $$

5.  **Node C (Transshipment/Destination):**
    Net Supply at C = $0 - 50 = -50$.
    $$
    x_{XC} + x_{YC} + x_{AC} + x_{BC} - x_{CA} - x_{CB} = 50
    $$

### C. Non-negativity Constraints
$$
x_{ij} \ge 0 \quad \forall \text{ feasible arcs } (i,j)
$$

## Summary of Model Structure

| Component | Definition |
| :--- | :--- |
| **Decision Variables** | $x_{ij}$: Amount shipped from $i$ to $j$ |
| **Objective** | $\min Z = \sum c_{ij} x_{ij}$ (Sum of distance $\times$ flow for all arcs) |
| **Constraint 1 (X)** | $x_{XY} + x_{XA} + x_{XB} + x_{XC} - x_{YX} = 70$ |
| **Constraint 2 (Y)** | $x_{YX} + x_{YA} + x_{YB} + x_{YC} - x_{XY} = 55$ |
| **Constraint 3 (A)** | $x_{XA} + x_{YA} + x_{BA} + x_{CA} - x_{AB} - x_{AC} = 35$ |
| **Constraint 4 (B)** | $x_{XB} + x_{YB} + x_{AB} + x_{CB} - x_{BA} - x_{BC} = 40$ |
| **Constraint 5 (C)** | $x_{XC} + x_{YC} + x_{AC} + x_{BC} - x_{CA} - x_{CB} = 50$ |
| **Bounds** | $x_{ij} \ge 0$ |
