## 1. Problem Analysis

**Objective:** Minimize total cost (production variable cost + fixed production cost + storage cost).

**Key Parameters (Unit Consistency Check):**
*   **Time Horizon:** $T = 6$ months.
*   **Units:** The table header specifies "Delivery (hundreds of units)". To avoid scaling errors, we will work in **hundreds of units** (let's call this "H-units").
    *   Demand $d_t$ (in H-units): $[1, 2, 5, 3, 2, 1]$.
    *   Production Capacity: 400 units/month = **4 H-units/month**.
    *   Storage Capacity: 300 units = **3 H-units**.
    *   Variable Production Cost: 10,000 yuan per 100 units = **10,000 yuan per H-unit**.
    *   Fixed Production Cost: 4,000 yuan (if $x_t > 0$).
    *   Storage Cost: 1,000 yuan per 100 units per month = **1,000 yuan per H-unit per month**.
*   **Initial/Final Inventory:** $I_0 = 0$, $I_6 = 0$.

**Model Type:** Mixed Integer Linear Programming (MILP).
*   Continuous variables for production quantities $x_t$ and inventory levels $I_t$ (since costs are linear in these quantities and fractional production is theoretically possible in LP relaxation, though physically discrete, the problem asks for "how many units" implying we can solve for the continuous optimum which will likely be integer given the data, or we treat them as continuous for the LP/MILP formulation. Given the fixed cost, we need binary variables for the "production takes place" condition).
*   Binary variables $y_t$ to indicate if production occurs in month $t$.

## 2. Mathematical Formulation

### Index Sets & Parameters

*   **Sets:**
    *   $T = \{1, 2, 3, 4, 5, 6\}$: Set of months.
*   **Parameters (in hundreds of units and yuan):**
    *   $d_t$: Demand in month $t$ (H-units).
        *   $d_1=1, d_2=2, d_3=5, d_4=3, d_5=2, d_6=1$.
    *   $C_{cap}$: Production capacity per month = 4 (H-units).
    *   $I_{cap}$: Warehouse storage capacity = 3 (H-units).
    *   $c_v$: Variable production cost = 10,000 (yuan/H-unit).
    *   $c_f$: Fixed production cost = 4,000 (yuan).
    *   $c_s$: Storage cost = 1,000 (yuan/H-unit/month).
    *   $M$: A sufficiently large constant for the fixed-charge link constraint. We can use $M = C_{cap} = 4$.

### Decision Variables

*   $x_t$: Amount of production in month $t$ (H-units). Domain: $x_t \ge 0, \forall t \in T$.
*   $I_t$: Inventory level at the **end** of month $t$ (H-units). Domain: $I_t \ge 0, \forall t \in T$.
*   $y_t$: Binary variable indicating if production occurs in month $t$.
    *   $y_t = 1$ if $x_t > 0$
    *   $y_t = 0$ if $x_t = 0$
    *   Domain: $y_t \in \{0, 1\}, \forall t \in T$.

### Objective Function

Minimize Total Cost $Z$:
$$ Z = \sum_{t=1}^{6} \left( c_v x_t + c_f y_t \right) + \sum_{t=1}^{5} c_s I_t $$
*(Note: Storage cost is incurred on the inventory held at the end of months 1 through 5. The problem states "no inventory... remaining after the final delivery at the end of June", implying $I_6=0$, so no storage cost is charged for $I_6$ as it is zero. Even if $I_6$ were non-zero, storage is usually charged for the duration it is held. Standard convention: charge $c_s$ for $I_t$ for $t=1$ to $T-1$ if $I_T$ must be 0. Let's verify: "storage cost is ... per month". Usually, you pay for the stock you hold during the month. If you hold $I_t$ at end of month $t$, you held it during month $t$? Or did you hold it in month $t+1$?
Standard Inventory Problem Convention:
- $I_t$ is inventory at end of period $t$.
- Storage cost is typically associated with the inventory held *during* the period. If we define $I_t$ as end-of-period inventory, the cost for period $t$ is often based on average inventory or end-of-period inventory. Given the discrete nature, "1,000 yuan per 100 units per month" usually applies to the quantity held at the end of the month for the next month's availability, or simply the ending balance of that month.
- Let's look at the timeline:
    - End of Month 1: Inventory $I_1$. Cost incurred for holding this stock? Usually, storage cost is charged for the time the item is in the warehouse. If it's there at the end of Month 1, it was there for Month 1 (or part of it).
    - Let's assume the cost is charged on the ending inventory of months 1 through 5. Since $I_6=0$, the cost for month 6 ending inventory is 0 anyway.
    - So, Storage Cost Term: $\sum_{t=1}^{6} c_s I_t$. Since $I_6=0$, this is equivalent to $\sum_{t=1}^{5} c_s I_t$.

$$ \text{Minimize } Z = 10000 \sum_{t=1}^{6} x_t + 4000 \sum_{t=1}^{6} y_t + 1000 \sum_{t=1}^{5} I_t $$

### Operational Constraints

**1. Inventory Balance Constraints (Flow Continuity):**
For each month $t \in \{1, \dots, 6\}$:
$$ I_{t-1} + x_t - d_t = I_t $$
With $I_0 = 0$ and $I_6 = 0$.
Explicitly:
*   $t=1$: $0 + x_1 - 1 = I_1 \implies x_1 - I_1 = 1$
*   $t=2$: $I_1 + x_2 - 2 = I_2$
*   $t=3$: $I_2 + x_3 - 5 = I_3$
*   $t=4$: $I_3 + x_4 - 3 = I_4$
*   $t=5$: $I_4 + x_5 - 2 = I_5$
*   $t=6$: $I_5 + x_6 - 1 = 0 \implies I_5 + x_6 = 1$

**2. Production Capacity Constraints:**
The factory cannot produce more than 4 H-units per month.
$$ x_t \le 4, \quad \forall t \in \{1, \dots, 6\} $$

**3. Storage Capacity Constraints:**
The warehouse cannot hold more than 3 H-units at the end of any month.
$$ I_t \le 3, \quad \forall t \in \{1, \dots, 5\} $$
($I_6 = 0$ is enforced by the balance equation and $x_6 \le 4, I_5 \le 3$).

**4. Fixed Charge Linking Constraints:**
If production occurs ($x_t > 0$), then $y_t$ must be 1. If $y_t = 0$, then $x_t$ must be 0.
$$ x_t \le 4 y_t, \quad \forall t \in \{1, \dots, 6\} $$
(Here $M=4$ is the upper bound on $x_t$).

**5. Non-negativity and Integrality:**
$$ x_t \ge 0, \quad I_t \ge 0, \quad \forall t \in \{1, \dots, 6\} $$
$$ y_t \in \{0, 1\}, \quad \forall t \in \{1, \dots, 6\} $$

## 3. Model Summary for Implementation

**Model Type:** MILP

**Parameters:**
*   `demand = [1, 2, 5, 3, 2, 1]` (H-units)
*   `cap_prod = 4` (H-units)
*   `cap_storage = 3` (H-units)
*   `cost_var_prod = 10000` (yuan/H-unit)
*   `cost_fixed_prod = 4000` (yuan)
*   `cost_storage = 1000` (yuan/H-unit)

**Variables:**
*   `x[1..6]`: Continuous, `lb=0`, `ub=4`
*   `I[1..5]`: Continuous, `lb=0`, `ub=3` (Note: $I_6$ is fixed to 0)
*   `y[1..6]`: Binary

**Objective:**
Minimize `10000 * sum(x) + 4000 * sum(y) + 1000 * sum(I[1..5])`

**Constraints:**
1.  `x[1] - I[1] == 1`
2.  `I[1] + x[2] - I[2] == 2`
3.  `I[2] + x[3] - I[3] == 5`
4.  `I[3] + x[4] - I[4] == 3`
5.  `I[4] + x[5] - I[5] == 2`
6.  `I[5] + x[6] == 1`
7.  `x[t] <= 4 * y[t]` for all `t in 1..6`
8.  `x[t] <= 4` for all `t in 1..6` (Redundant with 7 if y=1, but good for bounds)
9.  `I[t] <= 3` for all `t in 1..5`
