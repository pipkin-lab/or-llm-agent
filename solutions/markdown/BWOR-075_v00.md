# Problem Analysis: Offshore Oil Pipeline Network Design

## 1. Problem Classification
This is a **Minimum Spanning Tree (MST)** problem.
- **Graph Structure**: A complete undirected graph where nodes represent locations (Coast, Wells 1–8) and edge weights represent distances.
- **Goal**: Connect all nodes (Coast + 8 Wells) such that every node is reachable from the Coast (specifically starting at Well 1, but effectively the Coast is the root) with the minimum total edge weight.
- **Constraint**: Pipelines can only branch at well locations. This confirms that the solution must be a tree structure where nodes are exclusively the defined locations (Coast and Wells 1–8), ruling out Steiner points (intermediate branching points in the open ocean).

## 2. Decision Variables
Let $N$ be the set of nodes.
$N = \{C, 1, 2, 3, 4, 5, 6, 7, 8\}$
Where $C$ is the Coast and $1, \dots, 8$ are the oil wells.

Let $E$ be the set of possible edges (pipelines) between any two distinct nodes in $N$.
Let $x_{ij}$ be a binary decision variable for each edge $(i, j) \in E$:

$$
x_{ij} = 
\begin{cases} 
1 & \text{if a pipeline is built between node } i \text{ and node } j \\
0 & \text{otherwise}
\end{cases}
$$

## 3. Objective Function
**Minimize** the total length of the pipelines.

Let $d_{ij}$ be the distance between node $i$ and node $j$.
Note: The distance between the Coast ($C$) and Well 1 is given as 5 miles. The distance between the Coast and any other well $k$ (where $k \neq 1$) is not directly given. However, the problem states "Starting from the coast through Well 1". This implies the connection from the Coast is specifically to Well 1. In standard MST formulations for this specific phrasing ("starting from..."), the Coast is a fixed root connected to Well 1.

*Interpretation Check*: Does the Coast connect to other wells directly?
The problem says "Starting from the coast through Well 1... connect all oil wells". This usually implies the network is rooted at the Coast, connected to Well 1, and then Well 1 connects to the rest. It does *not* explicitly forbid a direct line from Coast to Well 2, but it also doesn't give the distance. In typical textbook problems of this type, if the distance from the source to other nodes isn't given, it is assumed that the source connects only to the specified entry point (Well 1), OR the "Coast" is treated as a node that only has an edge to Well 1.
*Assumption*: The Coast is only connected to Well 1. Therefore, the fixed cost is $d_{C,1} = 5$. The optimization occurs on the subgraph of Wells 1–8.

**Objective Function:**
$$
\text{Minimize } Z = 5 + \sum_{i \in \{1,\dots,8\}} \sum_{j \in \{2,\dots,8\}, j > i} d_{ij} \cdot x_{ij}
$$
*(Note: The term 5 is a constant, so it can be omitted from the optimization calculation, but represents the total physical length.)*

## 4. Operational Constraints

### A. Connectivity (Spanning Tree Constraint)
The selected edges must form a tree connecting all 8 wells. This ensures no cycles and full connectivity.
1.  **Number of Edges**: For 8 nodes (Wells 1-8), a spanning tree must have exactly $8 - 1 = 7$ edges.
    $$
    \sum_{i=1}^{8} \sum_{j=i+1}^{8} x_{ij} = 7
    $$
2.  **Acyclicity**: The graph formed by edges with $x_{ij}=1$ must not contain any cycles. (This is inherently handled if we use an algorithm like Prim's or Kruskal's, but in an Integer Linear Programming formulation, this requires Subtour Elimination Constraints or flow-based formulations).

### B. Node Degree Constraints
Since branching is only allowed at well locations, any well can have any degree from 1 to 7. There are no upper bound restrictions on the degree of a node other than the graph structure.

### C. Variable Domains
$$
x_{ij} \in \{0, 1\} \quad \forall (i, j) \in E, i < j
$$

---

### Summary of the Mathematical Model

**Parameters:**
*   $V = \{1, 2, 3, 4, 5, 6, 7, 8\}$: Set of oil wells.
*   $d_{ij}$: Distance between well $i$ and well $j$ (from Table 8-4).
*   $d_{coast} = 5$: Fixed distance from Coast to Well 1.

**Variables:**
*   $x_{ij} \in \{0,1\}$: 1 if pipeline is laid between well $i$ and $j$, 0 otherwise.

**Model:**

$$
\text{Minimize } Z = \sum_{1 \le i < j \le 8} d_{ij} x_{ij} + 5
$$

**Subject to:**
1.  **Spanning Tree Structure**: The subgraph defined by $\{ (i,j) \mid x_{ij}=1 \}$ is a spanning tree of the complete graph on $V$.
    *   *Implementation Note*: In practice, this is solved using standard MST algorithms (Prim's or Kruskal's) on the 8 nodes, rather than solving a complex ILP. The ILP formulation for MST is complex due to the acyclicity constraints. However, logically, the constraint is simply that the selected edges connect all 8 nodes without forming a loop.

2.  **Connectivity to Source**: Well 1 is the entry point. (Implicitly satisfied by the tree structure connecting all nodes, as the Coast is attached to Node 1).

### Recommended Solution Approach
Since this is a standard **Minimum Spanning Tree** problem on 8 nodes, the most appropriate "model" for execution is the application of **Kruskal's Algorithm** or **Prim's Algorithm** to the distance matrix provided, with the final total length being the MST weight plus 5 miles.
