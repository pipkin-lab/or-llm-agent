# Problem Analysis: Two-Machine Flow Shop with Mixed Routing

## 1. Decision Variables

Since this is a sequencing problem, we define binary decision variables to represent the relative order of jobs in the schedule.

Let $n = 12$ be the total number of jobs.
Let $J = \{1, 2, \dots, 12\}$ be the set of jobs.

**Binary Variable:**
Let $x_{ij}$ be a binary variable where:
$$
x_{ij} = 
\begin{cases} 
1 & \text{if job } i \text{ is scheduled immediately before job } j \\
0 & \text{otherwise}
\end{cases}
$$
*Note: While permutation variables $p_k$ (position of job $k$) are common, the "immediately before" formulation is standard for sequencing constraints. Alternatively, we can define the sequence directly as a permutation $\pi = (\pi_1, \pi_2, \dots, \pi_{12})$ where $\pi_k$ is the job at position $k$. For the purpose of defining the OR model structure, we will use the sequence position approach for clarity in calculating start times.*

Let $S_A(i)$ be the start time of job $i$ on Machine A.
Let $S_B(i)$ be the start time of job $i$ on Machine B.

## 2. Objective Function

**Goal:** Minimize the Makespan ($C_{max}$).
The makespan is the time at which the last job is completed on the last machine it visits.

$$
\text{Minimize } Z = C_{max}
$$

Where $C_{max}$ is defined by the completion times of the final operations:
- For Jobs 1–7 (Route A $\to$ B), completion is on Machine B: $C_B(i) = S_B(i) + P_B(i)$
- For Jobs 8–12 (Route B $\to$ A), completion is on Machine A: $C_A(i) = S_A(i) + P_A(i)$

$$
C_{max} = \max \left( \max_{i \in \{1..7\}} (S_B(i) + P_B(i)), \quad \max_{j \in \{8..12\}} (S_A(j) + P_A(j)) \right)
$$

## 3. Operational Constraints

### A. Routing and Processing Time Data
Based on Table 14-6:
- **Jobs 1–7:** Processed on A then B.
  - $P_A(1)=5, P_B(1)=5$
  - $P_A(2)=8, P_B(2)=9$
  - $P_A(3)=11, P_B(3)=4$
  - $P_A(4)=2, P_B(4)=3$
  - $P_A(5)=7, P_B(5)=7$
  - $P_A(6)=6, P_B(6)=9$
  - $P_A(7)=3, P_B(7)=5$
- **Jobs 8–12:** Processed on B then A.
  - $P_B(8)=4, P_A(8)=9$
  - $P_B(9)=9, P_A(9)=8$
  - $P_B(10)=5, P_A(10)=3$
  - $P_B(11)=3, P_A(11)=6$
  - $P_B(12)=4, P_A(12)=10$

### B. Machine Capacity Constraints (One job at a time)
For any two distinct jobs $i$ and $k$, they cannot overlap on the same machine.

**On Machine A:**
If job $i$ is scheduled before job $k$ in the global sequence, then:
$$ S_A(k) \ge S_A(i) + P_A(i) $$
*Note: The "before" relationship is determined by the permutation sequence. If we use binary variables $y_{ik}^A$ indicating order on Machine A, the constraint is:*
$$ S_A(k) \ge S_A(i) + P_A(i) - M(1 - y_{ik}^A) $$
$$ S_A(i) \ge S_A(k) + P_A(k) - M y_{ik}^A $$

**On Machine B:**
Similarly, if job $i$ is scheduled before job $k$ in the global sequence, then:
$$ S_B(k) \ge S_B(i) + P_B(i) $$
Or with binary variables $y_{ik}^B$:
$$ S_B(k) \ge S_B(i) + P_B(i) - M(1 - y_{ik}^B) $$
$$ S_B(i) \ge S_B(k) + P_B(k) - M y_{ik}^B $$

### C. Precedence Constraints (Flow Shop Logic)
Each job must finish on the first machine before starting on the second.

**For Jobs 1–7 (A $\to$ B):**
$$ S_B(i) \ge S_A(i) + P_A(i) \quad \forall i \in \{1, \dots, 7\} $$

**For Jobs 8–12 (B $\to$ A):**
$$ S_A(j) \ge S_B(j) + P_B(j) \quad \forall j \in \{8, \dots, 12\} $$

### D. Non-negativity
$$ S_A(i) \ge 0, \quad S_B(i) \ge 0 \quad \forall i \in \{1, \dots, 12\} $$

### E. Sequence Consistency (Optional but important for "Optimal Sequence" output)
Since the problem asks for a single "optimal job sequence," it implies a single permutation $\pi$ that defines the order of release/entry into the system or the order on the first machine of each respective path. However, in standard two-machine flow shops with mixed routing, the "sequence" usually refers to the order in which jobs are dispatched to the first machine they encounter.

*Clarification on "Sequence":* In mixed routing problems, a single global sequence does not strictly define the machine availability unless we assume the sequence dictates the order of *arrival* to the first machine.
- Let $\pi$ be the permutation of jobs.
- The order on Machine A for Jobs 1-7 follows the relative order in $\pi$.
- The order on Machine B for Jobs 1-7 follows the relative order in $\pi$.
- The order on Machine B for Jobs 8-12 follows the relative order in $\pi$.
- The order on Machine A for Jobs 8-12 follows the relative order in $\pi$.

Thus, the constraints in Section B must respect the relative order defined by the permutation $\pi$. If job $i$ appears before job $k$ in $\pi$, then $i$ is processed before $k$ on **both** machines (subject to the specific routing).

*Refined Constraint for Sequence $\pi$:*
If $\pi_i < \pi_k$ (Job $i$ is earlier in the sequence than Job $k$):
1. If both $i, k \in \{1..7\}$:
   - $S_A(k) \ge S_A(i) + P_A(i)$
   - $S_B(k) \ge S_B(i) + P_B(i)$
2. If both $i, k \in \{8..12\}$:
   - $S_B(k) \ge S_B(i) + P_B(i)$
   - $S_A(k) \ge S_A(i) + P_A(i)$
3. If $i \in \{1..7\}$ and $k \in \{8..12\}$ (or vice versa):
   - There is no direct machine conflict constraint based *solely* on the global sequence index for cross-group interactions, **except** that the start times are coupled via the machine availability.
   - *Correction:* The "Sequence" in mixed flow shops typically defines the order of job *releases* or the order on the bottleneck. However, standard interpretation of "determine the optimal job sequence" in this context (Jobs 1-7 on A->B, 8-12 on B->A) usually implies we are finding a permutation that optimizes the makespan, where the relative order on *each machine* for jobs visiting that machine is derived from this permutation.
   - Therefore, for any two jobs $i, k$ that share a machine, their order on that machine is determined by their relative position in $\pi$.

### Summary of the OR Model Structure

1.  **Variables:**
    *   Permutation $\pi$ of $\{1, \dots, 12\}$.
    *   Continuous start times $S_A(i), S_B(i)$.

2.  **Objective:**
    *   Minimize $Z = \max( \max_{i \in 1..7} (S_B(i)+P_B(i)), \max_{j \in 8..12} (S_A(j)+P_A(j)) )$.

3.  **Constraints:**
    *   **Precedence:**
        *   $S_B(i) \ge S_A(i) + P_A(i)$ for $i=1..7$
        *   $S_A(j) \ge S_B(j) + P_B(j)$ for $j=8..12$
    *   **Machine Sequencing:**
        *   For all $i, k \in \{1..7\}$: If $\pi_i < \pi_k$, then $S_A(k) \ge S_A(i) + P_A(i)$ and $S_B(k) \ge S_B(i) + P_B(i)$.
        *   For all $j, l \in \{8..12\}$: If $\pi_j < \pi_l$, then $S_B(l) \ge S_B(j) + P_B(j)$ and $S_A(l) \ge S_A(j) + P_A(j)$.
        *   *Cross-group interaction:* Jobs 1-7 and 8-12 do not directly constrain each other's order via the permutation on shared machines in a simple "before/after" manner *unless* we assume the global sequence dictates the order on *all* machines for *all* jobs.
        *   **Standard Interpretation for this specific problem type:** The "sequence" usually refers to the order in which jobs are fed into the system. Jobs 1-7 enter Machine A. Jobs 8-12 enter Machine B.
        *   If the "sequence" is a single global order, it dictates the order on Machine A for $\{1..7\} \cup \{8..12\}$? No, Jobs 8-12 visit A *second*.
        *   Usually, in such mixed-routing two-machine problems, the "sequence" determines the order of processing on the **first** machine of each group, and the order on the **second** machine is determined by the flow shop dynamics (FIFO on the second machine is not guaranteed; it's determined by completion on the first).
        *   *However*, the most common textbook formulation for "Find the optimal sequence" in a 2-machine flow shop with mixed routing implies that we select a permutation $\pi$ such that:
            1.  Jobs 1-7 are processed on A in the order of $\pi$.
            2.  Jobs 8-12 are processed on B in the order of $\pi$.
            3.  The subsequent processing on the other machine follows the standard flow shop rules (cannot start before previous op done, cannot start before machine free).

    *   **Final Constraint Set for Solver:**
        1.  $S_A(i) \ge 0, S_B(i) \ge 0$
        2.  $S_B(i) \ge S_A(i) + P_A(i)$ for $i \in \{1..7\}$
        3.  $S_A(j) \ge S_B(j) + P_B(j)$ for $j \in \{8..12\}$
        4.  For $i, k \in \{1..7\}$ with $\pi_i < \pi_k$: $S_A(k) \ge S_A(i) + P_A(i)$
        5.  For $j, l \in \{8..12\}$ with $\pi_j < \pi_l$: $S_B(l) \ge S_B(j) + P_B(j)$
        6.  *Implicit Machine Availability for Second Machines:*
            *   For Jobs 1-7 on Machine B: $S_B(i)$ must also respect the order of *completion* from A, but since A's order is fixed by $\pi$ and B's order is *also* fixed by $\pi$ (if we assume the sequence dictates order on the first machine of each path, and the second machine just takes them in the order they arrive *or* the same sequence?), there is ambiguity.
            *   *Standard Assumption:* In "Job Sequence" problems, the sequence $\pi$ defines the order on **both** machines for the jobs that visit them, **if** the routing was uniform. With mixed routing, it typically defines the order on the **first** machine. The order on the second machine is determined by the earliest available time (which depends on the first machine's completion and the second machine's current load).
            *   *Therefore, the constraints 4 and 5 above are sufficient to define the "Sequence". The actual start times $S_B(i)$ for $i \in 1..7$ and $S_A(j)$ for $j \in 8..12$ are determined by the recurrence relations of the flow shop given the release times from the first machine.*

This model captures the decision variables, the objective to minimize makespan, and the operational constraints governing the mixed routing flow shop.
