# Problem Analysis: Sequential Interview Hiring Strategy

## 1. Decision Variables

Let $S_i$ denote the observed score of the $i$-th candidate interviewed, where $i \in \{1, 2, 3\}$.
Let $A_i$ denote the **action** taken at stage $i$ (after observing $S_i$), subject to the state of previous decisions.

The decision variables are defined by the **policy** or **strategy** function $\pi$, which maps the current state (history of scores and actions) to an action. Specifically, we define decision rules for the points where a choice exists:

1.  **At Candidate 1 ($i=1$):**
    *   If $S_1 = 3$: Action is forced to **Hire** (Stop).
    *   If $S_1 = 1$: Action is forced to **Reject** (Continue).
    *   If $S_1 = 2$: Decision variable $D_1 \in \{H, R\}$ (Hire or Reject).

2.  **At Candidate 2 ($i=2$):**
    *   This stage is only reached if $D_1 = R$ (i.e., $S_1 \in \{1, 2\}$).
    *   If $S_2 = 3$: Action is forced to **Hire** (Stop).
    *   If $S_2 = 1$: Action is forced to **Reject** (Continue to 3).
    *   If $S_2 = 2$: Decision variable $D_2 \in \{H, R\}$ (Hire or Reject).

3.  **At Candidate 3 ($i=3$):**
    *   This stage is only reached if both previous candidates were rejected (specifically, $S_1 \in \{1,2\}$ and $D_1=R$, AND $S_2 \in \{1,2\}$ and $D_2=R$).
    *   Action is forced to **Hire** regardless of $S_3$.

**Summary of Decision Variables to Optimize:**
*   $D_1$: Action when $S_1 = 2$ (Hire or Reject).
*   $D_2$: Action when $S_2 = 2$ (Hire or Reject).

*(Note: Since the problem structure is small and deterministic given the scores, we analyze the 4 possible combinations of $(D_1, D_2)$ strategies.)*

## 2. Objective Function

**Maximize** the Expected Score of the Hired Candidate, denoted as $E[\text{Score}_{\text{hired}}]$.

$$ \text{Maximize } Z = E[S_{\text{final}}] $$

Where $S_{\text{final}}$ is the score of the candidate who is ultimately hired. The expectation is calculated over the joint probability distribution of the candidates' scores, assuming independence.

**Probabilities:**
*   $P(S=3) = 0.2$
*   $P(S=2) = 0.5$
*   $P(S=1) = 0.3$

## 3. Operational Constraints

1.  **Sequential Observation:** Candidates are interviewed in a fixed order (1, 2, 3). The score of candidate $i+1$ cannot be observed until candidate $i$ is rejected.
2.  **Irrevocable Rejection:** Once a candidate is rejected, they cannot be recalled.
3.  **Stopping Rules:**
    *   **Immediate Hire:** If a candidate scores 3, the process must stop and that candidate must be hired.
    *   **Mandatory Final Hire:** If the first two candidates are rejected, the third candidate must be hired regardless of their score.
    *   **Discretionary Hire:** A candidate scoring 2 can be hired (stopping the process) or rejected (continuing the process).
4.  **Independence:** The scores of the three candidates are independent and identically distributed (i.i.d.) according to the given probabilities.

### Logical Deduction of the Optimal Strategy (for context/verification)

To determine the optimal values for $D_1$ and $D_2$, we calculate the expected value for each of the 4 possible strategies:

**Let $V$ be the expected score of the final hired candidate.**

**Strategy 1: $D_1 = R$ (Reject 2 at pos 1), $D_2 = R$ (Reject 2 at pos 2)**
*   We only stop at 3s, or are forced to take the 3rd.
*   Path to stop at 1: $S_1=3$ (Prob $0.2$). Score = 3.
*   Path to stop at 2: $S_1 \in \{1,2\}$ and $S_2=3$.
    *   $P(S_1 \in \{1,2\}) = 0.8$.
    *   $P(S_2=3 | \text{reach 2}) = 0.2$.
    *   Joint Prob = $0.8 \times 0.2 = 0.16$. Score = 3.
*   Path to stop at 3: We reach candidate 3 if $S_1 \in \{1,2\}$ AND $S_2 \in \{1,2\}$.
    *   $P(\text{reach 3}) = 0.8 \times 0.8 = 0.64$.
    *   Given we reach 3, $S_3$ is distributed normally. $E[S_3] = 3(0.2) + 2(0.5) + 1(0.3) = 0.6 + 1.0 + 0.3 = 1.9$.
*   $Z_1 = 3(0.2) + 3(0.16) + 1.9(0.64) = 0.6 + 0.48 + 1.216 = 2.296$.

**Strategy 2: $D_1 = R$ (Reject 2 at pos 1), $D_2 = H$ (Hire 2 at pos 2)**
*   Stop at 1 if $S_1=3$.
*   Stop at 2 if ($S_1 \in \{1,2\}$) AND ($S_2 \in \{2,3\}$).
    *   If $S_2=3$, hire. If $S_2=2$, hire.
    *   Prob of reaching 2 is $0.8$.
    *   $P(S_2=3 | \text{reach 2}) = 0.2$. Score 3.
    *   $P(S_2=2 | \text{reach 2}) = 0.5$. Score 2.
*   Stop at 3 if ($S_1 \in \{1,2\}$) AND ($S_2=1$).
    *   Prob of reaching 3 is $0.8 \times 0.3 = 0.24$.
    *   $E[S_3] = 1.9$.
*   $Z_2 = 3(0.2) + [3(0.16) + 2(0.4)] + 1.9(0.24)$
    *   Note: $P(\text{reach 2} \cap S_2=3) = 0.8 \times 0.2 = 0.16$.
    *   $P(\text{reach 2} \cap S_2=2) = 0.8 \times 0.5 = 0.4$.
    *   $Z_2 = 0.6 + (0.48 + 0.8) + 0.456 = 0.6 + 1.28 + 0.456 = 2.336$.

**Strategy 3: $D_1 = H$ (Hire 2 at pos 1), $D_2 = R$ (Reject 2 at pos 2)**
*   Stop at 1 if $S_1 \in \{2,3\}$.
    *   $P(S_1=3) = 0.2 \rightarrow$ Score 3.
    *   $P(S_1=2) = 0.5 \rightarrow$ Score 2.
*   Stop at 2 if ($S_1=1$) AND ($S_2=3$).
    *   $P(S_1=1) = 0.3$.
    *   $P(S_2=3 | S_1=1) = 0.2$.
    *   Joint Prob = $0.3 \times 0.2 = 0.06$. Score 3.
*   Stop at 3 if ($S_1=1$) AND ($S_2 \in \{1,2\}$).
    *   Joint Prob = $0.3 \times 0.8 = 0.24$.
    *   $E[S_3] = 1.9$.
*   $Z_3 = 3(0.2) + 2(0.5) + 3(0.06) + 1.9(0.24)$
    *   $Z_3 = 0.6 + 1.0 + 0.18 + 0.456 = 2.236$.

**Strategy 4: $D_1 = H$ (Hire 2 at pos 1), $D_2 = H$ (Hire 2 at pos 2)**
*   Stop at 1 if $S_1 \in \{2,3\}$.
    *   $P(S_1=3) = 0.2 \rightarrow$ Score 3.
    *   $P(S_1=2) = 0.5 \rightarrow$ Score 2.
*   Stop at 2 if ($S_1=1$) AND ($S_2 \in \{2,3\}$).
    *   $P(S_1=1) = 0.3$.
    *   $P(S_2=3 | S_1=1) = 0.2 \rightarrow$ Score 3. Joint Prob $0.06$.
    *   $P(S_2=2 | S_1=1) = 0.5 \rightarrow$ Score 2. Joint Prob $0.15$.
*   Stop at 3 if ($S_1=1$) AND ($S_2=1$).
    *   Joint Prob = $0.3 \times 0.3 = 0.09$.
    *   $E[S_3] = 1.9$.
*   $Z_4 = 3(0.2) + 2(0.5) + 3(0.06) + 2(0.15) + 1.9(0.09)$
    *   $Z_4 = 0.6 + 1.0 + 0.18 + 0.30 + 0.171 = 2.251$.

**Comparison:**
*   $Z_1 = 2.296$
*   $Z_2 = 2.336$ (Maximum)
*   $Z_3 = 2.236$
*   $Z_4 = 2.251$

### Final Conclusion

**Optimal Strategy:**
1.  **Interview Candidate 1:**
    *   If Score = 3: **Hire**.
    *   If Score = 2: **Reject**.
    *   If Score = 1: **Reject**.
2.  **Interview Candidate 2 (only if Candidate 1 was rejected):**
    *   If Score = 3: **Hire**.
    *   If Score = 2: **Hire**.
    *   If Score = 1: **Reject**.
3.  **Interview Candidate 3 (only if both 1 and 2 were rejected):**
    *   **Hire** regardless of score.

**Maximum Expected Score:** $2.336$.
