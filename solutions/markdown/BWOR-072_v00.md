# OR Model: Spare Parts Allocation for Reliability Maximization

## 1. Decision Variables

Let $x_i$ be the number of spare parts allocated for component $i$, where $i \in \{1, 2, 3\}$.

$$
x_i \in \{0, 1, 2, 3\}, \quad i = 1, 2, 3
$$

*   $x_1$: Number of spares for $E_1$
*   $x_2$: Number of spares for $E_2$
*   $x_3$: Number of spares for $E_3$

*(Note: Based on the table, the maximum number of spares considered for any part is 3. If 0 spares are assigned, the increase in reliability is 0 and the cost is 0.)*

## 2. Objective Function

**Maximize** the total increase in reliability of the equipment.

Let $R_i(x_i)$ be the increase in reliability for component $i$ given $x_i$ spares.
Let $C_i(x_i)$ be the cost (in thousand yuan) for component $i$ given $x_i$ spares.

$$
\text{Maximize } Z = R_1(x_1) + R_2(x_2) + R_3(x_3)
$$

## 3. Operational Constraints

**Budget Constraint:**
The total cost of spare parts must not exceed 8,000 yuan (8 thousand yuan).

$$
C_1(x_1) + C_2(x_2) + C_3(x_3) \le 8
$$
