## Formal Formulation

### Index Sets & Parameters

**Sets:**
- $V = \{0, 1, 2, 3, 4, 5, 6, 7, 8\}$ — set of nodes, where node 0 = Coast, nodes 1–8 = Wells 1–8.
- $E = \{(i,j) : i, j \in V, i < j\}$ — set of all undirected edges (28 edges for 9 nodes).

**Parameters:**
- $c_{ij}$ — distance (miles) between node $i$ and node $j$, for all $(i,j) \in E$:
  - $c_{0,1} = 5.0$
  - $c_{1,2} = 1.3,\; c_{1,3} = 2.1,\; c_{1,4} = 0.9,\; c_{1,5} = 0.7,\; c_{1,6} = 1.8,\; c_{1,7} = 2.0,\; c_{1,8} = 1.5$
  - $c_{2,3} = 0.9,\; c_{2,4} = 1.8,\; c_{2,5} = 1.2,\; c_{2,6} = 2.6,\; c_{2,7} = 2.3,\; c_{2,8} = 1.1$
  - $c_{3,4} = 2.6,\; c_{3,5} = 1.7,\; c_{3,6} = 2.5,\; c_{3,7} = 1.9,\; c_{3,8} = 1.0$
  - $c_{4,5} = 0.7,\; c_{4,6} = 1.6,\; c_{4,7} = 1.5,\; c_{4,8} = 0.9$
  - $c_{5,6} = 0.9,\; c_{5,7} = 1.1,\; c_{5,8} = 0.8$
  - $c_{6,7} = 0.6,\; c_{6,8} = 1.0$
  - $c_{7,8} = 0.5$
- $|V| = 9$
- $|E| = 28$

### Decision Variables

- $x_{ij} \in \{0, 1\}$ for all $(i,j) \in E$ — binary variable; $x_{ij} = 1$ if edge $(i,j)$ is selected in the pipeline network, 0 otherwise.
- $y_{ik} \in \{0, 1\}$ for all $i \in V, k \in \{1, 2, \dots, 8\}$ — auxiliary binary variable for subtour elimination (used in the DFJ / cutset formulation). Alternatively, we use the **degree + cutset** formulation below.

> **Chosen formulation:** We use the **cutset (subtour elimination) formulation** with auxiliary variables $u_i$ (continuous, ordered potentials) in a Miller-Tucker-Zemlin-style approach adapted for undirected MST, OR equivalently the **degree + cutset** formulation. For clarity and solver-readiness, we use the **directed-arc reformulation** with flow-based subtour elimination:

**Revised Decision Variables (Directed Arc Formulation):**
- $x_{ij} \in \{0, 1\}$ for all ordered pairs $(i,j) \in V \times V,\; i \neq j$ — binary; 1 if arc $(i,j)$ is used in the directed representation of the tree.
- $u_i \in [0, |V|-1]$ for all $i \in V$ — continuous auxiliary variable for subtour elimination.

### Objective Function

$$\min \sum_{(i,j) \in E} c_{ij} \cdot x_{ij}$$

where $x_{ij}$ in the undirected sense is represented as $x_{ij}^{dir} + x_{ji}^{dir}$ in the directed model. To keep it clean, we work with **undirected edges** and use the **cutset formulation** with auxiliary variables:

**Final Decision Variables (Cutset / DFJ Formulation):**
- $x_{ij} \in \{0,1\}$ for all $(i,j) \in E$ (undirected, $i < j$)
- $u_i \in \mathbb{R}$ for all $i \in V \setminus \{0\}$ — auxiliary ordering variable (subtour elimination). Fix $u_0 = 0$.

**Objective:**
$$\min \sum_{(i,j) \in E} c_{ij} \, x_{ij}$$

### Operational Constraints

**1. Tree cardinality (exactly |V|−1 edges selected):**
$$\sum_{(i,j) \in E} x_{ij} = |V| - 1 = 8$$

**2. Degree upper bound (no node has degree > 2 in a tree path… actually for a general tree, degree can be up to |V|−1):**

For a general MST (not a path), we do NOT restrict degree to ≤ 2. Instead, we use:

**2. Subtour elimination (DFJ / cutset constraints):**

For every non-trivial subset $S \subset V$ (i.e., $\emptyset \neq S \neq V$):
$$\sum_{(i,j) \in \delta(S)} x_{ij} \geq 2 \quad \text{for all } S \subset V, \; S \neq \emptyset, \; S \neq V$$

where $\delta(S) = \{(i,j) \in E : i \in S, j \notin S\}$.

> **Practical note:** Enumerating all $2^{|V|}-2 = 510$ cutset constraints is feasible for 9 nodes.

**3. Non-negativity / Binary bounds:**
$$x_{ij} \in \{0, 1\} \quad \forall (i,j) \in E$$

### Alternative: MTZ-Style Formulation (More Compact for Solvers)

Since the graph is small (9 nodes), we can also use a **directed-arc + MTZ** formulation which is often easier to implement:

**Decision Variables:**
- $z_{ij} \in \{0,1\}$ for all $(i,j) \in V \times V, i \neq j$ — 1 if arc $i \to j$ is used.
- $u_i \in [0, 8]$ for all $i \in V$ — ordering variable. Fix $u_0 = 0$.

**Objective:**
$$\min \sum_{(i,j) \in E} c_{ij} \, (z_{ij} + z_{ji})$$

**Constraints:**

1. **Out-degree of root (coast, node 0):**
$$\sum_{j \in V \setminus \{0\}} z_{0j} = 1$$

2. **Flow conservation for non-root nodes:** For all $i \in V \setminus \{0\}$:
$$\sum_{j \in V \setminus \{i\}} z_{ji} = 1$$
(each non-root node has exactly one incoming arc in the arborescence)

3. **No self-loops / unused arcs bound:**
$$z_{ij} = 0 \quad \forall (i,j) \text{ such that } i = j$$
$$z_{ij} \in \{0,1\} \quad \forall i \neq j$$

4. **MTZ subtour elimination:** For all $i, j \in V \setminus \{0\}, i \neq j$:
$$u_i - u_j + 9 \cdot z_{ij} \leq 8$$

5. **Bounds on ordering variables:**
$$u_0 = 0$$
$$0 \leq u_i \leq 8 \quad \forall i \in V \setminus \{0\}$$

> **Verification (Rule 20):** Root node 0 is EXCLUDED from MTZ constraints. The MTZ domain is $i, j \in \{1,2,3,4,5,6,7,8\}, i \neq j$. The root participates only in flow conservation (out-degree = 1) and the objective. ✓

> **Verification (Rule 20 – Inflow on root):** The root has NO inflow constraint (it is the source of the arborescence). The constraint $\sum_j z_{0j} = 1$ is an out-degree constraint. No MTZ constraint references $u_0$ on the left side with a $z_{0j}$ term in a way that creates infeasibility. ✓
