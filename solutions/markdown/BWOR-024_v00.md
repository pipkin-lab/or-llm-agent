# Flow Shop Scheduling Problem (2-Machine)

## 1. Decision Variables
Let $n = 6$ be the number of jobs.
Let $\sigma = (\sigma(1), \sigma(2), \dots, \sigma(6))$ denote the permutation (sequence) of the 6 jobs on the machines.
The primary decision variable is the **position** of each job in the sequence.
Alternatively, we can define binary variables $x_{jk}$ such that:
$$
x_{jk} = \begin{cases} 
1 & \text{if job } j \text{ is scheduled in position } k \text{ in the sequence} \\
0 & \text{otherwise}
\end{cases}
$$
Where $j \in \{1, 2, 3, 4, 5, 6\}$ and $k \in \{1, 2, 3, 4, 5, 6\}$.

## 2. Objective Function
**Minimize** the Makespan ($C_{max}$), which is the total time to complete all jobs on Machine B.

$$
\text{Minimize } Z = C_{max}
$$

Where $C_{max}$ is the completion time of the last job on Machine B.

## 3. Operational Constraints

### A. Assignment Constraints
Each job must be assigned to exactly one position in the sequence, and each position must contain exactly one job.

1.  **Each job appears exactly once in the sequence:**
    $$ \sum_{k=1}^{6} x_{jk} = 1, \quad \forall j \in \{1, \dots, 6\} $$

2.  **Each position in the sequence is occupied by exactly one job:**
    $$ \sum_{j=1}^{6} x_{jk} = 1, \quad \forall k \in \{1, \dots, 6\} $$

### B. Precedence Constraints (Flow Shop Logic)
Jobs must be processed on Machine A before Machine B. The completion time on Machine B depends on the completion time on Machine A and the previous job's completion on Machine B.

Let $C_{A,k}$ be the cumulative completion time on Machine A up to position $k$.
Let $C_{B,k}$ be the cumulative completion time on Machine B up to position $k$.

The recursive relations (which define the calculation of the objective) are:
1.  **Machine A Completion:**
    $$ C_{A,k} = C_{A,k-1} + \sum_{j=1}^{6} A_j x_{jk} $$
    Where $C_{A,0} = 0$.

2.  **Machine B Completion:**
    $$ C_{B,k} = \max(C_{A,k}, C_{B,k-1}) + \sum_{j=1}^{6} B_j x_{jk} $$
    Where $C_{B,0} = 0$.

3.  **Makespan Definition:**
    $$ C_{max} = C_{B,6} $$

*(Note: In a rigorous Integer Linear Programming formulation, the `max` function in the recursive step for Machine B is linearized using auxiliary variables and big-M constraints, but the logical operational constraint remains that a job cannot start on Machine B until it has finished on Machine A AND Machine B is free from the previous job.)*

### C. Specific Data Parameters
*   $A = [30, 60, 60, 20, 80, 90]$
*   $B = [70, 70, 50, 60, 30, 40]$
