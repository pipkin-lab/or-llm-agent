# Operations Research Model: Strategic Bomber Fleet Optimization

## 1. Decision Variables

Let the fleet consist of $N$ identical bombers (the total number of aircraft is a fixed parameter of the fleet, not a decision variable; however, the *allocation* of bombs to targets by the fleet is the decision). To simplify the model, we define the decision variables as the total number of heavy and light bombs allocated to each of the four key parts.

Let:
- $x_i$: Number of **heavy bombs** dropped on Key Part $i$ (for $i = 1, 2, 3, 4$).
- $y_i$: Number of **light bombs** dropped on Key Part $i$ (for $i = 1, 2, 3, 4$).

**Variable Constraints:**
$x_i, y_i \in \mathbb{Z}_{\ge 0}$ (Non-negative integers).

*Note: Implicitly, the sum of bombs allocated to a target cannot exceed the total bombs available, and the "reachability" of the target depends on the bomb load. The model below incorporates reachability via logical constraints or by defining the feasible region based on range.*

## 2. Objective Function

The goal is to **Maximize** the probability that **at least one** of the four key parts is destroyed.

Let $P_i$ be the probability that Key Part $i$ is destroyed.
Given independent bombing events, the probability that Key Part $i$ is **not** destroyed is:
$$ Q_i = (1 - 0.10)^{x_i} (1 - 0.08)^{y_i} \quad \text{for } i=1 $$
$$ Q_i = (1 - 0.20)^{x_i} (1 - 0.16)^{y_i} \quad \text{for } i=2 $$
$$ Q_i = (1 - 0.15)^{x_i} (1 - 0.12)^{y_i} \quad \text{for } i=3 $$
$$ Q_i = (1 - 0.25)^{x_i} (1 - 0.20)^{y_i} \quad \text{for } i=4 $$

The probability that **all** parts survive is $\prod_{i=1}^4 Q_i$.
Therefore, the probability that **at least one** part is destroyed is:
$$ P_{\text{success}} = 1 - \prod_{i=1}^4 Q_i $$

**Objective:**
$$ \text{Maximize } Z = 1 - \prod_{i=1}^4 \left[ (1 - p_{H,i})^{x_i} (1 - p_{L,i})^{y_i} \right] $$
Where $p_{H,i}$ and $p_{L,i}$ are the single-bomb destruction probabilities for heavy and light bombs on part $i$.

*(Equivalently, to simplify computation, one can Minimize $\prod_{i=1}^4 Q_i$)*.

## 3. Operational Constraints

### A. Resource Constraints (Global)
The total number of bombs used cannot exceed the fleet's capacity.
1.  **Total Heavy Bombs:**
    $$ \sum_{i=1}^4 x_i \le 48 $$
2.  **Total Light Bombs:**
    $$ \sum_{i=1}^4 y_i \le 32 $$

### B. Fuel and Range Constraints (Per Sortie/Target)
This is the most complex part. The problem states "For each bombing sortie...". We must determine if a specific bomb allocation to a target is physically possible given the fuel limits.

Let $D_i$ be the distance to target $i$.
Let $H$ be the number of heavy bombs on board for a sortie to target $i$.
Let $L$ be the number of light bombs on board for a sortie to target $i$.

**Fuel Consumption Model for a Single Sortie to Target $i$:**
1.  **Outbound Leg:** Distance $D_i$. Fuel efficiency depends on load.
    *   If carrying heavy bombs: Efficiency $= 2$ km/L. Fuel $= D_i / 2$.
    *   If carrying light bombs: Efficiency $= 3$ km/L. Fuel $= D_i / 3$.
    *   *Note: Usually, a plane carries a mix. Let's assume the plane carries specific numbers $x_i$ and $y_i$ for the target. However, the problem implies a fleet. A more robust interpretation is that the **fleet** must be able to reach the targets with the allocated bombs. Let's assume a standard sortie profile where a plane carries a specific payload.*

    *Refined Interpretation:* The problem asks for a "bombing plan". This usually implies determining how many bombs of each type are assigned to each target. The constraint is that **any** bomb assigned to target $i$ must be deliverable to target $i$.

    Let's define the maximum range of a bomber carrying a specific payload.
    Let $h$ be the number of heavy bombs carried, $l$ be the number of light bombs carried.
    
    **Case 1: Carrying only Heavy Bombs ($l=0$)**
    *   Outbound Fuel: $D_i / 2$
    *   Landing/Takeoff Fuel: $100 + 100 = 200$ L (Note: The prompt says "100 liters... each for takeoff and landing", so 200L total overhead).
    *   Return Leg (Empty): Efficiency $= 4$ km/L. Fuel $= D_i / 4$.
    *   Total Fuel Required: $F_H(D_i) = \frac{D_i}{2} + 200 + \frac{D_i}{4} = \frac{3D_i}{4} + 200$.

    **Case 2: Carrying only Light Bombs ($h=0$)**
    *   Outbound Fuel: $D_i / 3$
    *   Landing/Takeoff Fuel: $200$ L.
    *   Return Leg (Empty): Fuel $= D_i / 4$.
    *   Total Fuel Required: $F_L(D_i) = \frac{D_i}{3} + 200 + \frac{D_i}{4} = \frac{7D_i}{12} + 200$.

    **Case 3: Carrying Mixed Bombs ($h>0, l>0$)**
    The problem states: "When carrying a heavy bomb... 2 km/L; when carrying a light bomb... 3 km/L."
    This usually implies a weighted average or that the aircraft's range is limited by the most inefficient component if mixed, or a linear combination. Standard OR problems of this type often assume the plane carries a specific type to a specific target, or that the range is determined by the *worst-case* efficiency or a blended efficiency.
    
    *Assumption for Modeling:* Given the discrete nature, it is most likely that we assign **Heavy Bombs** to some targets and **Light Bombs** to others, or the plane can carry both but the range is constrained by the total fuel.
    
    Let's calculate the **Maximum Distance** a plane can reach and return, given the total fuel limit of 48,000 L *per fleet*? No, "fuel consumption is limited to 48,000 liters" is likely the **total fleet fuel**.
    
    Let's re-read carefully: "constraints are: fuel consumption is limited to 48,000 liters...". This is a global constraint.
    
    We need to link the bomb allocation to fuel usage.
    Let $n_{H,i}$ be the number of heavy bombs dropped on target $i$.
    Let $n_{L,i}$ be the number of light bombs dropped on target $i$.
    
    To drop these bombs, the fleet must perform sorties.
    Assume each sortie carries a standard load or variable load? The problem doesn't specify max bombs per plane. It gives total fleet resources.
    
    *Standard Approach for this specific classic problem:*
    The constraint is that the **total fuel consumed by the fleet** to deliver all allocated bombs must not exceed 48,000 L.
    
    We need the fuel cost per bomb.
    However, fuel is consumed per *sortie*, not per bomb directly.
    
    Let's assume the fleet consists of planes that can carry a maximum of 1 heavy bomb or 1 light bomb? Or a mix?
    Actually, looking at the numbers:
    48 Heavy, 32 Light.
    If we assume each plane carries **one** bomb (either H or L) per sortie:
    
    **Fuel Cost for one Heavy Bomb to Target $i$:**
    $C_{H,i} = \frac{3D_i}{4} + 200$ Liters.
    
    **Fuel Cost for one Light Bomb to Target $i$:**
    $C_{L,i} = \frac{7D_i}{12} + 200$ Liters.
    
    **Global Fuel Constraint:**
    $$ \sum_{i=1}^4 \left( x_i \cdot C_{H,i} + y_i \cdot C_{L,i} \right) \le 48,000 $$
    
    Let's verify the coefficients with the distances:
    *   $i=1 (D=450)$:
        $C_{H,1} = 3(450)/4 + 200 = 337.5 + 200 = 537.5$ L
        $C_{L,1} = 7(450)/12 + 200 = 262.5 + 200 = 462.5$ L
    *   $i=2 (D=480)$:
        $C_{H,2} = 3(480)/4 + 200 = 360 + 200 = 560$ L
        $C_{L,2} = 7(480)/12 + 200 = 280 + 200 = 480$ L
    *   $i=3 (D=540)$:
        $C_{H,3} = 3(540)/4 + 200 = 405 + 200 = 605$ L
        $C_{L,3} = 7(540)/12 + 200 = 315 + 200 = 515$ L
    *   $i=4 (D=600)$:
        $C_{H,4} = 3(600)/4 + 200 = 450 + 200 = 650$ L
        $C_{L,4} = 7(600)/12 + 200 = 350 + 200 = 550$ L

    *(Self-Correction/Refinement)*: Does a plane carry multiple bombs? The problem says "A fleet... is ordered". It doesn't specify the number of planes or bomb capacity per plane. However, it lists total resources. The most logical OR model assumes that the "cost" of a bomb is the fuel required to deliver it and return. If a plane can carry multiple bombs, the fuel cost per bomb decreases (fixed 200L overhead is shared).
    
    *However*, without knowing the bomb capacity per plane, we cannot model the fixed overhead sharing. In many textbook versions of this problem, it is assumed that **each bomb requires a separate sortie** or that the "fuel per bomb" is an average effective cost. Given the explicit "100L takeoff/landing", this overhead is significant.
    
    *Alternative Interpretation:* The 48,000L is the total fuel. We have 48H and 32L bombs. If we assume 1 bomb per sortie, the max fuel usage is bounded.
    Max fuel if all 48H go to D=600: $48 * 650 = 31,200$ L.
    Max fuel if all 32L go to D=600: $32 * 550 = 17,600$ L.
    Total max = $48,800$ L.
    The limit is 48,000 L. This is very close to the sum of maximums. This strongly suggests the model assumes **1 bomb per sortie** (or that the marginal cost is additive as calculated). If planes could carry multiple bombs, the fuel limit would likely be less binding or the numbers would be different. The proximity of the max possible fuel (48,800) to the limit (48,000) confirms that the additive cost model $C_{H,i}$ and $C_{L,i}$ is the intended constraint structure.

### Summary of Constraints

1.  **Bomb Supply:**
    $$ \sum_{i=1}^4 x_i \le 48 $$
    $$ \sum_{i=1}^4 y_i \le 32 $$

2.  **Fuel Budget:**
    $$ 537.5 x_1 + 560 x_2 + 605 x_3 + 650 x_4 + 462.5 y_1 + 480 y_2 + 515 y_3 + 550 y_4 \le 48,000 $$

3.  **Non-negativity and Integrality:**
    $$ x_i, y_i \in \mathbb{Z}_{\ge 0} \quad \forall i \in \{1,2,3,4\} $$

### Final Model Structure

**Maximize:**
$$ Z = 1 - \left[ (0.90)^{x_1} (0.92)^{y_1} \right] \cdot \left[ (0.80)^{x_2} (0.84)^{y_2} \right] \cdot \left[ (0.85)^{x_3} (0.88)^{y_3} \right] \cdot \left[ (0.75)^{x_4} (0.80)^{y_4} \right] $$

**Subject to:**
1.  $\sum_{i=1}^4 x_i \le 48$
2.  $\sum_{i=1}^4 y_i \le 32$
3.  $537.5 x_1 + 560 x_2 + 605 x_3 + 650 x_4 + 462.5 y_1 + 480 y_2 + 515 y_3 + 550 y_4 \le 48,000$
4.  $x_i, y_i \ge 0$, integers.
