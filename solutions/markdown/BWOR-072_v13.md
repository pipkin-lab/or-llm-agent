## Mathematical Optimization Model

### Model Type Declaration
**MILP** (Mixed-Integer Linear Programming). The decision involves selecting a discrete number of spare parts (0, 1, 2, or 3) for each of three part types, subject to a budget constraint.

---

### MANDATORY COST INVENTORY (PRE-MODELING STEP)

| Entity | Cost at z=0 | Cost at z=1 | Cost at z=2 | Cost at z=3 |
|--------|-------------|-------------|-------------|-------------|
| E₁ (thousand yuan) | 0 | 1 | 2 | 3 |
| E₂ (thousand yuan) | 0 | 3 | 5 | 6 |
| E₃ (thousand yuan) | 0 | 2 | 3 | 4 |

- Total budget: **8,000 yuan = 8 thousand yuan** (consistent with table units).
- Reliability gains (increments) are given per level; the total reliability increase is the sum of the marginal gains for the chosen level of each part type.

**Cross-check:** The cost figures in the table (1, 2, 3 for E₁; 3, 5, 6 for E₂; 2, 3, 4 for E₃) are the total costs at each spare-part level, not per-unit costs. The budget is 8 thousand yuan. These are the objective-relevant parameters.

---

### Index Sets & Parameters

| Symbol | Description | Value |
|--------|-------------|-------|
| $P$ | Set of spare part types | $\{1, 2, 3\}$ corresponding to $E_1, E_2, E_3$ |
| $Z$ | Set of possible spare part levels | $\{0, 1, 2, 3\}$ |
| $B$ | Total budget (thousand yuan) | $8$ |
| $r_{p,z}$ | Reliability increase for part type $p$ at level $z$ (cumulative from 0 to $z$) | See table below |
| $c_{p,z}$ | Total cost (thousand yuan) for part type $p$ at level $z$ | See table below |

**Reliability increase parameters** $r_{p,z}$ (the table gives the *increase in reliability* at each level; interpreting these as the **total** reliability gain when $z$ spares are stocked, i.e., the row value is the cumulative gain from baseline):

| $z$ | $r_{1,z}$ (E₁) | $r_{2,z}$ (E₂) | $r_{3,z}$ (E₃) |
|-----|----------------|----------------|----------------|
| 0   | 0.0            | 0.0            | 0.0            |
| 1   | 0.3            | 0.2            | 0.1            |
| 2   | 0.4            | 0.5            | 0.2            |
| 3   | 0.5            | 0.9            | 0.7            |

**Cost parameters** $c_{p,z}$ (thousand yuan):

| $z$ | $c_{1,z}$ (E₁) | $c_{2,z}$ (E₂) | $c_{3,z}$ (E₃) |
|-----|----------------|----------------|----------------|
| 0   | 0              | 0              | 0              |
| 1   | 1              | 3              | 2              |
| 2   | 2              | 5              | 3              |
| 3   | 3              | 6              | 4              |

### Decision Variables

For each part type $p \in P$ and each level $z \in Z$, define a binary variable:

$$
x_{p,z} = \begin{cases}
1 & \text{if part type } p \text{ is stocked at level } z \\
0 & \text{otherwise}
\end{cases}
$$

**Domain:** $x_{p,z} \in \{0, 1\}$ for all $p \in P$, $z \in Z$.

---

### Objective Function

**MAXIMIZE** total reliability increase:

$$
\max \sum_{p=1}^{3} \sum_{z=0}^{3} r_{p,z} \, x_{p,z}
$$

Expanded:

$$
\max \; 0.3\,x_{1,1} + 0.4\,x_{1,2} + 0.5\,x_{1,3} + 0.2\,x_{2,1} + 0.5\,x_{2,2} + 0.9\,x_{2,3} + 0.1\,x_{3,1} + 0.2\,x_{3,2} + 0.7\,x_{3,3}
$$

*(Note: $r_{p,0} = 0$ for all $p$, so those terms vanish.)*

---

### Operational Constraints

**1. Exactly one level selected per part type:**

$$
\sum_{z=0}^{3} x_{p,z} = 1 \quad \forall\, p \in \{1, 2, 3\}
$$

This ensures each part type is assigned to exactly one stocking level.

**2. Budget constraint (total cost ≤ 8 thousand yuan):**

$$
\sum_{p=1}^{3} \sum_{z=0}^{3} c_{p,z} \, x_{p,z} \leq 8
$$

Expanded:

$$
1\,x_{1,1} + 2\,x_{1,2} + 3\,x_{1,3} + 3\,x_{2,1} + 5\,x_{2,2} + 6\,x_{2,3} + 2\,x_{3,1} + 3\,x_{3,2} + 4\,x_{3,3} \leq 8
$$

**3. Variable domains:**

$$
x_{p,z} \in \{0, 1\} \quad \forall\, p \in \{1,2,3\},\; z \in \{0,1,2,3\}
$$

---

### Feasibility Sanity Check
