**Model Type:** MILP (Mixed Integer Linear Programming)

### 1. Index Sets & Parameters

**Sets:**
*   $T = \{1, 2, 3\}$: Set of tasks.
*   $M = \{Tch, Lab\}$: Set of worker types (Technician, Laborer).
*   $K_{t} \subseteq \mathbb{Z}^+ \times \mathbb{Z}^+$: Set of feasible crew compositions (teams) for task $t$. A crew composition is a pair $(a, b)$ where $a$ is the number of technicians and $b$ is the number of laborers.

**Parameters:**
*   $w_{Tch} = 100$: Weekly wage per technician (yuan/week).
*   $w_{Lab} = 80$: Weekly wage per laborer (yuan/week).
*   $h_{Tch} = 42$: Effective weekly working hours per technician.
*   $h_{Lab} = 36$: Effective weekly working hours per laborer.
*   $D_t$: Total required effective working hours for task $t$ (hours/week).
    *   $D_1 = 10,000$
    *   $D_2 = 20,000$
    *   $D_3 = 30,000$
*   $Cap_{Tch} = 400$: Maximum number of technicians available.
*   $Cap_{Lab} = 800$: Maximum number of laborers available.

**Crew Compositions ($K_t$):**
Based on the problem description:
*   **Task 1 ($t=1$):**
    *   Option 1: 1 Technician, 0 Laborers.
    *   Option 2: 1 Technician, 2 Laborers.
    *   $K_1 = \{(1, 0), (1, 2)\}$
*   **Task 2 ($t=2$):**
    *   Option 1: 1 Technician, 0 Laborers.
    *   Option 2: 0 Technicians, 1 Laborer.
    *   $K_2 = \{(1, 0), (0, 1)\}$
*   **Task 3 ($t=3$):**
    *   Option 1: 0 Technicians, 5 Laborers.
    *   Option 2: 1 Technician, 3 Laborers.
    *   $K_3 = \{(0, 5), (1, 3)\}$

Let $k$ index the specific crew options within task $t$. Let $a_{t,k}$ be the number of technicians in crew option $k$ of task $t$, and $b_{t,k}$ be the number of laborers in crew option $k$ of task $t$.

*   For $t=1$:
    *   $k=1: a_{1,1}=1, b_{1,1}=0$
    *   $k=2: a_{1,2}=1, b_{1,2}=2$
*   For $t=2$:
    *   $k=1: a_{2,1}=1, b_{2,1}=0$
    *   $k=2: a_{2,2}=0, b_{2,2}=1$
*   For $t=3$:
    *   $k=1: a_{3,1}=0, b_{3,1}=5$
    *   $k=2: a_{3,2}=1, b_{3,2}=3$

### 2. Decision Variables

Let $x_{t,k}$ be the number of crews of type $k$ assigned to task $t$.
*   $x_{t,k} \in \mathbb{Z}_{\ge 0}$ for all $t \in T, k \in K_t$.

The total number of technicians recruited is $N_{Tch} = \sum_{t \in T} \sum_{k \in K_t} a_{t,k} x_{t,k}$.
The total number of laborers recruited is $N_{Lab} = \sum_{t \in T} \sum_{k \in K_t} b_{t,k} x_{t,k}$.

### 3. Objective Function

Minimize the total weekly wage cost:

$$
\text{Minimize } Z = w_{Tch} \left( \sum_{t \in T} \sum_{k \in K_t} a_{t,k} x_{t,k} \right) + w_{Lab} \left( \sum_{t \in T} \sum_{k \in K_t} b_{t,k} x_{t,k} \right)
$$

Substituting the specific values:

$$
\text{Minimize } Z = 100 \left( 1x_{1,1} + 1x_{1,2} + 1x_{2,1} + 0x_{2,2} + 0x_{3,1} + 1x_{3,2} \right) + 80 \left( 0x_{1,1} + 2x_{1,2} + 0x_{2,1} + 1x_{2,2} + 5x_{3,1} + 3x_{3,2} \right)
$$

Simplified:
$$
\text{Minimize } Z = 100(x_{1,1} + x_{1,2} + x_{2,1} + x_{3,2}) + 80(2x_{1,2} + x_{2,2} + 5x_{3,1} + 3x_{3,2})
$$
$$
\text{Minimize } Z = 100x_{1,1} + 100x_{1,2} + 100x_{2,1} + 100x_{3,2} + 160x_{1,2} + 80x_{2,2} + 400x_{3,1} + 240x_{3,2}
$$
$$
\text{Minimize } Z = 100x_{1,1} + 260x_{1,2} + 100x_{2,1} + 80x_{2,2} + 400x_{3,1} + 340x_{3,2}
$$

### 4. Operational Constraints

**1. Workload Constraints:**
The total effective working hours provided by the crews for each task must meet or exceed the required hours for that task.

For each task $t \in \{1, 2, 3\}$:
$$
\sum_{k \in K_t} (a_{t,k} h_{Tch} + b_{t,k} h_{Lab}) x_{t,k} \ge D_t
$$

Expanded for each task:

*   **Task 1 ($D_1 = 10,000$):**
    *   Crew 1 (1 Tch, 0 Lab) hours: $1(42) + 0(36) = 42$ hours/week.
    *   Crew 2 (1 Tch, 2 Lab) hours: $1(42) + 2(36) = 42 + 72 = 114$ hours/week.
    $$
    42 x_{1,1} + 114 x_{1,2} \ge 10,000
    $$

*   **Task 2 ($D_2 = 20,000$):**
    *   Crew 1 (1 Tch, 0 Lab) hours: $1(42) + 0(36) = 42$ hours/week.
    *   Crew 2 (0 Tch, 1 Lab) hours: $0(42) + 1(36) = 36$ hours/week.
    $$
    42 x_{2,1} + 36 x_{2,2} \ge 20,000
    $$

*   **Task 3 ($D_3 = 30,000$):**
    *   Crew 1 (0 Tch, 5 Lab) hours: $0(42) + 5(36) = 180$ hours/week.
    *   Crew 2 (1 Tch, 3 Lab) hours: $1(42) + 3(36) = 42 + 108 = 150$ hours/week.
    $$
    180 x_{3,1} + 150 x_{3,2} \ge 30,000
    $$

**2. Recruitment Capacity Constraints:**
The total number of technicians and laborers used across all tasks cannot exceed the maximum recruitment limits.

*   **Technician Limit ($Cap_{Tch} = 400$):**
    $$
    \sum_{t \in T} \sum_{k \in K_t} a_{t,k} x_{t,k} \le 400
    $$
    Expanded:
    $$
    1x_{1,1} + 1x_{1,2} + 1x_{2,1} + 0x_{2,2} + 0x_{3,1} + 1x_{3,2} \le 400
    $$
    $$
    x_{1,1} + x_{1,2} + x_{2,1} + x_{3,2} \le 400
    $$

*   **Laborer Limit ($Cap_{Lab} = 800$):**
    $$
    \sum_{t \in T} \sum_{k \in K_t} b_{t,k} x_{t,k} \le 800
    $$
    Expanded:
    $$
    0x_{1,1} + 2x_{1,2} + 0x_{2,1} + 1x_{2,2} + 5x_{3,1} + 3x_{3,2} \le 800
    $$
    $$
    2x_{1,2} + x_{2,2} + 5x_{3,1} + 3x_{3,2} \le 800
    $$

**3. Non-negativity and Integrality:**
$$
x_{t,k} \in \mathbb{Z}_{\ge 0} \quad \forall t \in T, k \in K_t
$$

### Final Model Summary

**Minimize**
$$ Z = 100x_{1,1} + 260x_{1,2} + 100x_{2,1} + 80x_{2,2} + 400x_{3,1} + 340x_{3,2} $$

**Subject to:**
1.  $42 x_{1,1} + 114 x_{1,2} \ge 10,000$
2.  $42 x_{2,1} + 36 x_{2,2} \ge 20,000$
3.  $180 x_{3,1} + 150 x_{3,2} \ge 30,000$
4.  $x_{1,1} + x_{1,2} + x_{2,1} + x_{3,2} \le 400$
5.  $2x_{1,2} + x_{2,2} + 5x_{3,1} + 3x_{3,2} \le 800$
6.  $x_{1,1}, x_{1,2}, x_{2,1}, x_{2,2}, x_{3,1}, x_{3,2} \ge 0, \text{ integers}$
