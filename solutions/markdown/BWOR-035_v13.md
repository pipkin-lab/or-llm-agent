## Model Type Declaration
**Model Type:** NON-LINEAR (Non-Linear Programming / MIP depending on integrality of bomb counts)
**Solver Note:** The objective function involves a product of probability terms (non-linear). The decision variables (number of bombs) are inherently discrete (integers), so this is technically a Mixed-Integer Non-Linear Program (MINLP). However, given the small scale (4 targets, limited bombs), this can often be solved via enumeration or specialized non-linear solvers.

**Fuel Calculation per Bomb:**
This is the tricky part. The fuel efficiency depends on the payload.
If an aircraft carries Heavy bombs, efficiency is 2 km/L. If Light, 3 km/L. If Empty, 4 km/L.
Does the aircraft carry a mix? The problem says "When carrying a heavy bomb... when carrying a light bomb...". Usually, in these problems, we assume the aircraft is loaded with the specific type of bomb it is delivering to a specific target.
If an aircraft delivers $x_{k,H}$ heavy bombs to target $k$, it flies out loaded with heavy bombs (efficiency $R_H$) and returns empty (efficiency $R_{empty}$).
Fuel for outbound leg ($D_k$ km) with Heavy bombs: $D_k / R_H$
Fuel for return leg ($D_k$ km) empty: $D_k / R_{empty}$
Plus fixed takeoff/landing: $F_{fixed}$
Total fuel for **one** heavy bomb to target $k$:
$F_{k,H} = \frac{D_k}{R_H} + \frac{D_k}{R_{empty}} + F_{fixed} = D_k(\frac{1}{2} + \frac{1}{4}) + 100 = 0.75 D_k + 100$

**Probability Calculation:**
The probability that target part $k$ is **not** destroyed by $x_{k,H}$ heavy and $x_{k,L}$ light bombs is:
$S_k = (1 - P_{k,H})^{x_{k,H}} (1 - P_{k,L})^{x_{k,L}}$
The probability that target part $k$ **is** destroyed is $1 - S_k$.
The probability that the **entire target** is destroyed (at least one part destroyed) is:
$P_{total} = 1 - \prod_{k=1}^{4} S_k = 1 - \prod_{k=1}^{4} \left[ (1 - P_{k,H})^{x_{k,H}} (1 - P_{k,L})^{x_{k,L}} \right]$

**Objective:**
Maximize $P_{total}$.
This is equivalent to **Minimizing** the survival probability of all parts:
$Z = \prod_{k=1}^{4} \left[ (1 - P_{k,H})^{x_{k,H}} (1 - P_{k,L})^{x_{k,L}} \right]$
Minimizing $Z$ is equivalent to minimizing $\ln(Z) = \sum_{k=1}^{4} \left[ x_{k,H} \ln(1 - P_{k,H}) + x_{k,L} \ln(1 - P_{k,L}) \right]$.
Since $\ln(1-P)$ is negative, this is a Linear Programming problem if we relax integrality!
Wait, $\ln(Z)$ is linear in $x$.
$\min \sum_{k} \sum_{b} x_{k,b} \ln(1 - P_{k,b})$
Subject to linear constraints.
Since the objective is linear in the variables (in log-space) and constraints are linear, and the function is convex (log of product of exponentials... actually log of sum is concave, but here it's log of product which is sum of logs), the minimization of a linear function over a convex polytope yields an extreme point solution.
Crucially, because the objective in log-space is linear, and the constraints are linear, we can solve this as an **LP** (if we allow fractional bombs) or **MILP**.
However, the original objective is non-linear. But since maximizing $1 - \exp(\text{linear})$ is equivalent to minimizing $\text{linear}$, the optimal solution to the LP relaxation (fractional bombs) might not be integer. But for this specific structure (independent targets, multiplicative probabilities), the "greedy" allocation based on "efficiency" (reduction in log-survival per unit cost) is optimal.
Actually, because the log-objective is linear, the problem is a **Linear Programming** problem in terms of finding the optimal allocation if we treat the log-probability as the objective.
Let $C_{k,b} = -\ln(1 - P_{k,b})$. This is the "damage potential" per bomb.
We want to Maximize $\sum_{k,b} x_{k,b} C_{k,b}$.
This is a **Linear Program** (LP) if $x$ are continuous, or **MILP** if $x$ are integers.
Given bombs are discrete, it is a **MILP** (specifically, a Linear Integer Program).
*Correction*: The problem asks to "maximize the probability". The direct mathematical formulation is non-linear. However, it is **isomorphic** to a Linear Maximization problem over the log-survival term.
I will formulate it as a **MILP** (Mixed Integer Linear Program) by transforming the objective, as this is the standard and most solvable approach. I will note the transformation.
