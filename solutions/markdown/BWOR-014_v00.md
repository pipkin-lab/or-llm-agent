# Goal Programming Model Formulation

## 1. Decision Variables
Let the decision variables represent the daily consumption amount (in units of 500g) of each food item:
*   $x_1$: Amount of Milk consumed (units of 500g)
*   $x_2$: Amount of Beef consumed (units of 500g)
*   $x_3$: Amount of Eggs consumed (units of 500g)

Let the deviation variables for the goals be:
*   $d_i^-$: Underachievement deviation (unmet requirement) for the $i$-th goal
*   $d_i^+$: Overachievement deviation (excess intake) for the $i$-th goal

Specifically:
*   $d_1^-, d_1^+$: Deviations for Vitamin A requirement
*   $d_2^-, d_2^+$: Deviations for Vitamin C requirement
*   $d_3^-, d_3^+$: Deviations for Vitamin D requirement
*   $d_4^-, d_4^+$: Deviations for Cholesterol intake (relative to a threshold or simply minimizing total)
*   $d_5^-, d_5^+$: Deviations for Food Cost (relative to a threshold or simply minimizing total)

*Note: In standard Goal Programming, "minimize" goals like cost and cholesterol are often modeled by minimizing the positive deviation ($d^+$) from a target value (often 0 or a specific limit), or by including the variable directly in the objective function if no specific target is given. Given the context "Minimize daily cholesterol intake" and "Minimize daily food cost" without specific target numbers, we model these as minimizing the total amount, which in GP is typically handled by setting a target of 0 and minimizing the positive deviation, or treating them as soft constraints where the positive deviation from 0 is the cost. However, standard practice for "minimize" without a target is to minimize the variable itself. To fit the GP structure strictly, we define targets $G_i$.*

Let's refine the Goal Definitions based on standard GP practices:
1.  **Vitamin A**: Target = 1 mg. We want to avoid underachievement ($d_1^-$).
2.  **Vitamin C**: Target = 30 mg. We want to avoid underachievement ($d_2^-$).
3.  **Vitamin D**: Target = 10 mg. We want to avoid underachievement ($d_3^-$).
4.  **Cholesterol**: Target = 0 (Minimize intake). We want to minimize overachievement ($d_4^+$).
5.  **Cost**: Target = 0 (Minimize cost). We want to minimize overachievement ($d_5^+$).

*(Alternatively, if specific monetary/health limits were provided, those would be targets. Since they are not, we minimize the positive deviation from 0).*

## 2. Objective Function
The objective is to minimize the weighted sum of unwanted deviations.
*   Priorities: Usually, meeting nutritional minimums (Goals 1-3) are hard constraints or high priority. Minimizing cholesterol and cost are secondary.
*   Let $P_1$ be the highest priority (meeting vitamin minimums).
*   Let $P_2$ be the second priority (minimizing cholesterol).
*   Let $P_3$ be the third priority (minimizing cost).
    *(Note: The problem lists 3 goals. Often, all "meet minimum" goals are Priority 1, and "minimize" goals are subsequent. We assume lexicographic ordering: 1. Vitamins, 2. Cholesterol, 3. Cost. Or potentially Vitamins are P1, Cholesterol P2, Cost P3.)*

**Objective Function (Lexicographic Minimization):**
$$ \min Z = [P_1(d_1^- + d_2^- + d_3^-), \quad P_2(d_4^+), \quad P_3(d_5^+)] $$

*Where:*
*   $d_1^-, d_2^-, d_3^-$: Unmet vitamin requirements (undesirable).
*   $d_4^+$: Excess cholesterol intake (undesirable).
*   $d_5^+$: Excess cost (undesirable).

*(If a single weighted objective is required instead of lexicographic, weights $w_i$ would be assigned: $\min Z = w_1(d_1^-+d_2^-+d_3^-) + w_2 d_4^+ + w_3 d_5^+$)*. We will present the standard lexicographic form as it is more common for distinct goal types.

## 3. Operational Constraints

**System Constraints (Goal Equations):**

1.  **Vitamin A:**
    $$ 1x_1 + 1x_2 + 10x_3 + d_1^- - d_1^+ = 1 $$

2.  **Vitamin C:**
    $$ 100x_1 + 10x_2 + 10x_3 + d_2^- - d_2^+ = 30 $$

3.  **Vitamin D:**
    $$ 10x_1 + 100x_2 + 10x_3 + d_3^- - d_3^+ = 10 $$

4.  **Cholesterol (Minimize Intake):**
    $$ 70x_1 + 50x_2 + 120x_3 + d_4^- - d_4^+ = 0 $$
    *(Note: Since we are minimizing intake, we treat the total intake as the variable to be kept low. The equation balances the intake against the target of 0. $d_4^+$ represents the actual amount of cholesterol consumed, which we want to minimize. $d_4^-$ would be 0 because intake cannot be negative).*

5.  **Cost (Minimize Cost):**
    $$ 1.5x_1 + 8x_2 + 4x_3 + d_5^- - d_5^+ = 0 $$
    *(Similarly, $d_5^+$ represents the total cost incurred, which we want to minimize).*

**Non-negativity Constraints:**
$$ x_1, x_2, x_3 \geq 0 $$
$$ d_i^-, d_i^+ \geq 0 \quad \text{for } i = 1, \dots, 5 $$

**Complementary Slackness (Implicit in GP):**
$$ d_i^- \cdot d_i^+ = 0 \quad \text{for all } i $$
*(Usually handled by the optimization solver, but theoretically only one deviation can be non-zero for a specific goal equation).*
