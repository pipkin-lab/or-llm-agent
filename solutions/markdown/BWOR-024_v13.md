Based on the problem description, this is a classic **2-Machine Flow Shop Scheduling Problem** ($F2||C_{max}$). The goal is to find a permutation of the 6 jobs that minimizes the makespan (total processing time), subject to the precedence constraint that every job must be processed on Machine A before Machine B.

### Model Type Declaration
**MILP (Mixed Integer Linear Programming)**
*Note: While Jackson's rule (a heuristic based on Johnson's algorithm) can solve this specific instance analytically, the formal mathematical model for the general case is a MILP. For 6 jobs, the state space is small ($6! = 720$), making it suitable for exact optimization.*

### Index Sets & Parameters

**Sets:**
- $J = \{1, 2, 3, 4, 5, 6\}$: Set of jobs.
- $M = \{A, B\}$: Set of machines.

**Parameters:**
- $A_j$: Processing time of job $j$ on Machine A (minutes).
- $B_j$: Processing time of job $j$ on Machine B (minutes).
- $N$: Total number of jobs ($|J| = 6$).
- $T_{max}$: A sufficiently large constant (Big-M) for sequencing constraints. We can estimate an upper bound for the makespan.
  - Sum of all A times: $30+60+60+20+80+90 = 340$.
  - Sum of all B times: $70+70+50+60+30+40 = 320$.
  - A safe upper bound for makespan is $\sum A_j + \max B_j = 340 + 90 = 430$. Let $M = 430$.

### Decision Variables

1.  **$x_{jk}$**: Binary variable.
    -   $x_{jk} = 1$ if job $j$ is scheduled at position $k$ in the sequence.
    -   $x_{jk} = 0$ otherwise.
    -   Domain: $x_{jk} \in \{0, 1\}$ for all $j \in J, k \in \{1, \dots, N\}$.

2.  **$C_{j,A}$**: Continuous variable.
    -   Completion time of job $j$ on Machine A.
    -   Domain: $C_{j,A} \ge 0$.

3.  **$C_{j,B}$**: Continuous variable.
    -   Completion time of job $j$ on Machine B.
    -   Domain: $C_{j,B} \ge 0$.

4.  **$C_{max}$**: Continuous variable.
    -   The makespan (total processing time / time when the last job finishes on Machine B).
    -   Domain: $C_{max} \ge 0$.

### Objective Function

Minimize the total processing time (Makespan):
$$ \text{Minimize } Z = C_{max} $$

### Operational Constraints

**1. Sequence Assignment Constraints (Permutation):**
Each job must be assigned to exactly one position, and each position must contain exactly one job.

$$ \sum_{k=1}^{N} x_{jk} = 1 \quad \forall j \in J $$
$$ \sum_{j \in J} x_{jk} = 1 \quad \forall k \in \{1, \dots, N\} $$

**2. Machine A Scheduling Constraints:**
The start time of a job on Machine A depends on its position in the sequence. If job $j$ is at position $k$, its start time is the sum of processing times of all jobs scheduled before it (positions $1$ to $k-1$).
$$ C_{j,A} = \sum_{l=1}^{N} \sum_{m=1}^{l-1} A_m x_{m,l} \cdot x_{j,l} \quad \forall j \in J $$
*Note: The term $x_{j,l}$ ensures we only calculate the completion time for job $j$ if it is actually assigned to position $l$. Since $x_{j,l}$ is binary, this is linear if we use the property that $x_{j,l}^2 = x_{j,l}$. However, standard linearization for flow shops often uses position-based start times directly.*

A more standard linear formulation for $C_{j,A}$ using position variables $Pos_j$ (where $Pos_j = \sum k \cdot x_{jk}$) is complex to linearize directly with products. A cleaner MILP formulation for 2-machine flow shop often uses relative ordering variables or simply enumerates positions. Let's use the **Position-Based Completion Time** formulation which is standard for small $N$:

Let $S_{j,A}$ be the start time of job $j$ on Machine A.
$S_{j,A} = \sum_{p=1}^{N} \sum_{q=1}^{p-1} A_q x_{q,p} x_{j,p}$
Since $x_{j,p}$ is 1 only for the assigned position $p$, this simplifies to:
If job $j$ is at position $p$, $S_{j,A} = \sum_{q \in J} A_q (\text{indicator that } q \text{ is before } j)$.

To keep it strictly Linear (LP/MILP without quadratic terms), we define the start time based on the sum of processing times of all jobs that precede job $j$ in the sequence.
Let $Y_{ij}$ be a binary variable where $Y_{ij} = 1$ if job $i$ is scheduled before job $j$.
*Alternative simpler approach for small N (6 jobs) using the $x_{jk}$ definition directly:*

For each job $j$ and position $k$:
If $x_{jk}=1$, then:
$$ C_{j,A} = \sum_{l=1}^{k-1} A_{j'} x_{j', l} \quad \text{(This is non-linear due to product of variables if not careful)} $$

Let's use the **Disjunctive / Big-M formulation** for pairwise ordering, which is robust and linear.

**Revised Decision Variables for Robust MILP:**
1.  $x_{ij}$: Binary variable, $x_{ij}=1$ if job $i$ is processed before job $j$ on both machines. (Note: In a permutation flow shop, the order is the same on both machines).
    *   Actually, simpler: Use the position variables $x_{jk}$ as defined above.
    *   To calculate $C_{j,A}$ linearly:
        $$ C_{j,A} \ge \sum_{l=1}^{N} \sum_{m=1}^{l-1} A_m x_{m,l} x_{j,l} $$
        This product $x_{m,l} x_{j,l}$ is non-linear.
        
    **Standard Linear Formulation for F2||Cmax (using start times and Big-M):**
    
    Let $s_{j,A}$ be start time on A, $s_{j,B}$ be start time on B.
    Let $x_{jk}$ be binary variable: 1 if job $j$ is at position $k$.
    
    1.  **Assignment:**
        $$ \sum_{k=1}^N x_{jk} = 1 \quad \forall j $$
        $$ \sum_{j=1}^N x_{jk} = 1 \quad \forall k $$
    
    2.  **Completion on A (Linearized via Position Sums):**
        Since the order on A is fixed by the permutation, the start time of the job at position $k$ is the sum of $A$ times of jobs at positions $1$ to $k-1$.
        Let $P_k$ be the job at position $k$. $A_{P_k} = \sum_{j} A_j x_{jk}$.
        Start time of job at position $k$ on A: $St_{k,A} = \sum_{l=1}^{k-1} A_{P_l} = \sum_{l=1}^{k-1} \sum_{j} A_j x_{jl}$.
        Completion time of job at position $k$ on A: $C_{k,A} = St_{k,A} + A_{P_k}$.
        
        We need to map this back to job-specific variables or just minimize the final completion time on B.
        
    3.  **Completion on B:**
        The start time of a job on B depends on:
        a) The completion of the *previous* job on B.
        b) The completion of the *same* job on A.
        
        Let's define $C_{j,B}$ for each job $j$.
        For any two distinct jobs $i$ and $j$, either $i$ comes before $j$ or $j$ comes before $i$.
        Let $z_{ij}$ be a binary variable: $z_{ij}=1$ if job $i$ precedes job $j$.
        Constraint: $z_{ij} + z_{ji} = 1$ for all $i \neq j$.
        
        **Precedence on Machine A:**
        $$ C_{j,A} \ge C_{i,A} + A_j - M(1 - z_{ij}) \quad \forall i \neq j $$
        $$ C_{j,A} \ge A_j \quad \forall j $$
        (This ensures if $z_{ij}=1$ (i before j), then $C_{j,A} \ge C_{i,A} + A_j$. If $z_{ij}=0$, the constraint is $C_{j,A} \ge A_j - M$, which is loose).
        
        **Precedence on Machine B:**
        $$ C_{j,B} \ge C_{i,B} + B_j - M(1 - z_{ij}) \quad \forall i \neq j $$
        $$ C_{j,B} \ge C_{j,A} \quad \forall j \quad \text{(Job must finish A before starting B)} $$
        $$ C_{j,B} \ge B_j \quad \forall j $$
        
        **Objective:**
        $$ \text{Minimize } C_{max} $$
        $$ C_{max} \ge C_{j,B} \quad \forall j $$

    **Parameters for Big-M:**
    $M$ must be larger than the maximum possible difference in completion times.
    Max sum of A times = 340. Max sum of B times = 320.
    A safe $M = 340 + 320 = 660$ (or simply sum of all processing times).

### Final Formal Model

**Model Type:** MILP

**Index Sets:**
- $J = \{1, 2, 3, 4, 5, 6\}$
- $J^2_{\neq} = \{(i,j) \mid i,j \in J, i \neq j\}$

**Parameters:**
- $A_j$: Processing time on A (30, 60, 60, 20, 80, 90)
- $B_j$: Processing time on B (70, 70, 50, 60, 30, 40)
- $M = 660$ (Big-M constant)

**Decision Variables:**
- $C_{j,A} \in \mathbb{R}^+$: Completion time of job $j$ on Machine A.
- $C_{j,B} \in \mathbb{R}^+$: Completion time of job $j$ on Machine B.
- $z_{ij} \in \{0, 1\}$: Binary variable, $z_{ij}=1$ if job $i$ is scheduled immediately before or somewhere before job $j$ (i.e., $i$ precedes $j$).
- $C_{max} \in \mathbb{R}^+$: Makespan.

**Objective Function:**
$$ \text{Minimize } C_{max} $$

**Constraints:**

1.  **Precedence on Machine A:**
    For all $i, j \in J, i \neq j$:
    $$ C_{j,A} \ge C_{i,A} + A_j - M(1 - z_{ij}) $$
    $$ C_{j,A} \ge A_j $$
    *(Note: The constraint $C_{j,A} \ge A_j$ handles the start time 0 case implicitly if we assume the first job starts at 0. More formally, for the first job, there is no $i$ preceding it. The Big-M constraint handles the relative ordering. To ensure the first job starts at 0, we rely on the minimization of $C_{max}$ pushing start times down. Alternatively, we can add $C_{j,A} \ge 0$ and $C_{j,A} \le A_j + \sum_{k \neq j} A_k$, but the Big-M formulation with minimization naturally finds the tightest schedule starting at 0.)*
    
    *Refinement for strict linearity and correctness:*
    The standard formulation ensures that if $z_{ij}=1$, $C_{j,A} \ge C_{i,A} + A_j$.
    We also need to ensure that the "first" job has $C_{j,A} = A_j$. This is handled by the fact that if no job precedes $j$, the constraints from other $i$'s are relaxed, and $C_{j,A}$ can be as small as $A_j$ (due to $C_{j,A} \ge A_j$).

2.  **Precedence on Machine B:**
    For all $i, j \in J, i \neq j$:
    $$ C_{j,B} \ge C_{i,B} + B_j - M(1 - z_{ij}) $$
    $$ C_{j,B} \ge C_{j,A} $$
    $$ C_{j,B} \ge B_j $$

3.  **Ordering Consistency:**
    The sequence must be a total order. For all $i, j \in J, i \neq j$:
    $$ z_{ij} + z_{ji} = 1 $$

4.  **Makespan Definition:**
    For all $j \in J$:
    $$ C_{max} \ge C_{j,B} $$

5.  **Bounds:**
    $$ C_{j,A} \ge 0, \quad C_{j,B} \ge 0, \quad C_{max} \ge 0 $$
    $$ z_{ij} \in \{0, 1\} $$

### Solution Verification (Johnson's Rule)
Although the model above is the formal MILP, we can verify the expected answer using Johnson's Rule for a 2-machine flow shop to ensure the model's output will be correct.

**Johnson's Rule Algorithm:**
1.  Find the minimum processing time among all remaining jobs.
2.  If the minimum is on Machine A, schedule that job as early as possible.
3.  If the minimum is on Machine B, schedule that job as late as possible.
4.  Repeat until all jobs are scheduled.

**Data:**
- Job 1: A=30, B=70
- Job 2: A=60, B=70
- Job 3: A=60, B=50
- Job 4: A=20, B=60
- Job 5: A=80, B=30
- Job 6: A=90, B=40

**Step-by-Step:**
1.  Min time is **20** (Job 4, Machine A). Schedule Job 4 **first**.
    Sequence: [4, _, _, _, _, _]
2.  Remaining Min time is **30** (Job 1, Machine A). Schedule Job 1 **next** (earliest available).
    Sequence: [4, 1, _, _, _, _]
3.  Remaining Min time is **30** (Job 5, Machine B). Schedule Job 5 **last**.
    Sequence: [4, 1, _, _, _, 5]
4.  Remaining Min time is **40** (Job 6, Machine B). Schedule Job 6 **next to last**.
    Sequence: [4, 1, _, _, 6, 5]
5.  Remaining Min time is **50** (Job 3, Machine B). Schedule Job 3 **next to last** (position 4).
    Sequence: [4, 1, _, 3, 6, 5]
6.  Remaining Jobs: 2.
    Job 2: A=60, B=70.
    Job 3 was picked? No, Job 3 is placed.
    Remaining are Job 2 and Job 3? No, Job 3 is placed at pos 4.
    Let's re-evaluate remaining after Step 2: Jobs 2, 3, 5, 6.
    - Min is 30 (Job 5, B). Place 5 last. Pos 6.
    - Remaining: 2, 3, 6.
    - Min is 40 (Job 6, B). Place 6 next to last. Pos 5.
    - Remaining: 2, 3.
    - Min is 50 (Job 3, B). Place 3 next to last. Pos 4.
    - Remaining: 2. Place 2 at Pos 3.
    
    **Final Sequence:** 4, 1, 2, 3, 6, 5.

**Calculate Makespan for Sequence 4-1-2-3-6-5:**

| Job | $A_j$ | $B_j$ | Start A | Finish A | Start B | Finish B |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 4 | 20 | 60 | 0 | 20 | 20 | 80 |
| 1 | 30 | 70 | 20 | 50 | 80 | 150 |
| 2 | 60 | 70 | 50 | 110 | 150 | 220 |
| 3 | 60 | 50 | 110 | 170 | 220 | 270 |
| 6 | 90 | 40 | 170 | 260 | 270 | 310 |
| 5 | 80 | 30 | 260 | 340 | 340 | 370 |

**Total Processing Time (Makespan) = 370 minutes.**

The MILP model formulated above will yield an optimal objective value of **370**.
