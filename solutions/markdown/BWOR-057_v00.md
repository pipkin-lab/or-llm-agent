# Operational Research Model: Container Production and Substitution

## 1. Decision Variables

We define two sets of decision variables: one for production quantities and one for machine activation (binary).

**Set Definitions:**
*   $I = \{1, 2, 3, 4, 5, 6\}$: Set of container types (sorted by increasing capacity).
*   $N = \{1, \dots, 6\}$: Set of demand nodes (corresponding to container types).

**Production Variables ($x_{ij}$):**
*   $x_{ij} \geq 0$: The number of units of container type $i$ produced to satisfy the demand of container type $j$.
    *   *Constraint on Substitution Logic*: Since only larger or equal capacities can substitute for smaller ones, we restrict $x_{ij}$ such that if $i < j$ (container $i$ is smaller than demand $j$), then $x_{ij} = 0$.
    *   Specifically, valid pairs $(i,j)$ are those where $Capacity_i \geq Capacity_j$.

**Binary Activation Variables ($y_i$):**
*   $y_i \in \{0, 1\}$: Binary variable indicating whether machine $i$ is active.
    *   $y_i = 1$ if machine $i$ produces any quantity ($\sum_{j} x_{ij} > 0$).
    *   $y_i = 0$ if machine $i$ is not used.

## 2. Objective Function

**Minimize Total Cost**

The total cost consists of the fixed costs for activated machines and the variable costs for all units produced.

$$
\text{Minimize } Z = \sum_{i \in I} (1200 \cdot y_i) + \sum_{i \in I} \sum_{j \in N} (c_i \cdot x_{ij})
$$

Where:
*   $1200$ is the fixed cost per machine (Yuan).
*   $c_i$ is the variable cost per unit for container type $i$ (Yuan).
    *   $c = [5, 8, 10, 12, 16, 18]$

## 3. Operational Constraints

### A. Demand Satisfaction Constraints
The total quantity of containers assigned to meet demand $j$ (from all eligible producers $i$) must equal the exact demand $D_j$.

$$
\sum_{i: Capacity_i \geq Capacity_j} x_{ij} = D_j, \quad \forall j \in N
$$

Where $D = [500, 550, 700, 900, 400, 300]$.

*Expanded logically (since $i$ must be $\geq j$ for capacity):*
*   For Demand 1 ($1500 \text{ cm}^3$): $x_{11} + x_{21} + x_{31} + x_{41} + x_{51} + x_{61} = 500$
*   For Demand 2 ($2500 \text{ cm}^3$): $x_{22} + x_{32} + x_{42} + x_{52} + x_{62} = 550$
*   For Demand 3 ($4000 \text{ cm}^3$): $x_{33} + x_{43} + x_{53} + x_{63} = 700$
*   For Demand 4 ($6000 \text{ cm}^3$): $x_{44} + x_{54} + x_{64} = 900$
*   For Demand 5 ($9000 \text{ cm}^3$): $x_{55} + x_{65} = 400$
*   For Demand 6 ($12000 \text{ cm}^3$): $x_{66} = 300$ *(Note: Only container 6 can satisfy demand 6)*

### B. Machine Activation Linking Constraints
A machine can only produce if it is active. We use a Big-M constraint to link the binary variable $y_i$ to the production variables $x_{ij}$.

$$
\sum_{j \in N} x_{ij} \leq M_i \cdot y_i, \quad \forall i \in I
$$

Where $M_i$ is an upper bound on the total production of machine $i$. Since demand is finite, $M_i$ can be set to the sum of all demands (or a tighter bound specific to machine $i$'s eligible demands). Let $D_{total} = \sum_{j} D_j = 3350$.

$$
\sum_{j} x_{ij} \leq 3350 \cdot y_i, \quad \forall i \in I
$$

### C. Non-negativity and Integrality
$$
x_{ij} \geq 0 \quad \forall (i,j) \text{ such that } Capacity_i \geq Capacity_j
$$
$$
y_i \in \{0, 1\} \quad \forall i \in I
$$
*(Note: In practice, container counts are integers, so $x_{ij}$ should ideally be constrained to be integer variables, i.e., $x_{ij} \in \mathbb{Z}^+$. Given the scale, linear relaxation might yield integer solutions due to the network flow structure, but strict integrality is required for physical units.)*
