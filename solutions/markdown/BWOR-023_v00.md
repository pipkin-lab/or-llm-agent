# Mathematical Formulation: Traveling Salesman Problem (TSP)

## 1. Decision Variables

Let the set of cities be $V = \{1, 2, 3, 4\}$, with city 1 as the start/end node ($v_1$).
Let $S \subseteq V \setminus \{1\}$ be a subset of cities visited.
Let $k \in V \setminus \{1\}$ be the last city visited in the sequence for a given subset $S$.

**Dynamic Programming State Variable:**
$$C(S, k) = \text{Minimum distance to start at city 1, visit all cities in subset } S \text{ exactly once, and end at city } k.$$

*Note: $k \in S$ and $1 \notin S$.*

## 2. Objective Function

**Minimize** the total path length $Z$:

$$Z = \min \left[ C(\{2, 3, 4\}, 2) + d(2, 1), \quad C(\{2, 3, 4\}, 3) + d(3, 1), \quad C(\{2, 3, 4\}, 4) + d(4, 1) \right]$$

Where $d(i, j)$ is the distance between city $i$ and city $j$ as given in the table.

## 3. Operational Constraints & Recurrence Relations

### A. Distance Matrix Constraints
The cost coefficients $d(i, j)$ are fixed constants derived from Table 7-24:
- $d(1,2)=6, d(1,3)=7, d(1,4)=9$
- $d(2,1)=8, d(2,3)=9, d(2,4)=7$
- $d(3,1)=5, d(3,2)=8, d(3,4)=8$
- $d(4,1)=6, d(4,2)=5, d(4,3)=5$

### B. Recurrence Relation (Bellman Equation)
For any subset $S$ containing $k$ (where $|S| > 1$), the cost is defined recursively as:

$$C(S, k) = \min_{j \in S \setminus \{k\}} \left[ C(S \setminus \{k\}, j) + d(j, k) \right]$$

*Constraint:* The minimum is taken over all possible predecessors $j$ in the subset $S$ excluding the current endpoint $k$.

### C. Base Case (Initialization)
For subsets of size 1 (starting directly from city 1 to city $k$):

$$C(\{k\}, k) = d(1, k) \quad \text{for } k \in \{2, 3, 4\}$$

Specifically:
- $C(\{2\}, 2) = 6$
- $C(\{3\}, 3) = 7$
- $C(\{4\}, 4) = 9$

### D. Subset Constraints
1. **Subset Validity**: $S$ must be a non-empty proper subset of $\{2, 3, 4\}$.
2. **Endpoint Validity**: $k$ must be an element of $S$.
3. **Predecessor Validity**: In the recurrence, $j$ must be in $S$ but $j \neq k$.
4. **Completeness**: The final solution must consider all permutations ending in each possible city $k \in \{2, 3, 4\}$ and add the return distance to city 1.
