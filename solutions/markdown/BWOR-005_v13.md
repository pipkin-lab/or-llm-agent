**Model Type:** LP (Linear Programming)

### 1. Index Sets & Parameters

**Index Sets:**
- $i \in \{F, M, R\}$: Set of compartments (Front, Middle, Rear).
- $j \in \{A, B, C\}$: Set of cargo types.

**Parameters (extracted from Tables 1-24 and 1-25):**

*Compartment Capacities:*
- $\text{CapW}_i$: Maximum allowable load weight (tons).
  - $\text{CapW}_F = 2000$
  - $\text{CapW}_M = 3000$
  - $\text{CapW}_R = 1500$
- $\text{CapV}_i$: Maximum allowable volume ($m^3$).
  - $\text{CapV}_F = 4000$
  - $\text{CapV}_M = 5000$
  - $\text{CapV}_R = 1500$

*Cargo Data:*
- $\text{Qty}_j$: Total available quantity of cargo type $j$ (pieces).
  - $\text{Qty}_A = 600$
  - $\text{Qty}_B = 1000$
  - $\text{Qty}_C = 800$
- $v_j$: Volume per piece of cargo type $j$ ($m^3$/piece).
  - $v_A = 10$
  - $v_B = 5$
  - $v_C = 7$
- $w_j$: Weight per piece of cargo type $j$ (tons/piece).
  - $w_A = 8$
  - $w_B = 6$
  - $w_C = 4$
- $r_j$: Freight rate (revenue per piece) for cargo type $j$ (dollars/piece).
  - $r_A = 1000$
  - $r_B = 700$
  - $r_C = 600$

*Balance Deviation Limits:*
- $\delta_{FM} = 0.15$ (15% deviation limit for Front/Middle ratio)
- $\delta_{RM} = 0.15$ (15% deviation limit for Rear/Middle ratio)
- $\delta_{FR} = 0.10$ (10% deviation limit for Front/Rear ratio)

*Target Ratios (based on Max Allowable Loads):*
- Ratio $F:M = 2000 : 3000 = 2:3$.
- Ratio $R:M = 1500 : 3000 = 1:2$.
- Ratio $F:R = 2000 : 1500 = 4:3$.

### 2. Decision Variables

Let $x_{ij}$ be the number of pieces of cargo type $j$ loaded in compartment $i$.
- **Domain:** $x_{ij} \in \mathbb{Z}^+$ (Non-negative integers).
  *(Note: While LP relaxations allow continuous variables, cargo is counted in discrete pieces. However, standard LP formulations often treat these as continuous if quantities are large, or explicitly as MILP. Given the instruction "formulate the linear programming model", we define them as non-negative variables. If integrality is strictly required by the "pieces" nature, it is a MILP. In many textbook cargo problems, LP relaxation is accepted, but "pieces" implies integrality. We will specify **Integer** variables to be precise, making it a MILP, but the constraints are linear.)*

Let $W_i$ be the total weight in compartment $i$ (tons).
Let $V_i$ be the total volume in compartment $i$ ($m^3$).

*Auxiliary Variable for Balance Constraints:*
To linearize the ratio constraints, we do not need auxiliary variables if we cross-multiply, but we must ensure the denominators are non-zero. Since we are maximizing revenue and all costs are positive, and we have strict capacity limits, we assume optimal loading will utilize significant portions of the capacity. However, strictly speaking, if a compartment is empty, the ratio is undefined. The problem implies "roughly the same proportion", implying non-empty states. We will formulate the constraints directly using cross-multiplication.

### 3. Objective Function

Maximize Total Revenue:
$$ \text{Maximize } Z = \sum_{i \in \{F, M, R\}} \sum_{j \in \{A, B, C\}} r_j x_{ij} $$
$$ Z = 1000(x_{FA} + x_{MA} + x_{RA}) + 700(x_{FB} + x_{MB} + x_{RB}) + 600(x_{FC} + x_{MC} + x_{RC}) $$

### 4. Operational Constraints

**1. Cargo Availability Constraints:**
The total amount of each cargo type loaded across all compartments cannot exceed the available quantity.
$$ \sum_{i \in \{F, M, R\}} x_{iA} \le 600 $$
$$ \sum_{i \in \{F, M, R\}} x_{iB} \le 1000 $$
$$ \sum_{i \in \{F, M, R\}} x_{iC} \le 800 $$

**2. Compartment Volume Constraints:**
The total volume of cargo in each compartment must not exceed its capacity.
$$ 10x_{FA} + 5x_{FB} + 7x_{FC} \le 4000 \quad (\text{Front}) $$
$$ 10x_{MA} + 5x_{MB} + 7x_{MC} \le 5000 \quad (\text{Middle}) $$
$$ 10x_{RA} + 5x_{RB} + 7x_{RC} \le 1500 \quad (\text{Rear}) $$

**3. Compartment Weight Constraints:**
The total weight of cargo in each compartment must not exceed its maximum allowable load.
$$ 8x_{FA} + 6x_{FB} + 4x_{FC} \le 2000 \quad (\text{Front}) $$
$$ 8x_{MA} + 6x_{MB} + 4x_{MC} \le 3000 \quad (\text{Middle}) $$
$$ 8x_{RA} + 6x_{RB} + 4x_{RC} \le 1500 \quad (\text{Rear}) $$

**4. Balance (Stability) Constraints:**
Let $W_F, W_M, W_R$ be the total weights in Front, Middle, and Rear compartments respectively.
$W_F = 8x_{FA} + 6x_{FB} + 4x_{FC}$
$W_M = 8x_{MA} + 6x_{MB} + 4x_{MC}$
$W_R = 8x_{RA} + 6x_{RB} + 4x_{RC}$

The problem states the load weight ratios must not deviate by more than specified percentages from the ratios of their max allowable loads.

*   **Front/Middle Ratio Constraint:**
    Target Ratio: $W_F / W_M \approx 2000 / 3000 = 2/3$.
    Deviation limit: 15%.
    $$ 0.85 \times \frac{2}{3} \le \frac{W_F}{W_M} \le 1.15 \times \frac{2}{3} $$
    $$ \frac{17}{45} \le \frac{W_F}{W_M} \le \frac{23}{45} $$
    Assuming $W_M > 0$ (which is guaranteed in any revenue-maximizing solution given the high capacity and positive revenue), we can cross-multiply to linearize:
    $$ \text{Lower Bound: } 45 W_F - 17 W_M \ge 0 \implies 45(8x_{FA} + 6x_{FB} + 4x_{FC}) - 17(8x_{MA} + 6x_{MB} + 4x_{MC}) \ge 0 $$
    $$ \text{Upper Bound: } 45 W_F - 23 W_M \le 0 \implies 45(8x_{FA} + 6x_{FB} + 4x_{FC}) - 23(8x_{MA} + 6x_{MB} + 4x_{MC}) \le 0 $$

*   **Rear/Middle Ratio Constraint:**
    Target Ratio: $W_R / W_M \approx 1500 / 3000 = 1/2$.
    Deviation limit: 15%.
    $$ 0.85 \times \frac{1}{2} \le \frac{W_R}{W_M} \le 1.15 \times \frac{1}{2} $$
    $$ \frac{17}{40} \le \frac{W_R}{W_M} \le \frac{23}{40} $$
    Cross-multiplying (assuming $W_M > 0$):
    $$ \text{Lower Bound: } 40 W_R - 17 W_M \ge 0 \implies 40(8x_{RA} + 6x_{RB} + 4x_{RC}) - 17(8x_{MA} + 6x_{MB} + 4x_{MC}) \ge 0 $$
    $$ \text{Upper Bound: } 40 W_R - 23 W_M \le 0 \implies 40(8x_{RA} + 6x_{RB} + 4x_{RC}) - 23(8x_{MA} + 6x_{MB} + 4x_{MC}) \le 0 $$

*   **Front/Rear Ratio Constraint:**
    Target Ratio: $W_F / W_R \approx 2000 / 1500 = 4/3$.
    Deviation limit: 10%.
    $$ 0.90 \times \frac{4}{3} \le \frac{W_F}{W_R} \le 1.10 \times \frac{4}{3} $$
    $$ \frac{36}{30} \le \frac{W_F}{W_R} \le \frac{44}{30} \implies 1.2 \le \frac{W_F}{W_R} \le 1.466... $$
    Using fractions: Lower $= \frac{6}{5}$, Upper $= \frac{22}{15}$.
    Cross-multiplying (assuming $W_R > 0$):
    $$ \text{Lower Bound: } 5 W_F - 6 W_R \ge 0 \implies 5(8x_{FA} + 6x_{FB} + 4x_{FC}) - 6(8x_{RA} + 6x_{RB} + 4x_{RC}) \ge 0 $$
    $$ \text{Upper Bound: } 15 W_F - 22 W_R \le 0 \implies 15(8x_{FA} + 6x_{FB} + 4x_{FC}) - 22(8x_{RA} + 6x_{RB} + 4x_{RC}) \le 0 $$

**5. Non-negativity and Integrality:**
$$ x_{ij} \ge 0, \quad x_{ij} \in \mathbb{Z} \quad \forall i \in \{F, M, R\}, j \in \{A, B, C\} $$
