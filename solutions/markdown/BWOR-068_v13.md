# Production/Inventory Planning Problem

## MANDATORY COST INVENTORY (PRE-MODELING STEP)

| # | Numeric Value | Entity Modified | Role in Model |
|---|---|---|---|
| 1 | 48 yuan | Order of 10 pairs | Variable order cost coefficient |
| 2 | 86 yuan | Order of 20 pairs | Variable order cost coefficient |
| 3 | 118 yuan | Order of 30 pairs | Variable order cost coefficient |
| 4 | 138 yuan | Order of 40 pairs | Variable order cost coefficient |
| 5 | 160 yuan | Order of 50 pairs | Variable order cost coefficient |
| 6 | 10 yuan | Any order placed (fixed) | Fixed ordering cost (setup) |
| 7 | 0.2 yuan | Per pair per month | Holding cost rate |
| 8 | 40 pairs | End-of-month inventory | Maximum inventory capacity |
| 9-14 | 40,20,30,40,30,20 | Monthly demands (Oct–Mar) | Demand parameters |

**Count check:** 5 order-quantity options → 5 variable cost figures (48, 86, 118, 138, 160) ✓. All objective parameters matched.

## Model Type

**MILP** (Mixed-Integer Linear Program). Binary variables for order-quantity selection and setup; continuous/integer for inventory.

---

## Index Sets & Parameters

**Index Sets:**
- $T = \{1, 2, 3, 4, 5, 6\}$ : months (1=October, 2=November, 3=December, 4=January, 5=February, 6=March)
- $K = \{1, 2, 3, 4, 5\}$ : discrete order-size options, where $q_k = 10k$ pairs

**Parameters:**

| Symbol | Value | Description |
|--------|-------|-------------|
| $D_t$ | $D_1=40, D_2=20, D_3=30, D_4=40, D_5=30, D_6=20$ | Demand in month $t$ (pairs) |
| $q_k$ | $10, 20, 30, 40, 50$ | Order quantity for option $k$ (pairs) |
| $c_k$ | $48, 86, 118, 138, 160$ | Variable order cost for option $k$ (yuan) |
| $f$ | $10$ | Fixed ordering cost per order (yuan) |
| $h$ | $0.2$ | Holding cost per pair per month (yuan/pair) |
| $I_{\max}$ | $40$ | Maximum end-of-month inventory (pairs) |
| $I_0$ | $0$ | Initial inventory (pairs) |
| $I_6$ | $0$ | Final inventory (pairs) |

**Derived: Unit prices** $p_k = c_k / q_k$:
- $p_1 = 48/10 = 4.8$, $p_2 = 86/20 = 4.3$, $p_3 = 118/30 \approx 3.933$, $p_4 = 138/40 = 3.45$, $p_5 = 160/50 = 3.2$ yuan/pair

Note: Bulk discount structure — larger orders have lower per-unit cost.

---

## Decision Variables

| Variable | Domain | Description |
|----------|--------|-------------|
| $x_{t,k} \in \{0,1\}$ | Binary, $\forall t \in T, \forall k \in K$ | 1 if an order of size $q_k$ is placed in month $t$ |
| $y_t \in \{0,1\}$ | Binary, $\forall t \in T$ | 1 if any order is placed in month $t$ (setup indicator) |
| $I_t \geq 0$ | Integer, $\forall t \in T$ | End-of-month inventory in month $t$ (pairs) |

> **Domain rationale:** Inventory is in whole pairs (discrete physical units) → Integer. Order-size selection is discrete → Binary. Setup is binary.

---

## Objective Function

**MINIMIZE** Total Cost:

$$\min \sum_{t=1}^{6} \sum_{k=1}^{5} c_k \, x_{t,k} \;+\; f \sum_{t=1}^{6} y_t \;+\; h \sum_{t=1}^{6} I_t$$

Expanded:

$$\min \sum_{t=1}^{6}\left[ 48\,x_{t,1} + 86\,x_{t,2} + 118\,x_{t,3} + 138\,x_{t,4} + 160\,x_{t,5} + 10\,y_t + 0.2\,I_t \right]$$

**Unit verification:** All terms are in **yuan**. The final answer will be in **yuan**. ✓

**Magnitude sanity check (greedy solution estimate):**
- Total demand = 40+20+30+40+30+20 = 180 pairs
- If all purchased at best unit price (50-pair lots, 3.2 yuan/pair): 180 × 3.2 = 576 yuan
- Plus fixed costs: ~4–6 orders × 10 = 40–60 yuan
- Plus holding: max ~40 pairs × 0.2 × ~3 months avg ≈ 24 yuan
- **Expected total: ~650–750 yuan**

If a solution orders 40 in Oct, 20 in Nov, 30 in Dec, 40 in Jan, 30 in Feb, 20 in Mar (no inventory):
- Cost: 138 + 86 + 118 + 138 + 118 + 86 = 684 yuan (variable) + 6×10 = 60 (fixed) + 0 (holding) = **744 yuan**

This confirms the answer should be in the **hundreds of yuan** range. ✓

## Operational Constraints

### 1. At most one order size per month (mutual exclusivity)

$$\sum_{k=1}^{5} x_{t,k} \leq 1, \quad \forall\, t \in T$$

### 2. Setup activation (fixed cost only if an order is placed)

$$y_t \geq x_{t,k}, \quad \forall\, t \in T,\; \forall\, k \in K$$

(Equivalently: $y_t \geq \sum_k x_{t,k}$, but since at most one $x$ can be 1, the per-$k$ form is sufficient and tighter.)

### 3. Inventory balance (flow conservation)

$$I_t = I_{t-1} + \sum_{k=1}^{5} q_k \, x_{t,k} - D_t, \quad \forall\, t \in T$$

With $I_0 = 0$ (given: zero inventory at beginning of peak season).

Explicitly:
- $I_1 = 0 + \sum_k q_k x_{1,k} - 40$
- $I_2 = I_1 + \sum_k q_k x_{2,k} - 20$
- $I_3 = I_2 + \sum_k q_k x_{3,k} - 30$
- $I_4 = I_3 + \sum_k q_k x_{4,k} - 40$
- $I_5 = I_4 + \sum_k q_k x_{5,k} - 30$
- $I_6 = I_5 + \sum_k q_k x_{6,k} - 20 = 0$ (given: zero inventory at end of peak season)

### 4. Inventory capacity

$$0 \leq I_t \leq 40, \quad \forall\, t \in T$$

### 5. Non-negativity and integrality

$$x_{t,k} \in \{0,1\}, \quad \forall\, t \in T,\; \forall\, k \in K$$
$$y_t \in \{0,1\}, \quad \forall\, t \in T$$
$$I_t \in \mathbb{Z}_{\geq 0}, \quad \forall\, t \in T$$

## Feasibility Sanity Check

**Total demand:** $40+20+30+40+30+20 = 180$ pairs

**Minimum total orders needed:** Since max order = 50, need at least $\lceil 180/50 \rceil = 4$ orders.

**Inventory capacity check:** Max inventory = 40 pairs. Since max single order = 50 and minimum demand in any month = 20, it is possible to hold up to 50 pairs after ordering but the cap is 40. Let's verify feasibility:

- Can we always find a feasible plan? Yes. For example:
  - Oct: order 50 → $I_1 = 50 - 40 = 10$ ✓ (≤40)
  - Nov: order 20 → $I_2 = 10 + 20 - 20 = 10$ ✓
  - Dec: order 30 → $I_3 = 10 + 30 - 30 = 10$ ✓
  - Jan: order 40 → $I_4 = 10 + 40 - 40 = 10$ ✓
  - Feb: order 30 → $I_5 = 10 + 30 - 30 = 10$ ✓
  - Mar: need $I_6 = 0$, so $I_5 + \text{order} - 20 = 0$ → order = 10 → $I_6 = 10 + 10 - 20 = 0$ ✓

  All inventories ≤ 40. **Feasible.** ✓

**Zero-solution test (Rule 18):** The inventory balance is an **equality** (not inequality), and $I_6 = 0$ is enforced. If all $x_{t,k} = 0$, then $I_1 = -40 < 0$, violating $I_t \geq 0$. The trivial zero solution is **infeasible**. ✓

**Boundary condition verification (Rule 10):** End-of-month-$t$ inventory $I_t$ includes units ordered in month $t$ that remain after satisfying month-$t$ demand. The balance equation $I_t = I_{t-1} + Q_t - D_t$ correctly includes current-period orders. For $t=1$: $I_1 = 0 + Q_1 - D_1$. ✓

## Final Model Summary

$$\boxed{
\begin{aligned}
\min \quad & \sum_{t=1}^{6}\sum_{k=1}^{5} c_k\, x_{t,k} + 10\sum_{t=1}^{6} y_t + 0.2\sum_{t=1}^{6} I_t \\[6pt]
\text{s.t.} \quad & \sum_{k=1}^{5} x_{t,k} \leq 1 && \forall\, t \\[4pt]
& y_t \geq x_{t,k} && \forall\, t,\, k \\[4pt]
& I_t = I_{t-1} + \sum_{k=1}^{5} q_k\, x_{t,k} - D_t && \forall\, t \\[4pt]
& I_0 = 0, \quad I_6 = 0 \\[4pt]
& 0 \leq I_t \leq 40 && \forall\, t \\[4pt]
& x_{t,k} \in \{0,1\}, \quad y_t \in \{0,1\}, \quad I_t \in \mathbb{Z}_{\geq 0}
\end{aligned}
}
$$

All parameters are explicitly defined from the problem statement. The model is a **MILP** solvable by any standard MILP solver (CPLEX, Gurobi, OR-Tools, etc.).
