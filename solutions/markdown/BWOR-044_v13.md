## Mathematical Optimization Model

**Model Type:** LP (Linear Program)

---

### MANDATORY COST INVENTORY (PRE-MODELING STEP)

| Numeric Value | Entity Modified | Role |
|---|---|---|
| 1, 2, 2 (row 1) | Transport costs from Origin 1 to A, B, C | Objective coefficients $c_{1j}$ |
| 1, 4, 5 (row 2) | Transport costs from Origin 2 to A, B, C | Objective coefficients $c_{2j}$ |
| 2, 3, 3 (row 3) | Transport costs from Origin 3 to A, B, C | Objective coefficients $c_{3j}$ |
| 5 | Storage cost per unshipped unit at Origin 1 | Objective coefficient for unused supply at origin 1 |
| 4 | Storage cost per unshipped unit at Origin 2 | Objective coefficient for unused supply at origin 2 |
| 3 | Storage cost per unshipped unit at Origin 3 | Objective coefficient for unused supply at origin 3 |
| 20, 40, 30 | Supply at origins 1, 2, 3 | Supply parameters $S_i$ |
| 30, 20, 20 | Demand at destinations A, B, C | Demand parameters $D_j$ |
| 38 | Minimum shipment requirement from Origin 2 | Lower bound constraint |
| 27 | Minimum shipment requirement from Origin 3 | Lower bound constraint |

Total supply = 90, Total demand = 70. Since supply > demand, unshipped units will incur storage costs.

### Index Sets & Parameters

**Sets:**
- Origins: $I = \{1, 2, 3\}$
- Destinations: $J = \{A, B, C\}$

**Parameters (all explicitly from Table 3-17 and problem text):**

| Parameter | Meaning | Values |
|---|---|---|
| $c_{1A}, c_{1B}, c_{1C}$ | Transport cost from origin 1 | 1, 2, 2 |
| $c_{2A}, c_{2B}, c_{2C}$ | Transport cost from origin 2 | 1, 4, 5 |
| $c_{3A}, c_{3B}, c_{3C}$ | Transport cost from origin 3 | 2, 3, 3 |
| $h_1, h_2, h_3$ | Storage cost per unshipped unit | 5, 4, 3 |
| $S_1, S_2, S_3$ | Supply at each origin | 20, 40, 30 |

---

### Decision Variables

- $x_{ij} \geq 0$, **continuous** — quantity shipped from origin $i$ to destination $j$, for all $i \in I, j \in J$.
- $u_i \geq 0$, **continuous** — quantity of unshipped (stored) units at origin $i$, for all $i \in I$.

---

### Objective Function

**MINIMIZE** total cost (transportation + storage):

$$\min \; Z = \sum_{i \in I} \sum_{j \in J} c_{ij} \, x_{ij} + \sum_{i \in I} h_i \, u_i$$

Expanded:

$$\min \; Z = (x_{1A} + 2x_{1B} + 2x_{1C}) + (x_{2A} + 4x_{2B} + 5x_{2C}) + (2x_{3A} + 3x_{3B} + 3x_{3C}) + 5u_1 + 4u_2 + 3u_3$$

---

### Operational Constraints

**1. Supply Balance (Equality — Rule 9: supply > demand, all units must be allocated):**

Every unit of supply must either be shipped or stored:

$$\sum_{j \in J} x_{ij} + u_i = S_i, \quad \forall i \in I$$

Explicitly:
- $x_{1A} + x_{1B} + x_{1C} + u_1 = 20$
- $x_{2A} + x_{2B} + x_{2C} + u_2 = 40$
- $x_{3A} + x_{3B} + x_{3C} + u_3 = 30$

**2. Demand Satisfaction (Equality — all demand must be met):**

$$\sum_{i \in I} x_{ij} = D_j, \quad \forall j \in J$$

Explicitly:
- $x_{1A} + x_{2A} + x_{3A} = 30$
- $x_{1B} + x_{2B} + x_{3B} = 20$
- $x_{1C} + x_{2C} + x_{3C} = 20$

**3. Minimum Shipment Constraints:**

$$\sum_{j \in J} x_{2j} \geq 38$$
$$\sum_{j \in J} x_{3j} \geq 27$$

**4. Non-negativity Bounds:**

$$x_{ij} \geq 0, \quad \forall i \in I, j \in J$$
$$u_i \geq 0, \quad \forall i \in I$$

---

### Feasibility Sanity Check

- Total supply = 20 + 40 + 30 = 90
- Total demand = 30 + 20 + 20 = 70
- Total unshipped (stored) = 90 − 70 = 20 units (must be allocated via $u_i$)
- Origin 1: max ship = 20 (full supply), so $u_1 = 20 - \sum_j x_{1j} \geq 0$. Min shipment from origin 1 is not constrained, so $u_1$ can absorb up to 20.
- Origin 2: must ship ≥ 38, supply = 40, so $u_2 \leq 2$.
- Origin 3: must ship ≥ 27, supply = 30, so $u_3 \leq 3$.
- Total unshipped = 20. Since $u_2 \leq 2$ and $u_3 \leq 3$, we need $u_1 \geq 20 - 2 - 3 = 15$. This is feasible since $u_1 \leq 20$.
- **Feasibility confirmed.**
