## Model Type
**LP** (Linear Programming). The problem is a transshipment problem with continuous flow variables (tons).

---

## Index Sets & Parameters

### Index Sets
- $O = \{X, Y\}$: Set of supply origins.
- $D = \{A, B, C\}$: Set of demand destinations.
- $N = O \cup D = \{X, Y, A, B, C\}$: Set of all nodes.
- $E$: Set of all directed arcs $(i, j)$ such that a direct shipment from $i$ to $j$ is physically possible and the distance is defined in the tables. Based on the tables:
  - From Table 3-23 (X, Y to X, Y): Arcs $(X,Y), (Y,X)$. (Note: $(X,X)$ and $(Y,Y)$ are self-loops with distance 0, typically excluded from flow variables as they add no value, or included with 0 cost. We exclude self-loops for simplicity as they don't affect the objective or flow balance meaningfully).
  - From Table 3-24 (X, Y to A, B, C): Arcs $(X,A), (X,B), (X,C), (Y,A), (Y,B), (Y,C)$.
  - From Table 3-25 (A, B, C to A, B, C): Arcs $(A,B), (A,C), (B,A), (B,C), (C,A), (C,B)$. (Self-loops $(A,A), (B,B), (C,C)$ excluded).

### Parameters
**Supply ($S_i$) in tons:**
- $S_X = 70$

**Demand ($D_j$) in tons:**
- $D_A = 35$
- $D_B = 40$
- $D_C = 50$

*Check:* Total Supply = $70 + 55 = 125$. Total Demand = $35 + 40 + 50 = 125$. Balanced.

**Distances ($c_{ij}$) in km:**
*From Table 3-23:*

*From Table 3-24:*
- $c_{X,A} = 10$
- $c_{X,B} = 14$
- $c_{X,C} = 12$
- $c_{Y,A} = 15$
- $c_{Y,B} = 12$
- $c_{Y,C} = 18$

*From Table 3-25:*
- $c_{A,B} = 14$
- $c_{A,C} = 11$
- $c_{B,A} = 10$
- $c_{B,C} = 4$

- $c_{C,B} = 12$

## Decision Variables

Let $x_{ij}$ be the amount of goods (in tons) shipped directly from node $i$ to node $j$ along arc $(i, j) \in E$.

**Domain:**
$$x_{ij} \ge 0, \quad \forall (i, j) \in E$$

---

## Objective Function

Minimize the total transportation distance (cost is proportional to distance, assume unit cost per ton-km is 1).

$$
\text{Minimize } Z = \sum_{(i,j) \in E} c_{ij} x_{ij}
$$

Expanding explicitly:
$$
Z = 12 x_{X,Y} + 10 x_{Y,X} + 10 x_{X,A} + 14 x_{X,B} + 12 x_{X,C} + 15 x_{Y,A} + 12 x_{Y,B} + 18 x_{Y,C} + 14 x_{A,B} + 11 x_{A,C} + 10 x_{B,A} + 4 x_{B,C} + 8 x_{C,A} + 12 x_{C,B}
$$

---

## Operational Constraints

### 1. Flow Balance Constraints
For every node $k \in N$, the total inflow plus initial supply (if $k \in O$) must equal the total outflow plus final demand (if $k \in D$).

General form for node $k$:
$$
\sum_{i \in N} x_{i,k} + S_k = \sum_{j \in N} x_{k,j} + D_k
$$
Where $S_k = 0$ if $k \notin O$ and $D_k = 0$ if $k \notin D$.

**Expanded by Node:**

**Node X (Supply = 70, Demand = 0):**
Inflow: $x_{Y,X}$
Outflow: $x_{X,Y} + x_{X,A} + x_{X,B} + x_{X,C}$
$$
x_{Y,X} + 70 = x_{X,Y} + x_{X,A} + x_{X,B} + x_{X,C}
$$
Or:
$$
x_{X,Y} + x_{X,A} + x_{X,B} + x_{X,C} - x_{Y,X} = 70
$$

**Node Y (Supply = 55, Demand = 0):**
Inflow: $x_{X,Y}$
Outflow: $x_{Y,X} + x_{Y,A} + x_{Y,B} + x_{Y,C}$
$$
x_{X,Y} + 55 = x_{Y,X} + x_{Y,A} + x_{Y,B} + x_{Y,C}
$$
Or:
$$
x_{Y,X} + x_{Y,A} + x_{Y,B} + x_{Y,C} - x_{X,Y} = 55
$$

**Node A (Supply = 0, Demand = 35):**
Inflow: $x_{X,A} + x_{Y,A} + x_{B,A} + x_{C,A}$
Outflow: $x_{A,B} + x_{A,C}$
$$
x_{X,A} + x_{Y,A} + x_{B,A} + x_{C,A} = x_{A,B} + x_{A,C} + 35
$$
Or:
$$
x_{A,B} + x_{A,C} - x_{X,A} - x_{Y,A} - x_{B,A} - x_{C,A} = -35
$$

**Node B (Supply = 0, Demand = 40):**
Inflow: $x_{X,B} + x_{Y,B} + x_{A,B} + x_{C,B}$
Outflow: $x_{B,A} + x_{B,C}$
$$
x_{X,B} + x_{Y,B} + x_{A,B} + x_{C,B} = x_{B,A} + x_{B,C} + 40
$$
Or:
$$
x_{B,A} + x_{B,C} - x_{X,B} - x_{Y,B} - x_{A,B} - x_{C,B} = -40
$$

**Node C (Supply = 0, Demand = 50):**
Inflow: $x_{X,C} + x_{Y,C} + x_{A,C} + x_{B,C}$
Outflow: $x_{C,A} + x_{C,B}$
$$
x_{X,C} + x_{Y,C} + x_{A,C} + x_{B,C} = x_{C,A} + x_{C,B} + 50
$$
Or:
$$
x_{C,A} + x_{C,B} - x_{X,C} - x_{Y,C} - x_{A,C} - x_{B,C} = -50
$$

### 2. Non-negativity
$$
x_{ij} \ge 0 \quad \forall (i,j) \in E
$$

## Feasibility Sanity Check
- Total Supply (125) = Total Demand (125).
- The network is strongly connected enough to allow flow from X/Y to any A/B/C directly or via transshipment.
- No explicit capacity constraints on arcs are given, so only non-negativity applies.
- The system of linear equations has a solution (e.g., direct shipment only: $x_{X,A}=35, x_{X,B}=35, x_{Y,C}=50$ is a valid starting point, though likely not optimal).
