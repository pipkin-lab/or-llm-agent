# Model Type: MILP (Integer Linear Programming)

## Index Sets & Parameters

**Index Sets:**
- $W = \{1, 2, 3, 4\}$: set of warehouses, indexed by $w$
- $U = \{2, 3, 4\}$: set of allowable patrol unit assignments, indexed by $u$

**Parameters:**
- $P = 12$: total number of patrol units available
- $a_{w,u}$: expected number of accidents per year for warehouse $w$ when assigned $u$ patrol units (from Table 7-11):

| $a_{w,u}$ | $u=2$ | $u=3$ | $u=4$ |
|-----------|-------|-------|-------|
| $w=1$    | 18    | 16    | 12    |
| $w=2$    | 38    | 36    | 30    |
| $w=3$    | 14    | 12    | 11    |
| $w=4$    | 34    | 31    | 25    |

All parameters are explicitly provided in the problem statement.

## Decision Variables

For each warehouse $w \in W$ and each allowable assignment $u \in U$:

$$x_{w,u} \in \{0, 1\} \quad \forall w \in W, \; u \in U$$

where $x_{w,u} = 1$ if warehouse $w$ is assigned exactly $u$ patrol units, and $0$ otherwise.

## Objective Function

$$\min \sum_{w=1}^{4} \sum_{u \in \{2,3,4\}} a_{w,u} \, x_{w,u}$$

Expanded explicitly:
$$\min \; 18x_{1,2} + 16x_{1,3} + 12x_{1,4} + 38x_{2,2} + 36x_{2,3} + 30x_{2,4} + 14x_{3,2} + 12x_{3,3} + 11x_{3,4} + 34x_{4,2} + 31x_{4,3} + 25x_{4,4}$$

## Operational Constraints

**1. Each warehouse is assigned exactly one patrol-unit level:**
$$\sum_{u \in \{2,3,4\}} x_{w,u} = 1 \quad \forall w \in W$$

Explicitly:
- $x_{1,2} + x_{1,3} + x_{1,4} = 1$
- $x_{2,2} + x_{2,3} + x_{2,4} = 1$
- $x_{3,2} + x_{3,3} + x_{3,4} = 1$
- $x_{4,2} + x_{4,3} + x_{4,4} = 1$

**2. Total patrol units used equals the available supply:**
$$\sum_{w=1}^{4} \sum_{u \in \{2,3,4\}} u \cdot x_{w,u} = 12$$

Explicitly:
$$2(x_{1,2}+x_{2,2}+x_{3,2}+x_{4,2}) + 3(x_{1,3}+x_{2,3}+x_{3,3}+x_{4,3}) + 4(x_{1,4}+x_{2,4}+x_{3,4}+x_{4,4}) = 12$$

**3. Variable bounds (integrality):**
$$x_{w,u} \in \{0, 1\} \quad \forall w \in W, \; u \in \{2,3,4\}$$

## Feasibility Sanity Check

- Minimum total units: $4 \times 2 = 8$
- Maximum total units: $4 \times 4 = 16$
- Required total: $12$, which lies in $[8, 16]$. ✓
- The constraint $\sum u \cdot x = 12$ combined with per-warehouse exactly-one constraints means the sum of the four chosen $u$-values must equal 12. Valid combinations of four integers each in $\{2,3,4\}$ summing to 12 include: $\{2,2,4,4\}$, $\{2,3,3,4\}$, $\{3,3,3,3\}$. The model correctly captures all feasible assignments.

## Optimal Solution (Verification)

Evaluating the feasible combinations:
- **$\{3,3,3,3\}$**: $16+36+12+31 = 95$
- **$\{2,3,3,4\}$** permutations: best is $W1\!=\!4, W2\!=\!3, W3\!=\!3, W4\!=\!2$ → $12+36+12+34 = 94$
- **$\{2,2,4,4\}$** permutations: best is $W1\!=\!4, W2\!=\!4, W3\!=\!2, W4\!=\!2$ → $12+30+14+34 = 90$

**Optimal assignment: $W1=4, W2=4, W3=2, W4=2$ with minimum total expected accidents = 90.**
