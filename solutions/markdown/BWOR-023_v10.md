## Dynamic Programming Solution (as requested by the problem)

The problem asks to solve via Dynamic Programming. The Held-Karp DP for this 4-city TSP:

**State:** $f(i, S)$ = minimum cost of a path starting at city 1, visiting exactly the set $S \subseteq \{2,3,4\}$, and ending at city $i \in S$.

**Recurrence:**
$$f(i, S) = \min_{j \in S \setminus \{i\}} \bigl[ f(j, S \setminus \{i\}) + d(j, i) \bigr]$$

**Base case:** $f(i, \{i\}) = d(1, i)$ for $i \in \{2,3,4\}$.

**Final answer:**
$$\text{OPT} = \min_{i \in \{2,3,4\}} \bigl[ f(i, \{2,3,4\}) + d(i, 1) \bigr]$$
