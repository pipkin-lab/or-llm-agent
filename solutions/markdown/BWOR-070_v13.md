## 1. Problem Analysis

This is an **Unbounded Knapsack Problem** (a special case of Integer Linear Programming). We have 4 types of items, each with a specific weight, volume, and value. We want to maximize the total value subject to weight and volume capacity constraints. Since items are discrete physical units (you cannot load a fraction of a "good"), the decision variables must be integers.

**Data Extraction:**
*   **Item 1**: Weight = 2 t, Volume = 2 m³, Value = 3 thousand yuan
*   **Item 2**: Weight = 3 t, Volume = 2 m³, Value = 4 thousand yuan
*   **Item 3**: Weight = 4 t, Volume = 2 m³, Value = 5 thousand yuan
*   **Item 4**: Weight = 5 t, Volume = 3 m³, Value = 6 thousand yuan
*   **Constraints**: Max Weight = 15 t, Max Volume = 10 m³

**Objective:** Maximize Total Value.

## 2. Model Formulation

### Model Type
**MILP** (Mixed Integer Linear Programming) — specifically a pure Integer Linear Program (ILP) since all variables are integer.

### Index Sets & Parameters

*   **Index Set**: $i \in \{1, 2, 3, 4\}$ representing the 4 types of goods.
*   **Parameters** (from Table 7-9):
    *   $w_i$: Weight of item $i$ (tons)
        *   $w_1 = 2, w_2 = 3, w_3 = 4, w_4 = 5$
    *   $v_i$: Volume of item $i$ (m³)
        *   $v_1 = 2, v_2 = 2, v_3 = 2, v_4 = 3$
    *   $c_i$: Value of item $i$ (thousand yuan)
        *   $c_1 = 3, c_2 = 4, c_3 = 5, c_4 = 6$
*   **Capacity Limits**:
    *   $W_{max} = 15$ (tons)
    *   $V_{max} = 10$ (m³)

### Decision Variables

*   $x_i$: The number of units of item type $i$ to load onto the truck.
    *   **Domain**: $x_i \in \mathbb{Z}_{\ge 0}$ for $i = 1, 2, 3, 4$.

### Objective Function

Maximize the total value of the cargo:

$$
\text{Maximize } Z = 3x_1 + 4x_2 + 5x_3 + 6x_4
$$

### Operational Constraints

1.  **Weight Capacity Constraint**: The total weight of all loaded items must not exceed the truck's maximum weight capacity.
    $$
    2x_1 + 3x_2 + 4x_3 + 5x_4 \le 15
    $$

2.  **Volume Capacity Constraint**: The total volume of all loaded items must not exceed the truck's maximum volume capacity.
    $$
    2x_1 + 2x_2 + 2x_3 + 3x_4 \le 10
    $$

3.  **Non-negativity and Integrality**:
    $$
    x_i \in \mathbb{Z}_{\ge 0}, \quad \forall i \in \{1, 2, 3, 4\}
    $$

---

### Feasibility & Sanity Check

Let's verify if a feasible non-trivial solution exists.
*   Consider loading only Item 3 (highest value/weight ratio among heavy items? Let's check ratios).
    *   Value/Weight: $I_1: 1.5, I_2: 1.33, I_3: 1.25, I_4: 1.2$
    *   Value/Volume: $I_1: 1.5, I_2: 2.0, I_3: 2.5, I_4: 2.0$
*   Try a mix. Suppose we load 3 units of Item 3 and 1 unit of Item 1.
    *   Weight: $3(4) + 1(2) = 14 \le 15$
    *   Volume: $3(2) + 1(2) = 8 \le 10$
    *   Value: $3(5) + 1(3) = 18$
*   Try 5 units of Item 2.
    *   Weight: $5(3) = 15 \le 15$
    *   Volume: $5(2) = 10 \le 10$
    *   Value: $5(4) = 20$
*   Try 4 units of Item 2 and 1 unit of Item 1.
    *   Weight: $4(3) + 1(2) = 14 \le 15$
    *   Volume: $4(2) + 1(2) = 10 \le 10$
    *   Value: $4(4) + 1(3) = 19$
*   Try 2 units of Item 4 and 1 unit of Item 3.
    *   Weight: $2(5) + 1(4) = 14 \le 15$
    *   Volume: $2(3) + 1(2) = 8 \le 10$
    *   Value: $2(6) + 1(5) = 17$
*   Try 1 unit of Item 4, 2 units of Item 3, 1 unit of Item 1.
    *   Weight: $1(5) + 2(4) + 1(2) = 15 \le 15$
    *   Volume: $1(3) + 2(2) + 1(2) = 9 \le 10$
    *   Value: $1(6) + 2(5) + 1(3) = 19$
*   Try 3 units of Item 2, 1 unit of Item 4, 1 unit of Item 1.
    *   Weight: $3(3) + 1(5) + 1(2) = 16 > 15$ (Infeasible)

The model is feasible. The optimal solution will be found by the solver, but the formulation above strictly captures the problem requirements. The maximum value is expected to be around 20-22 thousand yuan.
