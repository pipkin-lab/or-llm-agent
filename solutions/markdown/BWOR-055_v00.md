# OR Problem Analysis: Hongdou Garment Factory Production Planning

## 1. Decision Variables

Let:
*   $x_1$: Number of Shirts produced per week
*   $x_2$: Number of T-shirts produced per week
*   $x_3$: Number of Casual Wear items produced per week

Let:
*   $y_1$: Binary variable where $y_1 = 1$ if Shirt production is active (equipment operated), $y_1 = 0$ otherwise
*   $y_2$: Binary variable where $y_2 = 1$ if T-shirt production is active (equipment operated), $y_2 = 0$ otherwise
*   $y_3$: Binary variable where $y_3 = 1$ if Casual Wear production is active (equipment operated), $y_3 = 0$ otherwise

**Variable Domains:**
*   $x_1, x_2, x_3 \geq 0$ (Continuous or Integer, depending on whether indivisibility is required; typically continuous in standard LP formulations unless specified)
*   $y_1, y_2, y_3 \in \{0, 1\}$

## 2. Objective Function

**Goal:** Maximize Total Weekly Profit

**Profit Calculation per Unit (Contribution Margin):**
*   Shirt: Selling Price - Variable Cost = $120 - 60 = 60$
*   T-shirt: Selling Price - Variable Cost = $80 - 40 = 40$
*   Casual Wear: Selling Price - Variable Cost = $180 - 80 = 100$

**Total Profit Function:**
$$ \text{Maximize } Z = 60x_1 + 40x_2 + 100x_3 - (2000y_1 + 1500y_2 + 1000y_3) $$

## 3. Operational Constraints

### A. Resource Constraints
The total resource usage cannot exceed weekly availability.

1.  **Labor Constraint:**
    $$ 3x_1 + 2x_2 + 6x_3 \leq 150 $$

2.  **Material Constraint:**
    $$ 4x_1 + 3x_2 + 6x_3 \leq 160 $$

### B. Logical Linking Constraints (Fixed Cost Activation)
Production of a product is only possible if its corresponding equipment is operated. This links the continuous production variables ($x$) to the binary operation variables ($y$). We use Big-M constraints where $M$ is a sufficiently large number representing the maximum possible production of each item (bounded by resources).

*   **Maximum Production Bounds (for Big-M):**
    *   Max Shirts ($M_1$): Limited by Labor ($150/3=50$) and Material ($160/4=40$) $\rightarrow M_1 = 40$
    *   Max T-shirts ($M_2$): Limited by Labor ($150/2=75$) and Material ($160/3 \approx 53.3$) $\rightarrow M_2 = 53$
    *   Max Casual Wear ($M_3$): Limited by Labor ($150/6=25$) and Material ($160/6 \approx 26.6$) $\rightarrow M_3 = 25$

*   **Linking Inequalities:**
    $$ x_1 \leq 40y_1 $$
    $$ x_2 \leq 53y_2 $$
    $$ x_3 \leq 25y_3 $$

    *(Note: If $y_i = 0$, then $x_i$ must be 0. If $y_i = 1$, $x_i$ can be up to its resource-limited maximum.)*

### C. Non-negativity and Integrality
*   $x_1, x_2, x_3 \geq 0$
*   $y_1, y_2, y_3 \in \{0, 1\}$
