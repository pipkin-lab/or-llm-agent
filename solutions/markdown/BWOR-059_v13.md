# Mathematical Optimization Model

## Model Type: MILP (Mixed-Integer Linear Program)

## Index Sets & Parameters

### Index Sets
- $P = \{1, 2, 3\}$: Set of automobile brands, where:
  - $p=1$: Zhujiang
  - $p=2$: Songhuajiang
  - $p=3$: Huanghe$

### Parameters (all values extracted from Table 5-13)
- $a_{steel,p}$: Steel required (tons) per unit of brand $p$:
  - $a_{steel,1} = 1.5$
  - $a_{steel,2} = 3.0$
  - $a_{steel,3} = 5.0$
- $a_{labor,p}$: Labor required (hours) per unit of brand $p$:
  - $a_{labor,1} = 300$
  - $a_{labor,2} = 250$
  - $a_{labor,3} = 400$
- $c_p$: Expected profit (Yuan) per unit of brand $p$:
  - $c_1 = 2000$
  - $c_2 = 3000$
  - $c_3 = 4000$
- $S_{steel}$: Monthly steel availability (tons) = 6000
- $S_{labor}$: Monthly labor availability (hours) = 600000
- $B = 1000$: Minimum economic production batch size (units)

## Decision Variables
- $x_p \geq 0$, CONTINUOUS: Number of units of brand $p$ produced per month, for each $p \in P$.
- $y_p \in \{0, 1\}$, BINARY: Indicator variable for each $p \in P$, where $y_p = 1$ if brand $p$ is produced, and $y_p = 0$ otherwise.

## Objective Function
$$ \text{Maximize } Z = \sum_{p=1}^{3} c_p \cdot x_p = 2000 x_1 + 3000 x_2 + 4000 x_3 $$

## Operational Constraints

### 1. Resource Constraints
- **Steel Constraint:**
  $$ 1.5 x_1 + 3.0 x_2 + 5.0 x_3 \leq 6000 $$
- **Labor Constraint:**
  $$ 300 x_1 + 250 x_2 + 400 x_3 \leq 600000 $$

### 2. Minimum Batch Size Constraints (Semi-Continuous Logic)
For each $p \in P$:
- **Linking Constraint** (if $y_p = 0$, then $x_p = 0$):
  $$ x_p \leq M \cdot y_p $$
  where $M$ is a sufficiently large upper bound on $x_p$. Based on the most restrictive resource, we can compute $M_p = \min\left(\frac{S_{steel}}{a_{steel,p}}, \frac{S_{labor}}{a_{labor,p}}\right)$:
  - $M_1 = \min(6000/1.5, 600000/300) = \min(4000, 2000) = 2000$
  - $M_2 = \min(6000/3.0, 600000/250) = \min(2000, 2400) = 2000$
  - $M_3 = \min(6000/5.0, 600000/400) = \min(1200, 1500) = 1200$
  
  Therefore:
  $$ x_1 \leq 2000 y_1 $$
  $$ x_2 \leq 2000 y_2 $$
  $$ x_3 \leq 1200 y_3 $$

- **Minimum Production Constraint** (if $y_p = 1$, then $x_p \geq 1000$):
  $$ x_p \geq 1000 \cdot y_p $$
  
  Therefore:
  $$ x_1 \geq 1000 y_1 $$
  $$ x_2 \geq 1000 y_2 $$
  $$ x_3 \geq 1000 y_3 $$

### 3. Non-negativity and Domain Bounds
- $x_p \geq 0$ for all $p \in P$ (implied by the minimum production constraint when $y_p=0$)
- $y_p \in \{0, 1\}$ for all $p \in P$
