## Objective Function

**MAXIMIZE** total annual profit (thousand yuan):

$$\max \; Z = \sum_{t=1}^{4} s_t \, z_t + \sum_{1 \leq i < j \leq 4} s_j \, y_{ij} - \sum_{t=1}^{4} p_t \, x_t - \sum_{1 \leq i < j \leq 4} (a + b \cdot u_{ij}) \, y_{ij}$$

Substituting all numeric values:

$$\max \; Z = 425 z_1 + 440 z_2 + 465 z_3 + 455 z_4$$
$$+ 440 y_{12} + 465 y_{13} + 455 y_{14} + 465 y_{23} + 455 y_{24} + 455 y_{34}$$
$$- 410 x_1 - 430 x_2 - 460 x_3 - 450 x_4$$
$$- 170 y_{12} - 270 y_{13} - 370 y_{14} - 170 y_{23} - 270 y_{24} - 170 y_{34}$$

**Consolidated coefficients** (net revenue per unit of each flow):

| Variable | Net coefficient | Derivation |
|----------|----------------|------------|
| $z_1$ | $425 - 410 = 15$ | Sell Winter in Winter |
| $z_2$ | $440 - 430 = 10$ | Sell Spring in Spring |
| $z_3$ | $465 - 460 = 5$ | Sell Summer in Summer |
| $z_4$ | $455 - 450 = 5$ | Sell Autumn in Autumn |
| $y_{12}$ | $440 - 410 - 170 = -140$ | Buy Winter, sell Spring |
| $y_{13}$ | $465 - 410 - 270 = -215$ | Buy Winter, sell Summer |
| $y_{14}$ | $455 - 410 - 370 = -325$ | Buy Winter, sell Autumn |
| $y_{23}$ | $465 - 430 - 170 = -135$ | Buy Spring, sell Summer |
| $y_{24}$ | $455 - 430 - 270 = -245$ | Buy Spring, sell Autumn |
| $y_{34}$ | $455 - 460 - 170 = -175$ | Buy Summer, sell Autumn |

So the simplified objective is:

$$\max \; Z = 15 z_1 + 10 z_2 + 5 z_3 + 5 z_4 - 140 y_{12} - 215 y_{13} - 325 y_{14} - 135 y_{23} - 245 y_{24} - 175 y_{34}$$

**Key observation**: All cross-quarter flows have **negative** net profit. The optimal solution will set all $y_{ij} = 0$, meaning all timber is bought and sold within the same quarter. The problem reduces to buying and selling within each quarter up to demand limits, subject to warehouse capacity.

## Operational Constraints

### 1. Purchase-Flow Balance (per quarter)
Total purchased in quarter $t$ equals total sold from that quarter's purchase (same-quarter sale + stored for later quarters):

$$x_t = z_t + \sum_{j=t+1}^{4} y_{tj}, \quad t = 1, 2, 3, 4$$

Explicitly:
- $x_1 = z_1 + y_{12} + y_{13} + y_{14}$
- $x_2 = z_2 + y_{23} + y_{24}$
- $x_3 = z_3 + y_{34}$
- $x_4 = z_4$

### 2. Sales Volume Constraints (per quarter)
Total sold in quarter $t$ (from current-quarter purchase + stored from earlier quarters) cannot exceed the maximum sales volume:

$$z_t + \sum_{i=1}^{t-1} y_{it} \leq D_t, \quad t = 1, 2, 3, 4$$

Explicitly:
- $z_1 \leq 100$
- $z_2 + y_{12} \leq 140$
- $z_3 + y_{13} + y_{23} \leq 200$
- $z_4 + y_{14} + y_{24} + y_{34} \leq 160$

### 3. Warehouse Capacity Constraints (per quarter)
Ending inventory at end of quarter $t$ must not exceed the warehouse capacity of 20 thousand m³.

**Inventory recursion** (end-of-quarter $t$ inventory = beginning inventory + purchases − sales in quarter $t$):

$$I_0 = 0$$
$$I_t = I_{t-1} + x_t - \left(z_t + \sum_{i=1}^{t-1} y_{it}\right), \quad t = 1, 2, 3, 4$$

With $I_0 = 0$:

- $I_1 = x_1 - z_1 = y_{12} + y_{13} + y_{14}$
- $I_2 = I_1 + x_2 - (z_2 + y_{12}) = y_{13} + y_{14} + y_{23} + y_{24}$
- $I_3 = I_2 + x_3 - (z_3 + y_{13} + y_{23}) = y_{14} + y_{24} + y_{34}$
- $I_4 = I_3 + x_4 - (z_4 + y_{14} + y_{24} + y_{34}) = 0$

**Capacity constraints**:
$$I_t \leq 20, \quad t = 1, 2, 3, 4$$

Explicitly:
- $y_{12} + y_{13} + y_{14} \leq 20$
- $y_{13} + y_{14} + y_{23} + y_{24} \leq 20$
- $y_{14} + y_{24} + y_{34} \leq 20$
- $0 \leq 20$ (trivially satisfied)

### 4. "Must Sell by End of Autumn" Constraint
All stored timber must be sold by the end of autumn (quarter 4). This is automatically enforced by the model structure: $I_4 = 0$ is an identity (no storage beyond autumn), and there are no $y_{4j}$ variables for $j > 4$. ✓

### 5. Non-Negativity Bounds
$$x_t \geq 0, \quad z_t \geq 0, \quad y_{ij} \geq 0, \quad I_t \geq 0, \quad \forall \text{ applicable indices}$$

## Feasibility Sanity Check

- **Total maximum demand**: $100 + 140 + 200 + 160 = 600$ thousand m³
- **Warehouse capacity**: 20 thousand m³ (only limits cross-quarter storage, not same-quarter buy-sell)
- Since all cross-quarter flows have negative profit, the optimal solution sets $y_{ij} = 0$ for all $i < j$, and $I_t = 0$ for all $t$.
- The problem reduces to: $z_t = D_t$ for each $t$ (sell up to max demand), with $x_t = z_t$.
- **Optimal objective** (greedy): $15(100) + 10(140) + 5(200) + 5(160) = 1500 + 1400 + 1000 + 800 = 4700$ thousand yuan.
- This is well within warehouse capacity (zero inventory), so the solution is feasible. ✓

The expected answer is in the thousands of thousand-yuan range (i.e., millions of yuan), which is consistent with a company buying and selling hundreds of thousand m³ of timber at prices around 400+ thousand yuan per thousand m³. The objective value of ~4700 thousand yuan is reasonable. ✓
