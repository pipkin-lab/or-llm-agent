# Operations Research Model: Hanguang Automobile Production Plan

## 1. Decision Variables

The problem involves a production decision with a fixed-charge logic (produce either 0 or at least 1,000 units). This requires a mixed-integer formulation.

Let:
*   $x_1$: Number of **Zhujiang** automobiles produced per month.
*   $x_2$: Number of **Songhuajiang** automobiles produced per month.
*   $x_3$: Number of **Huanghe** automobiles produced per month.

Let:
*   $y_1, y_2, y_3 \in \{0, 1\}$: Binary indicator variables.
    *   $y_i = 1$ if brand $i$ is produced ($x_i \ge 1000$).
    *   $y_i = 0$ if brand $i$ is not produced ($x_i = 0$).

## 2. Objective Function

**Maximize** the total expected monthly profit.

$$ \text{Maximize } Z = 2000x_1 + 3000x_2 + 4000x_3 $$

## 3. Operational Constraints

### A. Resource Constraints
The total consumption of steel and labor must not exceed the monthly availability.

1.  **Steel Constraint:**
    $$ 1.5x_1 + 3.0x_2 + 5.0x_3 \le 6000 $$

2.  **Labor Constraint:**
    $$ 300x_1 + 250x_2 + 400x_3 \le 600,000 $$

### B. Production Batch Size Constraints (Fixed-Charge Logic)
The problem states that if a brand is produced, the quantity must be at least 1,000. If not produced, it is 0. We use the binary variables $y_i$ to link the continuous/integer production variables $x_i$ to this logic.

Let $M$ be a sufficiently large upper bound for $x_i$. Based on the steel constraint alone, the maximum possible production for any single car is limited by $6000 / \text{min steel usage}$.
*   Max possible $x_1 \approx 6000 / 1.5 = 4000$
*   Max possible $x_2 \approx 6000 / 3.0 = 2000$
*   Max possible $x_3 \approx 6000 / 5.0 = 1200$

We can set specific upper bounds $M_i$ for tighter formulation, or use a common $M$ (e.g., $M=4000$). Here we use specific logical bounds derived from resources for precision, or simply $M=4000$ for all for simplicity in standard form.

1.  **Linking $x_1$ and $y_1$:**
    *   If $y_1 = 0 \implies x_1 = 0$
    *   If $y_1 = 1 \implies x_1 \ge 1000$
    *   Constraint:
        $$ 1000y_1 \le x_1 \le 4000y_1 $$
        *(Note: $4000$ is an upper bound derived from steel: $6000/1.5$)*

2.  **Linking $x_2$ and $y_2$:**
    *   Constraint:
        $$ 1000y_2 \le x_2 \le 2000y_2 $$
        *(Note: $2000$ is an upper bound derived from steel: $6000/3.0$)*

3.  **Linking $x_3$ and $y_3$:**
    *   Constraint:
        $$ 1000y_3 \le x_3 \le 1200y_3 $$
        *(Note: $1200$ is an upper bound derived from steel: $6000/5.0$)*

### C. Non-negativity and Integrality
*   $x_1, x_2, x_3 \ge 0$ and integer (since cars are discrete units).
*   $y_1, y_2, y_3 \in \{0, 1\}$.
