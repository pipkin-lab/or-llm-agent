## Model Type: MILP (Project Scheduling / CPM Formulation)

**Problem Identification:** This is a classic **Critical Path Method (CPM)** project scheduling problem. The goal is to find the minimum time to complete all tasks subject to precedence constraints.

**Objective Identification Gate:** The problem asks for the "shortest possible duration... from start to full completion." This is a **MINIMIZATION** of the project makespan (completion time of the last task).

---

### 1. Index Sets & Parameters

**Sets:**
*   $T = \{a, b, c, d, e, f, g, h, i, j, k, L, m, n\}$: The set of all tasks.
*   $P(t)$: The set of predecessor tasks for task $t$.

**Parameters (Duration in days):**
*   $D_a = 10$
*   $D_b = 8$
*   $D_c = 6$
*   $D_d = 16$
*   $D_e = 24$
*   $D_f = 4$
*   $D_g = 4$
*   $D_h = 10$
*   $D_i = 4$
*   $D_j = 12$
*   $D_k = 16$
*   $D_L = 8$
*   $D_m = 24$
*   $D_n = 4$

**Precedence Relationships:**
*   $P(a) = \emptyset$
*   $P(b) = \emptyset$
*   $P(c) = \{a, b\}$
*   $P(d) = \{b\}$
*   $P(e) = \{c\}$
*   $P(f) = \{d, e\}$
*   $P(g) = \{f\}$
*   $P(h) = \{f\}$
*   $P(i) = \{f\}$
*   $P(j) = \{g\}$
*   $P(k) = \{h, i, j\}$
*   $P(L) = \{c\}$
*   $P(m) = \{L\}$
*   $P(n) = \{k, m\}$

---

### 2. Decision Variables

Let $S_t$ be the **start time** of task $t$ (measured in days from the project start, where $S_t \ge 0$).

*   $S_t \in \mathbb{R}_{\ge 0}$ for all $t \in T$.
    *(Note: While durations are integers, start times can be continuous in a standard LP relaxation of CPM. However, since all durations are integers and precedence constraints are linear, the optimal solution will yield integer start times. We declare them as continuous variables for a standard LP formulation, which is sufficient for CPM.)*

Let $Z$ be the **project completion time** (makespan).
*   $Z \in \mathbb{R}_{\ge 0}$.

---

### 3. Objective Function

Minimize the total project duration:
$$ \text{Minimize } Z $$

---

### 4. Operational Constraints

**A. Precedence Constraints:**
For every task $t \in T$ and for every predecessor $p \in P(t)$, task $t$ cannot start before task $p$ is completed.
$$ S_t \ge S_p + D_p \quad \forall t \in T, \forall p \in P(t) $$

Explicitly:
1.  $S_c \ge S_a + 10$
2.  $S_c \ge S_b + 8$
3.  $S_d \ge S_b + 8$
4.  $S_e \ge S_c + 6$
5.  $S_f \ge S_d + 16$
6.  $S_f \ge S_e + 24$
7.  $S_g \ge S_f + 4$
8.  $S_h \ge S_f + 4$
9.  $S_i \ge S_f + 4$
10. $S_j \ge S_g + 4$
11. $S_k \ge S_h + 10$
12. $S_k \ge S_i + 4$
13. $S_k \ge S_j + 12$
14. $S_L \ge S_c + 6$
15. $S_m \ge S_L + 8$
16. $S_n \ge S_k + 16$
17. $S_n \ge S_m + 24$

**B. Project Completion Definition:**
The project completion time $Z$ must be at least the finish time of every task. Since task $n$ (Site cleanup and final inspection) is the only task with no successors (it is the unique terminal node in the graph, as it depends on $k$ and $m$, and no other task depends on $n$), $Z$ is simply the finish time of $n$. However, to be rigorous for any terminal set:
$$ Z \ge S_t + D_t \quad \forall t \in \{t \in T \mid \text{no successors}\} $$

In this specific network, $n$ is the only terminal node.
$$ Z \ge S_n + 4 $$

*(Verification: Are there other terminal nodes? $k$ is a predecessor to $n$. $m$ is a predecessor to $n$. $g, h, i, j, L$ have successors. $a, b, c, d, e, f$ have successors. Yes, $n$ is the unique sink.)*

**C. Non-negativity:**
$$ S_t \ge 0 \quad \forall t \in T $$
$$ Z \ge 0 $$

---

### Feasibility & Critical Path Analysis (Sanity Check)

To verify the model captures the correct minimum duration, let's trace the longest path (Critical Path) manually:

1.  **Path 1:** $a \to c \to e \to f \to g \to j \to k \to n$
    *   $a$: 10
    *   $c$: 6 (Starts at 10, since $b$ takes 8 and $a$ takes 10, $c$ starts at max(10,8)=10. Finish $c$ at 16.)
    *   $e$: 24 (Starts at 16. Finish $e$ at 40.)
    *   $f$: 4 (Predecessors $d, e$. $d$ starts at 8 (after $b$), finishes at 8+16=24. $e$ finishes at 40. So $f$ starts at max(24, 40) = 40. Finish $f$ at 44.)
    *   $g$: 4 (Starts at 44. Finish $g$ at 48.)
    *   $j$: 12 (Starts at 48. Finish $j$ at 60.)
    *   $k$: 16 (Predecessors $h, i, j$.
        *   $h$ starts at 44, finishes at 54.
        *   $i$ starts at 44, finishes at 48.
        *   $j$ finishes at 60.
        *   So $k$ starts at max(54, 48, 60) = 60. Finish $k$ at 76.)
    *   $n$: 4 (Predecessors $k, m$.
        *   $k$ finishes at 76.
        *   $m$: $L$ starts after $c$ (finishes 16). $L$ takes 8, finishes 24. $m$ starts 24, takes 24, finishes 48.
        *   So $n$ starts at max(76, 48) = 76. Finish $n$ at 80.)

2.  **Check Alternative Paths:**
    *   Path via $d$: $b \to d \to f \dots$ $b$ finishes 8, $d$ finishes 24. $f$ is constrained by $e$ (finishes 40) anyway. So this path is not critical.
    *   Path via $L, m$: $c \to L \to m \to n$. $c$ finishes 16, $L$ finishes 24, $m$ finishes 48. $n$ waits for $k$ (76). So this is not critical.
    *   Path via $h$ or $i$: $f$ finishes 44. $h$ finishes 54, $i$ finishes 48. $k$ waits for $j$ (60). So these are not critical.

The critical path is $a \to c \to e \to f \to g \to j \to k \to n$.
Total Duration = $10 + 6 + 24 + 4 + 4 + 12 + 16 + 4 = 80$ days.

The model will yield $Z = 80$.

### Final Answer Formulation Summary

*   **Model Type:** LP (Linear Program)
*   **Objective:** Minimize $Z$
*   **Key Constraint:** $Z \ge S_n + 4$
*   **Expected Optimal Value:** 80 days
