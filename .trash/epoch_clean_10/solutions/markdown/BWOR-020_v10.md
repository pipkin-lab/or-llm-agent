To formulate this problem, we must determine which trucks are used to satisfy the specific delivery requirements of the customers while respecting truck capacities and incompatibility constraints.

### 1. Index Sets & Parameters

**Sets:**
*   $K = \{A, B, C, D, E\}$: Set of customers.
*   $J = \{1, 2, 3, 4\}$: Set of trucks.

**Parameters:**
*   $D_k$: Demand (units) for customer $k$.
    *   $D_A = 1$
    *   $D_B = 2$
    *   $D_C = 3$
    *   $D_D = 4$
    *   $D_E = 8$
*   $C_j$: Capacity of truck $j$.
    *   $C_1 = 2$
    *   $C_2 = 6$
    *   $C_3 = 8$
    *   $C_4 = 11$
*   $c_j$: Cost of using truck $j$.
    *   $c_1, c_2, c_3, c_4$ are given cost parameters.

### 2. Decision Variables

Since the problem asks to assign deliveries to trucks and trucks have fixed costs for being used, we define binary variables to indicate assignment. However, a standard assignment where a truck serves *one* customer is not explicitly stated; rather, a truck can potentially serve multiple customers as long as capacity is respected.

Let $x_{k,j}$ be a binary variable:
$$
x_{k,j} = \begin{cases} 
1 & \text{if truck } j \text{ is assigned to deliver to customer } k \\
0 & \text{otherwise}
\end{cases}
$$

*Note on Objective Function:* The problem states "The cost of using truck $j$ is $c_j$". This implies a fixed charge for using a truck. If a truck is assigned to at least one customer, the cost $c_j$ is incurred. To model this linearly, we can use the variable $y_j$ which indicates if truck $j$ is used at all. However, since $x_{k,j}$ exists for all $k$, we can link them. Alternatively, if the cost is strictly per truck usage (fixed cost), we need a variable $y_j$. But wait, if a truck is used, it costs $c_j$. If it's not used, it costs 0.
Let $y_j$ be a binary variable:
$$
y_j = \begin{cases} 
1 & \text{if truck } j \text{ is used (assigned to at least one customer)} \\
0 & \text{otherwise}
\end{cases}
$$

Linking constraint: If any $x_{k,j}=1$, then $y_j=1$.
$$ y_j \ge x_{k,j} \quad \forall k \in K, j \in J $$

**Objective:** Minimize Total Cost
$$ \min Z = \sum_{j \in J} c_j y_j $$

### 3. Operational Constraints

**1. Customer Demand Satisfaction:**
Each customer must be served by exactly one truck.
$$ \sum_{j \in J} x_{k,j} = 1 \quad \forall k \in K $$

**2. Truck Capacity Constraints:**
The total demand of customers assigned to a truck cannot exceed its capacity.
$$ \sum_{k \in K} D_k x_{k,j} \le C_j y_j \quad \forall j \in J $$
*(Note: Using $C_j y_j$ ensures that if $y_j=0$, the RHS is 0, forcing all $x_{k,j}=0$. If $y_j=1$, the capacity limit $C_j$ applies. This is a standard big-M formulation where M is the capacity.)*

**3. Incompatibility Constraints:**
*   A truck cannot deliver to both Customer A and Customer C.
    $$ x_{A,j} + x_{C,j} \le 1 \quad \forall j \in J $$
*   A truck cannot deliver to both Customer B and Customer D.
    $$ x_{B,j} + x_{D,j} \le 1 \quad \forall j \in J $$

**4. Variable Domains:**
$$ x_{k,j} \in \{0, 1\} \quad \forall k \in K, j \in J $$
$$ y_j \in \{0, 1\} \quad \forall j \in J $$

---

### Refinement & Simplification Check

Is the $y_j$ variable strictly necessary?
If we minimize $\sum c_j y_j$, and we have the constraint $y_j \ge x_{k,j}$, the solver will set $y_j=1$ if and only if any $x_{k,j}=1$ (since $c_j > 0$, we want $y_j$ as small as possible). So yes, $y_j$ is required to correctly charge the fixed cost $c_j$ only when the truck is active.

However, there is a subtlety: "each used only once". This is already handled by the binary nature of $x_{k,j}$ and $y_j$. A truck is either used (for a set of customers) or not.

Let's double check the "Set Covering" aspect mentioned in the title. Usually, set covering implies we choose subsets of items to cover. Here, each "set" is a truck's assignment. The structure above is a standard **Capacitated Facility Location / Assignment** hybrid, which fits the "Set Covering" label in the context of covering all customer demands with available truck resources.

### Final Model Structure

**Index Sets:**
*   $K = \{A, B, C, D, E\}$
*   $J = \{1, 2, 3, 4\}$

**Parameters:**
*   $D_A=1, D_B=2, D_C=3, D_D=4, D_E=8$
*   $C_1=2, C_2=6, C_3=8, C_4=11$
*   $c_1, c_2, c_3, c_4$ (Given costs)

**Decision Variables:**
*   $x_{k,j} \in \{0,1\}$: 1 if truck $j$ serves customer $k$, 0 otherwise.
*   $y_j \in \{0,1\}$: 1 if truck $j$ is used, 0 otherwise.

**Objective Function:**
$$ \min Z = \sum_{j=1}^{4} c_j y_j $$

**Constraints:**

1.  **Assignment (Each customer served exactly once):**
    $$ \sum_{j=1}^{4} x_{k,j} = 1 \quad \forall k \in \{A, B, C, D, E\} $$

2.  **Capacity (Demand assigned to truck $j$ must not exceed capacity if used):**
    $$ \sum_{k \in K} D_k x_{k,j} \le C_j y_j \quad \forall j \in \{1, 2, 3, 4\} $$
    *Explicitly:*
    *   $1 x_{A,1} + 2 x_{B,1} + 3 x_{C,1} + 4 x_{D,1} + 8 x_{E,1} \le 2 y_1$
    *   $1 x_{A,2} + 2 x_{B,2} + 3 x_{C,2} + 4 x_{D,2} + 8 x_{E,2} \le 6 y_2$
    *   $1 x_{A,3} + 2 x_{B,3} + 3 x_{C,3} + 4 x_{D,3} + 8 x_{E,3} \le 8 y_3$
    *   $1 x_{A,4} + 2 x_{B,4} + 3 x_{C,4} + 4 x_{D,4} + 8 x_{E,4} \le 11 y_4$

3.  **Linking (If truck used, it must serve at least one customer - implied by minimization of cost with positive $c_j$ and $y_j \ge x_{k,j}$, but explicit logical constraint is standard):**
    $$ y_j \ge x_{k,j} \quad \forall k \in K, j \in J $$
    *(Note: $y_j \le \sum x_{k,j}$ is not strictly necessary for correctness of the optimal solution if costs are positive, as the solver will set $y_j=0$ if all $x_{k,j}=0$. However, $y_j \ge x_{k,j}$ is crucial to activate the capacity constraint and cost.)*

4.  **Incompatibility (A and C cannot be on same truck):**
    $$ x_{A,j} + x_{C,j} \le 1 \quad \forall j \in J $$

5.  **Incompatibility (B and D cannot be on same truck):**
    $$ x_{B,j} + x_{D,j} \le 1 \quad \forall j \in J $$

6.  **Domain:**
    $$ x_{k,j} \in \{0, 1\}, \quad y_j \in \{0, 1\} $$
