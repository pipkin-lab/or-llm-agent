### 1. Index Sets & Parameters

**Index Sets:**
*   $V = \{1, 2, 3, 4, 5, 6, 7, 8\}$: Set of oil wells.
*   $A = \{(i, j) \mid i, j \in V, i \neq j\}$: Set of all possible directed arcs between wells.

**Parameters:**
*   $d_{ij}$: Distance (in miles) from well $i$ to well $j$. The distance is symmetric, i.e., $d_{ij} = d_{ji}$. The values are derived from Table 8-4:
    *   $d_{12}=1.3, d_{13}=2.1, d_{14}=0.9, d_{15}=0.7, d_{16}=1.8, d_{17}=2.0, d_{18}=1.5$
    *   $d_{23}=0.9, d_{24}=1.8, d_{25}=1.2, d_{26}=2.6, d_{27}=2.3, d_{28}=1.1$
    *   $d_{34}=2.6, d_{35}=1.7, d_{36}=2.5, d_{37}=1.9, d_{38}=1.0$
    *   $d_{45}=0.7, d_{46}=1.6, d_{47}=1.5, d_{48}=0.9$
    *   $d_{56}=0.9, d_{57}=1.1, d_{58}=0.8$
    *   $d_{67}=0.6, d_{68}=1.0$
    *   $d_{78}=0.5$
*   $d_{01} = 5$: Distance from the coast (node 0) to Well 1.
*   $N = |V| = 8$: Number of wells.

### 2. Decision Variables

*   $x_{ij} \in \{0, 1\}$: Binary variable for all $(i, j) \in A$.
    *   $x_{ij} = 1$ if a pipeline segment is built from well $i$ to well $j$.
    *   $x_{ij} = 0$ otherwise.
*   $u_i \in \mathbb{R}$: Continuous auxiliary variable for all $i \in V \setminus \{1\}$ (nodes 2 through 8).
    *   These variables are used in the MTZ (Miller-Tucker-Zemlin) constraints to eliminate subtours.

### 3. Objective Function

Minimize the total length of the pipelines. Note that the pipeline from the coast to Well 1 is fixed at 5 miles. Since this is a constant, it can be added to the objective or ignored for optimization purposes, but typically in such problems, we minimize the variable cost part. However, to be precise about "total pipeline length", we include the constant.

$$ \text{Minimize } Z = 5 + \sum_{i \in V} \sum_{j \in V, j \neq i} d_{ij} x_{ij} $$

*Note: Since the graph is undirected but we model it with directed arcs, and we will enforce a tree structure rooted at 1, each undirected edge $\{i,j\}$ will be selected exactly once in the optimal solution as either $x_{ij}=1$ or $x_{ji}=1$ (or both if we don't constrain symmetry, but MTZ/tree logic usually handles directionality). To ensure we don't double count costs in an undirected context, standard MST formulations on directed arcs usually sum over all directed pairs. However, since $x_{ij}$ and $x_{ji}$ are distinct, and the tree structure implies a direction away from the root, exactly one of $x_{ij}$ or $x_{ji}$ will be 1 for any connected pair in the final tree. Thus, summing over all directed pairs is correct.*

### 4. Operational Constraints

**1. Flow Conservation / Tree Structure Constraints:**
The network must form a spanning tree rooted at Well 1. This means:
*   Well 1 (the root) has no incoming flow (it is the source).
*   Every other well $j \in V \setminus \{1\}$ has exactly one incoming connection (one parent).

$$ \sum_{i \in V, i \neq j} x_{ij} = 0 \quad \forall j = 1 $$
$$ \sum_{i \in V, i \neq j} x_{ij} = 1 \quad \forall j \in \{2, 3, 4, 5, 6, 7, 8\} $$

**2. Subtour Elimination Constraints (MTZ):**
To ensure the resulting graph is a single connected tree and not a collection of disjoint cycles (subtours), we use the Miller-Tucker-Zemlin formulation.
For all $i, j \in \{2, 3, 4, 5, 6, 7, 8\}$ with $i \neq j$:

$$ u_i - u_j + N \cdot x_{ij} \leq N - 1 $$

**3. Variable Bounds:**
*   $x_{ij} \in \{0, 1\} \quad \forall (i, j) \in A$
*   $0 \leq u_i \leq N - 1 \quad \forall i \in \{2, 3, 4, 5, 6, 7, 8\}$
*   $u_1$ is not a variable; it is implicitly 0 in the context of the MTZ constraints relative to the root (or simply excluded from the set where $u$ is defined, and the constraints only apply to non-root nodes). The standard MTZ formulation for a root $r$ fixes $u_r = 0$ and applies constraints for $i,j \neq r$.

### Model Verification & Notes
*   **Problem Type**: This is a Minimum Spanning Tree (MST) problem rooted at node 1.
*   **Integrality**: The $x_{ij}$ variables are binary. The $u_i$ variables are continuous.
*   **Correctness**: The constraint $\sum_{i \neq j} x_{ij} = 1$ for $j \neq 1$ ensures every node has exactly one parent. The MTZ constraints ensure that the "rank" or "depth" of nodes increases along the path from the root, preventing cycles that do not include the root.
*   **Scale**: With $N=8$, the MTZ formulation is computationally trivial and exact. No LP relaxation is needed as the integrality gap for MST with these constraints is typically zero or the problem size is small enough for exact MILP solvers to find the integer solution immediately.
