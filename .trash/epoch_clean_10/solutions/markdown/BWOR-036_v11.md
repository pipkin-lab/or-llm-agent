# Linear Programming Model for Timber Storage and Transportation

## 1. Index Sets & Parameters

**Index Sets:**
- $T = \{1, 2, 3, 4\}$: Set of quarters in the year.
  - $t=1$: Winter
  - $t=2$: Spring
  - $t=3$: Summer
  - $t=4$: Autumn

**Parameters (from Table 1-18 and problem description):**
- $P_t$: Purchase price in quarter $t$ (thousand yuan per thousand $m^3$)
  - $P_1 = 410, P_2 = 430, P_3 = 460, P_4 = 450$
- $S_t$: Selling price in quarter $t$ (thousand yuan per thousand $m^3$)
  - $S_1 = 425, S_2 = 440, S_3 = 465, S_4 = 455$
- $D_t$: Estimated maximum sales volume in quarter $t$ (thousand $m^3$)
  - $D_1 = 100, D_2 = 140, D_3 = 200, D_4 = 160$
- $C_{max}$: Maximum warehouse storage capacity = 20 (thousand $m^3$)
- $a = 70$, $b = 100$: Parameters for storage cost.
- Storage cost rate for timber stored for $u$ quarters: $h_u = a + b \cdot u$ (yuan per $m^3$).
  - Note on Units: Prices are in **thousand yuan** per **thousand $m^3$**. This is equivalent to **yuan per $m^3$**.
    - Example: 410 thousand yuan / 1000 $m^3$ = 410 yuan / $m^3$.
    - Storage cost is given as $(a+bu)$ **yuan** per $m^3$.
    - Therefore, the units are consistent. We will work in **thousand yuan** and **thousand $m^3$**.
    - Storage cost in **thousand yuan** per **thousand $m^3$** for $u$ quarters is:
      - If stored for 1 quarter ($u=1$): $70 + 100(1) = 170$ yuan/$m^3$ = 170 thousand yuan / thousand $m^3$.
      - If stored for 2 quarters ($u=2$): $70 + 100(2) = 270$ yuan/$m^3$ = 270 thousand yuan / thousand $m^3$.
      - If stored for 3 quarters ($u=3$): $70 + 100(3) = 370$ yuan/$m^3$ = 370 thousand yuan / thousand $m^3$.

## 2. Decision Variables

Let $x_{t, k}$ be the quantity of timber (in thousand $m^3$) **purchased** in quarter $t$ and **sold** in quarter $k$, where $k \ge t$.
- $x_{t, k} \ge 0$ for all $t, k \in T$ with $k \ge t$.
- Since all stored timber must be sold by the end of autumn ($t=4$), the maximum storage duration is 3 quarters (bought in Winter, sold in Autumn).
- Possible variables:
  - Bought in Winter ($t=1$): $x_{1,1}$ (sold Winter), $x_{1,2}$ (sold Spring), $x_{1,3}$ (sold Summer), $x_{1,4}$ (sold Autumn).
  - Bought in Spring ($t=2$): $x_{2,2}$ (sold Spring), $x_{2,3}$ (sold Summer), $x_{2,4}$ (sold Autumn).
  - Bought in Summer ($t=3$): $x_{3,3}$ (sold Summer), $x_{3,4}$ (sold Autumn).
  - Bought in Autumn ($t=4$): $x_{4,4}$ (sold Autumn).

Alternatively, we can define variables based on inventory flow, but the "purchase-sale pair" definition $x_{t,k}$ makes the storage cost calculation direct and linear.

## 3. Objective Function

Maximize Total Annual Profit (in thousand yuan).

Profit for each unit sold = Selling Price - Purchase Price - Storage Cost.

- **Winter purchases ($t=1$):**
  - $x_{1,1}$: Sold in Winter. Storage time $u=0$ (or negligible, as it's bought and sold in the same quarter). Cost = $P_1$. Revenue = $S_1$. Profit = $S_1 - P_1 = 425 - 410 = 15$.
  - $x_{1,2}$: Sold in Spring. Storage time $u=1$. Storage Cost = $70 + 100(1) = 170$. Profit = $S_2 - P_1 - 170 = 440 - 410 - 170 = -140$.
  - $x_{1,3}$: Sold in Summer. Storage time $u=2$. Storage Cost = $70 + 100(2) = 270$. Profit = $S_3 - P_1 - 270 = 465 - 410 - 270 = -215$.
  - $x_{1,4}$: Sold in Autumn. Storage time $u=3$. Storage Cost = $70 + 100(3) = 370$. Profit = $S_4 - P_1 - 370 = 455 - 410 - 370 = -325$.

- **Spring purchases ($t=2$):**
  - $x_{2,2}$: Sold in Spring. $u=0$. Profit = $S_2 - P_2 = 440 - 430 = 10$.
  - $x_{2,3}$: Sold in Summer. $u=1$. Storage Cost = 170. Profit = $S_3 - P_2 - 170 = 465 - 430 - 170 = -135$.
  - $x_{2,4}$: Sold in Autumn. $u=2$. Storage Cost = 270. Profit = $S_4 - P_2 - 270 = 455 - 430 - 270 = -245$.

- **Summer purchases ($t=3$):**
  - $x_{3,3}$: Sold in Summer. $u=0$. Profit = $S_3 - P_3 = 465 - 460 = 5$.
  - $x_{3,4}$: Sold in Autumn. $u=1$. Storage Cost = 170. Profit = $S_4 - P_3 - 170 = 455 - 460 - 170 = -175$.

- **Autumn purchases ($t=4$):**
  - $x_{4,4}$: Sold in Autumn. $u=0$. Profit = $S_4 - P_4 = 455 - 450 = 5$.

**Objective Function:**
$$ \text{Maximize } Z = 15 x_{1,1} - 140 x_{1,2} - 215 x_{1,3} - 325 x_{1,4} + 10 x_{2,2} - 135 x_{2,3} - 245 x_{2,4} + 5 x_{3,3} - 175 x_{3,4} + 5 x_{4,4} $$

## 4. Operational Constraints

**1. Sales Demand Constraints:**
The total quantity sold in each quarter $k$ cannot exceed the estimated maximum sales volume $D_k$.
- Quarter 1 (Winter): $x_{1,1} \le 100$
- Quarter 2 (Spring): $x_{1,2} + x_{2,2} \le 140$
- Quarter 3 (Summer): $x_{1,3} + x_{2,3} + x_{3,3} \le 200$
- Quarter 4 (Autumn): $x_{1,4} + x_{2,4} + x_{3,4} + x_{4,4} \le 160$

**2. Warehouse Capacity Constraints:**
The total quantity of timber stored in the warehouse at the end of each quarter must not exceed the maximum capacity $C_{max} = 20$.
The timber stored at the end of quarter $t$ is the sum of all timber purchased in quarter $t$ that is sold in future quarters ($k > t$).

- End of Winter (after sales in Q1, before sales in Q2):
  Stored timber = $x_{1,2} + x_{1,3} + x_{1,4}$
  Constraint: $x_{1,2} + x_{1,3} + x_{1,4} \le 20$

- End of Spring (after sales in Q2, before sales in Q3):
  Stored timber = $x_{1,3} + x_{1,4} + x_{2,3} + x_{2,4}$
  Constraint: $x_{1,3} + x_{1,4} + x_{2,3} + x_{2,4} \le 20$

- End of Summer (after sales in Q3, before sales in Q4):
  Stored timber = $x_{1,4} + x_{2,4} + x_{3,4}$
  Constraint: $x_{1,4} + x_{2,4} + x_{3,4} \le 20$

- End of Autumn:
  All timber must be sold by the end of Autumn. Thus, no timber is stored after Q4.
  Constraint: $0 \le 20$ (Always satisfied, no storage variable remains).

**3. Non-negativity Constraints:**
$x_{t, k} \ge 0$ for all valid $t, k$.
