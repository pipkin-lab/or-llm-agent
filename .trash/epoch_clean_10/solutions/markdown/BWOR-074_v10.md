To minimize the total sorting workload when sorting items by recognizing one category at a time, we must analyze the physical process of the sorting operation.

### 1. Problem Analysis
The problem asks to minimize the "total sorting workload" for sorting 50,000 sheets into 5 categories (A, B, C, D, E) using a machine that can only recognize **one specific grade per scan**.

This is a classic **Optimal Sorting Sequence** problem. The "workload" is typically defined as the total number of items that must be handled or scanned.
- If we select a grade to scan first, the machine scans the entire pile.
- The items matching that grade are removed (sorted).
- The remaining items (those not matching the first grade) must be scanned again for the second grade.
- This process continues until all items are sorted.

Let $n_k$ be the number of items in category $k$.
Let the sorting order be a permutation $\pi = (k_1, k_2, k_3, k_4, k_5)$.
- Scan 1 (for $k_1$): The machine processes all $N$ items. Workload $W_1 = N$.
- Scan 2 (for $k_2$): The machine processes all items except those already removed ($k_1$). Workload $W_2 = N - n_{k_1}$.
- Scan 3 (for $k_3$): The machine processes all items except $k_1$ and $k_2$. Workload $W_3 = N - n_{k_1} - n_{k_2}$.
- ...
- Scan $t$ (for $k_t$): Workload $W_t = N - \sum_{j=1}^{t-1} n_{k_j}$.

Total Workload $Z = \sum_{t=1}^{5} W_t$.

To minimize the total workload, we need to minimize the sum of the remaining items at each step. This is equivalent to **removing the largest groups first**. By removing the largest group early, we reduce the size of the pile that needs to be scanned in all subsequent steps.

Mathematically, if we sort in order of **decreasing** frequency, the large counts are subtracted from the workload sums as early as possible.

Let's verify with the given percentages (scaled to $N=50,000$):
- A: 10% $\rightarrow 5,000$
- B: 25% $\rightarrow 12,500$
- C: 30% $\rightarrow 15,000$
- D: 20% $\rightarrow 10,000$
- E: 15% $\rightarrow 7,500$

Sorted by **decreasing** count: C (15,000), B (12,500), D (10,000), E (7,500), A (5,000).

**Workload Calculation for Decreasing Order (C, B, D, E, A):**
1. Scan for C: Process 50,000. Remove 15,000. Remaining: 35,000.
2. Scan for B: Process 35,000. Remove 12,500. Remaining: 22,500.
3. Scan for D: Process 22,500. Remove 10,000. Remaining: 12,500.
4. Scan for E: Process 12,500. Remove 7,500. Remaining: 5,000.
5. Scan for A: Process 5,000. Remove 5,000. Remaining: 0.
Total Workload = $50,000 + 35,000 + 22,500 + 12,500 + 5,000 = 125,000$.

**Workload Calculation for Increasing Order (A, E, D, B, C) - Just to compare:**
1. Scan for A: Process 50,000. Remove 5,000. Remaining: 45,000.
2. Scan for E: Process 45,000. Remove 7,500. Remaining: 37,500.
3. Scan for D: Process 37,500. Remove 10,000. Remaining: 27,500.
4. Scan for B: Process 27,500. Remove 12,500. Remaining: 15,000.
5. Scan for C: Process 15,000. Remove 15,000. Remaining: 0.
Total Workload = $50,000 + 45,000 + 37,500 + 27,500 + 15,000 = 175,000$.

Clearly, the **decreasing** order yields a lower workload.

### 2. Mathematical Formulation

Although this is a combinatorial sequencing problem that can be solved analytically (sort by decreasing size), it can be formulated as a Linear Assignment Problem (or a simple ordering LP if we relax integrality, though assignment is exact here for small $N$). Given the instruction to build a formal model, we will use a standard sequencing formulation using binary variables.

**Sets & Parameters:**
- $K = \{A, B, C, D, E\}$: Set of grades.
- $N = 50,000$: Total number of participants.
- $n_k$: Number of sheets for grade $k$.
  - $n_A = 0.10 \times 50,000 = 5,000$
  - $n_B = 0.25 \times 50,000 = 12,500$
  - $n_C = 0.30 \times 50,000 = 15,000$
  - $n_D = 0.20 \times 50,000 = 10,000$
  - $n_E = 0.15 \times 50,000 = 7,500$
- $T = \{1, 2, 3, 4, 5\}$: Set of sorting steps (positions in the sequence).

**Decision Variables:**
- $x_{k,t} \in \{0, 1\}$: Binary variable where $x_{k,t} = 1$ if grade $k$ is sorted at step $t$, and 0 otherwise.

**Objective Function:**
Minimize Total Workload $Z$.
The workload at step $t$ is the number of items remaining before step $t$.
Items remaining before step $t$ = $N - \sum_{j=1}^{t-1} \sum_{k \in K} n_k x_{k,j}$.
So, $Z = \sum_{t=1}^{5} \left( N - \sum_{j=1}^{t-1} \sum_{k \in K} n_k x_{k,j} \right)$.

This can be simplified. The term $N$ is added 5 times. The term $n_k x_{k,j}$ is subtracted from the workload of all steps *after* step $j$.
If grade $k$ is at position $j$, it is subtracted from the workload of steps $j+1, j+2, \dots, 5$.
Number of times $n_k$ is subtracted = $5 - j$.
So, $Z = 5N - \sum_{j=1}^{5} \sum_{k \in K} n_k x_{k,j} (5 - j)$.
Since $5N$ is constant, minimizing $Z$ is equivalent to **Maximizing** $\sum_{j=1}^{5} \sum_{k \in K} n_k x_{k,j} (5 - j)$.
Alternatively, we can just minimize the original sum directly in the solver. Let's stick to the intuitive "Minimize Sum of Remaining Items" formulation for clarity, or the weighted sum maximization.

Let's use the **Maximize Weighted Sum** approach as it is computationally simpler (linear objective).
Maximize $W = \sum_{j=1}^{5} \sum_{k \in K} w_j n_k x_{k,j}$ where $w_j = 5 - j$.
Weights $w_j$:
- $j=1 \rightarrow w_1 = 4$
- $j=2 \rightarrow w_2 = 3$
- $j=3 \rightarrow w_3 = 2$
- $j=4 \rightarrow w_4 = 1$
- $j=5 \rightarrow w_5 = 0$

We want to assign the largest $n_k$ to the largest weights $w_j$. This confirms the decreasing order strategy.

**Constraints:**
1. Each grade is assigned to exactly one step.
2. Each step is assigned exactly one grade.

### Final Mathematical Model

#### 1. Index Sets & Parameters
*   **Sets:**
    *   $K = \{A, B, C, D, E\}$: Set of grades.
    *   $T = \{1, 2, 3, 4, 5\}$: Set of sorting steps (1 is first, 5 is last).
*   **Parameters:**
    *   $n_k$: Count of sheets for grade $k$.
        *   $n_A = 5,000$
        *   $n_B = 12,500$
        *   $n_C = 15,000$
        *   $n_D = 10,000$
        *   $n_E = 7,500$
    *   $w_t$: Weight representing the number of future scans in which items sorted at step $t$ are *not* included.
        *   $w_t = |T| - t = 5 - t$.
        *   $w_1 = 4, w_2 = 3, w_3 = 2, w_4 = 1, w_5 = 0$.

#### 2. Decision Variables
*   $x_{k,t}$: Binary variable.
    *   $x_{k,t} = 1$ if grade $k$ is selected for sorting at step $t$.
    *   $x_{k,t} = 0$ otherwise.
    *   Domain: $x_{k,t} \in \{0, 1\}$ for all $k \in K, t \in T$.

#### 3. Objective Function
Minimize the total sorting workload.
As derived, minimizing workload is equivalent to maximizing the weighted sum of counts, where earlier steps have higher weights.

$$ \text{Maximize } Z = \sum_{t=1}^{5} \sum_{k \in K} w_t \cdot n_k \cdot x_{k,t} $$

*(Note: The minimum workload value can be calculated as $Z_{min} = \sum_{t=1}^5 N_{remaining}(t)$. The solver maximizes the "savings".)*

#### 4. Operational Constraints

**Assignment Constraints:**
Each grade must be assigned to exactly one step:
$$ \sum_{t=1}^{5} x_{k,t} = 1 \quad \forall k \in K $$

Each step must have exactly one grade assigned to it:
$$ \sum_{k \in K} x_{k,t} = 1 \quad \forall t \in T $$

**Bounds:**
$$ x_{k,t} \in \{0, 1\} \quad \forall k \in K, t \in T $$

### Solution Interpretation
Solving this assignment problem will assign the largest $n_k$ to the largest $w_t$.
- Largest $n_k$ is $C$ (15,000). Largest $w_t$ is $w_1$ (4). So $x_{C,1}=1$.
- Next largest $n_k$ is $B$ (12,500). Next largest $w_t$ is $w_2$ (3). So $x_{B,2}=1$.
- Next largest $n_k$ is $D$ (10,000). Next largest $w_t$ is $w_3$ (2). So $x_{D,3}=1$.
- Next largest $n_k$ is $E$ (7,500). Next largest $w_t$ is $w_4$ (1). So $x_{E,4}=1$.
- Smallest $n_k$ is $A$ (5,000). Smallest $w_t$ is $w_5$ (0). So $x_{A,5}=1$.

**Optimal Order:** C, B, D, E, A.
