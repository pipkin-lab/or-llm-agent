# Mathematical Optimization Model

## 1. Index Sets & Parameters

**Index Sets:**
- $I = \{1, 2, 3, 4\}$: Set of potential factories ($A_1, A_2, A_3, A_4$).
- $J = \{1, 2, 3, 4\}$: Set of demand locations ($B_1, B_2, B_3, B_4$).

**Parameters:**
- $c_{ij}$: Unit transportation cost from factory $i$ to location $j$ (thousand yuan/kt).
  - $c_{1} = [2, 9, 3, 4]$
  - $c_{2} = [8, 3, 5, 7]$
  - $c_{3} = [7, 6, 1, 2]$
  - $c_{4} = [4, 5, 2, 5]$
- $S_i$: Production capacity of factory $i$ (kt/year).
  - $S_1 = 400$
  - $S_2 = 600$
  - $S_3 = 200$
  - $S_4 = 200$
- $D_j$: Annual demand at location $j$ (kt/year).
  - $D = [350, 400, 300, 150]$
- $F_i$: Fixed annual production cost for new factory $i$ (thousand yuan).
  - $F_3 = 1200$
  - $F_4 = 1500$
  - $F_1 = 0, F_2 = 0$ (Existing factories have no fixed cost in this context).

**Total Demand:** $\sum_{j \in J} D_j = 350 + 400 + 300 + 150 = 1200$ kt/year.
**Total Existing Capacity:** $S_1 + S_2 = 400 + 600 = 1000$ kt/year.
**Note:** Since existing capacity (1000) < Total Demand (1200), a new factory MUST be built to satisfy demand. The problem asks to choose between building $A_3$ or $A_4$ (implying we cannot build both, or we must select the optimal single addition). Given the phrasing "decide whether to build factory $A_3$ or $A_4$", this is a choice between two mutually exclusive options for the new facility.

## 2. Decision Variables

Let $x_{ij}$ be the amount of material shipped from factory $i$ to location $j$ (kt/year).
- Domain: $x_{ij} \ge 0, \forall i \in I, j \in J$.

Let $y_i$ be a binary variable indicating whether factory $i$ is built/operational.
- $y_3 = 1$ if factory $A_3$ is built, $0$ otherwise.
- $y_4 = 1$ if factory $A_4$ is built, $0$ otherwise.
- Domain: $y_3, y_4 \in \{0, 1\}$.

*Note on Existing Factories:* Factories $A_1$ and $A_2$ are already operational. Thus, we treat their capacity as always available. We do not need binary variables for $A_1$ and $A_2$ as they are not subject to the "build or not" decision. However, to maintain a unified formulation structure where capacity is limited by "built" status, we can implicitly set $y_1 = 1$ and $y_2 = 1$.

## 3. Objective Function

Minimize the total annual cost, which includes transportation costs and the fixed production cost of the new factory.

$$
\text{Minimize } Z = \sum_{i \in I} \sum_{j \in J} c_{ij} x_{ij} + F_3 y_3 + F_4 y_4
$$

Substituting known values:
$$
Z = \sum_{i=1}^{4} \sum_{j=1}^{4} c_{ij} x_{ij} + 1200 y_3 + 1500 y_4
$$

## 4. Operational Constraints

### 1. Demand Satisfaction Constraints
The total amount shipped to each demand location $j$ must equal the demand $D_j$.
$$
\sum_{i \in I} x_{ij} = D_j, \quad \forall j \in J
$$

### 2. Capacity Constraints
The total amount shipped from each factory $i$ cannot exceed its production capacity $S_i$. This capacity is only available if the factory is built. For existing factories ($i=1,2$), they are always built. For new factories ($i=3,4$), capacity is available only if $y_i = 1$.

$$
\sum_{j \in J} x_{ij} \le S_i y_i, \quad \forall i \in I
$$
Where:
- $y_1 = 1$ (Fixed)
- $y_2 = 1$ (Fixed)
- $y_3 \in \{0, 1\}$
- $y_4 \in \{0, 1\}$

Explicitly:
- $i=1: \sum_{j=1}^{4} x_{1j} \le 400$
- $i=2: \sum_{j=1}^{4} x_{2j} \le 600$
- $i=3: \sum_{j=1}^{4} x_{3j} \le 200 y_3$
- $i=4: \sum_{j=1}^{4} x_{4j} \le 200 y_4$

### 3. Facility Selection Constraint
We must build exactly one new factory ($A_3$ or $A_4$).
$$
y_3 + y_4 = 1
$$

### 4. Non-negativity and Integrality
$$
x_{ij} \ge 0, \quad \forall i \in I, j \in J
$$
$$
y_3, y_4 \in \{0, 1\}
$$

---
### Model Verification & Notes

1.  **Scale Check:** The units are in kilotons (kt) and thousand yuan. The total volume is 1200 kt. This is an aggregate flow problem. While $x_{ij}$ represents physical goods, in standard transportation LPs of this scale, continuous variables are standard. The fixed cost nature of the new factory makes this a **Mixed Integer Linear Program (MILP)** due to the binary variables $y_3, y_4$.
2.  **Feasibility:**
    -   If $y_3=1, y_4=0$: Total Capacity = $400 + 600 + 200 = 1200$ kt. Demand = 1200 kt. Feasible (tight).
    -   If $y_3=0, y_4=1$: Total Capacity = $400 + 600 + 200 = 1200$ kt. Demand = 1200 kt. Feasible (tight).
    -   Since Total Capacity = Total Demand in both scenarios, the capacity constraints will be binding (equality) for the selected new factory and likely for existing ones as well, forcing a basic feasible solution structure.
3.  **Objective Direction:** Minimization of cost is correctly applied.
4.  **Explicit Bounds:** All variables have non-negativity bounds. Binary variables are bounded between 0 and 1.
