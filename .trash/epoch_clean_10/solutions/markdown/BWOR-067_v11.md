To model this problem, we must first address the non-linearity in the production cost function. The cost is given as $x^2$, which is a convex quadratic function. Standard Linear Programming (LP) solvers cannot handle quadratic objective functions directly. According to the modeling rules, we must use a **Piecewise Linear Approximation (PWLA)** to linearize the cost function.

Given the demands are around 100-120, the production quantities $x_t$ will likely be in the range of 0 to 200. To ensure high accuracy and exactness for integer-like behavior (since the marginal cost increases by 2 per unit step in a $x^2$ function: $(k+1)^2 - k^2 = 2k+1$), we will discretize the production variable into unit segments.

Let the production in month $t$ be $x_t$. We approximate the cost $C(x_t) = x_t^2$ using $K$ segments of width $\Delta = 1$.
The marginal cost for the $k$-th unit (segment) is the difference in cost between $x=k$ and $x=k-1$:
$MC_k = k^2 - (k-1)^2 = 2k - 1$.

We define the maximum possible production. Since total demand is $100+110+120=330$ and ending inventory is 0, total production must be 330. No single month needs to produce more than 330 (worst case), but practically, we can set an upper bound $UB$ slightly higher than the max demand, e.g., 200, to keep the model size manageable while remaining safe. Let's set $K=200$ segments of width $\Delta=1$.

### 1. Index Sets & Parameters

**Index Sets:**
*   $t \in \{1, 2, 3\}$: Set of months.
*   $k \in \{1, \dots, K\}$: Set of production segments (where $K=200$).

**Parameters:**
*   $d_t$: Demand in month $t$.
    *   $d_1 = 100$
    *   $d_2 = 110$
    *   $d_3 = 120$
*   $h$: Inventory holding cost per unit per month = $1$.
*   $s_0$: Initial inventory = $0$.
*   $s_3$: Final inventory = $0$.
*   $\Delta$: Width of each linear segment = $1$.
*   $mc_k$: Marginal cost for the $k$-th unit of production.
    *   $mc_k = 2k - 1$ for $k=1, \dots, K$.
    *   (Note: $mc_1 = 1, mc_2 = 3, mc_3 = 5, \dots$)

### 2. Decision Variables

*   $z_{t, k}$: Continuous variable representing the amount of production in month $t$ allocated to the $k$-th cost segment.
    *   Domain: $0 \le z_{t, k} \le \Delta$ (i.e., $0 \le z_{t, k} \le 1$) for all $t, k$.
*   $x_t$: Total production quantity in month $t$.
    *   Domain: $x_t \ge 0$.
*   $I_t$: Inventory level at the end of month $t$.
    *   Domain: $I_t \ge 0$.

*(Note: $x_t$ is defined as the sum of segments $z_{t,k}$. We do not need a separate binary variable for the "on/off" state of segments because the convex cost structure naturally pushes production to the lower-cost segments first. However, to strictly enforce the piecewise linear structure in a generic solver, we typically just sum the segments. Since the marginal costs are increasing, the solver will automatically fill $z_{t,1}$ before $z_{t,2}$, etc., without needing binary "activation" variables, provided we minimize cost. This is a standard property of convex piecewise linear minimization.)*

### 3. Objective Function

Minimize total production cost + total holding cost.

$$
\text{Minimize } Z = \sum_{t=1}^{3} \left( \sum_{k=1}^{K} mc_k \cdot z_{t, k} \right) + \sum_{t=1}^{3} h \cdot I_t
$$

Substituting parameters:
$$
Z = \sum_{t=1}^{3} \sum_{k=1}^{200} (2k - 1) z_{t, k} + 1 \cdot I_1 + 1 \cdot I_2 + 1 \cdot I_3
$$

### 4. Operational Constraints

**1. Production Definition:**
The total production in each month is the sum of all segment allocations.
$$
x_t = \sum_{k=1}^{200} z_{t, k} \quad \forall t \in \{1, 2, 3\}
$$

**2. Inventory Balance Equations:**
Inventory at the end of month $t$ equals inventory from previous month + current production - current demand.
$$
I_t = I_{t-1} + x_t - d_t \quad \forall t \in \{1, 2, 3\}
$$
With specific values:
*   $I_1 = 0 + x_1 - 100$
*   $I_2 = I_1 + x_2 - 110$
*   $I_3 = I_2 + x_3 - 120$

**3. Inventory Bounds:**
*   Initial Inventory: $I_0 = 0$
*   Final Inventory: $I_3 = 0$
*   Non-negativity of Inventory: $I_t \ge 0 \quad \forall t \in \{1, 2, 3\}$

**4. Segment Bounds:**
$$
0 \le z_{t, k} \le 1 \quad \forall t \in \{1, 2, 3\}, \forall k \in \{1, \dots, 200\}
$$

**5. Non-negativity of Production:**
$$
x_t \ge 0 \quad \forall t \in \{1, 2, 3\}
$$
*(Note: Since $z_{t,k} \ge 0$, $x_t \ge 0$ is implicitly satisfied, but included for completeness.)*

### Verification of Model Logic
1.  **Convexity Handling**: By using increasing marginal costs ($mc_k$), the LP will naturally assign production to the cheapest segments first (low $k$) before moving to expensive segments (high $k$). This correctly approximates the $x^2$ cost function.
2.  **Scale**: With $K=200$, the maximum representable production is 200 per month. Total demand is 330. Is it possible a month needs > 200?
    *   If $x_1 = 330$, cost is $330^2 = 108,900$.
    *   If $x_1=110, x_2=110, x_3=110$, cost is $3 \times 110^2 = 36,300$ + holding costs.
    *   Producing excess in one month is penalized quadratically. It is highly unlikely optimal production exceeds 120 (max demand) by a large margin because the marginal cost of the 121st unit is 241, while holding cost is 1. The "economic order quantity" logic suggests producing close to demand. A cap of 200 is safe. If a higher cap is needed, $K$ can be increased, but 200 is sufficient for this demand profile.
3.  **Integrality**: The problem does not require integer units. The PWLA with $\Delta=1$ allows fractional production (e.g., $z_{t,1}=1, z_{t,2}=0.5$), which is appropriate for a continuous LP relaxation. The marginal cost for the partial 3rd unit would be 5. This linearly interpolates the quadratic curve, which is standard.

### Final Output Structure

**Index Sets:**
*   $T = \{1, 2, 3\}$: Months.
*   $K = \{1, \dots, 200\}$: Cost segments.

**Parameters:**
*   $d_1=100, d_2=110, d_3=120$
*   $h=1$
*   $mc_k = 2k - 1$ for $k \in K$

**Decision Variables:**
*   $z_{t,k} \in [0, 1]$ for all $t \in T, k \in K$
*   $I_t \in [0, \infty)$ for all $t \in T$
*   $x_t \in [0, \infty)$ for all $t \in T$

**Objective:**
$$ \text{Minimize } \sum_{t \in T} \sum_{k \in K} (2k-1)z_{t,k} + \sum_{t \in T} I_t $$

**Constraints:**
1.  $x_t = \sum_{k=1}^{200} z_{t,k}, \quad \forall t \in T$
2.  $I_t = I_{t-1} + x_t - d_t, \quad \forall t \in T$ (with $I_0=0$)
3.  $I_3 = 0$
4.  $I_t \ge 0, \quad \forall t \in T$
5.  $0 \le z_{t,k} \le 1, \quad \forall t \in T, k \in K$
