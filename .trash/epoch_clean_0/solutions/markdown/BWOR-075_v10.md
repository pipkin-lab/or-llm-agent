### 4. Operational Constraints

The problem requires connecting all wells into a single network (tree) that is connected to the Coast via Well 1. This is equivalent to finding a **Minimum Spanning Tree (MST)** on the nodes $N=\{1,\dots,8\}$.

To model the MST constraint in a linear programming framework (specifically MILP), we must ensure:
1.  **Connectivity**: All nodes are connected.
2.  **Acyclicity**: No cycles exist (since it's a tree).

A standard way to model this in an MILP context without non-linear constraints is to use the **Subtour Elimination Constraints** (similar to the Traveling Salesman Problem, but for MST). However, for small $N$ (like $N=8$), we can use the **Degree and Subtour** formulation or simply rely on the fact that minimizing cost with connectivity constraints naturally leads to a tree if we prevent cycles.

A robust formulation for MST uses:
1.  **Degree Constraints**: In a tree with $N$ nodes, there are exactly $N-1$ edges.
    $$
    \sum_{i \in N} \sum_{j \in N, j > i} y_{ij} = N - 1 = 7
    $$
    *Wait*: This constraint alone allows disconnected cycles (e.g., two separate cycles). We need to ensure connectivity.

2.  **Subtour Elimination Constraints**:
    For every proper subset $S \subset N$ such that $S \neq \emptyset$ and $N \setminus S \neq \emptyset$:
    The number of edges connecting $S$ to $N \setminus S$ must be at least 1? No, that's for Steiner trees or specific cuts.
    
    Actually, the standard MTZ formulation for TSP doesn't apply directly to MST. For MST, a common MILP formulation uses:
    
    **Option 1: Subtour Elimination via Cuts**
    For every subset $S \subset N$ with $|S| < N$:
    $$
    \sum_{i \in S} \sum_{j \in N \setminus S} y_{ij} \ge 1
    $$
    This ensures that no proper subset $S$ is disconnected from the rest of the graph. If we enforce this for all $S$, the graph is connected. Combined with the edge count constraint $\sum y_{ij} = N-1$, a connected graph with $N$ nodes and $N-1$ edges is a tree.
