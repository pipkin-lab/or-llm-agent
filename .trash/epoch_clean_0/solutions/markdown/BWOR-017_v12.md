### 1. Index Sets & Parameters

**Index Sets:**
*   $I$: Set of products, $I = \{1, 2, 3\}$ corresponding to Product I, II, and III.
*   $J$: Set of resources, $J = \{A, B, C\}$.

**Parameters:**
*   $b_j$: Available amount of resource $j$.
    *   $b_A = 500$
    *   $b_B = 300$
    *   $b_C = 100$
*   $a_{ji}$: Unit consumption of resource $j$ for one unit of product $i$.
    *   $a_{A,1}=2, a_{A,2}=4, a_{A,3}=8$
    *   $a_{B,1}=2, a_{B,2}=3, a_{B,3}=4$
    *   $c_{C,1}=1, c_{C,2}=2, c_{C,3}=3$ (Note: using $a_{C,i}$ for consistency, so $a_{C,1}=1, a_{C,2}=2, a_{C,3}=3$)
*   $p_i$: Selling price per unit of product $i$.
    *   $p_1 = 8, p_2 = 10, p_3 = 12$
*   $v_i$: Variable cost per unit of product $i$.
    *   $v_1 = 4, v_2 = 5, v_3 = 6$
*   $f_i$: Fixed cost for organizing production of product $i$.
    *   $f_1 = 100, f_2 = 150, f_3 = 200$
*   $c_i$: Net variable profit per unit of product $i$ (contribution margin).
    *   $c_1 = p_1 - v_1 = 8 - 4 = 4$
    *   $c_2 = p_2 - v_2 = 10 - 5 = 5$
    *   $c_3 = p_3 - v_3 = 12 - 6 = 6$

**Assumptions:**
*   Since the problem asks to "maximize total profit" and involves fixed costs that are incurred only if a product is produced, this is a Fixed-Charge Linear Programming problem.
*   The problem does not specify that production quantities must be integers. In standard production planning of this type (especially with capacities in hundreds), continuous variables are typically expected unless "integer units" are explicitly requested. We will model $x_i$ as continuous variables ($x_i \ge 0$).
*   The fixed cost $f_i$ is incurred if and only if $x_i > 0$.

### 2. Decision Variables

*   $x_i$: Quantity of product $i$ produced, for $i \in I$.
    *   Domain: $x_i \ge 0$ (Continuous)
*   $y_i$: Binary variable indicating whether product $i$ is produced.
    *   $y_i = 1$ if $x_i > 0$
    *   $y_i = 0$ if $x_i = 0$
    *   Domain: $y_i \in \{0, 1\}$

### 3. Objective Function

Maximize Total Profit $Z$:

$$
\text{Maximize } Z = \sum_{i \in I} (c_i x_i - f_i y_i)
$$

Substituting the calculated net variable profits and fixed costs:

$$
Z = (4 x_1 - 100 y_1) + (5 x_2 - 150 y_2) + (6 x_3 - 200 y_3)
$$

### 4. Operational Constraints

**Resource Constraints:**
The total consumption of each resource must not exceed its available amount.

1.  **Resource A:**
    $$ 2 x_1 + 4 x_2 + 8 x_3 \le 500 $$
2.  **Resource B:**
    $$ 2 x_1 + 3 x_2 + 4 x_3 \le 300 $$
3.  **Resource C:**
    $$ 1 x_1 + 2 x_2 + 3 x_3 \le 100 $$

**Linking Constraints (Fixed Charge Logic):**
Ensure that the fixed cost is incurred only if production is positive. We use the "Big-M" method. Let $M_i$ be a sufficiently large upper bound on the production of product $i$.
A valid upper bound for $x_i$ can be derived from the tightest resource constraint.
*   For Product 1: Min($500/2, 300/2, 100/1$) = Min(250, 150, 100) = 100. So $M_1 = 100$.
*   For Product 2: Min($500/4, 300/3, 100/2$) = Min(125, 100, 50) = 50. So $M_2 = 50$.
*   For Product 3: Min($500/8, 300/4, 100/3$) = Min(62.5, 75, 33.33) = 33.33. So $M_3 = 33.33$ (or simply 34 to be safe, or just use the exact fraction 100/3). Let's use $M_i$ as the theoretical max production based on resources.

Constraints:
$$ x_i \le M_i y_i \quad \forall i \in I $$

Specifically:
1.  $x_1 \le 100 y_1$
2.  $x_2 \le 50 y_2$
3.  $x_3 \le 33.33 y_3$ (Using $100/3$ for precision: $x_3 \le \frac{100}{3} y_3$)

**Non-negativity and Integrality:**
$$ x_i \ge 0 \quad \forall i \in I $$
$$ y_i \in \{0, 1\} \quad \forall i \in I $$
