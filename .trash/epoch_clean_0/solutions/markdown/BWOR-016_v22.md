| $c_{14}$ | 4 | Transport $A_1 \to B_4$ |

| $c_{23}$ | 5 | Transport $A_2 \to B_3$ |

All transportation costs are in **thousand yuan per kiloton**. Fixed costs are in **thousand yuan per year**. The objective is in **thousand yuan**.

## Model Type

**MILP** (Mixed-Integer Linear Program). Binary variables are needed for the discrete facility location decisions.

## Index Sets & Parameters

**Sets:**
- $I = \{1, 2, 3, 4\}$: Set of all factories (supplies). Factories $A_1$ and $A_2$ are existing; $A_3$ and $A_4$ are candidate new factories.
- $J = \{1, 2, 3, 4\}$: Set of demand locations.
- $K = \{3, 4\}$: Set of candidate new factories.

**Parameters:**
- $S_i$: Annual production capacity of factory $A_i$ (kt/year):
  - $S_1 = 400$, $S_2 = 600$, $S_3 = 200$, $S_4 = 200$
- $D_j$: Annual demand at location $B_j$ (kt/year):
  - $D_1 = 350$, $D_2 = 400$, $D_3 = 300$, $D_4 = 150$
- $c_{ij}$: Unit transportation cost from $A_i$ to $B_j$ (thousand yuan/kt):

| $c_{ij}$ | $B_1$ | $B_2$ | $B_3$ | $B_4$ |
|-----------|-------|-------|-------|-------|
| $A_1$ | 2 | 9 | 3 | 4 |
| $A_2$ | 8 | 3 | 5 | 7 |
| $A_3$ | 7 | 6 | 1 | 2 |
| $A_4$ | 4 | 5 | 2 | 5 |

- $F_k$: Fixed annual production cost if candidate factory $A_k$ is built (thousand yuan/year):
  - $F_3 = 1200$, $F_4 = 1500$

## Decision Variables

- $x_{ij} \geq 0$, **CONTINUOUS**: Amount of material (kt/year) shipped from factory $A_i$ to location $B_j$, for all $i \in I, j \in J$.
- $y_k \in \{0, 1\}$, **BINARY**: Facility location indicator for candidate factory $A_k$, for $k \in K$:
  - $y_k = 1$ if factory $A_k$ is built; $y_k = 0$ otherwise.

## Objective Function

**MINIMIZE** total annual cost (thousand yuan):

$$\min \sum_{i=1}^{4} \sum_{j=1}^{4} c_{ij} \, x_{ij} \;+\; 1200 \, y_3 \;+\; 1500 \, y_4$$

Explicitly:

$$\min \; 2x_{11} + 9x_{12} + 3x_{13} + 4x_{14} + 8x_{21} + 3x_{22} + 5x_{23} + 7x_{24} + 7x_{31} + 6x_{32} + 1x_{33} + 2x_{34} + 4x_{41} + 5x_{42} + 2x_{43} + 5x_{44} + 1200\,y_3 + 1500\,y_4$$

## Operational Constraints

### 1. Supply Capacity Constraints
For each factory, total shipment cannot exceed its capacity. For candidate factories, capacity is only available if the factory is built:

- $x_{11} + x_{12} + x_{13} + x_{14} \leq 400$
- $x_{21} + x_{22} + x_{23} + x_{24} \leq 600$
- $x_{31} + x_{32} + x_{33} + x_{34} \leq 200 \, y_3$
- $x_{41} + x_{42} + x_{43} + x_{44} \leq 200 \, y_4$

### 2. Demand Satisfaction Constraints
Each location's demand must be met exactly:

- $x_{11} + x_{21} + x_{31} + x_{41} = 350$
- $x_{12} + x_{22} + x_{32} + x_{42} = 400$
- $x_{13} + x_{23} + x_{33} + x_{43} = 300$
- $x_{14} + x_{24} + x_{34} + x_{44} = 150$

### 3. Single-Facility Selection Constraint
Exactly one of the two candidate factories must be built:

$$y_3 + y_4 = 1$$

### 4. Non-negativity and Domain Bounds

$$x_{ij} \geq 0 \quad \forall \, i \in I, \, j \in J$$

$$y_k \in \{0, 1\} \quad \forall \, k \in K$$

## Feasibility Sanity Check

- **Total demand**: $350 + 400 + 300 + 150 = 1200$ kt/year.
- **Total existing supply** ($A_1 + A_2$): $400 + 600 = 1000$ kt/year.
- **Deficit**: $1200 - 1000 = 200$ kt/year.
- **Candidate capacity**: Each candidate factory has capacity 200 kt/year, which exactly covers the deficit.
- Since exactly one candidate factory is built (constraint 3), total available supply = $1000 + 200 = 1200$ kt/year = total demand. The model is **feasible**. The supply constraints for existing factories use $\leq$ (they may not need to operate at full capacity), while the new factory's capacity is linked to its binary variable.
