# Transportation Problem Model

## 1. Index Sets & Parameters

**Sets:**
- $I = \{1, 2, 3, 4\}$: Set of supply origins (A1, A2, A3, A4).
- $J = \{1, 2, 3, 4, 5, 6\}$: Set of demand destinations (B1, B2, B3, B4, B5, B6).

**Parameters:**
- $S_i$: Supply available at origin $i$.
  - $S_1 = 50, S_2 = 40, S_3 = 60, S_4 = 31$
- $D_j$: Demand required at destination $j$.
  - $D_1 = 30, D_2 = 50, D_3 = 20, D_4 = 40, D_5 = 30, D_6 = 11$
- $c_{ij}$: Unit transportation cost from origin $i$ to destination $j$.

| $i \backslash j$ | B1 | B2 | B3 | B4 | B5 | B6 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **A1** | 2 | 1 | 3 | 3 | 3 | 5 |
| **A2** | 4 | 2 | 2 | 4 | 4 | 4 |
| **A3** | 3 | 5 | 4 | 2 | 4 | 1 |
| **A4** | 4 | 2 | 2 | 1 | 2 | 2 |

**Balance Check:**
- Total Supply: $50 + 40 + 60 + 31 = 181$
- Total Demand: $30 + 50 + 20 + 40 + 30 + 11 = 181$
- The problem is **balanced** ($\sum S_i = \sum D_j$).

## 2. Decision Variables

- $x_{ij}$: Amount of goods transported from origin $i$ to destination $j$.
  - Domain: $x_{ij} \ge 0$ for all $i \in I, j \in J$.
  - *Note: As this is a standard transportation problem with aggregate quantities (not discrete indivisible units like ships), continuous variables are appropriate.*

## 3. Objective Function

Minimize the total transportation cost:

$$ \text{Minimize } Z = \sum_{i=1}^{4} \sum_{j=1}^{6} c_{ij} x_{ij} $$

Expanded:
$$ Z = 2x_{11} + 1x_{12} + 3x_{13} + 3x_{14} + 3x_{15} + 5x_{16} $$
$$ + 4x_{21} + 2x_{22} + 2x_{23} + 4x_{24} + 4x_{25} + 4x_{26} $$
$$ + 3x_{31} + 5x_{32} + 4x_{33} + 2x_{34} + 4x_{35} + 1x_{36} $$
$$ + 4x_{41} + 2x_{42} + 2x_{43} + 1x_{44} + 2x_{45} + 2x_{46} $$

## 4. Operational Constraints

**Supply Constraints (Outflow from each origin equals supply):**
For each $i \in \{1, 2, 3, 4\}$:
1. $\sum_{j=1}^{6} x_{1j} = 50$
2. $\sum_{j=1}^{6} x_{2j} = 40$
3. $\sum_{j=1}^{6} x_{3j} = 60$
4. $\sum_{j=1}^{6} x_{4j} = 31$

**Demand Constraints (Inflow to each destination equals demand):**
For each $j \in \{1, 2, 3, 4, 5, 6\}$:
1. $\sum_{i=1}^{4} x_{i1} = 30$
2. $\sum_{i=1}^{4} x_{i2} = 50$
3. $\sum_{i=1}^{4} x_{i3} = 20$
4. $\sum_{i=1}^{4} x_{i4} = 40$
5. $\sum_{i=1}^{4} x_{i5} = 30$
6. $\sum_{i=1}^{4} x_{i6} = 11$

**Non-negativity Constraints:**
$$ x_{ij} \ge 0, \quad \forall i \in I, j \in J $$
