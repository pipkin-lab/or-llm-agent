### 1. Index Sets & Parameters

**Index Sets:**
*   $N = \{X, Y, A, B, C\}$: Set of all nodes in the network.
    *   $S = \{X, Y\}$: Set of supply nodes (origins).
    *   $D = \{A, B, C\}$: Set of demand nodes (destinations).
*   $i \in S$: Supply node index.
*   $j \in D$: Demand node index.
*   $k \in \{A, B, C\}$: Transshipment node index (which are also demand nodes).

**Parameters:**

*   **Supply Capacities ($Supply_i$):**
    *   $Supply_X = 70$ tons
    *   $Supply_Y = 55$ tons
    *   *Note: Total Supply = 125 tons.*

*   **Demand Requirements ($Demand_j$):**
    *   $Demand_A = 35$ tons
    *   $Demand_B = 40$ tons
    *   $Demand_C = 50$ tons
    *   *Note: Total Demand = 125 tons. The problem is balanced.*

*   **Distances ($d_{uv}$):** Distance in km from node $u$ to node $v$. Based on the provided tables:
    *   **From Origins (Table 3-23 & 3-24):**
        *   $d_{X,Y} = 12$
        *   $d_{Y,X} = 10$
        *   $d_{X,A} = 10, \quad d_{X,B} = 14, \quad d_{X,C} = 12$
        *   $d_{Y,A} = 15, \quad d_{Y,B} = 12, \quad d_{Y,C} = 18$
    *   **Between Destinations/Transshipment Points (Table 3-25):**
        *   $d_{A,B} = 14, \quad d_{A,C} = 11$
        *   $d_{B,A} = 10, \quad d_{B,C} = 4$
        *   $d_{C,A} = 8, \quad d_{C,B} = 12$
        *   $d_{A,A} = 0, \quad d_{B,B} = 0, \quad d_{C,C} = 0$
    *   *Assumption:* Goods can be shipped directly from Origin to Destination, or from Origin to Transshipment Node, or from Transshipment Node to Destination. The problem implies a network where any node can send to any other node if a distance is defined. The tables cover all necessary arcs: Origins to Destinations, Origins to each other (implied transshipment between sources, though usually sources don't need to transship to each other unless one is empty, but here we model the full network), and Destinations to each other (transshipment).
    *   *Clarification on Network Structure:* Standard transshipment problems allow flow between any two nodes.
        *   Arcs from $X$: $X \to Y, X \to A, X \to B, X \to C$
        *   Arcs from $Y$: $Y \to X, Y \to A, Y \to B, Y \to C$
        *   Arcs from $A$: $A \to B, A \to C$ (and $A \to A$ is internal, handled by balance eq)
        *   Arcs from $B$: $B \to A, B \to C$
        *   Arcs from $C$: $C \to A, C \to B$
        *   *Note:* $A \to X$ and $A \to Y$ distances are not provided in the tables. Typically, in such textbook problems, flow is directed from Origins to Destinations, and Destinations to each other. Reverse flow from Destination to Origin is not explicitly given. We assume the network is directed as per the tables provided: Origins can send to Destinations and each other; Destinations can send to each other.

### 2. Decision Variables

Let $x_{uv}$ be the amount of goods (in tons) shipped from node $u$ to node $v$.

*   $x_{X,Y}, x_{X,A}, x_{X,B}, x_{X,C} \ge 0$
*   $x_{Y,X}, x_{Y,A}, y_{Y,B}, x_{Y,C} \ge 0$  *(Correction: $x_{Y,B}$)*
*   $x_{A,B}, x_{A,C} \ge 0$
*   $x_{B,A}, x_{B,C} \ge 0$
*   $x_{C,A}, x_{C,B} \ge 0$

**Variable Domains:**
All $x_{uv}$ are **Continuous** variables ($x_{uv} \ge 0$).
*Reasoning:* The quantities are in "tons". This is a standard transportation/transshipment problem. The scale (70, 55, 35, 40, 50) suggests aggregate goods. Fractional tons are physically possible (e.g., bulk commodities). Standard LP relaxation is expected and appropriate here.

### 3. Objective Function

Minimize the total transportation distance (Total Cost = Sum of Flow $\times$ Distance).

$$
\text{Minimize } Z = \sum_{(u,v) \in \text{Arcs}} d_{uv} \cdot x_{uv}
$$

Expanding explicitly:

$$
\begin{aligned}
Z = & 12 x_{X,Y} + 10 x_{X,A} + 14 x_{X,B} + 12 x_{X,C} \\
    + & 10 x_{Y,X} + 15 x_{Y,A} + 12 x_{Y,B} + 18 x_{Y,C} \\
    + & 14 x_{A,B} + 11 x_{A,C} \\
    + & 10 x_{B,A} + 4 x_{B,C} \\
    + & 8 x_{C,A} + 12 x_{C,B}
\end{aligned}
$$

### 4. Operational Constraints

**Flow Balance Constraints:**
For each node, the total inflow plus the net supply (if origin) must equal the total outflow plus the demand (if destination).
General form: $\sum_{v} x_{v,u} + Supply_u = \sum_{v} x_{u,v} + Demand_u$

*   **Node X (Supply 70, Demand 0):**
    Inflow from Y: $x_{Y,X}$
    Outflow to Y, A, B, C: $x_{X,Y} + x_{X,A} + x_{X,B} + x_{X,C}$
    $$ x_{Y,X} + 70 = x_{X,Y} + x_{X,A} + x_{X,B} + x_{X,C} $$
    *(Rearranged: $x_{X,Y} + x_{X,A} + x_{X,B} + x_{X,C} - x_{Y,X} = 70$)*

*   **Node Y (Supply 55, Demand 0):**
    Inflow from X: $x_{X,Y}$
    Outflow to X, A, B, C: $x_{Y,X} + x_{Y,A} + x_{Y,B} + x_{Y,C}$
    $$ x_{X,Y} + 55 = x_{Y,X} + x_{Y,A} + x_{Y,B} + x_{Y,C} $$
    *(Rearranged: $x_{Y,X} + x_{Y,A} + x_{Y,B} + x_{Y,C} - x_{X,Y} = 55$)*

*   **Node A (Supply 0, Demand 35):**
    Inflow from X, Y, B, C: $x_{X,A} + x_{Y,A} + x_{B,A} + x_{C,A}$
    Outflow to B, C: $x_{A,B} + x_{A,C}$
    $$ x_{X,A} + x_{Y,A} + x_{B,A} + x_{C,A} = x_{A,B} + x_{A,C} + 35 $$
    *(Rearranged: $x_{A,B} + x_{A,C} - x_{X,A} - x_{Y,A} - x_{B,A} - x_{C,A} = -35$)*

*   **Node B (Supply 0, Demand 40):**
    Inflow from X, Y, A, C: $x_{X,B} + x_{Y,B} + x_{A,B} + x_{C,B}$
    Outflow to A, C: $x_{B,A} + x_{B,C}$
    $$ x_{X,B} + x_{Y,B} + x_{A,B} + x_{C,B} = x_{B,A} + x_{B,C} + 40 $$
    *(Rearranged: $x_{B,A} + x_{B,C} - x_{X,B} - x_{Y,B} - x_{A,B} - x_{C,B} = -40$)*

*   **Node C (Supply 0, Demand 50):**
    Inflow from X, Y, A, B: $x_{X,C} + x_{Y,C} + x_{A,C} + x_{B,C}$
    Outflow to A, B: $x_{C,A} + x_{C,B}$
    $$ x_{X,C} + x_{Y,C} + x_{A,C} + x_{B,C} = x_{C,A} + x_{C,B} + 50 $$
    *(Rearranged: $x_{C,A} + x_{C,B} - x_{X,C} - x_{Y,C} - x_{A,C} - x_{B,C} = -50$)*

**Non-negativity Constraints:**
$$ x_{uv} \ge 0 \quad \forall u,v \in \text{defined arcs} $$
