## Model Type: MILP

This is a Mixed-Integer Linear Programming problem. We need to decide **whether** to produce each product (binary variables to capture fixed costs) and **how much** to produce (continuous variables for production quantities).

## Index Sets & Parameters

**Index Sets:**
- $i \in \{1, 2, 3\}$: Product index, where $1$ = Shirt, $2$ = T-shirt, $3$ = Casual Wear.

**Parameters (from Table 5-10 and problem text):**

| Parameter | Description | $i=1$ (Shirt) | $i=2$ (T-shirt) | $i=3$ (Casual Wear) |
|---|---|---|---|---|
| $a_i$ | Labor per unit | 3 | 2 | 6 |
| $b_i$ | Material per unit | 4 | 3 | 6 |
| $p_i$ | Selling price per unit | 120 | 80 | 180 |
| $c_i$ | Variable cost per unit | 60 | 40 | 80 |
| $f_i$ | Fixed cost per week if produced | 2000 | 1500 | 1000 |

**Resource Capacities:**
- $A = 150$: Total available labor units per week
- $B = 160$: Total available material units per week

**Derived Parameters:**
- Contribution margin per unit: $m_i = p_i - c_i$
  - $m_1 = 120 - 60 = 60$
  - $m_2 = 80 - 40 = 40$
  - $m_3 = 180 - 80 = 100$

## Decision Variables

For each product $i \in \{1, 2, 3\}$:

1. **$x_i \geq 0$** (CONTINUOUS): Number of units of product $i$ to produce per week.
2. **$y_i \in \{0, 1\}$** (BINARY): Indicator variable where $y_i = 1$ if product $i$ is produced (i.e., the specialized equipment for product $i$ is operated), and $y_i = 0$ otherwise.

## Objective Function

**Maximize** total weekly profit, which equals total contribution margin minus total fixed costs:

$$\max \quad Z = \sum_{i=1}^{3} m_i \, x_i - \sum_{i=1}^{3} f_i \, y_i$$

Expanded:

$$\max \quad Z = 60\,x_1 + 40\,x_2 + 100\,x_3 - 2000\,y_1 - 1500\,y_2 - 1000\,y_3$$

## Operational Constraints

**1. Resource Constraints (Labor and Material):**

$$\sum_{i=1}^{3} a_i \, x_i \leq A \quad \Longrightarrow \quad 3x_1 + 2x_2 + 6x_3 \leq 150$$

$$\sum_{i=1}^{3} b_i \, x_i \leq B \quad \Longrightarrow \quad 4x_1 + 3x_2 + 6x_3 \leq 160$$

**2. Big-M Linking Constraints (Production implies equipment operation):**

If $x_i > 0$, then $y_i$ must be 1. We use an upper bound $M_i$ on $x_i$ to link $x_i$ and $y_i$:

$$x_i \leq M_i \, y_i, \quad \forall\, i \in \{1, 2, 3\}$$

To determine tight valid upper bounds $M_i$, note that $x_i$ is bounded by both resource constraints. The tightest individual upper bound for each product is:

- $M_1 = \min\!\left(\left\lfloor \frac{150}{3} \right\rfloor, \left\lfloor \frac{160}{4} \right\rfloor\right) = \min(50, 40) = 40$
- $M_2 = \min\!\left(\left\lfloor \frac{150}{2} \right\rfloor, \left\lfloor \frac{160}{3} \right\rfloor\right) = \min(75, 53) = 53$
- $M_3 = \min\!\left(\left\lfloor \frac{150}{6} \right\rfloor, \left\lfloor \frac{160}{6} \right\rfloor\right) = \min(25, 26) = 25$

Thus:

$$x_1 \leq 40\, y_1$$
$$x_2 \leq 53\, y_2$$
$$x_3 \leq 25\, y_3$$

**3. Non-negativity and Domain Constraints:**

$$x_i \geq 0, \quad \forall\, i \in \{1, 2, 3\}$$
$$y_i \in \{0, 1\}, \quad \forall\, i \in \{1, 2, 3\}$$

## Feasibility Sanity Check

- If all three products are produced, the resource constraints must be jointly satisfiable. For example, producing only Casual Wear: $x_3 \leq 25$ (labor: $6 \times 25 = 150$), material: $6 \times 25 = 150 \leq 160$ ✓. Profit = $100(25) - 1000 = 1500$.
- Producing only Shirts: $x_1 \leq 40$ (material: $4 \times 40 = 160$), labor: $3 \times 40 = 120 \leq 150$ ✓. Profit = $60(40) - 2000 = 400$.
- Producing only T-shirts: $x_2 \leq 53$ (material: $3 \times 53 = 159 \leq 160$), labor: $2 \times 53 = 106 \leq 150$ ✓. Profit = $40(53) - 1500 = 620$.
- The model is feasible (e.g., $x_1=x_2=x_3=0, y_1=y_2=y_3=0$ is feasible with $Z=0$). The problem is well-posed.
