**Model Type:** Linear Programming (LP)

### Index Sets & Parameters

**Index Sets:**
*   $I$: Set of students, $I = \{1, 2, 3, 4, 5, 6\}$
*   $D$: Set of days, $D = \{1, 2, 3, 4, 5\}$ corresponding to Monday, Tuesday, Wednesday, Thursday, Friday.
*   $I_U$: Set of undergraduate students, $I_U = \{1, 2, 3, 4\}$
*   $I_G$: Set of graduate students, $I_G = \{5, 6\}$

**Parameters (extracted from Table 5-9 and problem text):**

*   $w_i$: Hourly wage for student $i$ (yuan/hour).
    *   $w_1 = 10.0$
    *   $w_2 = 10.0$
    *   $w_3 = 9.9$
    *   $w_4 = 9.8$
    *   $w_5 = 10.8$
    *   $w_6 = 11.3$
*   $M_{i,d}$: Maximum available work hours for student $i$ on day $d$.
    *   **Student 1:** $M_{1,1}=6, M_{1,2}=0, M_{1,3}=9, M_{1,4}=0, M_{1,5}=7$
    *   **Student 2:** $M_{2,1}=0, M_{2,2}=9, M_{2,3}=0, M_{2,4}=6, M_{2,5}=0$
    *   **Student 3:** $M_{3,1}=4, M_{3,2}=8, M_{3,3}=3, M_{3,4}=0, M_{3,5}=5$
    *   **Student 4:** $M_{4,1}=5, M_{4,2}=5, M_{4,3}=6, M_{4,4}=0, M_{4,5}=4$
    *   **Student 5:** $M_{5,1}=3, M_{5,2}=0, M_{5,3}=4, M_{5,4}=8, M_{5,5}=0$
    *   **Student 6:** $M_{6,1}=0, M_{6,2}=9, M_{6,3}=0, M_{6,4}=6, M_{6,5}=3$
*   $H_{req, d}$: Required coverage hours per day $d$.
    *   The lab is open 14 hours/day and requires exactly 1 student on duty at all times.
    *   Therefore, $H_{req, d} = 14$ for all $d \in D$.
*   $L_U$: Minimum weekly hours for undergraduate students.
    *   $L_U = 8$
*   $L_G$: Minimum weekly hours for graduate students.
    *   $L_G = 7$

### Decision Variables

Let $x_{i,d}$ be the number of hours student $i$ works on day $d$.

*   **Domain:** $x_{i,d} \ge 0$ for all $i \in I, d \in D$.
    *   *Note:* Since wages are linear and constraints are linear, and there are no fixed costs or non-convexities, continuous variables are appropriate. The problem does not specify that shifts must be in integer increments (e.g., 1 hour blocks), so continuous hours are the standard assumption for such scheduling LPs unless specified otherwise.

### Objective Function

Minimize the total weekly wage payment:

$$
\text{Minimize } Z = \sum_{i \in I} \sum_{d \in D} w_i x_{i,d}
$$

Explicitly:
$$
Z = 10.0(x_{1,1} + x_{1,2} + x_{1,3} + x_{1,4} + x_{1,5}) + 10.0(x_{2,1} + x_{2,2} + x_{2,3} + x_{2,4} + x_{2,5}) + 9.9(x_{3,1} + x_{3,2} + x_{3,3} + x_{3,4} + x_{3,5}) + 9.8(x_{4,1} + x_{4,2} + x_{4,3} + x_{4,4} + x_{4,5}) + 10.8(x_{5,1} + x_{5,2} + x_{5,3} + x_{5,4} + x_{5,5}) + 11.3(x_{6,1} + x_{6,2} + x_{6,3} + x_{6,4} + x_{6,5})
$$

### Operational Constraints

**1. Daily Coverage Constraints:**
The total hours worked by all students on any given day $d$ must equal the required 14 hours.

$$
\sum_{i \in I} x_{i,d} = 14 \quad \forall d \in D
$$

*   **Day 1 (Mon):** $x_{1,1} + x_{2,1} + x_{3,1} + x_{4,1} + x_{5,1} + x_{6,1} = 14$
*   **Day 2 (Tue):** $x_{1,2} + x_{2,2} + x_{3,2} + x_{4,2} + x_{5,2} + x_{6,2} = 14$
*   **Day 3 (Wed):** $x_{1,3} + x_{2,3} + x_{3,3} + x_{4,3} + x_{5,3} + x_{6,3} = 14$
*   **Day 4 (Thu):** $x_{1,4} + x_{2,4} + x_{3,4} + x_{4,4} + x_{5,4} + x_{6,4} = 14$
*   **Day 5 (Fri):** $x_{1,5} + x_{2,5} + x_{3,5} + x_{4,5} + x_{5,5} + x_{6,5} = 14$

**2. Maximum Availability Constraints:**
No student can work more than their maximum available hours on a specific day.

$$
x_{i,d} \le M_{i,d} \quad \forall i \in I, d \in D
$$

Specifically:
*   $x_{1,1} \le 6, \quad x_{1,2} \le 0, \quad x_{1,3} \le 9, \quad x_{1,4} \le 0, \quad x_{1,5} \le 7$
*   $x_{2,1} \le 0, \quad x_{2,2} \le 9, \quad x_{2,3} \le 0, \quad x_{2,4} \le 6, \quad x_{2,5} \le 0$
*   $x_{3,1} \le 4, \quad x_{3,2} \le 8, \quad x_{3,3} \le 3, \quad x_{3,4} \le 0, \quad x_{3,5} \le 5$
*   $x_{4,1} \le 5, \quad x_{4,2} \le 5, \quad x_{4,3} \le 6, \quad x_{4,4} \le 0, \quad x_{4,5} \le 4$
*   $x_{5,1} \le 3, \quad x_{5,2} \le 0, \quad x_{5,3} \le 4, \quad x_{5,4} \le 8, \quad x_{5,5} \le 0$
*   $x_{6,1} \le 0, \quad x_{6,2} \le 9, \quad x_{6,3} \le 0, \quad x_{6,4} \le 6, \quad x_{6,5} \le 3$

**3. Minimum Weekly Hours Constraints (Undergraduates):**
Each undergraduate student must work at least 8 hours in total over the week.

$$
\sum_{d \in D} x_{i,d} \ge 8 \quad \forall i \in I_U = \{1, 2, 3, 4\}
$$

*   **Student 1:** $x_{1,1} + x_{1,2} + x_{1,3} + x_{1,4} + x_{1,5} \ge 8$
*   **Student 2:** $x_{2,1} + x_{2,2} + x_{2,3} + x_{2,4} + x_{2,5} \ge 8$
*   **Student 3:** $x_{3,1} + x_{3,2} + x_{3,3} + x_{3,4} + x_{3,5} \ge 8$
*   **Student 4:** $x_{4,1} + x_{4,2} + x_{4,3} + x_{4,4} + x_{4,5} \ge 8$

**4. Minimum Weekly Hours Constraints (Graduates):**
Each graduate student must work at least 7 hours in total over the week.

$$
\sum_{d \in D} x_{i,d} \ge 7 \quad \forall i \in I_G = \{5, 6\}
$$

*   **Student 5:** $x_{5,1} + x_{5,2} + x_{5,3} + x_{5,4} + x_{5,5} \ge 7$
*   **Student 6:** $x_{6,1} + x_{6,2} + x_{6,3} + x_{6,4} + x_{6,5} \ge 7$

**5. Non-negativity:**
$$
x_{i,d} \ge 0 \quad \forall i \in I, d \in D
$$
