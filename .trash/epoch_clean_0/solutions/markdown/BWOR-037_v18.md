**Model Type:** MILP (Mixed Integer Linear Programming)

### 1. Index Sets & Parameters

**Sets:**
*   $T = \{1, 2, 3\}$: Set of tasks.
*   $K = \{T, L\}$: Set of worker types ($T$ = Technician, $L$ = Laborer).

**Parameters:**
*   $c_T = 100$: Weekly wage for a Technician (yuan).
*   $c_L = 80$: Weekly wage for a Laborer (yuan).
*   $U_T = 42$: Effective weekly working hours for a Technician.
*   $U_L = 36$: Effective weekly working hours for a Laborer.
*   $D_1 = 10,000$: Total effective hours required for Task 1.
*   $D_2 = 20,000$: Total effective hours required for Task 2.
*   $D_3 = 30,000$: Total effective hours required for Task 3.
*   $M_T = 400$: Maximum number of Technicians available.
*   $M_L = 800$: Maximum number of Laborers available.

**Task Configuration Data:**
The problem specifies specific team compositions required to "complete" a task instance. In workforce planning contexts of this type, this implies that the total workforce must be divisible into these specific crew structures to generate the required total hours. The "capacity" of each crew type is derived from the effective hours of its members.

*   **Task 1 Options:**
    *   Option 1A: 1 Technician. Capacity $C_{1A} = 1 \times 42 = 42$ hours/week.
    *   Option 1B: 1 Technician + 2 Laborers. Capacity $C_{1B} = 1 \times 42 + 2 \times 36 = 114$ hours/week.
*   **Task 2 Options:**
    *   Option 2A: 1 Technician. Capacity $C_{2A} = 1 \times 42 = 42$ hours/week.
    *   Option 2B: 1 Laborer. Capacity $C_{2B} = 1 \times 36 = 36$ hours/week.
*   **Task 3 Options:**
    *   Option 3A: 5 Laborers. Capacity $C_{3A} = 5 \times 36 = 180$ hours/week.
    *   Option 3B: 1 Technician + 3 Laborers. Capacity $C_{3B} = 1 \times 42 + 3 \times 36 = 150$ hours/week.

### 2. Decision Variables

Let $x_{ij}$ be the integer number of crews of type $j$ assigned to task $i$.
*   $x_{1A}, x_{1B} \in \mathbb{Z}^+$: Number of Task 1 crews of type A and B.
*   $x_{2A}, x_{2B} \in \mathbb{Z}^+$: Number of Task 2 crews of type A and B.
*   $x_{3A}, x_{3B} \in \mathbb{Z}^+$: Number of Task 3 crews of type A and B.

Alternatively, we can define the total number of technicians and laborers recruited as the primary variables, but since the tasks have specific *combinatorial* requirements (team structures), it is more rigorous to model the crew counts directly and derive the total workforce from them. However, the problem asks for "how many technicians and laborers should be recruited". This implies the total counts $N_T$ and $N_L$ are the final outputs, but they are constrained by the sum of crews.

Let's define the decision variables as the number of crews:
*   $x_{1A}, x_{1B}, x_{2A}, x_{2B}, x_{3A}, x_{3B} \ge 0$, Integer.

The total number of technicians $N_T$ and laborers $N_L$ are then calculated as:
*   $N_T = x_{1A} + x_{1B} + x_{2A} + x_{3B}$
*   $N_L = 2x_{1B} + x_{2B} + 5x_{3A} + 3x_{3B}$

### 3. Objective Function

Minimize total weekly wage cost $Z$:

$$
\text{Minimize } Z = 100 N_T + 80 N_L
$$

Substituting the expressions for $N_T$ and $N_L$ in terms of crew variables:

$$
Z = 100(x_{1A} + x_{1B} + x_{2A} + x_{3B}) + 80(2x_{1B} + x_{2B} + 5x_{3A} + 3x_{3B})
$$

Simplifying coefficients for each variable:
*   $x_{1A}$: $100(1) + 80(0) = 100$
*   $x_{1B}$: $100(1) + 80(2) = 260$
*   $x_{2A}$: $100(1) + 80(0) = 100$
*   $x_{2B}$: $100(0) + 80(1) = 80$
*   $x_{3A}$: $100(0) + 80(5) = 400$
*   $x_{3B}$: $100(1) + 80(3) = 340$

$$
\text{Minimize } Z = 100x_{1A} + 260x_{1B} + 100x_{2A} + 80x_{2B} + 400x_{3A} + 340x_{3B}
$$

### 4. Operational Constraints

**1. Task Completion Constraints (Workload Requirements):**
The total effective hours generated by the assigned crews for each task must meet or exceed the required hours.

*   **Task 1:** $42 x_{1A} + 114 x_{1B} \ge 10,000$
*   **Task 2:** $42 x_{2A} + 36 x_{2B} \ge 20,000$
*   **Task 3:** $180 x_{3A} + 150 x_{3B} \ge 30,000$

**2. Workforce Availability Constraints:**
The total number of technicians and laborers used across all tasks must not exceed the recruitment limits.

*   **Technicians:** $x_{1A} + x_{1B} + x_{2A} + x_{3B} \le 400$
*   **Laborers:** $2x_{1B} + x_{2B} + 5x_{3A} + 3x_{3B} \le 800$

**3. Non-negativity and Integrality:**
*   $x_{1A}, x_{1B}, x_{2A}, x_{2B}, x_{3A}, x_{3B} \in \mathbb{Z}_{\ge 0}$
