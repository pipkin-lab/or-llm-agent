# Cargo Loading Optimization Model

## Model Type: LP (Linear Programming)

**Rationale:** All decision variables are continuous quantities of cargo pieces (standard for aggregate cargo loading where pieces are treated as divisible units for LP relaxation; if integer enforcement is required, it becomes a MILP, but the problem asks for an LP formulation). The objective and all constraints are linear.

## Index Sets & Parameters

**Sets:**
- $C = \{A, B, C\}$: Set of cargo types
- $K = \{F, M, R\}$: Set of compartments (Front, Middle, Rear)

**Parameters (from Tables 1-24 and 1-25):**

*Compartment Capacities:*
| Parameter | Description | F | M | R |
| :--- | :--- | :--- | :--- | :--- |
| $L_k$ (t) | Max Allowable Load | 2000 | 3000 | 1500 |
| $V_k$ ($m^3$) | Max Volume | 4000 | 5000 | 1500 |

*Cargo Data:*
| Parameter | Description | A | B | C |
| :--- | :--- | :--- | :--- | :--- |
| $S_j$ (pieces) | Supply/Quantity | 600 | 1000 | 800 |
| $v_j$ ($m^3$/piece) | Volume per piece | 10 | 5 | 7 |
| $w_j$ (t/piece) | Weight per piece | 8 | 6 | 4 |
| $p_j$ ($/piece) | Freight Rate | 1000 | 700 | 600 |

*Balance Parameters (derived from max loads $L_k$):*
The reference ratios are based on the maximum allowable loads:
- Ratio Front/Middle: $r_{FM} = L_F / L_M = 2000 / 3000 = 2/3$
- Ratio Rear/Middle: $r_{RM} = L_R / L_M = 1500 / 3000 = 1/2$
- Ratio Front/Rear: $r_{FR} = L_F / L_R = 2000 / 1500 = 4/3$

*Deviation Limits:*
- $\delta_{FM} = 15\% = 0.15$
- $\delta_{RM} = 15\% = 0.15$
- $\delta_{FR} = 10\% = 0.10$

## Decision Variables

Let $x_{jk}$ be the number of pieces of cargo type $j$ loaded in compartment $k$.

- $x_{jk} \ge 0, \quad \forall j \in C, k \in K$
- (Note: While physical pieces are discrete, LP formulations typically treat these as continuous variables. If strict integrality is needed, $x_{jk} \in \mathbb{Z}_{\ge 0}$, making it a MILP. Per the prompt "formulate the linear programming model", we define them as continuous non-negative variables.)

## Objective Function

Maximize total revenue:

$$
\text{Maximize } Z = \sum_{j \in C} \sum_{k \in K} p_j x_{jk}
$$

Expanded:
$$
Z = 1000(x_{AF} + x_{AM} + x_{AR}) + 700(x_{BF} + x_{BM} + x_{BR}) + 600(x_{CF} + x_{CM} + x_{CR})
$$

## Operational Constraints

### 1. Cargo Supply Constraints
The total amount of each cargo type loaded cannot exceed its available quantity.

$$
\sum_{k \in K} x_{jk} \le S_j, \quad \forall j \in C
$$

- For A: $x_{AF} + x_{AM} + x_{AR} \le 600$
- For B: $x_{BF} + x_{BM} + x_{BR} \le 1000$
- For C: $x_{CF} + x_{CM} + x_{CR} \le 800$

### 2. Volume Capacity Constraints
The total volume of cargo in each compartment cannot exceed the compartment's volume limit.

$$
\sum_{j \in C} v_j x_{jk} \le V_k, \quad \forall k \in K
$$

- Front: $10x_{AF} + 5x_{BF} + 7x_{CF} \le 4000$
- Middle: $10x_{AM} + 5x_{BM} + 7x_{CM} \le 5000$
- Rear: $10x_{AR} + 5x_{BR} + 7x_{CR} \le 1500$

### 3. Weight Capacity Constraints
The total weight of cargo in each compartment cannot exceed the compartment's weight limit.

$$
\sum_{j \in C} w_j x_{jk} \le L_k, \quad \forall k \in K
$$

- Front: $8x_{AF} + 6x_{BF} + 4x_{CF} \le 2000$
- Middle: $8x_{AM} + 6x_{BM} + 4x_{CM} \le 3000$
- Rear: $8x_{AR} + 6x_{BR} + 4x_{CR} \le 1500$

### 4. Balance Constraints (Maritime Safety)
Let $W_k = \sum_{j \in C} w_j x_{jk}$ be the total weight in compartment $k$.
The constraints ensure the actual weight ratios stay within the specified percentage deviations of the reference ratios ($L_i/L_m$).

**a) Front/Middle Ratio Constraint:**
Reference ratio $r_{FM} = 2/3$. Deviation limit $15\%$.
Allowed range for $W_F / W_M$: $[ \frac{2}{3}(1 - 0.15), \frac{2}{3}(1 + 0.15) ] = [ \frac{2}{3}(0.85), \frac{2}{3}(1.15) ] = [ \frac{1.7}{3}, \frac{2.3}{3} ] = [ \frac{17}{30}, \frac{23}{30} ]$

$$
\frac{17}{30} W_M \le W_F \le \frac{23}{30} W_M
$$
Substituting $W_F$ and $W_M$:
$$
30 W_F - 23 W_M \le 0 \quad \text{(Upper Bound on Ratio)}
$$
$$
-30 W_F + 17 W_M \le 0 \quad \text{(Lower Bound on Ratio)}
$$

Expanding into linear constraints:
1. $30(8x_{AF} + 6x_{BF} + 4x_{CF}) - 23(8x_{AM} + 6x_{BM} + 4x_{CM}) \le 0$
2. $-30(8x_{AF} + 6x_{BF} + 4x_{CF}) + 17(8x_{AM} + 6x_{BM} + 4x_{CM}) \le 0$

**b) Rear/Middle Ratio Constraint:**
Reference ratio $r_{RM} = 1/2$. Deviation limit $15\%$.
Allowed range for $W_R / W_M$: $[ \frac{1}{2}(0.85), \frac{1}{2}(1.15) ] = [ 0.425, 0.575 ] = [ \frac{17}{40}, \frac{23}{40} ]$

$$
\frac{17}{40} W_M \le W_R \le \frac{23}{40} W_M
$$
Substituting:
3. $40 W_R - 23 W_M \le 0$
4. $-40 W_R + 17 W_M \le 0$

Expanding:
3. $40(8x_{AR} + 6x_{BR} + 4x_{CR}) - 23(8x_{AM} + 6x_{BM} + 4x_{CM}) \le 0$
4. $-40(8x_{AR} + 6x_{BR} + 4x_{CR}) + 17(8x_{AM} + 6x_{BM} + 4x_{CM}) \le 0$

**c) Front/Rear Ratio Constraint:**
Reference ratio $r_{FR} = 4/3$. Deviation limit $10\%$.
Allowed range for $W_F / W_R$: $[ \frac{4}{3}(0.90), \frac{4}{3}(1.10) ] = [ \frac{3.6}{3}, \frac{4.4}{3} ] = [ 1.2, \frac{22}{15} ] = [ \frac{6}{5}, \frac{22}{15} ]$

$$
\frac{6}{5} W_R \le W_F \le \frac{22}{15} W_R
$$
Substituting:
5. $15 W_F - 22 W_R \le 0$
6. $-15 W_F + 6 W_R \le 0$  *(Note: $W_F \ge 1.2 W_R \iff 1.2 W_R - W_F \le 0 \iff 6 W_R - 5 W_F \le 0$. Multiplying by 3 to clear decimals: $18 W_R - 15 W_F \le 0$ or simplified $6 W_R - 5 W_F \le 0$. Let's use integers: $15 W_F \ge 18 W_R \Rightarrow 15 W_F - 18 W_R \ge 0 \Rightarrow -15 W_F + 18 W_R \le 0$. Dividing by 3: $-5 W_F + 6 W_R \le 0$.)*

Expanding:
5. $15(8x_{AF} + 6x_{BF} + 4x_{CF}) - 22(8x_{AR} + 6x_{BR} + 4x_{CR}) \le 0$
6. $-15(8x_{AF} + 6x_{BF} + 4x_{CF}) + 18(8x_{AR} + 6x_{BR} + 4x_{CR}) \le 0$
   *(Simplified: $-5(8x_{AF} + 6x_{BF} + 4x_{CF}) + 6(8x_{AR} + 6x_{BR} + 4x_{CR}) \le 0$)*

### 5. Non-negativity
$$
x_{jk} \ge 0, \quad \forall j \in C, k \in K
$$
