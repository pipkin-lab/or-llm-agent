To formulate this problem, we first perform the mandatory cost and data inventory.

**Data Inventory & Parameter Extraction:**

The problem involves allocating a budget of 5 million yuan among 3 factories. Each factory has a set of mutually exclusive "plans" (or investment levels). The goal is to maximize total return.

**Available Plans per Factory:**

*   **Factory 1:**
    *   Plan 1: Investment = 0, Return = 0
    *   Plan 2: Investment = 1, Return = 5
    *   Plan 3: Investment = 2, Return = 6
    *   Plan 4: Not available ("-")

*   **Factory 2:**
    *   Plan 1: Investment = 0, Return = 0
    *   Plan 2: Investment = 2, Return = 8
    *   Plan 3: Investment = 3, Return = 9
    *   Plan 4: Investment = 4, Return = 12

*   **Factory 3:**
    *   Plan 1: Investment = 0, Return = 0
    *   Plan 2: Investment = 1, Return = 3
    *   Plan 3: Not available ("-")
    *   Plan 4: Not available ("-")

**Budget Constraint:**
Total available funds = 5 million yuan.

**Objective:**
Maximize Total Return.

**Model Type:**
This is a **MILP** (Mixed Integer Linear Programming) problem. Specifically, it is a variant of the **Multiple-Choice Knapsack Problem (MCKP)** or a resource allocation problem with discrete choices. We need binary variables to select exactly one plan for each factory.

---

### Formal Mathematical Model

**Model Type:** MILP (Mixed Integer Linear Programming)

#### 1. Index Sets & Parameters

*   **Sets:**
    *   $I = \{1, 2, 3\}$: Set of factories.
    *   $J_i = \{j \mid \text{Plan } j \text{ is available for factory } i\}$: Set of available plans for factory $i$.
        *   $J_1 = \{1, 2, 3\}$
        *   $J_2 = \{1, 2, 3, 4\}$
        *   $J_3 = \{1, 2\}$

*   **Parameters:**
    *   $C = 5$: Total available budget (million yuan).
    *   $a_{i,j}$: Investment required for plan $j$ of factory $i$ (million yuan).
    *   $r_{i,j}$: Return generated by plan $j$ of factory $i$ (million yuan).

    **Parameter Values:**

    | $i$ | $j$ | $a_{i,j}$ (Investment) | $r_{i,j}$ (Return) |
    | :--- | :--- | :---: | :---: |
    | 1 | 1 | 0 | 0 |
    | 1 | 2 | 1 | 5 |
    | 1 | 3 | 2 | 6 |
    | 2 | 1 | 0 | 0 |
    | 2 | 2 | 2 | 8 |
    | 2 | 3 | 3 | 9 |
    | 2 | 4 | 4 | 12 |
    | 3 | 1 | 0 | 0 |
    | 3 | 2 | 1 | 3 |

#### 2. Decision Variables

*   $x_{i,j}$: Binary variable.
    *   $x_{i,j} = 1$ if plan $j$ is selected for factory $i$.
    *   $x_{i,j} = 0$ otherwise.
    *   Domain: $x_{i,j} \in \{0, 1\}$ for all $i \in I, j \in J_i$.

#### 3. Objective Function

Maximize the total return:

$$
\text{Maximize } Z = \sum_{i \in I} \sum_{j \in J_i} r_{i,j} x_{i,j}
$$

Expanding with specific values:
$$
\text{Maximize } Z = 0x_{1,1} + 5x_{1,2} + 6x_{1,3} + 0x_{2,1} + 8x_{2,2} + 9x_{2,3} + 12x_{2,4} + 0x_{3,1} + 3x_{3,2}
$$

#### 4. Operational Constraints

**A. Mutually Exclusive Selection (One plan per factory):**
Each factory must choose exactly one plan from its available set.

1.  For Factory 1:
    $$ x_{1,1} + x_{1,2} + x_{1,3} = 1 $$

2.  For Factory 2:
    $$ x_{2,1} + x_{2,2} + x_{2,3} + x_{2,4} = 1 $$

3.  For Factory 3:
    $$ x_{3,1} + x_{3,2} = 1 $$

**B. Budget Constraint:**
The total investment across all factories must not exceed the available budget of 5 million yuan.

$$
\sum_{i \in I} \sum_{j \in J_i} a_{i,j} x_{i,j} \le 5
$$

Expanding with specific values:
$$
0x_{1,1} + 1x_{1,2} + 2x_{1,3} + 0x_{2,1} + 2x_{2,2} + 3x_{2,3} + 4x_{2,4} + 0x_{3,1} + 1x_{3,2} \le 5
$$

**C. Domain Constraints:**
$$
x_{i,j} \in \{0, 1\} \quad \forall i \in I, j \in J_i
$$
