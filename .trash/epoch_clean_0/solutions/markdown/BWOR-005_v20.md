# Operations Research Model: Cargo Loading Optimization

## Model Type Declaration
**LP (Linear Programming)**
The objective function and all constraints are linear in the decision variables.

## Index Sets & Parameters

**Sets:**
- $C = \{1, 2, 3\}$: Set of cargo types, indexed by $i$.
  - $i=1$: Cargo A
  - $i=2$: Cargo B
  - $i=3$: Cargo C
- $K = \{1, 2, 3\}$: Set of compartments, indexed by $k$.
  - $k=1$: Front
  - $k=2$: Middle
  - $k=3$: Rear

**Parameters (extracted from tables):**

*Compartment Data:*
- $W_k$: Maximum allowable load (t)
  - $W_1 = 2000$, $W_2 = 3000$, $W_3 = 1500$
- $V_k$: Maximum volume capacity ($m^3$)
  - $V_1 = 4000$, $V_2 = 5000$, $V_3 = 1500$

*Cargo Data:*
- $Q_i$: Total available quantity (pieces)
  - $Q_1 = 600$, $Q_2 = 1000$, $Q_3 = 800$
- $v_i$: Volume per piece ($m^3$/piece)
  - $v_1 = 10$, $v_2 = 5$, $v_3 = 7$
- $w_i$: Weight per piece (t/piece)
  - $w_1 = 8$, $w_2 = 6$, $w_3 = 4$
- $r_i$: Freight rate (dollar/piece)
  - $r_1 = 1000$, $r_2 = 700$, $r_3 = 600$

*Balance Ratios (derived from max allowable loads):*
- Ratio Front/Middle: $R_{12} = W_1 / W_2 = 2000 / 3000 = 2/3$
- Ratio Rear/Middle: $R_{32} = W_3 / W_2 = 1500 / 3000 = 1/2$
- Ratio Front/Rear: $R_{13} = W_1 / W_3 = 2000 / 1500 = 4/3$

*Deviation Tolerances:*
- $\delta_{12} = 0.15$ (15% for Front/Middle and Rear/Middle)
- $\delta_{13} = 0.10$ (10% for Front/Rear)

## Decision Variables

Let $x_{i,k}$ be the number of pieces of cargo type $i$ loaded in compartment $k$.
- **Domain**: $x_{i,k} \in \mathbb{Z}^+$ (Non-negative integers, as cargo comes in discrete pieces).
  - *Note: While technically an Integer Linear Program (ILP) due to integrality, standard LP relaxation is often used in textbook formulations for large numbers. However, strictly speaking, "pieces" implies integers. Given the prompt asks for a "linear programming model" and the quantities are large, we will define them as continuous variables $x_{i,k} \ge 0$ for the LP formulation, but note that in practice, they should be integers. For strict adherence to "Linear Programming" (as opposed to Integer Programming) in many academic contexts, continuous is acceptable if fractional pieces are theoretically splittable, but here "pieces" are discrete. I will specify **Continuous** variables as per standard LP definition, but acknowledge the physical discreteness. If integer constraints are required, it becomes MILP. Let's stick to standard LP formulation variables $x_{i,k} \ge 0$.*
  - **Refined Domain**: $x_{i,k} \ge 0$ (Continuous). *Self-correction*: The problem asks for "How many pieces". Usually, this implies integers. However, "Formulate the linear programming model" usually allows for continuous relaxation unless "integer" is explicitly emphasized in the model type request. Given the large numbers (hundreds), the LP relaxation will likely yield integer or near-integer solutions. I will define them as **Continuous** variables $x_{i,k} \ge 0$ to fit the "LP" designation, but note that $x_{i,k}$ represents the count.

## Objective Function

Maximize total revenue:
$$
\text{Maximize } Z = \sum_{i=1}^{3} \sum_{k=1}^{3} r_i x_{i,k}
$$
Substituting values:
$$
Z = 1000(x_{1,1} + x_{1,2} + x_{1,3}) + 700(x_{2,1} + x_{2,2} + x_{2,3}) + 600(x_{3,1} + x_{3,2} + x_{3,3})
$$

## Operational Constraints

### 1. Supply Constraints (Availability)
The total quantity of each cargo type loaded cannot exceed the available quantity.
$$
\sum_{k=1}^{3} x_{i,k} \le Q_i \quad \forall i \in C
$$
- For Cargo A ($i=1$): $x_{1,1} + x_{1,2} + x_{1,3} \le 600$
- For Cargo B ($i=2$): $x_{2,1} + x_{2,2} + x_{2,3} \le 1000$
- For Cargo C ($i=3$): $x_{3,1} + x_{3,2} + x_{3,3} \le 800$

### 2. Volume Capacity Constraints
The total volume of cargo in each compartment must not exceed the compartment's volume capacity.
$$
\sum_{i=1}^{3} v_i x_{i,k} \le V_k \quad \forall k \in K
$$
- Front ($k=1$): $10 x_{1,1} + 5 x_{2,1} + 7 x_{3,1} \le 4000$
- Middle ($k=2$): $10 x_{1,2} + 5 x_{2,2} + 7 x_{3,2} \le 5000$
- Rear ($k=3$): $10 x_{1,3} + 5 x_{2,3} + 7 x_{3,3} \le 1500$

### 3. Weight Capacity Constraints
The total weight of cargo in each compartment must not exceed the compartment's maximum allowable load.
$$
\sum_{i=1}^{3} w_i x_{i,k} \le W_k \quad \forall k \in K
$$
- Front ($k=1$): $8 x_{1,1} + 6 x_{2,1} + 4 x_{3,1} \le 2000$
- Middle ($k=2$): $8 x_{1,2} + 6 x_{2,2} + 4 x_{3,2} \le 3000$
- Rear ($k=3$): $8 x_{1,3} + 6 x_{2,3} + 4 x_{3,3} \le 1500$

Let $W_k^{\text{actual}} = \sum_{i=1}^{3} w_i x_{i,k}$ be the actual weight in compartment $k$.

### 4. Balance Constraints (Maritime Safety)
The actual weight ratios must stay within specified tolerances of the ideal ratios derived from max capacities.

**A. Front/Middle Ratio Constraint**
Ideal Ratio $R_{12} = 2/3$. Tolerance $\pm 15\%$.
Allowed Range for $W_1^{\text{actual}} / W_2^{\text{actual}}$:
$$
\frac{2}{3}(1 - 0.15) \le \frac{W_1^{\text{actual}}}{W_2^{\text{actual}}} \le \frac{2}{3}(1 + 0.15)
$$
$$
\frac{2}{3}(0.85) \le \frac{W_1^{\text{actual}}}{W_2^{\text{actual}}} \le \frac{2}{3}(1.15)
$$
$$
0.5667 \le \frac{W_1^{\text{actual}}}{W_2^{\text{actual}}} \le 0.7667
$$
To linearize, we cross-multiply (assuming $W_2^{\text{actual}} > 0$, which is guaranteed if we load any significant cargo, and even if 0, the constraints handle bounds):
1. $W_1^{\text{actual}} \le 0.7667 W_2^{\text{actual}} \implies W_1^{\text{actual}} - 0.7667 W_2^{\text{actual}} \le 0$
2. $W_1^{\text{actual}} \ge 0.5667 W_2^{\text{actual}} \implies W_1^{\text{actual}} - 0.5667 W_2^{\text{actual}} \ge 0$

Substituting $W_k^{\text{actual}}$:
- $8 x_{1,1} + 6 x_{2,1} + 4 x_{3,1} - 0.7667(8 x_{1,2} + 6 x_{2,2} + 4 x_{3,2}) \le 0$
- $8 x_{1,1} + 6 x_{2,1} + 4 x_{3,1} - 0.5667(8 x_{1,2} + 6 x_{2,2} + 4 x_{3,2}) \ge 0$

**B. Rear/Middle Ratio Constraint**
Ideal Ratio $R_{32} = 1/2 = 0.5$. Tolerance $\pm 15\%$.
Allowed Range for $W_3^{\text{actual}} / W_2^{\text{actual}}$:
$$
0.5(0.85) \le \frac{W_3^{\text{actual}}}{W_2^{\text{actual}}} \le 0.5(1.15)
$$
$$
0.425 \le \frac{W_3^{\text{actual}}}{W_2^{\text{actual}}} \le 0.575
$$
Linearized:
1. $W_3^{\text{actual}} - 0.575 W_2^{\text{actual}} \le 0$
2. $W_3^{\text{actual}} - 0.425 W_2^{\text{actual}} \ge 0$

Substituting $W_k^{\text{actual}}$:
- $8 x_{1,3} + 6 x_{2,3} + 4 x_{3,3} - 0.575(8 x_{1,2} + 6 x_{2,2} + 4 x_{3,2}) \le 0$
- $8 x_{1,3} + 6 x_{2,3} + 4 x_{3,3} - 0.425(8 x_{1,2} + 6 x_{2,2} + 4 x_{3,2}) \ge 0$

**C. Front/Rear Ratio Constraint**
Ideal Ratio $R_{13} = 4/3 \approx 1.3333$. Tolerance $\pm 10\%$.
Allowed Range for $W_1^{\text{actual}} / W_3^{\text{actual}}$:
$$
\frac{4}{3}(0.9) \le \frac{W_1^{\text{actual}}}{W_3^{\text{actual}}} \le \frac{4}{3}(1.1)
$$
$$
1.2 \le \frac{W_1^{\text{actual}}}{W_3^{\text{actual}}} \le 1.4667
$$
Linearized:
1. $W_1^{\text{actual}} - 1.4667 W_3^{\text{actual}} \le 0$
2. $W_1^{\text{actual}} - 1.2 W_3^{\text{actual}} \ge 0$

Substituting $W_k^{\text{actual}}$:
- $8 x_{1,1} + 6 x_{2,1} + 4 x_{3,1} - 1.4667(8 x_{1,3} + 6 x_{2,3} + 4 x_{3,3}) \le 0$
- $8 x_{1,1} + 6 x_{2,1} + 4 x_{3,1} - 1.2(8 x_{1,3} + 6 x_{2,3} + 4 x_{3,3}) \ge 0$

### 5. Non-negativity
$$
x_{i,k} \ge 0 \quad \forall i \in C, k \in K
$$
