To solve this problem, we must determine the minimum number of nurses required such that the staffing constraints for each time period are met, given the specific rotation pattern of "Plan 1".

### 1. Problem Analysis & Model Type

**Model Type:** Integer Linear Programming (ILP) / Linear Programming (LP)
*Note: Since the number of nurses must be an integer, strictly speaking, this is an Integer Program. However, in shift scheduling problems of this structure (cyclic staff scheduling), the constraint matrix is often Totally Unimodular, meaning the LP relaxation yields integer solutions. We will formulate it as an Integer Program to be precise, but it can be solved as an LP.*

### Formal Model

**Index Sets:**
*   $D = \{1, 2, 3, 4, 5, 6, 7\}$: Days of the week (Mon=1, Tue=2, ..., Sun=7).
*   $T = \{1, 2, 3, 4, 5\}$: Time periods (1: 6-10, 2: 10-14, 3: 14-18, 4: 18-22, 5: 22-6).

**Parameters:**
*   $R_t$: Required nurses for time period $t$.
    *   $R_1 = 18$
    *   $R_2 = 20$
    *   $R_3 = 19$
    *   $R_4 = 17$
    *   $R_5 = 12$
*   $A_{d, s}$: Matrix indicating if a nurse starting on day $d$ works on Shift $s$ on day $d'$.
    Actually, it is easier to define the constraints explicitly for each day $d \in D$ as derived above.

**Decision Variables:**
*   $y_d$: Number of nurses starting their 5-day work block on day $d$ ($d \in \{1,..,7\}$).
    *   Domain: $y_d \in \mathbb{Z}^+$ (Non-negative Integers).

**Objective Function:**
Minimize Total Number of Nurses:
$$ \text{Minimize } Z = \sum_{d=1}^{7} y_d $$

**Operational Constraints:**

For each day $d \in \{1,..,7\}$, let $N_{Sh1}^{(d)}, N_{Sh2}^{(d)}, N_{Sh3}^{(d)}, N_{Sh4}^{(d)}, N_{Sh5}^{(d)}$ be the number of nurses on each shift on that day.
Based on the rotation logic (Shift $k$ on day $d$ is worked by nurses who started $k-1$ days before $d$):
*   $N_{Sh1}^{(d)} = y_d$
*   $N_{Sh2}^{(d)} = y_{d-1}$ (where $0 \to 7, 1 \to 7$)
*   $N_{Sh3}^{(d)} = y_{d-2}$
*   $N_{Sh4}^{(d)} = y_{d-3}$
*   $N_{Sh5}^{(d)} = y_{d-4}$

*(Note: Indices are modulo 7. E.g., for Monday $d=1$, $d-1=0 \equiv 7$, $d-2=6$, $d-3=5$, $d-4=4$).*

The coverage constraints for each time period $t$ on each day $d$ are:
1.  $N_{Sh1}^{(d)} + N_{Sh2}^{(d)} \ge R_1$
2.  $N_{Sh2}^{(d)} + N_{Sh3}^{(d)} \ge R_2$
3.  $N_{Sh3}^{(d)} + N_{Sh4}^{(d)} \ge R_3$
4.  $N_{Sh4}^{(d)} + N_{Sh5}^{(d)} \ge R_4$
5.  $N_{Sh5}^{(d)} + N_{Sh1}^{(d)} \ge R_5$
