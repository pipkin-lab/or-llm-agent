# Model Type Declaration
**MILP (Mixed Integer Linear Programming)**
*Note: Since the investment amounts are discrete integers (0, 1, 2, 3, 4 thousand yuan) and the benefit function is non-linear (discrete points), we use binary expansion variables to linearize the relationship.*

### MANDATORY COST INVENTORY (PRE-MODELING STEP)
- **Total Capital**: 4 thousand yuan.
- **Benefit Parameters (Objective Coefficients)**:
  - Project A: $f_A(0)=0, f_A(1)=41, f_A(2)=48, f_A(3)=60, f_A(4)=66$.
  - Project B: $f_B(0)=0, f_B(1)=42, f_B(2)=50, f_B(3)=60, f_B(4)=66$.
  - Project C: $f_C(0)=0, f_C(1)=64, f_C(2)=68, f_C(3)=78, f_C(4)=76$.
- **Costs**: The "cost" of investment is the capital consumed. The objective is to maximize total benefit. The coefficients in the objective function are the benefit values from the table.

### Index Sets & Parameters

**Index Sets:**
- $J = \{A, B, C\}$: Set of projects.
- $K = \{1, 2, 3, 4\}$: Set of possible investment levels (in thousand yuan). Note that level 0 is handled by the absence of any selected level.

**Parameters:**
- $M$: Total available capital = 4 (thousand yuan).
- $B_{j,k}$: Benefit (thousand yuan) from investing amount $k$ in project $j$.
  - $B_{A,1}=41, B_{A,2}=48, B_{A,3}=60, B_{A,4}=66$
  - $B_{B,1}=42, B_{B,2}=50, B_{B,3}=60, B_{B,4}=66$
  - $B_{C,1}=64, B_{C,2}=68, B_{C,3}=78, B_{C,4}=76$

### Decision Variables

Let $x_{j,k}$ be a binary variable for each project $j \in J$ and investment level $k \in K$:
$$
x_{j,k} = 
\begin{cases} 
1 & \text{if project } j \text{ receives exactly } k \text{ thousand yuan} \\
0 & \text{otherwise}
\end{cases}
$$
**Domain:** $x_{j,k} \in \{0, 1\}$ for all $j \in J, k \in K$.

### Objective Function

Maximize the total benefit $Z$:
$$
\text{Maximize } Z = \sum_{j \in J} \sum_{k \in K} B_{j,k} x_{j,k}
$$
Expanding this with the given values:
$$
Z = 41x_{A,1} + 48x_{A,2} + 60x_{A,3} + 66x_{A,4} + 42x_{B,1} + 50x_{B,2} + 60x_{B,3} + 66x_{B,4} + 64x_{C,1} + 68x_{C,2} + 78x_{C,3} + 76x_{C,4}
$$

### Operational Constraints

1. **Single Investment Level per Project:**
   Each project can receive at most one specific investment amount. Since investing 0 is equivalent to selecting no $k \in \{1,2,3,4\}$, we enforce that the sum of selected levels for each project is $\le 1$.
   $$
   \sum_{k=1}^{4} x_{j,k} \le 1, \quad \forall j \in J
   $$
   - For A: $x_{A,1} + x_{A,2} + x_{A,3} + x_{A,4} \le 1$
   - For B: $x_{B,1} + x_{B,2} + x_{B,3} + x_{B,4} \le 1$
   - For C: $x_{C,1} + x_{C,2} + x_{C,3} + x_{C,4} \le 1$

2. **Capital Constraint:**
   The total amount invested across all projects cannot exceed the available capital (4 thousand yuan).
   $$
   \sum_{j \in J} \sum_{k \in K} k \cdot x_{j,k} \le M
   $$
   $$
   1(x_{A,1} + x_{B,1} + x_{C,1}) + 2(x_{A,2} + x_{B,2} + x_{C,2}) + 3(x_{A,3} + x_{B,3} + x_{C,3}) + 4(x_{A,4} + x_{B,4} + x_{C,4}) \le 4
   $$

3. **Variable Bounds:**
   $$
   x_{j,k} \in \{0, 1\}, \quad \forall j \in J, k \in K
   $$

---
**Feasibility Sanity Check:**
- Total capital is 4.
- We can invest in up to 3 projects.
- Example feasible solution: Invest 1 in A, 1 in B, 2 in C. Total cost = $1+1+2=4 \le 4$.
  - Benefits: $41 + 42 + 68 = 151$.
- Example feasible solution: Invest 2 in A, 2 in B, 0 in C. Total cost = $2+2+0=4 \le 4$.
  - Benefits: $48 + 50 + 0 = 98$.
- Example feasible solution: Invest 0 in A, 0 in B, 4 in C. Total cost = 4.
  - Benefits: $76$.
- Example feasible solution: Invest 1 in A, 3 in B, 0 in C. Total cost = 4.
  - Benefits: $41 + 60 = 101$.

The model is well-posed and feasible. The solver will find the optimal combination of discrete investments that sums to $\le 4$ and maximizes the sum of the corresponding benefits.
