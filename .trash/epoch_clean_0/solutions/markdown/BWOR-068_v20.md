## Model Type: MILP

### Index Sets & Parameters

**Index Sets:**
- $t \in \{1, 2, 3, 4, 5, 6\}$: Time periods (months), where $t=1$ is October, $t=2$ is November, ..., $t=6$ is March.

**Parameters:**
- $D_t$: Demand in month $t$ (pairs).
  - $D_1 = 40, D_2 = 20, D_3 = 30, D_4 = 40, D_5 = 30, D_6 = 20$.
- $K = \{1, 2, 3, 4, 5\}$: Set of possible order quantity levels.
- $q_k$: Order quantity for level $k$ (pairs).
  - $q_1 = 10, q_2 = 20, q_3 = 30, q_4 = 40, q_5 = 50$.
- $C_k$: Variable cost associated with ordering level $k$ (yuan).
  - $C_1 = 48, C_2 = 86, C_3 = 118, C_4 = 138, C_5 = 160$.
- $F$: Fixed ordering cost per order (yuan).
  - $F = 10$.
- $h$: Holding cost per pair per month (yuan).
  - $h = 0.2$.
- $I_{max}$: Maximum end-of-month inventory (pairs).
  - $I_{max} = 40$.

### Decision Variables

- $y_{t,k} \in \{0, 1\}$: Binary variable for each month $t$ and order level $k \in K$.
  - $y_{t,k} = 1$ if an order of size $q_k$ is placed in month $t$, otherwise 0.
- $I_t \ge 0$: Continuous variable representing the inventory at the end of month $t$ (pairs).

### Objective Function

Minimize the total cost over the 6 months, which includes the fixed ordering cost, the variable ordering cost, and the inventory holding cost.

$$
\text{Minimize } Z = \sum_{t=1}^{6} \left[ F \cdot \left( \sum_{k=1}^{5} y_{t,k} \right) + \sum_{k=1}^{5} C_k \cdot y_{t,k} + h \cdot I_t \right]
$$

Substituting the parameter values:

$$
\text{Minimize } Z = \sum_{t=1}^{6} \left[ 10 \cdot \left( \sum_{k=1}^{5} y_{t,k} \right) + 48 y_{t,1} + 86 y_{t,2} + 118 y_{t,3} + 138 y_{t,4} + 160 y_{t,5} + 0.2 I_t \right]
$$

### Operational Constraints

**1. Single Order Constraint:**
At most one order level can be selected in any given month. (The problem states "possible order quantities... are limited to...", implying a single choice of order size per month if ordering occurs. It is possible to order 0, which is handled by allowing all $y_{t,k}=0$).

$$
\sum_{k=1}^{5} y_{t,k} \le 1, \quad \forall t \in \{1, \dots, 6\}
$$

**2. Inventory Balance Constraint:**
The inventory at the end of month $t$ ($I_t$) is the inventory from the previous month ($I_{t-1}$) plus the order placed in month $t$ minus the demand in month $t$.
Note: $I_0 = 0$ (beginning of season inventory is zero).

$$
I_t = I_{t-1} + \sum_{k=1}^{5} q_k \cdot y_{t,k} - D_t, \quad \forall t \in \{1, \dots, 6\}
$$

Explicitly:
- $I_1 = 0 + 10y_{1,1} + 20y_{1,2} + 30y_{1,3} + 40y_{1,4} + 50y_{1,5} - 40$
- $I_2 = I_1 + 10y_{2,1} + 20y_{2,2} + 30y_{2,3} + 40y_{2,4} + 50y_{2,5} - 20$
- $I_3 = I_2 + 10y_{3,1} + 20y_{3,2} + 30y_{3,3} + 40y_{3,4} + 50y_{3,5} - 30$
- $I_4 = I_3 + 10y_{4,1} + 20y_{4,2} + 30y_{4,4} + 40y_{4,4} + 50y_{4,5} - 40$ *(Correction: $30y_{4,3}$)*
- $I_5 = I_4 + 10y_{5,1} + 20y_{5,2} + 30y_{5,3} + 40y_{5,4} + 50y_{5,5} - 30$
- $I_6 = I_5 + 10y_{6,1} + 20y_{6,2} + 30y_{6,3} + 40y_{6,4} + 50y_{6,5} - 20$

**3. Inventory Capacity Constraint:**
The end-of-month inventory must not exceed 40 pairs.

$$
I_t \le 40, \quad \forall t \in \{1, \dots, 6\}
$$

**4. End-of-Season Inventory Constraint:**
The inventory at the end of the peak season (end of March, month 6) must be zero.

$$
I_6 = 0
$$

**5. Non-negativity and Integrality:**
- $I_t \ge 0, \quad \forall t \in \{1, \dots, 6\}$
- $y_{t,k} \in \{0, 1\}, \quad \forall t \in \{1, \dots, 6\}, \forall k \in \{1, \dots, 5\}$
