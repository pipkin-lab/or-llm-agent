## Model Type: **LP** (Linear Programming)

## Index Sets & Parameters

**Index Sets:**
- $O = \{X, Y\}$: Supply origins
- $D = \{A, B, C\}$: Demand destinations
- $T = \{A, B, C\}$: Transshipment nodes (destinations can also act as transshipment points)

**Parameters (distances in km):**

*Supply capacities (tons):*
- $S_X = 70$
- $S_Y = 55$

*Demand requirements (tons):*
- $D_A = 35$
- $D_B = 40$
- $D_C = 50$

*Distance matrices (km):*

**Between origins (Table 3-23):**
- $d_{X,Y} = 12$
- $d_{Y,X} = 10$

**From origins to destinations (Table 3-24):**
- $d_{X,A} = 10$, $d_{X,B} = 14$, $d_{X,C} = 12$
- $d_{Y,A} = 15$, $d_{Y,B} = 12$, $d_{Y,C} = 18$

**Between destinations/transshipment points (Table 3-25):**
- $d_{A,B} = 14$, $d_{A,C} = 11$
- $d_{B,A} = 10$, $d_{B,C} = 4$
- $d_{C,A} = 8$, $d_{C,B} = 12$

## Decision Variables

Let $x_{ij}$ = tons of goods shipped directly from node $i$ to node $j$, where $i \in \{X, Y, A, B, C\}$ and $j \in \{A, B, C\}$, $i \neq j$.

All variables are **CONTINUOUS** and non-negative: $x_{ij} \geq 0$.

Specifically:
- $x_{X,A}, x_{X,B}, x_{X,C} \geq 0$: shipments from X to A, B, C
- $x_{Y,A}, x_{Y,B}, x_{Y,C} \geq 0$: shipments from Y to A, B, C
- $x_{A,B}, x_{A,C} \geq 0$: transshipments from A to B, C
- $x_{B,A}, x_{B,C} \geq 0$: transshipments from B to A, C
- $x_{C,A}, x_{C,B} \geq 0$: transshipments from C to A, B

## Objective Function

**MINIMIZE** total transport distance:

$$\min Z = 10\,x_{X,A} + 14\,x_{X,B} + 12\,x_{X,C} + 15\,x_{Y,A} + 12\,x_{Y,B} + 18\,x_{Y,C} + 14\,x_{A,B} + 11\,x_{A,C} + 10\,x_{B,A} + 4\,x_{B,C} + 8\,x_{C,A} + 12\,x_{C,B}$$

## Operational Constraints

**Supply constraints (equality — all supply must be dispatched):**

$$x_{X,A} + x_{X,B} + x_{X,C} = 70$$
$$x_{Y,A} + x_{Y,B} + x_{Y,C} = 55$$

**Demand/transshipment flow-balance constraints (net inflow must equal demand):**

For each destination $j \in \{A, B, C\}$, the total inflow minus total outflow must equal the demand at that node:

**Node A:**
$$x_{X,A} + x_{Y,A} + x_{B,A} + x_{C,A} - x_{A,B} - x_{A,C} = 35$$

**Node B:**
$$x_{X,B} + x_{Y,B} + x_{A,B} + x_{C,B} - x_{B,A} - x_{B,C} = 40$$

**Node C:**
$$x_{X,C} + x_{Y,C} + x_{A,C} + x_{B,C} - x_{C,A} - x_{C,B} = 50$$

**Non-negativity bounds:**
$$x_{X,A}, x_{X,B}, x_{X,C}, x_{Y,A}, x_{Y,B}, x_{Y,C}, x_{A,B}, x_{A,C}, x_{B,A}, x_{B,C}, x_{C,A}, x_{C,B} \geq 0$$

## Feasibility Sanity Check

- Total supply: $70 + 55 = 125$ tons
- Total demand: $35 + 40 + 50 = 125$ tons
- Supply equals demand → balanced transportation problem. The model is feasible.

**Verification of flow-balance logic:** Each destination node can both receive and forward goods (transshipment). The net flow into each node (inflow minus outflow) must exactly satisfy its demand. Goods that pass through a node (transshipped) appear on both the inflow and outflow sides, netting to zero for that portion, while the residual net inflow satisfies the local demand. This correctly models the transshipment network.
