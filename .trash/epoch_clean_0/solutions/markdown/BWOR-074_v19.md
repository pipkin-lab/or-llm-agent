To determine the optimal sorting order that minimizes the total sorting workload, we must first define the "workload" metric and establish the mathematical model for the sorting process.

### 1. Problem Analysis & Parameter Extraction

**Context:**
*   Total participants ($N$): 50,000.
*   Grades: $G = \{A, B, C, D, E\}$.
*   Distribution (Percentages):
    *   $p_A = 10\% = 0.10$
    *   $p_B = 25\% = 0.25$
    *   $p_C = 30\% = 0.30$
    *   $p_D = 20\% = 0.20$
    *   $p_E = 15\% = 0.15$
*   Process: The computer scans the remaining pile of unsorted sheets to find sheets of a specific grade. Each scan removes one sheet of that grade from the pile. The process repeats until all sheets are sorted.
*   Workload Definition: "Total sorting workload" in this context (sequential extraction) is typically defined as the total number of **scans** (or comparisons) required to extract all items. When extracting the $k$-th grade, the computer must scan through the previously sorted items (or rather, the items that are *not* of the current grade are skipped/checked) to find the next matching item.
    *   *Interpretation Check*: If the machine "recognizes one grade at a time," it implies a linear search through the *remaining* unsorted pool.
    *   Let $n_i$ be the count of grade $i$.
    *   If we sort grade $j$ first, we scan the entire pile of $N$ items to find all $n_j$ items. The number of scans to extract all items of grade $j$ from a pile of size $S$ is effectively $S$ (scanning every item to check if it is $j$). Once grade $j$ is removed, the pile size reduces to $S - n_j$.
    *   Total Workload $W = \sum_{k=1}^{5} S_{k}$, where $S_k$ is the size of the pile at the start of the $k$-th sorting phase.
    *   $S_1 = N$.
    *   $S_2 = N - n_{\sigma(1)}$ (where $\sigma(1)$ is the first grade selected).
    *   $S_3 = N - n_{\sigma(1)} - n_{\sigma(2)}$.
    *   ...
    *   $S_5 = n_{\sigma(5)}$.
    *   $S_6 = 0$ (Done).
    *   Total Scans $W = S_1 + S_2 + S_3 + S_4 + S_5$.

    Alternatively, this is equivalent to the weighted sum of the number of items "passed over" or the sum of remaining items. A more robust way to view this is:
    Each item of grade $i$ contributes to the workload of every sorting phase that occurs *before* it is extracted, plus its own extraction phase? No, simpler:
    The cost of extracting grade $\sigma(k)$ is the current pile size $S_k$.
    $W(\sigma) = \sum_{k=1}^{5} S_k$.
    
    Let's expand $S_k$:
    $S_1 = N$
    $S_2 = N - n_{\sigma(1)}$
    $S_3 = N - n_{\sigma(1)} - n_{\sigma(2)}$
    $S_4 = N - n_{\sigma(1)} - n_{\sigma(2)} - n_{\sigma(3)}$
    $S_5 = N - n_{\sigma(1)} - n_{\sigma(2)} - n_{\sigma(3)} - n_{\sigma(4)} = n_{\sigma(5)}$
    
    $W = 5N - 4n_{\sigma(1)} - 3n_{\sigma(2)} - 2n_{\sigma(3)} - 1n_{\sigma(4)} - 0n_{\sigma(5)}$.
    
    To **minimize** $W$, we need to **maximize** the subtracted term:
    $\text{Maximize } Z = 4n_{\sigma(1)} + 3n_{\sigma(2)} + 2n_{\sigma(3)} + 1n_{\sigma(4)} + 0n_{\sigma(5)}$.
    
    This is a classic assignment problem. To maximize the weighted sum where weights are decreasing ($4,3,2,1,0$), we must assign the **largest** counts to the **largest** weights.
    
    Therefore, the grade with the **largest count** should be sorted **first**. The grade with the **smallest count** should be sorted **last**.

    Let's verify the counts:
    *   $N = 50,000$
    *   $n_A = 5,000$
    *   $n_B = 12,500$
    *   $n_C = 15,000$
    *   $n_D = 10,000$
    *   $n_E = 7,500$

    Ranking by count (Descending):
    1.  C (15,000)
    2.  B (12,500)
    3.  D (10,000)
    4.  E (7,500)
    5.  A (5,000)

    Optimal Order: **C, B, D, E, A**.

    Let's double-check the logic.
    If we pick the largest group first, we remove the most items from the pile immediately, minimizing the size of the pile for all subsequent steps.
    If we pick the smallest group first, the pile remains large for many more steps, increasing the total sum of pile sizes.

    **Model Type:** This can be formulated as a Linear Assignment Problem (or simply a greedy sorting rule based on the derived objective). Since the question asks for the *order*, we will formulate it as a Permutation Optimization Problem (Assignment Problem).

### 2. Mathematical Formulation

**Index Sets & Parameters**

*   $G = \{A, B, C, D, E\}$: Set of grades.
*   $K = \{1, 2, 3, 4, 5\}$: Set of sorting positions (1st, 2nd, ..., 5th).
*   $N = 50,000$: Total number of participants.
*   $p_g$: Proportion of grade $g$.
    *   $p_A = 0.10$
    *   $p_B = 0.25$
    *   $p_C = 0.30$
    *   $p_D = 0.20$
    *   $p_E = 0.15$
*   $n_g = N \times p_g$: Absolute count of grade $g$.
    *   $n_A = 5,000$
    *   $n_B = 12,500$
    *   $n_C = 15,000$
    *   $n_D = 10,000$
    *   $n_E = 7,500$
*   $w_k$: Workload weight for position $k$.
    *   The number of times an item removed at position $k$ "costs" a scan in subsequent steps is related to how many steps remain.
    *   From the derivation $W = 5N - \sum_{k=1}^{5} (5-k)n_{\sigma(k)}$, the coefficient for $n_{\sigma(k)}$ in the *reduction* of workload is $5-k$.
    *   To minimize $W$, we maximize $\sum_{k=1}^{5} (5-k)n_{\sigma(k)}$.
    *   Let $c_k = 5-k$ be the benefit coefficient for placing a grade at position $k$.
        *   $c_1 = 4$
        *   $c_2 = 3$
        *   $c_3 = 2$
        *   $c_4 = 1$
        *   $c_5 = 0$

**Decision Variables**

*   $x_{g,k} \in \{0, 1\}$: Binary variable where $x_{g,k} = 1$ if grade $g$ is assigned to sorting position $k$, and 0 otherwise.

**Objective Function**

Minimize Total Workload $W$.
As derived, minimizing $W$ is equivalent to maximizing the benefit $Z$:
$$ \text{Maximize } Z = \sum_{k=1}^{5} \sum_{g \in G} (5-k) n_g x_{g,k} $$

*Note: Since $W = 5N - Z$, minimizing $W$ is mathematically identical to maximizing $Z$. We will state the objective as minimizing the actual workload for clarity, but the solver will handle the maximization of the benefit term or direct minimization of the expanded sum.*

Direct Minimization Form:
$$ \text{Minimize } W = \sum_{k=1}^{5} S_k $$
Where $S_k = N - \sum_{j=1}^{k-1} \sum_{g \in G} n_g x_{g,j}$.
This is non-linear due to the product of variables in the sum if expanded directly, but since it's an assignment problem, we use the linear equivalent:
$$ \text{Minimize } \sum_{g \in G} \sum_{k=1}^{5} k \cdot n_g \cdot x_{g,k} \quad \text{(Wait, let's re-verify the linear form)} $$

Let's re-evaluate the linear cost coefficient for position $k$.
Total Workload $W = \sum_{k=1}^5 S_k$.
$S_k = \sum_{m=k}^5 n_{\sigma(m)}$. (Sum of counts of grades sorted at $k$ or later).
$W = \sum_{k=1}^5 \sum_{m=k}^5 n_{\sigma(m)} = \sum_{m=1}^5 n_{\sigma(m)} \cdot (\text{number of } k \text{ such that } k \le m)$.
The number of $k \in \{1..5\}$ such that $k \le m$ is exactly $m$.
So, $W = \sum_{m=1}^5 m \cdot n_{\sigma(m)}$.

Therefore, the objective is:
$$ \text{Minimize } \sum_{g \in G} \sum_{k=1}^{5} k \cdot n_g \cdot x_{g,k} $$

This confirms: We want to assign large $n_g$ to small $k$ (early positions) to minimize the sum.
Coefficient for position 1 is 1.
Coefficient for position 2 is 2.
...
Coefficient for position 5 is 5.

**Operational Constraints**

1.  Each grade is assigned to exactly one position:
    $$ \sum_{k=1}^{5} x_{g,k} = 1, \quad \forall g \in G $$
2.  Each position is assigned exactly one grade:
    $$ \sum_{g \in G} x_{g,k} = 1, \quad \forall k \in K $$
3.  Binary constraint:
    $$ x_{g,k} \in \{0, 1\}, \quad \forall g \in G, k \in K $$

**Solution Derivation (Greedy Verification)**

To minimize $\sum k \cdot n_{\sigma(k)}$, we assign the largest $n$ to the smallest $k$.

Counts:
*   $n_C = 15,000$ (Largest) $\rightarrow$ Position 1 (Coeff 1)
*   $n_B = 12,500$ (2nd Largest) $\rightarrow$ Position 2 (Coeff 2)
*   $n_D = 10,000$ (3rd Largest) $\rightarrow$ Position 3 (Coeff 3)
*   $n_E = 7,500$ (4th Largest) $\rightarrow$ Position 4 (Coeff 4)
*   $n_A = 5,000$ (Smallest) $\rightarrow$ Position 5 (Coeff 5)

Order: **C, B, D, E, A**.

### Final Answer

**Model Type:** MILP (Mixed Integer Linear Programming) - specifically an Assignment Problem.

**Index Sets & Parameters**
*   $G = \{A, B, C, D, E\}$
*   $K = \{1, 2, 3, 4, 5\}$
*   $N = 50,000$
*   Counts $n_g$:
    *   $n_A = 5,000$
    *   $n_B = 12,500$
    *   $n_C = 15,000$
    *   $n_D = 10,000$
    *   $n_E = 7,500$

**Decision Variables**
*   $x_{g,k} \in \{0, 1\}$: 1 if grade $g$ is sorted at position $k$.

**Objective Function**
$$ \text{Minimize } Z = \sum_{g \in G} \sum_{k \in K} k \cdot n_g \cdot x_{g,k} $$

**Operational Constraints**
$$ \sum_{k=1}^{5} x_{g,k} = 1, \quad \forall g \in G $$
$$ \sum_{g \in G} x_{g,k} = 1, \quad \forall k \in K $$
$$ x_{g,k} \in \{0, 1\} $$

**Optimal Sorting Order**
Based on the assignment of largest counts to earliest positions (lowest $k$):
1.  Grade **C** (15,000 sheets)
2.  Grade **B** (12,500 sheets)
3.  Grade **D** (10,000 sheets)
4.  Grade **E** (7,500 sheets)
5.  Grade **A** (5,000 sheets)

The optimal order is **C, B, D, E, A**.
