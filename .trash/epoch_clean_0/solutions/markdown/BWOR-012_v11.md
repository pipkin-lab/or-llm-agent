### Mathematical Formulation

**Model Type:** Linear Programming (LP) - Specifically, a Preemptive Goal Programming model.

**Index Sets:**
*   $G = \{I, II, III\}$: Set of base liquor grades.
*   $B = \{R, Y, B\}$: Set of branded liquors (Red, Yellow, Blue). Note: Using $B$ for both Blue and Set is confusing. Let $K = \{Red, Yellow, Blue\}$.

**Parameters:**
*   $S_g$: Daily supply of grade $g$ (kg).
    *   $S_I = 1500, S_{II} = 2000, S_{III} = 1000$.
*   $C_g$: Cost of grade $g$ (Yuan/kg).
    *   $C_I = 6.0, C_{II} = 4.5, C_{III} = 3.0$.
*   $P_k$: Selling price of brand $k$ (Yuan/kg).
    *   $P_{Red} = 5.5, P_{Yellow} = 5.0, P_{Blue} = 4.8$.
*   $\alpha_k$: Minimum required percentage of Grade I in brand $k$.
    *   $\alpha_{Red} = 0.50, \alpha_{Yellow} = 0.20, \alpha_{Blue} = 0.10$.
*   $\beta_k$: Maximum allowed percentage of Grade III in brand $k$.
    *   $\beta_{Red} = 0.10, \beta_{Yellow} = 0.70, \beta_{Blue} = 0.50$.
*   $T_{Red}$: Target daily production of Red brand (kg).
    *   $T_{Red} = 2000$.

**Decision Variables:**
*   $x_{g,k}$: Amount of grade $g$ base liquor (kg) used in brand $k$. Domain: $x_{g,k} \ge 0, \forall g \in G, k \in K$.
*   $X_k$: Total amount of brand $k$ produced (kg). Domain: $X_k \ge 0$.
*   $d_{g,k}^-$: Negative deviation (shortfall) for minimum Grade I requirement in brand $k$ (kg). Domain: $d_{g,k}^- \ge 0$. (Specifically for Grade I).
*   $d_{g,k}^+$: Positive deviation (excess) for maximum Grade III requirement in brand $k$ (kg). Domain: $d_{g,k}^+ \ge 0$. (Specifically for Grade III).
*   $d_{Red}^-$: Negative deviation (shortfall) for Red brand production target (kg). Domain: $d_{Red}^- \ge 0$.
*   $Z$: Total daily profit (Yuan). Domain: $Z \in \mathbb{R}$.

**Objective Function:**
Minimize the lexicographic vector:
$$ \text{Lex Min } \left( \begin{aligned} & \text{Level 1: } \sum_{k \in K} (d_{I,k}^- + d_{III,k}^+) \\ & \text{Level 2: } -Z \\ & \text{Level 3: } d_{Red}^- \end{aligned} \right) $$

**Operational Constraints:**

1.  **Supply Constraints (Hard Constraints):**
    For each grade $g \in G$, the total usage cannot exceed the daily supply.
    $$ \sum_{k \in K} x_{g,k} \le S_g, \quad \forall g \in G $$
    Specifically:
    $$ x_{I,Red} + x_{I,Yellow} + x_{I,Blue} \le 1500 $$
    $$ x_{II,Red} + x_{II,Yellow} + x_{II,Blue} \le 2000 $$
    $$ x_{III,Red} + x_{III,Yellow} + x_{III,Blue} \le 1000 $$

2.  **Production Balance (Definition of Total Production):**
    For each brand $k \in K$:
    $$ X_k = \sum_{g \in G} x_{g,k} $$

3.  **Blending Goal Constraints (Soft Constraints for Priority 1):**
    These constraints define the deviations from the strict blending requirements.
    
    *Minimum Grade I Requirement:* $x_{I,k} \ge \alpha_k X_k$
    $$ x_{I,k} - \alpha_k X_k + d_{I,k}^+ - d_{I,k}^- = 0, \quad \forall k \in K $$
    *(Note: $d_{I,k}^+$ is not minimized, only $d_{I,k}^-$ is. We can omit $d_{I,k}^+$ from the objective but must keep it in the constraint for equality. Actually, since it's an inequality direction, we can just write $x_{I,k} - \alpha_k X_k + d_{I,k}^+ - d_{I,k}^- = 0$. Since we minimize $d^-$, the solver will push $d^-$ to 0 if possible. $d^+$ will be positive if we exceed the minimum, which is good/neutral.)*

    *Maximum Grade III Requirement:* $x_{III,k} \le \beta_k X_k$
    $$ x_{III,k} - \beta_k X_k + d_{III,k}^+ - d_{III,k}^- = 0, \quad \forall k \in K $$
    *(Note: We minimize $d_{III,k}^+$. $d_{III,k}^-$ is not minimized.)*

4.  **Red Brand Production Goal (Soft Constraint for Priority 3):**
    Target: $X_{Red} \ge 2000$
    $$ X_{Red} + d_{Red}^+ - d_{Red}^- = 2000 $$
    *(Note: We minimize $d_{Red}^-$. $d_{Red}^+$ is not minimized.)*

5.  **Profit Definition (For Priority 2):**
    $$ Z = \sum_{k \in K} P_k X_k - \sum_{g \in G} C_g \left( \sum_{k \in K} x_{g,k} \right) $$
    Expanded:
    $$ Z = 5.5 X_{Red} + 5.0 X_{Yellow} + 4.8 X_{Blue} - \left( 6.0 \sum_{k} x_{I,k} + 4.5 \sum_{k} x_{II,k} + 3.0 \sum_{k} x_{III,k} \right) $$

6.  **Non-negativity:**
    $$ x_{g,k} \ge 0, \quad X_k \ge 0, \quad d_{I,k}^- \ge 0, \quad d_{III,k}^+ \ge 0, \quad d_{Red}^- \ge 0 $$
