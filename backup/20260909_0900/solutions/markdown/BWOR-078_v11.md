# Project Scheduling Optimization Model

## 1. Index Sets & Parameters

**Index Sets:**
*   $T = \{a, b, c, d, e, f, g, h, i, j, k, L, m, n\}$: Set of all tasks.
*   $P_t$: Set of immediate predecessor tasks for task $t$.

**Parameters:**
*   $D_t$: Duration of task $t$ (in days).
    *   $D_a = 10, D_b = 8, D_c = 6, D_d = 16, D_e = 24, D_f = 4, D_g = 4$
    *   $D_h = 10, D_i = 4, D_j = 12, D_k = 16, D_L = 8, D_m = 24, D_n = 4$
*   $ES_t$: Earliest Start time of task $t$.
    *   $ES_a = 0, ES_b = 0$
    *   $ES_c = 18$ (after a, b)
    *   $ES_d = 8$ (after b)
    *   $ES_e = 24$ (after c)
    *   $ES_f = 48$ (after d, e)
    *   $ES_g = 52$ (after f)
    *   $ES_h = 52$ (after f)
    *   $ES_i = 52$ (after f)
    *   $ES_j = 56$ (after g)
    *   $ES_k = 72$ (after h, i, j)
    *   $ES_L = 24$ (after c)
    *   $ES_m = 32$ (after L)
    *   $ES_n = 76$ (after k, m)

**Precedence Relations (Successor Mapping):**
*   $a \to c$
*   $b \to c, b \to d$
*   $c \to e, c \to L$
*   $d \to f$
*   $e \to f$
*   $f \to g, f \to h, f \to i$
*   $g \to j$
*   $h \to k$
*   $i \to k$
*   $j \to k$
*   $L \to m$
*   $k \to n$
*   $m \to n$

## 2. Decision Variables

Let $S_t$ be the **start time** of task $t$ (in days from project start).
*   Domain: $S_t \ge 0$ for all $t \in T$. (Continuous or Integer; since durations are integers and constraints are difference inequalities, the optimal solution will naturally be integer).

## 3. Objective Function

Minimize the project completion time, which is the completion time of the final task $n$.

$$ \text{Minimize } Z = S_n + D_n $$

Alternatively, define a variable $T_{end}$:
$$ \text{Minimize } Z = T_{end} $$

## 4. Operational Constraints

**1. Precedence Constraints:**
For every task $t$ and its successor $s \in T$ (where $t$ is in $P_s$):
$$ S_s \ge S_t + D_t $$

Explicitly listed:
1.  $S_c \ge S_a + 10$
2.  $S_c \ge S_b + 8$
3.  $S_d \ge S_b + 8$
4.  $S_e \ge S_c + 6$
5.  $S_L \ge S_c + 6$
6.  $S_f \ge S_d + 16$
7.  $S_f \ge S_e + 24$
8.  $S_g \ge S_f + 4$
9.  $S_h \ge S_f + 4$
10. $S_i \ge S_f + 4$
11. $S_j \ge S_g + 4$
12. $S_k \ge S_h + 10$
13. $S_k \ge S_i + 4$
14. $S_k \ge S_j + 12$
15. $S_m \ge S_L + 8$
16. $S_n \ge S_k + 16$
17. $S_n \ge S_m + 24$

**2. Start Time Bounds:**
$$ S_t \ge 0 \quad \forall t \in T $$

## 5. Model Verification & Solution Derivation

To verify the model's output, we trace the critical path manually using the parameters above:

1.  **Start:** $S_a = 0, S_b = 0$.
2.  **Task a:** Finishes at $10$.
3.  **Task b:** Finishes at $8$.
4.  **Task c:** Predecessors a (fin 10), b (fin 8). Start $S_c = 10$. Finishes at $10 + 6 = 16$.
    *   *Correction on previous manual trace:* Let's re-calculate carefully.
    *   $S_a=0, C_a=10$.
    *   $S_b=0, C_b=8$.
    *   $S_c = \max(10, 8) = 10$. $C_c = 10 + 6 = 16$.
    *   $S_d = \max(8) = 8$. $C_d = 8 + 16 = 24$.
    *   $S_e = \max(16) = 16$. $C_e = 16 + 24 = 40$.
    *   $S_L = \max(16) = 16$. $C_L = 16 + 8 = 24$.
    *   $S_f = \max(C_d, C_e) = \max(24, 40) = 40$. $C_f = 40 + 4 = 44$.
    *   $S_g = \max(44) = 44$. $C_g = 44 + 4 = 48$.
    *   $S_h = \max(44) = 44$. $C_h = 44 + 10 = 54$.
    *   $S_i = \max(44) = 44$. $C_i = 44 + 4 = 48$.
    *   $S_j = \max(48) = 48$. $C_j = 48 + 12 = 60$.
    *   $S_m = \max(24) = 24$. $C_m = 24 + 24 = 48$.
    *   $S_k = \max(C_h, C_i, C_j) = \max(54, 48, 60) = 60$. $C_k = 60 + 16 = 76$.
    *   $S_n = \max(C_k, C_m) = \max(76, 48) = 76$. $C_n = 76 + 4 = 80$.

The shortest possible duration is determined by the critical path:
**Path:** $b \to c \to e \to f \to h \to k \to n$ ? No, let's check lengths.
*   Path $a \to c \to e \to f \to g \to j \to k \to n$: $10+6+24+4+4+12+16+4 = 80$.
*   Path $b \to c \to e \to f \to h \to k \to n$: $8+6+24+4+10+16+4 = 72$.
*   Path $b \to c \to L \to m \to n$: $8+6+8+24+4 = 50$.

The longest path is **80 days**.

**Answer:** The shortest possible duration is **80 days**.
