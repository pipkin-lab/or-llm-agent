**Model Type:** MILP (Mixed Integer Linear Programming)

**Objective Identification Gate:**
The problem asks to **MAXIMIZE total rental income**.
Rental income is defined as 20% of the annual profit.
Therefore, the objective is to Maximize $0.2 \times \sum (\text{Total Profit})$.
The answer will be in "thousand Yuan".

**Cost/Parameter Inventory:**
1.  **Total Area:** 5,000 m²
2.  **Rent Rate:** 20% (0.2)
3.  **Store 1 (Jewelry):**
    *   Area/store: 250 m²
    *   Min Stores: 1
    *   Max Stores: 3
    *   Profit per store if 1 store: 9
    *   Profit per store if 2 stores: 8
    *   Profit per store if 3 stores: 7
4.  **Store 2 (Shoes & Hats):**
    *   Area/store: 350 m²
    *   Min Stores: 1
    *   Max Stores: 2
    *   Profit per store if 1 store: 10
    *   Profit per store if 2 stores: 9
    *   Profit per store if 3 stores: N/A (Max is 2)
5.  **Store 3 (Department Store):**
    *   Area/store: 800 m²
    *   Min Stores: 1
    *   Max Stores: 3
    *   Profit per store if 1 store: 27
    *   Profit per store if 2 stores: 21
    *   Profit per store if 3 stores: 20
6.  **Store 4 (Bookstore):**
    *   Area/store: 400 m²
    *   Min Stores: 0
    *   Max Stores: 2
    *   Profit per store if 1 store: 16
    *   Profit per store if 2 stores: 10
    *   Profit per store if 3 stores: N/A (Max is 2)
7.  **Store 5 (Catering):**
    *   Area/store: 500 m²
    *   Min Stores: 1
    *   Max Stores: 3
    *   Profit per store if 1 store: 17
    *   Profit per store if 2 stores: 15
    *   Profit per store if 3 stores: 12

**Formulation Strategy:**
Since the profit per store depends on the *total number* of stores of that type opened, this is a fixed-charge or step-cost problem. We can model this by defining binary variables for each possible configuration (number of stores) for each store type.

Let $i \in \{1, 2, 3, 4, 5\}$ be the store type.
For each store type $i$, let $x_{i,k}$ be a binary variable indicating whether exactly $k$ stores of type $i$ are opened.
The possible values for $k$ depend on the Min and Max for type $i$.

*   **Type 1 (Jewelry):** $k \in \{1, 2, 3\}$. Variables: $x_{1,1}, x_{1,2}, x_{1,3}$.
*   **Type 2 (Shoes):** $k \in \{1, 2\}$. Variables: $x_{2,1}, x_{2,2}$.
*   **Type 3 (Dept Store):** $k \in \{1, 2, 3\}$. Variables: $x_{3,1}, x_{3,2}, x_{3,3}$.
*   **Type 4 (Bookstore):** $k \in \{0, 1, 2\}$. Variables: $x_{4,0}, x_{4,1}, x_{4,2}$.
*   **Type 5 (Catering):** $k \in \{1, 2, 3\}$. Variables: $x_{5,1}, x_{5,2}, x_{5,3}$.

**Index Sets & Parameters:**

*   $I = \{1, 2, 3, 4, 5\}$: Set of store types.
*   $K_i$: Set of allowed number of stores for type $i$.
    *   $K_1 = \{1, 2, 3\}$
    *   $K_2 = \{1, 2\}$
    *   $K_3 = \{1, 2, 3\}$
    *   $K_4 = \{0, 1, 2\}$
    *   $K_5 = \{1, 2, 3\}$
*   $A_i$: Area per store of type $i$ (m²).
    *   $A_1 = 250, A_2 = 350, A_3 = 800, A_4 = 400, A_5 = 500$.
*   $P_{i,k}$: Annual profit per store (thousand Yuan) for type $i$ when $k$ stores are opened.
    *   $P_{1,1}=9, P_{1,2}=8, P_{1,3}=7$
    *   $P_{2,1}=10, P_{2,2}=9$
    *   $P_{3,1}=27, P_{3,2}=21, P_{3,3}=20$
    *   $P_{4,1}=16, P_{4,2}=10$
    *   $P_{5,1}=17, P_{5,2}=15, P_{5,3}=12$
*   $r$: Rent rate = 0.2.
*   $A_{total}$: Total available area = 5000 m².

**Decision Variables:**

*   $x_{i,k} \in \{0, 1\}$ for all $i \in I, k \in K_i$.
    *   $x_{i,k} = 1$ if exactly $k$ stores of type $i$ are leased, 0 otherwise.

**Objective Function:**

Maximize Total Rental Income $Z$:
$$ \text{Maximize } Z = \sum_{i \in I} \sum_{k \in K_i} \left( k \cdot P_{i,k} \cdot r \right) x_{i,k} $$

Expanding the coefficients ($k \cdot P_{i,k} \cdot 0.2$):
*   Type 1: $1\cdot9\cdot0.2=1.8$, $2\cdot8\cdot0.2=3.2$, $3\cdot7\cdot0.2=4.2$
*   Type 2: $1\cdot10\cdot0.2=2.0$, $2\cdot9\cdot0.2=3.6$
*   Type 3: $1\cdot27\cdot0.2=5.4$, $2\cdot21\cdot0.2=8.4$, $3\cdot20\cdot0.2=12.0$
*   Type 4: $0\cdot16\cdot0.2=0$, $1\cdot16\cdot0.2=3.2$, $2\cdot10\cdot0.2=4.0$
*   Type 5: $1\cdot17\cdot0.2=3.4$, $2\cdot15\cdot0.2=6.0$, $3\cdot12\cdot0.2=7.2$

$$ \text{Maximize } Z = 1.8x_{1,1} + 3.2x_{1,2} + 4.2x_{1,3} + 2.0x_{2,1} + 3.6x_{2,2} + 5.4x_{3,1} + 8.4x_{3,2} + 12.0x_{3,3} + 0x_{4,0} + 3.2x_{4,1} + 4.0x_{4,2} + 3.4x_{5,1} + 6.0x_{5,2} + 7.2x_{5,3} $$

**Operational Constraints:**

1.  **Selection Constraint (Exactly one configuration per store type):**
    For each store type $i$, exactly one $x_{i,k}$ must be 1.
    $$ \sum_{k \in K_1} x_{1,k} = 1 \implies x_{1,1} + x_{1,2} + x_{1,3} = 1 $$
    $$ \sum_{k \in K_2} x_{2,k} = 1 \implies x_{2,1} + x_{2,2} = 1 $$
    $$ \sum_{k \in K_3} x_{3,k} = 1 \implies x_{3,1} + x_{3,2} + x_{3,3} = 1 $$
    $$ \sum_{k \in K_4} x_{4,k} = 1 \implies x_{4,0} + x_{4,1} + x_{4,2} = 1 $$
    $$ \sum_{k \in K_5} x_{5,k} = 1 \implies x_{5,1} + x_{5,2} + x_{5,3} = 1 $$

2.  **Area Constraint (Total area used $\le$ Total available area):**
    The total area used is the sum over all types of (number of stores $\times$ area per store).
    $$ \sum_{i \in I} A_i \left( \sum_{k \in K_i} k \cdot x_{i,k} \right) \le 5000 $$

    Expanding the area terms ($A_i \cdot k$):
    *   Type 1: $250(1)x_{1,1} + 250(2)x_{1,2} + 250(3)x_{1,3} = 250x_{1,1} + 500x_{1,2} + 750x_{1,3}$
    *   Type 2: $350(1)x_{2,1} + 350(2)x_{2,2} = 350x_{2,1} + 700x_{2,2}$
    *   Type 3: $800(1)x_{3,1} + 800(2)x_{3,2} + 800(3)x_{3,3} = 800x_{3,1} + 1600x_{3,2} + 2400x_{3,3}$
    *   Type 4: $400(0)x_{4,0} + 400(1)x_{4,1} + 400(2)x_{4,2} = 0x_{4,0} + 400x_{4,1} + 800x_{4,2}$
    *   Type 5: $500(1)x_{5,1} + 500(2)x_{5,2} + 500(3)x_{5,3} = 500x_{5,1} + 1000x_{5,2} + 1500x_{5,3}$

    Combined Area Constraint:
    $$ 250x_{1,1} + 500x_{1,2} + 750x_{1,3} + 350x_{2,1} + 700x_{2,2} + 800x_{3,1} + 1600x_{3,2} + 2400x_{3,3} + 400x_{4,1} + 800x_{4,2} + 500x_{5,1} + 1000x_{5,2} + 1500x_{5,3} \le 5000 $$

3.  **Variable Domains:**
    $$ x_{i,k} \in \{0, 1\} \quad \forall i \in I, k \in K_i $$

**Feasibility Sanity Check:**
Minimum area required (selecting min stores for each type):
Type 1 (1 store): 250
Type 2 (1 store): 350
Type 3 (1 store): 800
Type 4 (0 stores): 0
Type 5 (1 store): 500
Total Min Area = $250 + 350 + 800 + 0 + 500 = 1900$ m².
Since $1900 \le 5000$, the problem is feasible.

Maximum area possible (selecting max stores for each type):
Type 1 (3 stores): 750
Type 2 (2 stores): 700
Type 3 (3 stores): 2400
Type 4 (2 stores): 800
Type 5 (3 stores): 1500
Total Max Area = $750 + 700 + 2400 + 800 + 1500 = 6150$ m².
Since $6150 > 5000$, the area constraint is binding and will restrict some combinations.
