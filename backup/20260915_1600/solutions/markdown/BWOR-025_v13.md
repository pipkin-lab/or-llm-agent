To find the optimal job sequence and the minimum makespan for a two-machine flow shop problem, we apply **Johnson's Rule**. This algorithm guarantees the optimal sequence for minimizing the makespan ($C_{max}$) when all jobs pass through the same sequence of machines (A then B).

### 1. Problem Analysis & Data Extraction

**Machines:** $M_A$ (first), $M_B$ (second)

### 2. Application of Johnson's Rule

**Algorithm Steps:**
1. For each job, find the minimum processing time among the two machines.
2. If the minimum is on Machine A, schedule the job as **early** as possible (from the front).
3. If the minimum is on Machine B, schedule the job as **late** as possible (from the back).
4. If there is a tie, it can be placed in either position (conventionally, we treat ties as A-first or B-last; standard practice often allows flexibility, but let's follow the "Min on A -> Front, Min on B -> Back" strictly. If min is on both, it doesn't strictly matter for optimality, but let's group them).

**Step-by-Step Selection:**

### 3. Calculation of Makespan ($C_{max}$)

We calculate the completion time for each job on Machine A ($T_A$) and Machine B ($T_B$).
$T_{A,k} = T_{A,k-1} + p_{kA}$
$T_{B,k} = \max(T_{A,k}, T_{B,k-1}) + p_{kB}$
(With $T_{A,0}=0, T_{B,0}=0$)

| Step (Job) | $p_A$ | $p_B$ | $T_A$ (Cum. A) | $T_B$ (Cum. B) | Logic for $T_B$ |

| 1 (Job 4) | 2 | 3 | 2 | $\max(2, 0) + 3 = 5$ | |

**Total Makespan:** 82
