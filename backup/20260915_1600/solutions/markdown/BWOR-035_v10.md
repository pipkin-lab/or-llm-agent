## Model Type: NON-LINEAR (Mixed-Integer Non-Linear Programming / MINLP)

**Note:** The objective function involves products of binary/integer variables and non-linear probability terms. A non-linear solver (e.g., `scipy.optimize`, `GLOP` with relaxation, or a dedicated MINLP solver) is required.

### Index Sets & Parameters

**Index Sets:**
- $i \in \{1, 2, 3, 4\}$: Set of key parts of the enemy target.
- $b \in \{H, L\}$: Set of bomb types (H: Heavy, L: Light).

**Parameters:**
- $D_i$: Distance from airbase to key part $i$ (km).
  - $D_1 = 450$, $D_2 = 480$, $D_3 = 540$, $D_4 = 600$
- $p_{i,H}$: Probability of destroying key part $i$ by a single Heavy bomb.
  - $p_{1,H} = 0.10$, $p_{2,H} = 0.20$, $p_{3,H} = 0.15$, $p_{4,H} = 0.25$
- $p_{i,L}$: Probability of destroying key part $i$ by a single Light bomb.
  - $p_{1,L} = 0.08$, $p_{2,L} = 0.16$, $p_{3,L} = 0.12$, $p_{4,L} = 0.20$
- $v_H$: Fuel efficiency when carrying Heavy bombs (km/L) = 2.
- $v_L$: Fuel efficiency when carrying Light bombs (km/L) = 3.
- $v_E$: Fuel efficiency when returning empty (km/L) = 4.
- $F_{takeoff}$: Fixed fuel consumption for takeoff (L) = 100.
- $F_{landing}$: Fixed fuel consumption for landing (L) = 100.
- $F_{fixed}$: Total fixed fuel per sortie (L) = $100 + 100 = 200$.
- $S_F$: Total fuel available (L) = 48,000.
- $S_H$: Total Heavy bombs available = 48.
- $S_L$: Total Light bombs available = 32.

### Decision Variables

Let $x_{i,b}$ be the number of bombs of type $b$ dropped on key part $i$.
- $x_{i,H} \in \mathbb{Z}_{\ge 0}$ for all $i \in \{1,2,3,4\}$.
- $x_{i,L} \in \mathbb{Z}_{\ge 0}$ for all $i \in \{1,2,3,4\}$.

Let $z_i \in \{0, 1\}$ be a binary variable indicating whether key part $i$ is targeted (i.e., at least one bomb is allocated to it).
- $z_i = 1$ if $x_{i,H} + x_{i,L} \ge 1$, else $0$.

### Objective Function

Maximize the probability that **at least one** key part is destroyed.
The probability that key part $i$ is **not** destroyed given $x_{i,H}$ heavy and $x_{i,L}$ light bombs is:
$$ P(\text{Not Destroyed}_i) = (1 - p_{i,H})^{x_{i,H}} \times (1 - p_{i,L})^{x_{i,L}} $$
The probability that key part $i$ **is** destroyed is $1 - P(\text{Not Destroyed}_i)$.
Assuming independence between the destruction of different key parts, the probability that **none** of the key parts are destroyed is the product of the individual "not destroyed" probabilities.
The objective is to maximize:
$$ \text{Maximize } Z = 1 - \prod_{i=1}^{4} \left[ (1 - p_{i,H})^{x_{i,H}} (1 - p_{i,L})^{x_{i,L}} \right] $$

*Note: For solvers that do not support direct non-linear objective maximization with integer variables, this can be linearized or solved via penalty methods, but strictly mathematically, this is the objective.*

### Operational Constraints

**1. Bomb Supply Constraints:**
Total Heavy bombs used cannot exceed supply:
$$ \sum_{i=1}^{4} x_{i,H} \le 48 $$
Total Light bombs used cannot exceed supply:
$$ \sum_{i=1}^{4} x_{i,L} \le 32 $$

**2. Fuel Consumption Constraint:**
For each key part $i$ that is targeted ($z_i = 1$), the aircraft must make a sortie.
The fuel consumed for a sortie to target $i$ depends on the *type* of bombs carried. This creates a non-linear coupling. However, typically in these problems, if you carry a mix, the efficiency might be weighted or the constraint must ensure that *if* you carry heavy bombs, you have enough fuel for the heavy-bomb efficiency, and *if* you carry light, for light-bomb efficiency.
A more robust interpretation for a single sortie per target type:
If we send a plane to target $i$ with $x_{i,H}$ heavy bombs, the fuel required is:
$$ F_{req, i, H} = x_{i,H} > 0 \implies \text{Fuel} = 2 \cdot D_i + 100 + 100 $$
Wait, the problem says "for each bombing sortie... 100 liters for takeoff and landing". It implies one sortie per target visit.
Does one plane carry all bombs for a target in one trip? Or multiple trips?
"48 heavy bombs... 32 light bombs".
Usually, a bomber carries a limited load. The problem doesn't specify max payload per plane, but implies we are allocating the *stockpile*.
Let's assume the "sortie" is defined by the target visited. If we allocate $x_{i,H}$ heavy bombs to target $i$, do we send $x_{i,H}$ planes (1 bomb each) or 1 plane with $x_{i,H}$ bombs?
Given "48 heavy bombs" and "32 light bombs" are total resources, and fuel is per sortie, it is standard to assume **each bomb requires a separate sortie** or the fuel cost is proportional to the number of bombs if they are dropped separately.
However, "when carrying a heavy bomb... 2 km/L". This usually refers to the aircraft's performance *while loaded*.
If a plane carries 1 heavy bomb, fuel = $2 \cdot D_i + 200$.
If a plane carries 2 heavy bombs, does it still fly at 2 km/L? Or is the "carrying a heavy bomb" condition binary?
Standard interpretation in such OR problems: The decision is how many *sorties* of each type to make.
Let $y_{i,H}$ be the number of sorties to target $i$ carrying Heavy bombs.
Let $y_{i,L}$ be the number of sorties to target $i$ carrying Light bombs.
Each sortie drops **1** bomb? Or does the sortie drop all allocated bombs?
If a sortie drops multiple bombs, the probability of destruction is $(1-p)^k$.
If the fuel cost is per sortie, and we can pack multiple bombs, we would always pack max bombs to save fuel. But payload limits are not given.
Let's look at the numbers. 48 heavy, 32 light.
If 1 bomb per sortie:
Fuel for 1 Heavy to $i$: $2D_i + 200$.
Fuel for 1 Light to $i$: $3D_i + 200$.
If we assume 1 bomb per sortie (standard for "number of bombs" constraints without payload specs), then $x_{i,H}$ in the objective above actually represents the number of sorties $y_{i,H}$.
Let's redefine variables to be explicit:
$y_{i,H} \in \mathbb{Z}_{\ge 0}$: Number of sorties to target $i$ carrying 1 Heavy bomb.
$y_{i,L} \in \mathbb{Z}_{\ge 0}$: Number of sorties to target $i$ carrying 1 Light bomb.

**Revised Decision Variables:**
- $y_{i,H} \in \mathbb{Z}_{\ge 0}$
- $y_{i,L} \in \mathbb{Z}_{\ge 0}$

**Revised Objective:**
Maximize $Z = 1 - \prod_{i=1}^{4} \left[ (1 - p_{i,H})^{y_{i,H}} (1 - p_{i,L})^{y_{i,L}} \right]$

**Revised Constraints:**

1.  **Bomb Availability:**
    $$ \sum_{i=1}^{4} y_{i,H} \le 48 $$
    $$ \sum_{i=1}^{4} y_{i,L} \le 32 $$

2.  **Fuel Availability:**
    Total fuel = Sum of fuel for all sorties.
    Fuel for a Heavy sortie to $i$: $F_{H,i} = 2 \cdot D_i + 200$.
    Fuel for a Light sortie to $i$: $F_{L,i} = 3 \cdot D_i + 200$.
    
    Calculate specific fuel costs:
    -   $i=1 (450 \text{ km})$:
        -   $F_{H,1} = 2(450) + 200 = 1100$ L
        -   $F_{L,1} = 3(450) + 200 = 1550$ L
    -   $i=2 (480 \text{ km})$:
        -   $F_{H,2} = 2(480) + 200 = 1160$ L
        -   $F_{L,2} = 3(480) + 200 = 1640$ L
    -   $i=3 (540 \text{ km})$:
        -   $F_{H,3} = 2(540) + 200 = 1280$ L
        -   $F_{L,3} = 3(540) + 200 = 1820$ L
    -   $i=4 (600 \text{ km})$:
        -   $F_{H,4} = 2(600) + 200 = 1400$ L
        -   $F_{L,4} = 3(600) + 200 = 2000$ L

    Constraint:
    $$ 1100 y_{1,H} + 1550 y_{1,L} + 1160 y_{2,H} + 1640 y_{2,L} + 1280 y_{3,H} + 1820 y_{3,L} + 1400 y_{4,H} + 2000 y_{4,L} \le 48000 $$

3.  **Non-negativity and Integrality:**
    $$ y_{i,H}, y_{i,L} \in \mathbb{Z}_{\ge 0} \quad \forall i \in \{1,2,3,4\} $$
