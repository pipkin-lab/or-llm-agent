**Model Type:** MILP (Mixed-Integer Linear Programming)

### MANDATORY COST INVENTORY
Before modeling, I extract all cost-related figures from the problem text and table to ensure they are assigned correctly to the objective function.

1.  **Machine A:**
    *   Setup Cost: 1000 Yuan (Fixed cost if used)
    *   Unit Cost: 20 Yuan/unit (Variable cost)
    *   Max Capacity: 900 units
2.  **Machine B:**
    *   Setup Cost: 920 Yuan (Fixed cost if used)
    *   Unit Cost: 24 Yuan/unit (Variable cost)
    *   Max Capacity: 1000 units
3.  **Machine C:**
    *   Setup Cost: 800 Yuan (Fixed cost if used)
    *   Unit Cost: 16 Yuan/unit (Variable cost)
    *   Max Capacity: 1200 units
4.  **Machine D:**
    *   Setup Cost: 700 Yuan (Fixed cost if used)
    *   Unit Cost: 28 Yuan/unit (Variable cost)
    *   Max Capacity: 1600 units
5.  **Total Demand:** 2000 units.

There are no other costs or revenues mentioned. The objective is to minimize Total Cost = Total Setup Costs + Total Variable Production Costs.

### Index Sets & Parameters

**Index Sets:**
*   $I = \{A, B, C, D\}$: Set of available machines.

**Parameters:**
*   $D_{total} = 2000$: Total required production quantity (units).
*   $S_i$: Setup cost for machine $i$ (Yuan).
    *   $S_A = 1000$
    *   $S_B = 920$
    *   $S_C = 800$
    *   $S_D = 700$
*   $c_i$: Unit production cost for machine $i$ (Yuan/unit).
    *   $c_A = 20$
    *   $c_B = 24$
    *   $c_C = 16$
    *   $c_D = 28$
*   $U_i$: Maximum production capacity for machine $i$ (units).
    *   $U_A = 900$
    *   $U_B = 1000$
    *   $U_C = 1200$
    *   $U_D = 1600$

### Decision Variables

1.  $x_i \ge 0$: Continuous variable representing the number of units produced on machine $i$, for all $i \in I$.
2.  $y_i \in \{0, 1\}$: Binary variable representing whether machine $i$ is used.
    *   $y_i = 1$ if machine $i$ is used ($x_i > 0$).
    *   $y_i = 0$ if machine $i$ is not used ($x_i = 0$).

### Objective Function

Minimize the total cost, which is the sum of fixed setup costs for machines used and variable production costs for all units produced.

$$ \text{Minimize } Z = \sum_{i \in I} S_i y_i + \sum_{i \in I} c_i x_i $$

Substituting the specific values:
$$ \text{Minimize } Z = 1000 y_A + 920 y_B + 800 y_C + 700 y_D + 20 x_A + 24 x_B + 16 x_C + 28 x_D $$

### Operational Constraints

1.  **Demand Satisfaction Constraint:**
    The total production across all machines must exactly meet the required demand of 2,000 units.
    $$ \sum_{i \in I} x_i = 2000 $$
    $$ x_A + x_B + x_C + x_D = 2000 $$

2.  **Capacity Constraints:**
    The production on each machine cannot exceed its maximum capacity. Additionally, if a machine is not selected ($y_i = 0$), its production must be zero. This is modeled using the capacity as the upper bound for $x_i$ when $y_i=1$.
    $$ x_i \le U_i y_i, \quad \forall i \in I $$

    Specifically:
    $$ x_A \le 900 y_A $$
    $$ x_B \le 1000 y_B $$
    $$ x_C \le 1200 y_C $$
    $$ x_D \le 1600 y_D $$

3.  **Variable Domains and Bounds:**
    *   $x_i \ge 0$ (and implicitly $x_i \le U_i$ via the linking constraint) for all $i \in I$.
    *   $y_i \in \{0, 1\}$ for all $i \in I$.

### Feasibility Sanity Check
*   **Total Capacity:** $900 + 1000 + 1200 + 1600 = 4700$ units.
*   **Total Demand:** 2000 units.
*   Since Total Capacity ($4700$) > Total Demand ($2000$), a feasible solution exists. The model will select a subset of machines that can collectively produce 2000 units while minimizing the sum of setup and variable costs. For instance, using only Machine C (capacity 1200) is insufficient alone, so at least two machines must be used. The model will determine the optimal combination.
