## Model Type
**LP** (Linear Program)

All decision variables are continuous (hours worked), and both the objective function and all constraints are linear.

## Index Sets & Parameters

**Index Sets:**
- $I$: Set of students, $I = \{1, 2, 3, 4, 5, 6\}$
- $I^{UG}$: Set of undergraduate students, $I^{UG} = \{1, 2, 3, 4\}$
- $I^{GR}$: Set of graduate students, $I^{GR} = \{5, 6\}$
- $D$: Set of days, $D = \{1, 2, 3, 4, 5\}$ corresponding to $\{$Monday, Tuesday, Wednesday, Thursday, Friday$\}$

**Parameters:**
- $w_i$: Hourly wage (yuan/h) for student $i$

- $M_{i,d}$: Maximum available work hours for student $i$ on day $d$

| $M_{i,d}$ | Mon ($d=1$) | Tue ($d=2$) | Wed ($d=3$) | Thu ($d=4$) | Fri ($d=5$) |

| Student 2 | 0           | 9           | 0           | 6           | 0           |
| Student 3 | 4           | 8           | 3           | 0           | 5           |
| Student 4 | 5           | 5           | 6           | 0           | 4           |
| Student 5 | 3           | 0           | 4           | 8           | 0           |
| Student 6 | 0           | 9           | 0           | 6           | 3           |

- $H_{min}^{UG} = 8$: Minimum weekly hours for each undergraduate
- $H_{min}^{GR} = 7$: Minimum weekly hours for each graduate
- $H_{day} = 14$: Required daily coverage hours (14 hours, 8 AM to 10 PM, with exactly 1 student on duty at all times)

## Decision Variables

- $x_{i,d} \geq 0$: Continuous variable representing the number of hours student $i$ works on day $d$, for all $i \in I$, $d \in D$.

**Domain:** $x_{i,d} \in \mathbb{R}_{\geq 0}$ for all $i \in I, d \in D$.

---

## Objective Function

$$\text{MINIMIZE} \quad Z = \sum_{i \in I} \sum_{d \in D} w_i \cdot x_{i,d}$$

Expanded:
$$Z = 10.0(x_{1,1} + x_{1,2} + x_{1,3} + x_{1,4} + x_{1,5}) + 10.0(x_{2,1} + x_{2,2} + x_{2,3} + x_{2,4} + x_{2,5}) + 9.9(x_{3,1} + x_{3,2} + x_{3,3} + x_{3,4} + x_{3,5}) + 9.8(x_{4,1} + x_{4,2} + x_{4,3} + x_{4,4} + x_{4,5}) + 10.8(x_{5,1} + x_{5,2} + x_{5,3} + x_{5,4} + x_{5,5}) + 11.3(x_{6,1} + x_{6,2} + x_{6,3} + x_{6,4} + x_{6,5})$$

**Objective Parameter Cross-Reference:**
- All $w_i$ values are explicitly provided in Table 5-9. No parameters are [NOT_PROVIDED].

## Operational Constraints

### 1. Daily Coverage Constraints (Exactly 1 student on duty at all times, 14 hours/day)

For each day $d \in D$:
$$\sum_{i \in I} x_{i,d} = 14$$

Explicitly:
- **Monday ($d=1$):** $x_{1,1} + x_{2,1} + x_{3,1} + x_{4,1} + x_{5,1} + x_{6,1} = 14$
- **Tuesday ($d=2$):** $x_{1,2} + x_{2,2} + x_{3,2} + x_{4,2} + x_{5,2} + x_{6,2} = 14$
- **Wednesday ($d=3$):** $x_{1,3} + x_{2,3} + x_{3,3} + x_{4,3} + x_{5,3} + x_{6,3} = 14$
- **Thursday ($d=4$):** $x_{1,4} + x_{2,4} + x_{3,4} + x_{4,4} + x_{5,4} + x_{6,4} = 14$
- **Friday ($d=5$):** $x_{1,5} + x_{2,5} + x_{3,5} + x_{4,5} + x_{5,5} + x_{6,5} = 14$

### 2. Maximum Daily Availability Constraints

For each student $i \in I$ and each day $d \in D$:
$$x_{i,d} \leq M_{i,d}$$

All 30 individual constraints (student × day):
- $x_{1,1} \leq 6$, $x_{1,2} \leq 0$, $x_{1,3} \leq 9$, $x_{1,4} \leq 0$, $x_{1,5} \leq 7$
- $x_{2,1} \leq 0$, $x_{2,2} \leq 9$, $x_{2,3} \leq 0$, $x_{2,4} \leq 6$, $x_{2,5} \leq 0$
- $x_{3,1} \leq 4$, $x_{3,2} \leq 8$, $x_{3,3} \leq 3$, $x_{3,4} \leq 0$, $x_{3,5} \leq 5$
- $x_{4,1} \leq 5$, $x_{4,2} \leq 5$, $x_{4,3} \leq 6$, $x_{4,4} \leq 0$, $x_{4,5} \leq 4$
- $x_{5,1} \leq 3$, $x_{5,2} \leq 0$, $x_{5,3} \leq 4$, $x_{5,4} \leq 8$, $x_{5,5} \leq 0$
- $x_{6,1} \leq 0$, $x_{6,2} \leq 9$, $x_{6,3} \leq 0$, $x_{6,4} \leq 6$, $x_{6,5} \leq 3$

Note: Where $M_{i,d} = 0$, the constraint forces $x_{i,d} = 0$ (combined with non-negativity).

### 3. Minimum Weekly Hours — Undergraduate Students

For each $i \in I^{UG} = \{1, 2, 3, 4\}$:
$$\sum_{d \in D} x_{i,d} \geq 8$$

Explicitly:
- Student 1: $x_{1,1} + x_{1,2} + x_{1,3} + x_{1,4} + x_{1,5} \geq 8$
- Student 2: $x_{2,1} + x_{2,2} + x_{2,3} + x_{2,4} + x_{2,5} \geq 8$
- Student 3: $x_{3,1} + x_{3,2} + x_{3,3} + x_{3,4} + x_{3,5} \geq 8$
- Student 4: $x_{4,1} + x_{4,2} + x_{4,3} + x_{4,4} + x_{4,5} \geq 8$

### 4. Minimum Weekly Hours — Graduate Students

For each $i \in I^{GR} = \{5, 6\}$:
$$\sum_{d \in D} x_{i,d} \geq 7$$

Explicitly:
- Student 5: $x_{5,1} + x_{5,2} + x_{5,3} + x_{5,4} + x_{5,5} \geq 7$
- Student 6: $x_{6,1} + x_{6,2} + x_{6,3} + x_{6,4} + x_{6,5} \geq 7$

### 5. Non-Negativity

$$x_{i,d} \geq 0 \quad \forall i \in I, \; d \in D$$

## Feasibility Sanity Check

**Total required coverage:** $5 \text{ days} \times 14 \text{ hours/day} = 70$ hours

**Total maximum available hours:**
- Student 1: $6+0+9+0+7 = 22$
- Student 2: $0+9+0+6+0 = 15$
- Student 3: $4+8+3+0+5 = 20$
- Student 4: $5+5+6+0+4 = 20$
- Student 5: $3+0+4+8+0 = 15$
- Student 6: $0+9+0+6+3 = 18$
- **Total available:** $22+15+20+20+15+18 = 110$ hours

Since $110 > 70$, total capacity exceeds total demand. ✓

**Minimum weekly hours check:**
- Undergrads need $\geq 8$ each: $4 \times 8 = 32$ hours minimum
- Grad students need $\geq 7$ each: $2 \times 7 = 14$ hours minimum
- Total minimum: $32 + 14 = 46$ hours
- Required coverage: $70$ hours
- Since $70 > 46$, the coverage constraints will be binding and will drive hours above the minimums. ✓

**Per-day feasibility check (critical — some days have zero availability for many students):**
- **Monday:** Available: S1(≤6), S3(≤4), S4(≤5), S5(≤3). Max = $6+4+5+3 = 18 \geq 14$ ✓
- **Tuesday:** Available: S2(≤9), S3(≤8), S4(≤5), S6(≤9). Max = $9+8+5+9 = 31 \geq 14$ ✓
- **Wednesday:** Available: S1(≤9), S3(≤3), S4(≤6), S5(≤4). Max = $9+3+6+4 = 22 \geq 14$ ✓
- **Thursday:** Available: S2(≤6), S5(≤8), S6(≤6). Max = $6+8+6 = 20 \geq 14$ ✓
- **Friday:** Available: S1(≤7), S3(≤5), S4(≤4), S6(≤3). Max = $7+5+4+3 = 19 \geq 14$ ✓

All days are individually feasible. The model is expected to have a feasible solution.
