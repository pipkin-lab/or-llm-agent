To formulate the optimization model for the snow boot ordering problem, we must handle the non-linear ordering costs and the discrete nature of order quantities. Since the problem involves small integer quantities (max 50 pairs) and specific discrete order options, this is a Mixed Integer Linear Programming (MILP) problem.

### 1. Index Sets & Parameters

**Sets:**
*   $T = \{1, 2, 3, 4, 5, 6\}$: Set of months (1=Oct, 2=Nov, 3=Dec, 4=Jan, 5=Feb, 6=Mar).
*   $K = \{1, 2, 3, 4, 5\}$: Set of possible order quantity options.

**Parameters:**
*   $D_t$: Demand in month $t$ (pairs).
    *   $D_1=40, D_2=20, D_3=30, D_4=40, D_5=30, D_6=20$.
*   $Q_k$: Order quantity for option $k$ (pairs).
    *   $Q_1=10, Q_2=20, Q_3=30, Q_4=40, Q_5=50$.
*   $C_{order, k}$: Variable ordering cost for option $k$ (yuan).
    *   $C_{order, 1}=48, C_{order, 2}=86, C_{order, 3}=118, C_{order, 4}=138, C_{order, 5}=160$.
*   $F_{fixed}$: Fixed ordering cost per order (yuan). $F_{fixed} = 10$.
*   $H$: Holding cost per pair per month (yuan). $H = 0.2$.
*   $I_{max}$: Maximum end-of-month inventory (pairs). $I_{max} = 40$.
*   $I_0 = 0$: Initial inventory.
*   $I_6 = 0$: Final inventory (end of March).

### 2. Decision Variables

*   $x_{t, k}$: Binary variable.
    *   $x_{t, k} = 1$ if option $k$ is chosen in month $t$, 0 otherwise.
    *   Domain: $x_{t, k} \in \{0, 1\} \quad \forall t \in T, k \in K$.
*   $I_t$: Continuous variable representing end-of-month inventory for month $t$.
    *   Domain: $I_t \ge 0 \quad \forall t \in T$.
    *   *Note: While inventory could theoretically be integer, standard LP relaxation is often accepted for small-scale inventory unless strict integrality is enforced. Given the small scale (max 50), integrality of $I_t$ is likely natural if $x$ are binary, but defining $I_t$ as continuous is standard for flow conservation. However, since $Q_k$ and $D_t$ are integers, $I_t$ will naturally be integer if the system is balanced. We will define $I_t \ge 0$ continuous to allow for standard LP solvers, or specify integer if required by strict physical constraints. Given the "pairs" unit, $I_t$ should ideally be Integer. Let's specify $I_t \in \mathbb{Z}^+$ to be safe, or rely on the binary $x$ to drive integrality. In many OR contexts, if $x$ is binary and data is integer, $I$ is integer. We will define $I_t \ge 0$.*

### 4. Operational Constraints

**1. Order Selection Constraint (One option per month):**
For each month $t$, exactly one order option is selected.
$$
\sum_{k \in K} x_{t, k} = 1 \quad \forall t \in T
$$
*(Note: $K$ includes 0. If the problem strictly forbids 0, we would remove 0 from K and add a constraint allowing no order, but usually "limited to..." implies the set of *allowed positive* quantities, and 0 is implicitly allowed if demand is met by stock. Given the cost structure, allowing 0 is the only logical "minimization" path. If 0 were not allowed, we'd have to buy 10 pairs even if we had 40 in stock, which is absurd. Thus, $k=0$ is included.)*

**2. Inventory Balance Constraint:**
For each month $t$, Ending Inventory = Beginning Inventory + Orders - Demand.
$$
I_t = I_{t-1} + \sum_{k \in K} Q_k x_{t, k} - D_t \quad \forall t \in T
$$
With $I_0 = 0$.

**3. Inventory Capacity Constraint:**
End-of-month inventory must not exceed 40 pairs.
$$
I_t \le 40 \quad \forall t \in T
$$

**4. Final Inventory Constraint:**
Inventory at the end of the peak season (Month 6) must be zero.
$$
I_6 = 0
$$

**5. Non-negativity and Integrality:**
$$
x_{t, k} \in \{0, 1\} \quad \forall t \in T, k \in K
$$
$$
I_t \ge 0 \quad \forall t \in T
$$
*(Note: Since $I_0=0$, $D_t$ and $Q_k$ are integers, and we pick one $Q_k$, $I_t$ will naturally be an integer.)*

### Summary of Model Components

**Parameters:**
*   $D = [40, 20, 30, 40, 30, 20]$
*   $Q = [0, 10, 20, 30, 40, 50]$
*   $C_{var} = [0, 48, 86, 118, 138, 160]$ (Variable costs for $k=0..5$)
*   $F_{fixed} = 10$ (Applied to $k=1..5$)
*   $H = 0.2$

**Variables:**
*   $x_{t, k}$: Binary, $t \in \{1..6\}, k \in \{0..5\}$
*   $I_t$: Non-negative continuous (effectively integer), $t \in \{1..6\}$

**Objective:**
$$
\text{Min } \sum_{t=1}^6 \left( \sum_{k=0}^5 c_{t,k} x_{t,k} + 0.2 I_t \right)
$$
Where $c_{t,k} = C_{var}[k] + (10 \text{ if } k>0 \text{ else } 0)$.
$c_{t,0} = 0$
$c_{t,1} = 58$
$c_{t,2} = 96$
$c_{t,3} = 128$
$c_{t,4} = 148$
$c_{t,5} = 170$

**Constraints:**
1.  $\sum_{k=0}^5 x_{t,k} = 1, \quad t=1..6$
2.  $I_t = I_{t-1} + \sum_{k=0}^5 Q_k x_{t,k} - D_t, \quad t=1..6$ (with $I_0=0$)
3.  $I_t \le 40, \quad t=1..6$
4.  $I_6 = 0$
5.  $x_{t,k} \in \{0,1\}$
6.  $I_t \ge 0$
