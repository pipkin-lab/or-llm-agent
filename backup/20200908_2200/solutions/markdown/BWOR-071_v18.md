## 1. Index Sets & Parameters

**Sets:**
- $I = \{1, 2\}$: Set of products, where $1$ corresponds to Product A and $2$ corresponds to Product B.

**Parameters:**
- $C = 5$: Total available machine time per day (hours).
- $t_i$: Processing time per unit for product $i$ (hours/unit).
  - $t_1 = 1$ (Product A)
  - $t_2 = 1$ (Product B)
- $c_i$: Variable production cost per unit for product $i$ (yuan/unit).
  - $c_1 = 4$ (Product A)
  - $c_2 = 3$ (Product B)
- $a_i, b_i$: Parameters for the linear price function $p_i = a_i - b_i x_i$.
  - $a_1 = 12, b_1 = 1$ (Product A)
  - $a_2 = 13, b_2 = 2$ (Product B)

## 2. Decision Variables

- $x_i \ge 0$: Continuous variable representing the quantity of product $i$ produced per day.
  - *Note on Integrality*: While physical units are discrete, standard linear programming formulations for such aggregate production problems with non-linear (quadratic) objectives typically treat quantities as continuous variables to find the optimal operating point. Given the small scale, the optimal solution will likely be integer or near-integer, but the standard OR model for "maximize profit with linear demand curves" is a Quadratic Programming (QP) problem relaxed to continuous variables unless integer constraints are explicitly demanded. We will formulate it as a Continuous QP. If strict integrality is required, it would be a Quadratically Constrained Integer Program, but "how many units" in this context usually implies finding the optimal production level, which is best approximated by the continuous optimum or rounded if necessary. However, looking at the specific numbers, let's check if the continuous optimum is integer. If not, the problem might implicitly allow fractional units in the LP sense or expect the integer solution. Standard textbook problems of this type usually accept the continuous QP solution. Let's define $x_i$ as continuous.

## 3. Objective Function

**Goal:** Maximize Total Profit.

Total Profit ($Z$) = Total Revenue - Total Cost.

Revenue for product $i$: $R_i = x_i \cdot p_i = x_i (a_i - b_i x_i) = a_i x_i - b_i x_i^2$.
Cost for product $i$: $Cost_i = c_i x_i$.

Profit for product $i$: $\pi_i = a_i x_i - b_i x_i^2 - c_i x_i = (a_i - c_i)x_i - b_i x_i^2$.

Total Profit:
$$
\text{Maximize } Z = \sum_{i \in I} \left[ (a_i - c_i)x_i - b_i x_i^2 \right]
$$

Substituting the specific parameters:
- For Product A ($i=1$): $(12 - 4)x_1 - 1x_1^2 = 8x_1 - x_1^2$
- For Product B ($i=2$): $(13 - 3)x_2 - 2x_2^2 = 10x_2 - 2x_2^2$

$$
\text{Maximize } Z = 8x_1 - x_1^2 + 10x_2 - 2x_2^2
$$

*Note: This is a concave quadratic function (maximization of a concave function is a convex optimization problem, solvable as a QP).*

## 4. Operational Constraints

**1. Machine Capacity Constraint:**
The total time used by both products cannot exceed the available 5 hours. The problem states the machine "must operate 5 hours per day", which implies the capacity is fully utilized or at least bounded by 5. Since we are maximizing profit, and marginal profits are positive near zero, the constraint will likely bind.

$$
1 x_1 + 1 x_2 \le 5
$$
Or, if "must operate 5 hours" is interpreted as an equality constraint (which is often the case in such "full utilization" problems to avoid idle time if marginal profit is positive), it would be:
$$
x_1 + x_2 = 5
$$
However, standard practice is to use $\le$ unless idle time has a negative cost or is explicitly forbidden. Given the concave nature, if the unconstrained optimum for the sum was less than 5, we'd have slack. Let's check unconstrained maxima:
$dZ/dx_1 = 8 - 2x_1 = 0 \Rightarrow x_1 = 4$.
$dZ/dx_2 = 10 - 4x_2 = 0 \Rightarrow x_2 = 2.5$.
Sum = $6.5 > 5$. So the constraint is binding. Thus, $x_1 + x_2 \le 5$ is sufficient.

**2. Non-negativity Constraints:**
$$
x_1 \ge 0
$$
$$
x_2 \ge 0
$$

### Final Mathematical Model Summary

**Sets:** $I = \{1, 2\}$

**Parameters:**
- $a_1=12, b_1=1, c_1=4$
- $a_2=13, b_2=2, c_2=3$
- $C=5, t_1=1, t_2=1$

**Variables:**
- $x_1, x_2 \in \mathbb{R}_+$

**Model:**
$$
\begin{aligned}
\text{Maximize} \quad & Z = 8x_1 - x_1^2 + 10x_2 - 2x_2^2 \\
\text{Subject to} \quad & x_1 + x_2 \le 5 \\
& x_1 \ge 0, \quad x_2 \ge 0
\end{aligned}
$$
