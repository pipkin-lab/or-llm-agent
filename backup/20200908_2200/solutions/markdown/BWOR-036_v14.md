### 1. Index Sets & Parameters

**Index Sets:**
*   $t \in \{1, 2, 3, 4\}$: Set of quarters.
    *   $t=1$: Winter
    *   $t=2$: Spring
    *   $t=3$: Summer
    *   $t=4$: Autumn

**Parameters:**
*   $P_t$: Purchase price in quarter $t$ (thousand yuan / thousand m³).
    *   $P_1 = 410, P_2 = 430, P_3 = 460, P_4 = 450$
*   $S_t$: Selling price in quarter $t$ (thousand yuan / thousand m³).
    *   $S_1 = 425, S_2 = 440, S_3 = 465, S_4 = 455$
*   $D_t$: Maximum estimated sales volume in quarter $t$ (thousand m³).
    *   $D_1 = 100, D_2 = 140, D_3 = 200, D_4 = 160$
*   $C_{max}$: Maximum warehouse storage capacity (thousand m³).
    *   $C_{max} = 20$
*   $a$: Base storage cost coefficient (yuan / m³).
    *   $a = 70$
*   $b$: Time-dependent storage cost coefficient (yuan / m³ / quarter).
    *   $b = 100$
*   $U_{ij}$: Unit storage cost for timber purchased in quarter $i$ and sold in quarter $j$ (thousand yuan / thousand m³), where $i < j$.
    *   The problem states storage cost is $(a + b \cdot u)$ yuan per m³, where $u$ is storage time in quarters.
    *   Unit conversion: The price/cost parameters $P$ and $S$ are in **thousand yuan per thousand m³**. The storage cost is given in **yuan per m³**.
    *   $1 \text{ yuan/m}^3 = 1 \text{ thousand yuan} / 1000 \text{ m}^3$.
    *   Wait, let's look at units carefully.
        *   Price: 410 thousand yuan / 1 thousand m³. This is equivalent to 410,000 yuan / 1,000 m³ = 410 yuan/m³.
        *   Storage Cost: $(70 + 100u)$ yuan/m³.
        *   Therefore, the storage cost in units of "thousand yuan per thousand m³" is exactly equal to the numerical value in "yuan per m³".
        *   So, $U_{ij} = a + b \cdot (j - i) = 70 + 100(j - i)$.

    *   Calculated $U_{ij}$ for $i < j$:
        *   $U_{1,2} = 70 + 100(1) = 170$
        *   $U_{1,3} = 70 + 100(2) = 270$
        *   $U_{1,4} = 70 + 100(3) = 370$
        *   $U_{2,3} = 70 + 100(1) = 170$
        *   $U_{2,4} = 70 + 100(2) = 270$
        *   $U_{3,4} = 70 + 100(1) = 170$

### 2. Decision Variables

Let $x_{ij}$ be the quantity of timber (in thousand m³) **purchased in quarter $i$** and **sold in quarter $j$**.
*   Domain: $x_{ij} \ge 0$ for all $1 \le i < j \le 4$.
*   Note: We can also define $x_{ii}$ as timber purchased in quarter $i$ and sold in quarter $i$ (no storage).
    *   Domain: $x_{ii} \ge 0$ for all $1 \le i \le 4$.

Alternatively, to make the model more explicit regarding "purchase" and "sale" flows, we can define:
*   $P_t$: Quantity purchased in quarter $t$.
*   $S_t$: Quantity sold in quarter $t$.
*   $I_t$: Inventory at the end of quarter $t$.
*   This approach requires linking constraints. The direct flow variable $x_{ij}$ is often cleaner for small horizons. Let's use the flow variables $x_{ij}$.

**Variables:**
$x_{ij}$: Amount of timber (thousand m³) bought in quarter $i$ and sold in quarter $j$.
*   $x_{11}, x_{22}, x_{33}, x_{44} \ge 0$ (Buy and sell in same quarter)
*   $x_{12}, x_{13}, x_{14} \ge 0$ (Buy in Winter, sell in Spring/Summer/Autumn)
*   $x_{23}, x_{24} \ge 0$ (Buy in Spring, sell in Summer/Autumn)
*   $x_{34} \ge 0$ (Buy in Summer, sell in Autumn)

### 3. Objective Function

**Maximize Annual Profit (Z)**

Profit = Total Revenue - Total Purchase Cost - Total Storage Cost.

For each unit sold:
*   Revenue: $S_j$
*   Purchase Cost: $P_i$
*   Storage Cost: $U_{ij}$ if $i < j$, else 0.

$$
\text{Maximize } Z = \sum_{i=1}^{4} \sum_{j=i}^{4} (S_j - P_i - U_{ij}) x_{ij}
$$

Where $U_{ii} = 0$.

Expanding the coefficients $(S_j - P_i - U_{ij})$:

*   **Winter ($i=1$) Purchases:**
    *   $j=1$ (Sell Winter): $425 - 410 - 0 = 15$
    *   $j=2$ (Sell Spring): $440 - 410 - 170 = -140$
    *   $j=3$ (Sell Summer): $465 - 410 - 270 = -215$
    *   $j=4$ (Sell Autumn): $455 - 410 - 370 = -325$

*   **Spring ($i=2$) Purchases:**
    *   $j=2$ (Sell Spring): $440 - 430 - 0 = 10$
    *   $j=3$ (Sell Summer): $465 - 430 - 170 = -135$
    *   $j=4$ (Sell Autumn): $455 - 430 - 270 = -245$

*   **Summer ($i=3$) Purchases:**
    *   $j=3$ (Sell Summer): $465 - 460 - 0 = 5$
    *   $j=4$ (Sell Autumn): $455 - 460 - 170 = -175$

*   **Autumn ($i=4$) Purchases:**
    *   $j=4$ (Sell Autumn): $455 - 450 - 0 = 5$

**Objective Function:**
$$
\text{Maximize } Z = 15x_{11} - 140x_{12} - 215x_{13} - 325x_{14} + 10x_{22} - 135x_{23} - 245x_{24} + 5x_{33} - 175x_{34} + 5x_{44}
$$

### 4. Operational Constraints

**1. Sales Volume Constraints (Demand Limits)**
The total amount sold in each quarter $j$ cannot exceed the maximum estimated sales volume $D_j$.
$$
\sum_{i=1}^{j} x_{ij} \le D_j, \quad \forall j \in \{1, 2, 3, 4\}
$$

*   $j=1$ (Winter): $x_{11} \le 100$
*   $j=2$ (Spring): $x_{12} + x_{22} \le 140$
*   $j=3$ (Summer): $x_{13} + x_{23} + x_{33} \le 200$
*   $j=4$ (Autumn): $x_{14} + x_{24} + x_{34} + x_{44} \le 160$

**2. Storage Capacity Constraints**
The warehouse capacity is 20 thousand m³. The inventory at the end of each quarter $t$ must not exceed $C_{max}$.
Inventory at end of quarter $t$ consists of timber purchased in quarter $t$ (and previous quarters) that has not yet been sold.
Using the flow variables $x_{ij}$, the inventory at the end of quarter $t$ is the sum of all timber purchased in quarters $i \le t$ but sold in quarters $j > t$.

$$
\sum_{i=1}^{t} \sum_{j=t+1}^{4} x_{ij} \le C_{max}, \quad \forall t \in \{1, 2, 3\}
$$
(Note: Inventory at end of Quarter 4 is 0, as all timber must be sold by end of Autumn).

*   **End of Winter ($t=1$):**
    Timber bought in Winter ($i=1$) and sold in Spring ($j=2$), Summer ($j=3$), or Autumn ($j=4$).
    $$x_{12} + x_{13} + x_{14} \le 20$$

*   **End of Spring ($t=2$):**
    Timber bought in Winter ($i=1$) or Spring ($i=2$) and sold in Summer ($j=3$) or Autumn ($j=4$).
    $$(x_{13} + x_{14}) + (x_{23} + x_{24}) \le 20$$
    $$x_{13} + x_{14} + x_{23} + x_{24} \le 20$$

*   **End of Summer ($t=3$):**
    Timber bought in Winter ($i=1$), Spring ($i=2$), or Summer ($i=3$) and sold in Autumn ($j=4$).
    $$x_{14} + x_{24} + x_{34} \le 20$$

**3. Non-negativity Constraints**
$$
x_{ij} \ge 0, \quad \forall 1 \le i \le j \le 4
$$

### Summary of the Model

**Sets:**
$t \in \{1, 2, 3, 4\}$ representing Winter, Spring, Summer, Autumn.

**Parameters:**
*   $P = [410, 430, 460, 450]$
*   $S = [425, 440, 465, 455]$
*   $D = [100, 140, 200, 160]$
*   $C_{max} = 20$
*   Storage Cost $U_{ij} = 70 + 100(j-i)$ for $i < j$, else 0.

**Variables:**
$x_{ij} \ge 0$ for $1 \le i \le j \le 4$.

**Objective:**
Maximize $Z = \sum_{i=1}^{4} \sum_{j=i}^{4} (S_j - P_i - U_{ij}) x_{ij}$

**Constraints:**
1.  $\sum_{i=1}^{j} x_{ij} \le D_j, \quad \forall j$
2.  $\sum_{i=1}^{t} \sum_{k=t+1}^{4} x_{ik} \le C_{max}, \quad \forall t \in \{1, 2, 3\}$
3.  $x_{ij} \ge 0$
