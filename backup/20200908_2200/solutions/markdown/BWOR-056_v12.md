### 1. Index Sets & Parameters

**Sets:**
- $C$: Set of all available courses $\{ \text{Calculus, OR, Data Structures, Managerial Statistics, Computer Simulation, Computer Programming, Forecasting} \}$.
- $K$: Set of required course categories $\{ \text{Mathematics, Operations Research, Computer Science} \}$.

**Parameters:**
- $a_{c,k} \in \{0, 1\}$: Binary parameter indicating if course $c \in C$ belongs to category $k \in K$.
  - **Calculus**: Math (1)
  - **Operations Research**: OR (1), Math (1)
  - **Data Structures**: CS (1), Math (1)
  - **Managerial Statistics**: Math (1), OR (1)
  - **Computer Simulation**: CS (1), OR (1)
  - **Computer Programming**: CS (1)
  - **Forecasting**: OR (1), Math (1)
- $R_k$: Required number of courses for category $k$.
  - $R_{\text{Math}} = 2$
  - $R_{\text{OR}} = 2$
  - $R_{\text{CS}} = 2$
- $P_{c}$: Set of prerequisite courses for course $c$.
  - $P_{\text{Comp Sim}} = \{ \text{Comp Prog} \}$
  - $P_{\text{Data Struct}} = \{ \text{Comp Prog} \}$
  - $P_{\text{Mgmt Stats}} = \{ \text{Calc} \}$
  - $P_{\text{Forecast}} = \{ \text{Mgmt Stats} \}$
  - All other $P_c = \emptyset$.

### 2. Decision Variables

- $x_c \in \{0, 1\}$ for all $c \in C$:
  - $x_c = 1$ if course $c$ is taken.
  - $x_c = 0$ otherwise.

*Note: Since the number of courses is small (< 10) and discrete, integer/binary variables are required.*

### 3. Objective Function

Minimize the total number of courses taken:

$$
\text{Minimize } Z = \sum_{c \in C} x_c
$$

### 4. Operational Constraints

**1. Category Requirements:**
For each category $k \in K$, the sum of courses belonging to that category must meet or exceed the requirement $R_k$.

$$
\sum_{c \in C} a_{c,k} x_c \geq R_k, \quad \forall k \in K
$$

*Explicitly:*
- **Math**: $x_{\text{Calc}} + x_{\text{OR}} + x_{\text{Data Struct}} + x_{\text{Mgmt Stats}} + x_{\text{Forecast}} \geq 2$
- **OR**: $x_{\text{OR}} + x_{\text{Mgmt Stats}} + x_{\text{Comp Sim}} + x_{\text{Forecast}} \geq 2$
- **CS**: $x_{\text{Data Struct}} + x_{\text{Comp Sim}} + x_{\text{Comp Prog}} \geq 2$

**2. Prerequisite Constraints:**
If a course $c$ is taken ($x_c = 1$), all its prerequisites $p \in P_c$ must also be taken ($x_p = 1$). This is modeled as $x_c \leq x_p$ for all $p \in P_c$.

- $x_{\text{Comp Sim}} \leq x_{\text{Comp Prog}}$
- $x_{\text{Data Struct}} \leq x_{\text{Comp Prog}}$
- $x_{\text{Mgmt Stats}} \leq x_{\text{Calc}}$
- $x_{\text{Forecast}} \leq x_{\text{Mgmt Stats}}$

**3. Non-negativity and Integrality:**
$$
x_c \in \{0, 1\}, \quad \forall c \in C
$$
