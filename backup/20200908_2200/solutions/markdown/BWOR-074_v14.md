To minimize the total sorting workload, we must determine the optimal sequence in which to extract the five grades (A, B, C, D, E).

### 1. Index Sets & Parameters

**Sets:**
*   $G = \{A, B, C, D, E\}$: The set of distinct grades.
*   $P = \{1, 2, 3, 4, 5\}$: The set of processing positions (1 being the first grade extracted, 5 being the last).

**Parameters:**
*   $N = 50,000$: Total number of exam participants.
*   $p_g$: The percentage proportion of grade $g$ in the total population.
    *   $p_A = 0.10$
    *   $p_B = 0.25$
    *   $p_C = 0.30$
    *   $p_D = 0.20$
    *   $p_E = 0.15$
*   $N_g$: The absolute number of sheets for grade $g$, calculated as $N_g = N \times p_g$.
    *   $N_A = 5,000$
    *   $N_B = 12,500$
    *   $N_C = 15,000$
    *   $N_D = 10,000$
    *   $N_E = 7,500$

**Workload Logic:**
When sorting by extracting one grade at a time, a "scan" or "workload unit" is incurred for every sheet that has *not yet been removed* from the pile.
If we process the grades in a specific sequence, the total workload is the sum of the number of sheets remaining in the pile at each step.
Alternatively, this is equivalent to calculating the number of times each specific sheet is examined.
*   The grade extracted **first** (position 1): Its $N_g$ sheets are removed after the 1st pass. However, the *other* grades' sheets are also scanned during this pass.
*   Actually, a simpler way to view "workload" in this context (standard selection sort / extraction sort analogy) is:
    *   To extract the first grade, we scan the entire pile of $N$ sheets.
    *   To extract the second grade, we scan the remaining $N - N_{g1}$ sheets.
    *   ...
    *   To extract the last grade, we scan the remaining $N_{g5}$ sheets (or potentially 0 if we just assume the rest are that grade, but typically "recognizing one grade at a time" implies a physical separation process where you scan the remaining items to find the target).
    
    *Correction on Workload Definition*: The problem states "each scan can only detect one specific grade". This implies a process where we look for Grade $X$ in the current pile.
    If we pick Grade $A$ first:
    - We scan the whole pile ($N=50,000$) to find and remove all A's.
    - Remaining pile size: $50,000 - 5,000 = 45,000$.
    - Next, we pick Grade $B$ (for example). We scan the remaining 45,000 to find and remove all B's.
    - Remaining pile size: $45,000 - 12,500 = 32,500$.
    - And so on.
    
    Total Workload $W$ is the sum of the pile sizes at each step $k=1$ to $5$.
    $W = \sum_{k=1}^{5} (\text{Size of pile before extracting grade at step } k)$
    
    Let the sequence of grades be $\pi = [g_1, g_2, g_3, g_4, g_5]$.
    Let $S_0 = N$.
    Let $S_k = S_{k-1} - N_{g_k}$.
    The workload for step $k$ is $S_{k-1}$.
    Total Workload $Z = S_0 + S_1 + S_2 + S_3 + S_4$.
    Note: We do not include $S_5$ (which would be 0) as no scanning is needed for the last group if we assume the last group is identified by elimination, OR if we must scan to "recognize" the last grade, the cost is $S_4$. However, standard interpretation of "sorting by recognizing one grade at a time" usually implies the cost is proportional to the number of items examined. If we scan to find $g_5$ in the remaining $S_4$ items, the cost is $S_4$.
    
    Let's expand $Z$:
    $S_0 = N$
    $S_1 = N - N_{g_1}$
    $S_2 = N - N_{g_1} - N_{g_2}$
    $S_3 = N - N_{g_1} - N_{g_2} - N_{g_3}$
    $S_4 = N - N_{g_1} - N_{g_2} - N_{g_3} - N_{g_4}$
    
    $Z = N + (N - N_{g_1}) + (N - N_{g_1} - N_{g_2}) + (N - N_{g_1} - N_{g_2} - N_{g_3}) + (N - N_{g_1} - N_{g_2} - N_{g_3} - N_{g_4})$
    
    Grouping terms by $N_{g_i}$:
    - $N_{g_1}$ appears in $S_1, S_2, S_3, S_4$ (4 times).
    - $N_{g_2}$ appears in $S_2, S_3, S_4$ (3 times).
    - $N_{g_3}$ appears in $S_3, S_4$ (2 times).
    - $N_{g_4}$ appears in $S_4$ (1 time).
    - $N_{g_5}$ appears in none of the subtractions (0 times) in the cost formula derived above?
    
    Wait, let's re-verify the "last group" cost.
    If I have a pile of 10 items, 2 are A, 8 are B.
    Step 1: Scan 10 items to remove A's. Cost = 10. Remaining = 8.
    Step 2: Scan 8 items to remove B's? Or do I just know they are B?
    The problem says "recognizing one grade at a time". If I stop after removing A, B, C, D, the remaining items are E. Do I need to "scan" to recognize E? Usually, in these sorting problems (like the classic "minimum comparisons to sort by extraction"), the last group is identified by elimination, so no scan is needed for the last group, OR the scan is needed to verify.
    However, looking at the weights:
    If we sort by **largest first** (C, B, D, E, A):
    $N_C=15000, N_B=12500, N_D=10000, N_E=7500, N_A=5000$.
    
    Let's look at the coefficient of each $N_{g}$ in the total cost.
    $Z = 5N - (4N_{g_1} + 3N_{g_2} + 2N_{g_3} + 1N_{g_4} + 0N_{g_5})$?
    Let's check the sum:
    $Z = 5N - [4N_{g_1} + 3N_{g_2} + 2N_{g_3} + 1N_{g_4}]$.
    To **minimize** $Z$, we need to **maximize** the subtracted term: $4N_{g_1} + 3N_{g_2} + 2N_{g_3} + 1N_{g_4}$.
    
    This implies that the grade with the **largest** count $N$ should have the **largest** coefficient (4).
    Therefore, the grade with the largest count should be extracted **first**.
    The grade with the second largest count should be extracted **second**.
    ...
    The grade with the smallest count should be extracted **last** (coefficient 0, meaning its size doesn't penalize the previous steps, and it is the final remainder).
    
    **Optimal Strategy:** Sort in **decreasing order of frequency** (Largest group first).

### 2. Decision Variables

Since this is a sequencing problem to be solved analytically or via assignment, we can formulate it as an Assignment Problem to prove the ordering.

*   $x_{g, k}$: Binary variable, equal to 1 if grade $g$ is assigned to position $k$ in the sorting sequence, and 0 otherwise.
    *   Domain: $x_{g, k} \in \{0, 1\}$ for all $g \in G, k \in P$.

### 3. Objective Function

Minimize Total Workload $Z$.
Based on the derivation above, the total workload is:
$$ \min Z = 5N - \sum_{k=1}^{4} (5-k) \sum_{g \in G} N_g x_{g,k} $$
*Note: The term for $k=5$ has a coefficient of 0 (or effectively 0 if we consider the last scan unnecessary, or if we include it, the coefficient structure changes slightly but the "largest first" logic holds for minimizing the sum of remaining items).*

Let's refine the cost coefficient for position $k$ (1-indexed):
- Position 1 (extracted 1st): Its size is subtracted in steps 2, 3, 4, 5. It does NOT contribute to the cost of step 1 (which is full N). It reduces the cost of subsequent steps.
- Actually, it is easier to express the cost directly as the sum of remaining items.
  $Cost = \sum_{k=1}^{5} S_{k-1}$.
  $S_{k-1} = N - \sum_{j=1}^{k-1} N_{g_j}$.
  
  Expanding the sum:
  $Z = \sum_{k=1}^{5} \left( N - \sum_{j=1}^{k-1} N_{g_j} \right)$
  $Z = 5N - \sum_{k=1}^{5} \sum_{j=1}^{k-1} N_{g_j}$
  
  Let $C_j$ be the coefficient for the size of the grade extracted at position $j$.
  The grade at position $j$ is subtracted in steps $k$ where $k > j$.
  So, the grade at position $j$ is subtracted $(5-j)$ times.
  
  Thus, $Z = 5N - \sum_{j=1}^{5} (5-j) N_{g_j}$.
  
  To minimize $Z$, we must maximize $\sum_{j=1}^{5} (5-j) N_{g_j}$.
  The coefficients are:
  - Position 1 ($j=1$): Coeff $5-1=4$
  - Position 2 ($j=2$): Coeff $5-2=3$
  - Position 3 ($j=3$): Coeff $5-3=2$
  - Position 4 ($j=4$): Coeff $5-4=1$
  - Position 5 ($j=5$): Coeff $5-5=0$
  
  We assign the largest $N_g$ to the largest coefficient.
  
  **Linear Objective Function:**
  $$ \min Z = 5N - \sum_{g \in G} \sum_{k=1}^{5} (5-k) N_g x_{g,k} $$
  
  Or, to make it a standard minimization without the constant offset and negative signs (which can be confusing), we can maximize the savings:
  $$ \max \text{Savings} = \sum_{g \in G} \sum_{k=1}^{5} (5-k) N_g x_{g,k} $$

### 4. Operational Constraints

1.  **Each grade is assigned to exactly one position:**
    $$ \sum_{k=1}^{5} x_{g, k} = 1, \quad \forall g \in G $$

2.  **Each position is assigned exactly one grade:**
    $$ \sum_{g \in G} x_{g, k} = 1, \quad \forall k \in P $$

3.  **Binary Constraints:**
    $$ x_{g, k} \in \{0, 1\}, \quad \forall g \in G, k \in P $$

### Solution Analysis (Analytical)

1.  **Calculate Sizes ($N_g$):**
    *   $N_C = 15,000$ (Largest)
    *   $N_B = 12,500$ (2nd Largest)
    *   $N_D = 10,000$ (3rd Largest)
    *   $N_E = 7,500$ (4th Largest)
    *   $N_A = 5,000$ (Smallest)

2.  **Assign to Positions based on Coefficients (4, 3, 2, 1, 0):**
    *   Position 1 (Coeff 4): Assign Largest ($C$)
    *   Position 2 (Coeff 3): Assign 2nd Largest ($B$)
    *   Position 3 (Coeff 2): Assign 3rd Largest ($D$)
    *   Position 4 (Coeff 1): Assign 4th Largest ($E$)
    *   Position 5 (Coeff 0): Assign Smallest ($A$)

3.  **Optimal Order:**
    **C $\rightarrow$ B $\rightarrow$ D $\rightarrow$ E $\rightarrow$ A**

4.  **Calculate Minimum Workload:**
    *   Start: 50,000
    *   Scan for C: Cost 50,000. Remaining: $50,000 - 15,000 = 35,000$.
    *   Scan for B: Cost 35,000. Remaining: $35,000 - 12,500 = 22,500$.
    *   Scan for D: Cost 22,500. Remaining: $22,500 - 10,000 = 12,500$.
    *   Scan for E: Cost 12,500. Remaining: $12,500 - 7,500 = 5,000$.
    *   Scan for A: Cost 5,000. Remaining: $5,000 - 5,000 = 0$.
    *   *Note: If the last scan is required to "recognize" A, the cost is 5,000. If A is identified by elimination, the cost is 0. Given "recognizing one grade at a time", it is safest to assume the scan happens for all specified grades. However, even if the last is free, the order remains the same.*
    
    Total Workload = $50,000 + 35,000 + 22,500 + 12,500 + 5,000 = 125,000$.
    
    Let's check the alternative (Smallest First: A, E, D, B, C):
    *   Scan A: 50,000. Rem: 45,000.
    *   Scan E: 45,000. Rem: 37,500.
    *   Scan D: 37,500. Rem: 27,500.
    *   Scan B: 27,500. Rem: 15,000.
    *   Scan C: 15,000. Rem: 0.
    *   Total = $50,000 + 45,000 + 37,500 + 27,500 + 15,000 = 175,000$.
    
    $125,000 < 175,000$. The logic holds.

**Final Answer:**
The optimal order of sorting is **C, B, D, E, A** (in descending order of the number of exam sheets for each grade).
