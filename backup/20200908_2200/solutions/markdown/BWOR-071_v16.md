To formulate this problem, we must identify the objective function (profit) and the constraints (production capacity).

**1. Profit Function Derivation:**
*   **Product A:**
    *   Selling Price: $p_1 = 12 - x_1$
    *   Cost: $c_1 = 4$
    *   Total Profit for A: $P_A = \text{Revenue}_A - \text{Cost}_A = x_1(12 - x_1) - 4x_1 = 12x_1 - x_1^2 - 4x_1 = 8x_1 - x_1^2$
*   **Product B:**
    *   Selling Price: $p_2 = 13 - 2x_2$
    *   Cost: $c_2 = 3$
    *   Total Profit for B: $P_B = \text{Revenue}_B - \text{Cost}_B = x_2(13 - 2x_2) - 3x_2 = 13x_2 - 2x_2^2 - 3x_2 = 10x_2 - 2x_2^2$
*   **Total Profit:** $Z = (8x_1 - x_1^2) + (10x_2 - 2x_2^2)$

**2. Constraints:**
*   **Capacity:** The machine has 5 hours available. Producing one unit of A takes 1 hour, and one unit of B takes 1 hour. The problem states the machine *must* operate 5 hours per day.
    *   Constraint: $1x_1 + 1x_2 = 5$
*   **Non-negativity:** $x_1 \ge 0, x_2 \ge 0$

**3. Model Type Selection:**
The objective function contains squared terms ($x_1^2, x_2^2$), making this a **Quadratic Programming (QP)** problem, not a Linear Programming (LP) problem. Standard LP solvers cannot handle quadratic objectives directly.

According to the **QUADRATIC OBJECTIVE HANDLING** rule, if the solver is restricted to linear tools (like `pywraplp`/GLOP), we must use a **Piecewise Linear Approximation (PWLA)**.

However, because the constraint $x_1 + x_2 = 5$ is an equality, we can also solve this analytically or via simple substitution to verify the PWLA approach.
Substitute $x_2 = 5 - x_1$ into the profit function:
$Z(x_1) = 8x_1 - x_1^2 + 10(5-x_1) - 2(5-x_1)^2$
$Z(x_1) = 8x_1 - x_1^2 + 50 - 10x_1 - 2(25 - 10x_1 + x_1^2)$
$Z(x_1) = 8x_1 - x_1^2 + 50 - 10x_1 - 50 + 20x_1 - 2x_1^2$
$Z(x_1) = -3x_1^2 + 18x_1$

This is a concave quadratic function (parabola opening downward). The maximum occurs at the vertex:
$x_1 = -b / (2a) = -18 / (2 * -3) = 3$
$x_2 = 5 - 3 = 2$
Max Profit $Z = -3(3)^2 + 18(3) = -27 + 54 = 27$.

Since the problem asks for a formal OR model suitable for a solver, and the instructions emphasize handling quadratic objectives via PWLA for linear solvers, I will provide the PWLA formulation. This ensures the model is solvable by standard linear programming tools.

**Piecewise Linear Approximation Setup:**
*   Variable $x_1$ ranges from 0 to 5 (since $x_1+x_2=5$ and $x_2 \ge 0$).
*   Variable $x_2$ ranges from 0 to 5.
*   We approximate the function $f(x) = -x^2$ (for A) and $g(x) = -2x^2$ (for B) using linear segments.
*   Let's define segments for $x_1$ and $x_2$ separately.
*   For $x_1$: Range [0, 5]. Let $K=5$ segments of width $\Delta = 1$.
    *   Segments $k=1..5$ for $x_1$.
    *   $x_1 = \sum_{k=1}^5 z_{1,k}$
    *   $0 \le z_{1,k} \le 1$
    *   The marginal profit (slope) of $8x_1 - x_1^2$ is $8 - 2x_1$.
    *   Segment 1 (0 to 1): Avg slope $\approx 8 - 2(0.5) = 7$. Or more accurately, the change in profit is $f(1)-f(0) = (8-1) - 0 = 7$.
    *   Segment 2 (1 to 2): Change is $f(2)-f(1) = (16-4) - (8-1) = 12 - 7 = 5$.
    *   Segment 3 (2 to 3): Change is $f(3)-f(2) = (24-9) - 12 = 15 - 12 = 3$.
    *   Segment 4 (3 to 4): Change is $f(4)-f(3) = (32-16) - 15 = 16 - 15 = 1$.
    *   Segment 5 (4 to 5): Change is $f(5)-f(4) = (40-25) - 16 = 15 - 16 = -1$.
    *   Objective term for A: $7z_{1,1} + 5z_{1,2} + 3z_{1,3} + 1z_{1,4} - 1z_{1,5}$

*   For $x_2$: Range [0, 5]. Let $K=5$ segments of width $\Delta = 1$.
    *   $x_2 = \sum_{k=1}^5 z_{2,k}$
    *   $0 \le z_{2,k} \le 1$
    *   The profit function for B is $10x_2 - 2x_2^2$.
    *   Segment 1 (0 to 1): Change is $g(1)-g(0) = (10-2) - 0 = 8$.
    *   Segment 2 (1 to 2): Change is $g(2)-g(1) = (20-8) - 8 = 12 - 8 = 4$.
    *   Segment 3 (2 to 3): Change is $g(3)-g(2) = (30-18) - 12 = 12 - 12 = 0$.
    *   Segment 4 (3 to 4): Change is $g(4)-g(3) = (40-32) - 12 = 8 - 12 = -4$.
    *   Segment 5 (4 to 5): Change is $g(5)-g(4) = (50-50) - 8 = 0 - 8 = -8$.
    *   Objective term for B: $8z_{2,1} + 4z_{2,2} + 0z_{2,3} - 4z_{2,4} - 8z_{2,5}$

*   **Constraint Linking:** The constraint $x_1 + x_2 = 5$ becomes $\sum z_{1,k} + \sum z_{2,k} = 5$.

This PWLA model is a standard Linear Program.

### 1. Index Sets & Parameters

*   **Sets:**
    *   $K = \{1, 2, 3, 4, 5\}$: Index for the linear segments used in the piecewise approximation.
*   **Parameters:**
    *   $H = 5$: Total available machine hours per day.
    *   $t_A = 1$: Time required to produce one unit of Product A (hours/unit).
    *   $t_B = 1$: Time required to produce one unit of Product B (hours/unit).
    *   $c_A = 4$: Unit cost of Product A (yuan/unit).
    *   $c_B = 3$: Unit cost of Product B (yuan/unit).
    *   $\Delta = 1$: Width of each segment in the piecewise approximation.
    *   **Coefficients for Product A segments ($a_k$):**
        *   $a_1 = 7$
        *   $a_2 = 5$
        *   $a_3 = 3$
        *   $a_4 = 1$
        *   $a_5 = -1$
    *   **Coefficients for Product B segments ($b_k$):**
        *   $b_1 = 8$
        *   $b_2 = 4$
        *   $b_3 = 0$
        *   $b_4 = -4$
        *   $b_5 = -8$

### 2. Decision Variables

*   $z_{A,k} \ge 0$: Continuous variable representing the quantity of Product A produced in the $k$-th segment of the piecewise approximation.
*   $z_{B,k} \ge 0$: Continuous variable representing the quantity of Product B produced in the $k$-th segment of the piecewise approximation.

*(Note: While $x_A$ and $x_B$ are the physical quantities, they are defined by the sum of $z$ variables. We do not need separate variables for $x_A, x_B$ if we use the sums directly in constraints, but defining them can make constraints clearer. Here, we will use the sums directly or define auxiliary variables for clarity. Let's define $x_A$ and $x_B$ as auxiliary continuous variables linked to $z$.)*

*   $x_A \ge 0$: Total quantity of Product A produced.
*   $x_B \ge 0$: Total quantity of Product B produced.

### 3. Objective Function

Maximize total profit $Z$:

$$
\text{Maximize } Z = \sum_{k=1}^{5} a_k z_{A,k} + \sum_{k=1}^{5} b_k z_{B,k}
$$

Explicitly:
$$
Z = 7z_{A,1} + 5z_{A,2} + 3z_{A,3} + 1z_{A,4} - 1z_{A,5} + 8z_{B,1} + 4z_{B,2} + 0z_{B,3} - 4z_{B,4} - 8z_{B,5}
$$

### 4. Operational Constraints

1.  **Segment Bounds:**
    For each $k \in K$:
    $$
    0 \le z_{A,k} \le \Delta \quad (\text{i.e., } 0 \le z_{A,k} \le 1)
    $$
    $$
    0 \le z_{B,k} \le \Delta \quad (\text{i.e., } 0 \le z_{B,k} \le 1)
    $$

2.  **Quantity Aggregation:**
    $$
    x_A = \sum_{k=1}^{5} z_{A,k}
    $$
    $$
    x_B = \sum_{k=1}^{5} z_{B,k}
    $$

3.  **Machine Capacity Constraint:**
    The machine must operate for exactly 5 hours.
    $$
    t_A x_A + t_B x_B = H
    $$
    Substituting values:
    $$
    1 x_A + 1 x_B = 5
    $$

4.  **Non-negativity:**
    $$
    x_A \ge 0, \quad x_B \ge 0
    $$
    (These are implied by the non-negativity of $z$ variables and the aggregation equations, but stated for completeness).

**Assumption Note:** The piecewise linear approximation with $\Delta=1$ provides an exact solution for this specific quadratic problem because the optimal solution ($x_A=3, x_B=2$) falls exactly on the segment boundaries where the linear approximation is consistent with the discrete marginal changes calculated. Specifically, $z_{A,1}=1, z_{A,2}=1, z_{A,3}=1$ (sum=3) and $z_{B,1}=1, z_{B,2}=1$ (sum=2). The objective value will be $3(7+5+3) + 2(8+4) = 3(15) + 2(12) = 45 + 24 = 69$? $Z = 7(1) + 5(1) + 3(1) - 1(0) ... + 8(1) + 4(1) + 0(0) ...$
$Z = 7 + 5 + 3 + 8 + 4 = 27$.
This matches the analytical maximum of 27. The approximation is exact at the integer points and the linearity holds within the segments for the purpose of the LP solver finding the vertex.
