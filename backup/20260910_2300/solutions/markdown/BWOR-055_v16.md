# Model Type Declaration
**Model Type:** MILP (Mixed-Integer Linear Programming)
**Reasoning:** The problem involves production quantities that are inherently discrete (you cannot produce a fraction of a shirt in a standard discrete production context, though often LP is accepted for large scales; however, given the fixed costs associated with "operating equipment," binary variables are strictly required to determine if a product line is active). To be precise:
- Let $x_i$ be the production quantity (Continuous or Integer, typically Continuous in LP formulations for such textbook problems unless specified "integer units", but let's look at the fixed cost structure).
- The fixed costs depend on whether the equipment is operated. This requires binary variables $y_i$ to indicate if product $i$ is produced ($y_i=1$) or not ($y_i=0$).
- Linking constraints: $x_i \le M y_i$.
- Since $x_i$ can be fractional in a standard LP relaxation, but physically shirts are integers, we usually classify this as MILP if $x_i$ are integers, or MIP (Mixed Integer Program). Given the scale (150 labor), $x_i$ will likely be small integers. We will define $x_i$ as **Integer** variables to be safe, making it a MILP.

# 2. Index Sets & Parameters

**Index Sets:**
- $I = \{1, 2, 3\}$ representing the set of products.
  - $i=1$: Shirt
  - $i=2$: T-shirt
  - $i=3$: Casual Wear

**Parameters:**
- $p_i$: Selling price per unit for product $i$
- $c_i$: Variable cost per unit for product $i$
- $l_i$: Labor required per unit for product $i$
- $m_i$: Material required per unit for product $i$
- $F_i$: Fixed cost for operating equipment for product $i$
- $L_{max}$: Total available labor units (150)
- $M_{max}$: Total available material units (160)
- $U_i$: An upper bound on production for product $i$ (used for linking constraints). We can estimate a tight upper bound based on the most restrictive resource.
  - For Shirt ($i=1$): Min($150/3$, $160/4$) = Min(50, 40) = 40. So $U_1 = 40$.
  - For T-shirt ($i=2$): Min($150/2$, $160/3$) = Min(75, 53.33) = 53. So $U_2 = 53$.
  - For Casual ($i=3$): Min($150/6$, $160/6$) = Min(25, 26.66) = 25. So $U_3 = 25$.

| :---: | :---: | :---: | :---: | :---: | :---: | :---: |

# 3. Decision Variables

- $x_i$: Number of units of product $i$ produced per week.
  - Domain: $x_i \in \mathbb{Z}_{\ge 0}$ (Non-negative Integers) for $i \in I$.
- $y_i$: Binary variable indicating whether product $i$ is produced.
  - $y_i = 1$ if $x_i > 0$
  - $y_i = 0$ if $x_i = 0$
  - Domain: $y_i \in \{0, 1\}$ for $i \in I$.

# 4. Objective Function

Maximize Total Profit $Z$.
Profit = (Total Revenue - Total Variable Costs) - Total Fixed Costs.

$$
\text{Maximize } Z = \sum_{i=1}^{3} (p_i - c_i)x_i - \sum_{i=1}^{3} F_i y_i
$$

Substituting values:
$$
\text{Maximize } Z = (120 - 60)x_1 + (80 - 40)x_2 + (180 - 80)x_3 - 2000y_1 - 1500y_2 - 1000y_3
$$
$$
\text{Maximize } Z = 60x_1 + 40x_2 + 100x_3 - 2000y_1 - 1500y_2 - 1000y_3
$$

# 5. Operational Constraints

**1. Resource Constraints (Labor and Material):**
The total labor and material used must not exceed the weekly availability.

Labor Constraint:
$$
\sum_{i=1}^{3} l_i x_i \le L_{max}
$$
$$
3x_1 + 2x_2 + 6x_3 \le 150
$$

Material Constraint:
$$
\sum_{i=1}^{3} m_i x_i \le M_{max}
$$
$$
4x_1 + 3x_2 + 6x_3 \le 160
$$

**2. Linking Constraints (Fixed Cost Activation):**
If $x_i > 0$, then $y_i$ must be 1. If $y_i = 0$, then $x_i$ must be 0.
We use the upper bounds $U_i$ calculated earlier.

$$
x_i \le U_i y_i \quad \forall i \in I
$$

Specifically:
$$
x_1 \le 40 y_1
$$
$$
x_2 \le 53 y_2
$$
$$
x_3 \le 25 y_3
$$

**3. Variable Bounds:**
$$
x_i \ge 0, \quad x_i \in \mathbb{Z} \quad \forall i \in I
$$
$$
y_i \in \{0, 1\} \quad \forall i \in I
$$

# 6. Feasibility Sanity Check

Let's check if producing all three is feasible and profitable, or if some should be dropped.

*Contribution Margins:*
- Shirt: 60/unit
- T-shirt: 40/unit
- Casual: 100/unit

*Fixed Costs:*
- Shirt: 2000. Break-even units = $2000/60 = 33.33$. Need to produce >33 shirts to cover fixed cost.
- T-shirt: 1500. Break-even units = $1500/40 = 37.5$. Need to produce >37 T-shirts.
- Casual: 1000. Break-even units = $1000/100 = 10$. Need to produce >10 Casual items.

*Resource Check for "All Active" Scenario:*
If we try to produce enough of each to cover fixed costs:
- Min Shirts: 34
- Min T-shirts: 38
- Min Casual: 11

Labor Used: $3(34) + 2(38) + 6(11) = 102 + 76 + 66 = 244$.
Available Labor: 150.
$244 > 150$. **Infeasible** to produce minimum break-even quantities for all three simultaneously.

Therefore, the model must select a subset of products. The MILP formulation correctly handles this selection via the $y_i$ variables.

*Check specific subsets:*
1. **Only Casual ($y_3=1, y_1=y_2=0$):**
   Max $x_3$ limited by Labor: $6x_3 \le 150 \Rightarrow x_3 \le 25$.
   Max $x_3$ limited by Material: $6x_3 \le 160 \Rightarrow x_3 \le 26.6$.
   So max $x_3 = 25$.
   Profit = $100(25) - 1000 = 2500 - 1000 = 1500$.

2. **Only Shirt ($y_1=1$):**
   Max $x_1$ limited by Labor: $3x_1 \le 150 \Rightarrow x_1 \le 50$.
   Max $x_1$ limited by Material: $4x_1 \le 160 \Rightarrow x_1 \le 40$.
   So max $x_1 = 40$.
   Profit = $60(40) - 2000 = 2400 - 2000 = 400$.

3. **Only T-shirt ($y_2=1$):**
   Max $x_2$ limited by Labor: $2x_2 \le 150 \Rightarrow x_2 \le 75$.
   Max $x_2$ limited by Material: $3x_2 \le 160 \Rightarrow x_2 \le 53.3$.
   So max $x_2 = 53$.
   Profit = $40(53) - 1500 = 2120 - 1500 = 620$.

4. **Casual + Shirt ($y_3=1, y_1=1$):**
   Maximize $60x_1 + 100x_3 - 3000$
   s.t. $3x_1 + 6x_3 \le 150$
       $4x_1 + 6x_3 \le 160$
   From labor: $x_1 + 2x_3 \le 50 \Rightarrow x_1 \le 50 - 2x_3$.
   From material: $2x_1 + 3x_3 \le 80 \Rightarrow x_1 \le 40 - 1.5x_3$.
   
   Let's test integer values for $x_3$ (must be $>10$ to be profitable alone, but combined it just needs to contribute positively to the sum after shared fixed costs? No, fixed costs are sunk if $y=1$. We just maximize total contribution minus total fixed).
   
   Try $x_3 = 10$:
   $x_1 \le 50 - 20 = 30$.
   $x_1 \le 40 - 15 = 25$.
   So $x_1 = 25$.
   Profit = $60(25) + 100(10) - 3000 = 1500 + 1000 - 3000 = -500$. (Loss)
   
   Try $x_3 = 20$:
   $x_1 \le 50 - 40 = 10$.
   $x_1 \le 40 - 30 = 10$.
   So $x_1 = 10$.
   Profit = $60(10) + 100(20) - 3000 = 600 + 2000 - 3000 = -400$. (Loss)
   
   Try $x_3 = 25$ (Max possible for Casual):
   $x_1 \le 50 - 50 = 0$.
   $x_1 \le 40 - 37.5 = 2.5$.
   So $x_1 = 0$. But if $x_1=0$, $y_1$ should be 0. This reduces to Case 1.
   Profit = 1500.

5. **Casual + T-shirt ($y_3=1, y_2=1$):**
   Maximize $40x_2 + 100x_3 - 2500$
   s.t. $2x_2 + 6x_3 \le 150 \Rightarrow x_2 + 3x_3 \le 75$
       $3x_2 + 6x_3 \le 160 \Rightarrow x_2 + 2x_3 \le 53.33$
   
   From labor: $x_2 \le 75 - 3x_3$.
   From material: $x_2 \le 53.33 - 2x_3$.
   
   Try $x_3 = 10$:
   $x_2 \le 75 - 30 = 45$.
   $x_2 \le 53.33 - 20 = 33.33$.
   So $x_2 = 33$.
   Profit = $40(33) + 100(10) - 2500 = 1320 + 1000 - 2500 = -180$. (Loss)
   
   Try $x_3 = 15$:
   $x_2 \le 75 - 45 = 30$.
   $x_2 \le 53.33 - 30 = 23.33$.
   So $x_2 = 23$.
   Profit = $40(23) + 100(15) - 2500 = 920 + 1500 - 2500 = -580$. (Loss)
   
   Try $x_3 = 5$ (Below break even for casual alone, but maybe combined?):
   $x_2 \le 75 - 15 = 60$.
   $x_2 \le 53.33 - 10 = 43.33$.
   So $x_2 = 43$.
   Profit = $40(43) + 100(5) - 2500 = 1720 + 500 - 2500 = -280$.

   It seems combinations of fixed costs are too high relative to the resource constraints. The best single product is Casual Wear with a profit of 1500.

   Let's double check **Shirt + T-shirt**:
   Maximize $60x_1 + 40x_2 - 3500$
   s.t. $3x_1 + 2x_2 \le 150$
       $4x_1 + 3x_2 \le 160$
   Max possible contribution without fixed costs is bounded by resources.
   If $x_1=40, x_2=0$, Contrib=2400. Fixed=2000. Profit=400.
   If we mix:
   Try $x_1=20$.
   Labor: $60 + 2x_2 \le 150 \Rightarrow 2x_2 \le 90 \Rightarrow x_2 \le 45$.
   Mat: $80 + 3x_2 \le 160 \Rightarrow 3x_2 \le 80 \Rightarrow x_2 \le 26.6$.
   So $x_2=26$.
   Contrib = $60(20) + 40(26) = 1200 + 1040 = 2240$.
   Fixed = $2000 + 1500 = 3500$.
   Profit = $2240 - 3500 = -1260$. Loss.

   It appears the optimal solution is likely to produce only Casual Wear.

   The model is feasible and well-posed.

# Final Formulation Summary

**Model Type:** MILP

**Sets:**
$I = \{1, 2, 3\}$ (Shirt, T-shirt, Casual)

**Parameters:**
- $p = [120, 80, 180]$
- $c = [60, 40, 80]$
- $l = [3, 2, 6]$
- $m = [4, 3, 6]$
- $F = [2000, 1500, 1000]$
- $L_{max} = 150$
- $M_{max} = 160$
- $U = [40, 53, 25]$ (Upper bounds for linking)

**Variables:**
- $x_1, x_2, x_3 \in \mathbb{Z}_{\ge 0}$
- $y_1, y_2, y_3 \in \{0, 1\}$

**Objective:**
$$ \text{Maximize } Z = 60x_1 + 40x_2 + 100x_3 - 2000y_1 - 1500y_2 - 1000y_3 $$

**Constraints:**
1. $3x_1 + 2x_2 + 6x_3 \le 150$
2. $4x_1 + 3x_2 + 6x_3 \le 160$
3. $x_1 \le 40y_1$
4. $x_2 \le 53y_2$
5. $x_3 \le 25y_3$
6. $x_i \ge 0, \text{integer}$
7. $y_i \in \{0, 1\}$
