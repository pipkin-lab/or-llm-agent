## Model Type: LP (Linear Programming)

This is a classic **Assignment Problem**. Since each station must be assigned exactly one worker and each worker is assigned to exactly one station, the constraint matrix is totally unimodular. Therefore, the LP relaxation yields integer solutions, and no explicit integer restrictions are needed.

### Decision Variables

$$x_{w,s} = \begin{cases} 1 & \text{if worker } w \text{ is assigned to station } s \\ 0 & \text{otherwise} \end{cases} \quad \forall w \in W, \forall s \in S$$

**Domain**: $x_{w,s} \in \{0, 1\}$ (binary). *Note: Due to total unimodularity of the assignment constraint matrix, the LP relaxation $x_{w,s} \geq 0$ with the equality constraints below guarantees binary optimal solutions.*

### Objective Function

**MAXIMIZE** the overall production capacity of the assembly line.

> **Critical Interpretation Note**: The "overall production capacity" of a serial assembly line is determined by the **bottleneck** (the minimum throughput among all stations). However, the standard textbook formulation for this type of problem (maximizing total efficiency sum) treats the objective as the **sum of efficiencies** across all assigned station-worker pairs. Given the problem structure (a single assignment table with a maximization question and no explicit bottleneck/minimax language), the standard interpretation is to **maximize the sum of efficiencies**:

$$\text{MAXIMIZE } \quad Z = \sum_{w \in W} \sum_{s \in S} e_{w,s} \, x_{w,s}$$

$$Z = 2x_{A,I} + 3x_{A,II} + 4x_{A,III} + 1x_{A,IV} + 7x_{A,V} + 3x_{B,I} + 4x_{B,II} + 2x_{B,III} + 5x_{B,IV} + 6x_{B,V} + 2x_{C,I} + 5x_{C,II} + 3x_{C,III} + 4x_{C,IV} + 1x_{C,V} + 5x_{D,I} + 2x_{D,II} + 3x_{D,III} + 2x_{D,IV} + 5x_{D,V} + 3x_{E,I} + 7x_{E,II} + 6x_{E,III} + 2x_{E,IV} + 4x_{E,V}$$

### Operational Constraints

**1. Each station is assigned exactly one worker:**

$$\sum_{w \in W} x_{w,s} = 1 \quad \forall s \in S$$

Explicitly:
- $\sum_{w \in W} x_{w,I} = 1$  (Station I)
- $\sum_{w \in W} x_{w,II} = 1$  (Station II)
- $\sum_{w \in W} x_{w,III} = 1$  (Station III)
- $\sum_{w \in W} x_{w,IV} = 1$  (Station IV)
- $\sum_{w \in W} x_{w,V} = 1$  (Station V)

**2. Each worker is assigned to exactly one station:**

$$\sum_{s \in S} x_{w,s} = 1 \quad \forall w \in W$$

Explicitly:
