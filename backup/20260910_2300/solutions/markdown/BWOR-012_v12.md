### Model Type Declaration
**Model Type:** LP (Linear Program)

**Note:** The problem specifies "prioritized conditions" (1. Strict blending, 2. Maximize Profit, 3. Minimum Red production). In standard Operations Research, this implies a **Goal Programming** or **Lexicographic Optimization** structure. However, since Condition 1 (Blending) and Condition 3 (Min Red) are hard constraints that define the feasible region, and Condition 2 (Max Profit) is the sole objective within that region, the problem reduces to a standard Linear Program. The "priority" simply dictates that we do not sacrifice blending rules or the minimum Red volume to achieve higher profit. If the constraints are mutually exclusive or infeasible, the model is infeasible.

### Index Sets & Parameters

**Index Sets:**
*   $G = \{I, II, III\}$: Set of base liquor grades.
*   $B = \{R, Y, Bl\}$: Set of branded products (Red, Yellow, Blue).
*   $x_{g,b}$: Amount of Grade $g$ used in Brand $b$.

**Parameters (from Tables 4-13 and 4-14):**

*   **Supply Limits ($S_g$ in kg/day):**
    *   $S_I = 1500$
    *   $S_{II} = 2000$
    *   $S_{III} = 1000$

*   **Cost ($C_g$ in Yuan/kg):**
    *   $C_I = 6.0$
    *   $C_{II} = 4.5$
    *   $C_{III} = 3.0$

*   **Selling Price ($P_b$ in Yuan/kg):**
    *   $P_R = 5.5$
    *   $P_Y = 5.0$
    *   $P_{Bl} = 4.8$

*   **Blending Constraints (Proportions):**
    *   **Red ($R$):**
        *   Grade III < 10% $\Rightarrow$ Ratio of Grade III to Total Red < 0.10
        *   Grade I > 50% $\Rightarrow$ Ratio of Grade I to Total Red > 0.50
    *   **Yellow ($Y$):**
        *   Grade III < 70% $\Rightarrow$ Ratio of Grade III to Total Yellow < 0.70
        *   Grade I > 20% $\Rightarrow$ Ratio of Grade I to Total Yellow > 0.20
    *   **Blue ($Bl$):**
        *   Grade III < 50% $\Rightarrow$ Ratio of Grade III to Total Blue < 0.50
        *   Grade I > 10% $\Rightarrow$ Ratio of Grade I to Total Blue > 0.10

*   **Minimum Production Requirement:**
    *   Min Red Production = 2000 kg

### Decision Variables

Let $x_{g,b}$ be the amount (in kg) of base liquor Grade $g$ blended into Brand $b$.

*   **Domain:** $x_{g,b} \ge 0$ for all $g \in G, b \in B$.
*   **Variables:**
    *   $x_{I,R}, x_{II,R}, x_{III,R}$ (for Red)
    *   $x_{I,Y}, x_{II,Y}, x_{III,Y}$ (for Yellow)
    *   $x_{I,Bl}, x_{II,Bl}, x_{III,Bl}$ (for Blue)

Let $Z_b$ be the total production of Brand $b$:
*   $Z_R = x_{I,R} + x_{II,R} + x_{III,R}$
*   $Z_Y = x_{I,Y} + x_{II,Y} + x_{III,Y}$
*   $Z_{Bl} = x_{I,Bl} + x_{II,Bl} + x_{III,Bl}$

### Objective Function

Maximize Total Profit.
Profit = Total Revenue - Total Cost.

$$
\text{Maximize } Z_{obj} = \sum_{b \in B} P_b Z_b - \sum_{g \in G} C_g \left( \sum_{b \in B} x_{g,b} \right)
$$

Substituting values:
$$
\begin{aligned}
\text{Maximize } Z_{obj} = \;& 5.5(x_{I,R} + x_{II,R} + x_{III,R}) + 5.0(x_{I,Y} + x_{II,Y} + x_{III,Y}) + 4.8(x_{I,Bl} + x_{II,Bl} + x_{III,Bl}) \\
& - [6.0(x_{I,R} + x_{I,Y} + x_{I,Bl}) + 4.5(x_{II,R} + x_{II,Y} + x_{II,Bl}) + 3.0(x_{III,R} + x_{III,Y} + x_{III,Bl})]
\end{aligned}
$$

Simplifying coefficients per variable (Revenue - Cost):
*   **Grade I:** Cost 6.0.
    *   Red: $5.5 - 6.0 = -0.5$
    *   Yellow: $5.0 - 6.0 = -1.0$
    *   Blue: $4.8 - 6.0 = -1.2$
*   **Grade II:** Cost 4.5.
    *   Red: $5.5 - 4.5 = 1.0$
    *   Yellow: $5.0 - 4.5 = 0.5$
    *   Blue: $4.8 - 4.5 = 0.3$
*   **Grade III:** Cost 3.0.
    *   Red: $5.5 - 3.0 = 2.5$
    *   Yellow: $5.0 - 3.0 = 2.0$
    *   Blue: $4.8 - 3.0 = 1.8$

$$
\begin{aligned}
\text{Maximize } Z_{obj} = \;& -0.5x_{I,R} + 1.0x_{II,R} + 2.5x_{III,R} \\
& -1.0x_{I,Y} + 0.5x_{II,Y} + 2.0x_{III,Y} \\
& -1.2x_{I,Bl} + 0.3x_{II,Bl} + 1.8x_{III,Bl}
\end{aligned}
$$

### Operational Constraints

**1. Supply Constraints (Resource Availability):**
The total amount of each grade used across all brands cannot exceed the daily supply.
*   Grade I: $x_{I,R} + x_{I,Y} + x_{I,Bl} \le 1500$
*   Grade II: $x_{II,R} + x_{II,Y} + x_{II,Bl} \le 2000$
*   Grade III: $x_{III,R} + x_{III,Y} + x_{III,Bl} \le 1000$

**2. Minimum Production Constraint (Priority 3):**
At least 2,000 kg of Red brand liquor must be produced.
*   $x_{I,R} + x_{II,R} + x_{III,R} \ge 2000$

**3. Blending Proportion Constraints (Priority 1):**
These are linearized ratio constraints. Note that the problem uses strict inequalities ($<$ and $>$). In linear programming, strict inequalities are typically handled as non-strict ($\le$ or $\ge$) with a small epsilon or by assuming the boundary is effectively the limit. Given "strictly follow", we model the limits as the boundaries. If a variable is 0, the ratio is undefined, but since we have a minimum production of 2000 for Red, $Z_R > 0$. For Yellow and Blue, we must ensure $Z_Y, Z_{Bl} > 0$ if any blend is used, or handle the case where production is 0. Standard practice: If $Z_b$ can be 0, the constraints $x_{g,b} \le \alpha Z_b$ are valid (if $Z_b=0$, then $x_{g,b}=0$).

*   **Red Brand ($Z_R = x_{I,R} + x_{II,R} + x_{III,R}$):**
    *   Grade III < 10%: $x_{III,R} \le 0.10 Z_R \Rightarrow x_{III,R} \le 0.10(x_{I,R} + x_{II,R} + x_{III,R})$
        *   Rearranged: $0.90x_{III,R} \le 0.10(x_{I,R} + x_{II,R}) \Rightarrow 9x_{III,R} \le x_{I,R} + x_{II,R}$
    *   Grade I > 50%: $x_{I,R} \ge 0.50 Z_R \Rightarrow x_{I,R} \ge 0.50(x_{I,R} + x_{II,R} + x_{III,R})$
        *   Rearranged: $0.50x_{I,R} \ge 0.50(x_{II,R} + x_{III,R}) \Rightarrow x_{I,R} \ge x_{II,R} + x_{III,R}$

*   **Yellow Brand ($Z_Y = x_{I,Y} + x_{II,Y} + x_{III,Y}$):**
    *   Grade III < 70%: $x_{III,Y} \le 0.70 Z_Y \Rightarrow 3x_{III,Y} \le 0.70(x_{I,Y} + x_{II,Y})$ is incorrect simplification.
        *   $x_{III,Y} \le 0.7(x_{I,Y} + x_{II,Y} + x_{III,Y}) \Rightarrow 0.3x_{III,Y} \le 0.7(x_{I,Y} + x_{II,Y}) \Rightarrow 3x_{III,Y} \le 7(x_{I,Y} + x_{II,Y})$
    *   Grade I > 20%: $x_{I,Y} \ge 0.20 Z_Y \Rightarrow x_{I,Y} \ge 0.2(x_{I,Y} + x_{II,Y} + x_{III,Y})$
        *   $0.8x_{I,Y} \ge 0.2(x_{II,Y} + x_{III,Y}) \Rightarrow 4x_{I,Y} \ge x_{II,Y} + x_{III,Y}$

*   **Blue Brand ($Z_{Bl} = x_{I,Bl} + x_{II,Bl} + x_{III,Bl}$):**
    *   Grade III < 50%: $x_{III,Bl} \le 0.50 Z_{Bl} \Rightarrow x_{III,Bl} \le 0.5(x_{I,Bl} + x_{II,Bl})$
        *   $0.5x_{III,Bl} \le 0.5(x_{I,Bl} + x_{II,Bl}) \Rightarrow x_{III,Bl} \le x_{I,Bl} + x_{II,Bl}$
    *   Grade I > 10%: $x_{I,Bl} \ge 0.10 Z_{Bl} \Rightarrow x_{I,Bl} \ge 0.1(x_{I,Bl} + x_{II,Bl} + x_{III,Bl})$
        *   $0.9x_{I,Bl} \ge 0.1(x_{II,Bl} + x_{III,Bl}) \Rightarrow 9x_{I,Bl} \ge x_{II,Bl} + x_{III,Bl}$

**4. Non-negativity:**
$x_{g,b} \ge 0$ for all $g \in \{I, II, III\}, b \in \{R, Y, Bl\}$.

### Feasibility Sanity Check

1.  **Red Constraint Check:**
    *   We need $Z_R \ge 2000$.
    *   Constraint: $x_{I,R} \ge x_{II,R} + x_{III,R}$ and $x_{I,R} \ge 0.5 Z_R$.
    *   To minimize cost (and potentially allow more of other brands), we look at the most expensive ingredient in Red. Grade I is the most expensive (6.0).
    *   Min Grade I required for Red: Since $x_{I,R} \ge 0.5 Z_R$ and $Z_R \ge 2000$, we need at least $1000$ kg of Grade I for Red.
    *   Max Grade I available: 1500 kg.
    *   Remaining Grade I for Yellow/Blue: $1500 - 1000 = 500$ kg.

2.  **Grade III Constraint Check:**
    *   Total Supply Grade III: 1000 kg.
    *   Red uses $x_{III,R}$. From $9x_{III,R} \le x_{I,R} + x_{II,R}$, and knowing $x_{I,R} \ge 1000$, the max $x_{III,R}$ is limited.
    *   Actually, let's look at the "Grade III < 10%" constraint for Red.
    *   $x_{III,R} < 0.1 Z_R$. If $Z_R=2000$, $x_{III,R} < 200$.
    *   So Red consumes at most ~200 kg of Grade III.
    *   Remaining Grade III for Y/Bl: $1000 - 200 = 800$ kg.

3.  **Profitability Check:**
    *   Red uses Grade I (Loss 0.5), Grade II (Gain 1.0), Grade III (Gain 2.5).
    *   We want to maximize Grade II and III in Red, but constrained by $x_{I,R} \ge x_{II,R} + x_{III,R}$.
    *   Let $x_{II,R} = A, x_{III,R} = B$. Then $x_{I,R} \ge A+B$.
    *   $Z_R = A+B + (A+B) = 2(A+B)$? No, $Z_R = x_I + x_{II} + x_{III}$.
    *   If we set $x_I = x_{II} + x_{III}$, then $Z_R = 2(x_{II} + x_{III})$.
    *   To get $Z_R = 2000$, we need $x_{II} + x_{III} = 1000$.
    *   Maximize profit contribution from this mix: $1.0 x_{II} + 2.5 x_{III}$.
    *   We should use as much Grade III as possible in Red.
    *   Constraint on $x_{III,R}$: $x_{III,R} \le 0.1 Z_R = 200$.
    *   So max $x_{III,R} = 200$. Then $x_{II,R} = 800$.
    *   Check constraint $9x_{III,R} \le x_{I,R} + x_{II,R}$:
        *   LHS: $9(200) = 1800$.
        *   RHS: $x_{I,R} + 800$. Since $x_{I,R} \ge x_{II}+x_{III} = 1000$, RHS $\ge 1800$. Holds.
    *   So optimal Red Mix: $x_{I,R}=1000, x_{II,R}=800, x_{III,R}=200$.
    *   Cost of Red Ingredients: $1000(6) + 800(4.5) + 200(3) = 6000 + 3600 + 600 = 10200$.
    *   Revenue Red: $2000(5.5) = 11000$.
    *   Profit Red: 800.

4.  **Remaining Resources:**
    *   Grade I Used: 1000. Remaining: 500.
    *   Grade II Used: 800. Remaining: 1200.
    *   Grade III Used: 200. Remaining: 800.

5.  **Yellow and Blue Production:**
    *   We have 500 Grade I, 1200 Grade II, 800 Grade III left.
    *   Yellow Profit Coeffs: I(-1.0), II(0.5), III(2.0).
    *   Blue Profit Coeffs: I(-1.2), II(0.3), III(1.8).
    *   Yellow is more profitable for Grade II and III than Blue. We should prioritize Yellow.
    *   Yellow Constraints:
        *   $4x_{I,Y} \ge x_{II,Y} + x_{III,Y}$
        *   $3x_{III,Y} \le 7(x_{I,Y} + x_{II,Y})$
    *   We want to use up the cheap Grade III (Gain 2.0) and Grade II (Gain 0.5).
    *   Grade I is negative profit, so we use the minimum required.
    *   Min Grade I for Yellow: $x_{I,Y} \ge \frac{x_{II,Y} + x_{III,Y}}{4}$.
    *   Let's try to use all remaining Grade III (800) in Yellow.
    *   $x_{III,Y} = 800$.
    *   Constraint 2: $3(800) \le 7(x_{I,Y} + x_{II,Y}) \Rightarrow 2400 \le 7(x_{I,Y} + x_{II,Y}) \Rightarrow x_{I,Y} + x_{II,Y} \ge 342.86$.
    *   Constraint 1: $4x_{I,Y} \ge x_{II,Y} + 800 \Rightarrow x_{II,Y} \le 4x_{I,Y} - 800$.
    *   To maximize profit, we want to maximize $0.5 x_{II,Y}$. So we want large $x_{II,Y}$.
    *   Max $x_{II,Y}$ occurs when $x_{I,Y}$ is as large as possible? No, $x_{II,Y}$ is bounded above by $4x_{I,Y} - 800$.
    *   Also bounded by supply $x_{II,Y} \le 1200$.
    *   Also bounded by supply $x_{I,Y} \le 500$.
    *   Let's check if we can satisfy $x_{I,Y} + x_{II,Y} \ge 342.86$.
    *   If we set $x_{I,Y}$ to its minimum to save expensive Grade I? No, Grade I has negative profit, so we want *minimum* Grade I.
    *   Wait, the constraint is $4x_{I,Y} \ge x_{II,Y} + 800$. This links them.
    *   Substitute $x_{II,Y} = 4x_{I,Y} - 800$ (boundary case for max $x_{II}$ given $x_I$).
    *   Check other constraint: $x_{I,Y} + (4x_{I,Y} - 800) \ge 342.86 \Rightarrow 5x_{I,Y} \ge 1142.86 \Rightarrow x_{I,Y} \ge 228.57$.
    *   So min $x_{I,Y} \approx 229$.
    *   If $x_{I,Y} = 229$, then $x_{II,Y} = 4(229) - 800 = 916 - 800 = 116$.
    *   Check supply: $x_{I,Y}=229 \le 500$ (OK). $x_{II,Y}=116 \le 1200$ (OK).
    *   Profit from this Yellow batch:
        *   Rev: $5.0(229 + 116 + 800) = 5.0(1145) = 5725$.
        *   Cost: $229(6) + 116(4.5) + 800(3) = 1374 + 522 + 2400 = 4296$.
        *   Profit: $5725 - 4296 = 1429$.
    *   Remaining Resources after this Yellow:
        *   Grade I: $500 - 229 = 271$.
        *   Grade II: $1200 - 116 = 1084$.
        *   Grade III: $800 - 800 = 0$.
    *   Can we produce Blue?
        *   Blue requires Grade III? No, $x_{III,Bl} \le x_{I,Bl} + x_{II,Bl}$. We have 0 Grade III left. So $x_{III,Bl}=0$.
        *   Blue Profit Coeffs with 0 Grade III: I(-1.2), II(0.3).
        *   We have 271 Grade I and 1084 Grade II.
        *   Constraint: $9x_{I,Bl} \ge x_{II,Bl}$.
        *   We want to use Grade II (positive profit).
        *   Max $x_{II,Bl}$ subject to $x_{II,Bl} \le 9x_{I,Bl}$.
        *   Also $x_{I,Bl} \le 271$.
        *   Max $x_{I,Bl} = 271 \Rightarrow$ Max $x_{II,Bl} = 9(271) = 2439$.
        *   Supply of Grade II is 1084. So we can use all 1084 Grade II.
        *   Required Grade I for 1084 Grade II: $x_{I,Bl} \ge 1084/9 = 120.44$.
        *   Let $x_{II,Bl} = 1084, x_{I,Bl} = 121$ (integer not required, continuous). Let's use 120.45.
        *   Profit Blue:
            *   Rev: $4.8(120.45 + 1084) = 4.8(1204.45) = 5781.36$.
            *   Cost: $120.45(6) + 1084(4.5) = 722.7 + 4878 = 5600.7$.
            *   Profit: $5781.36 - 5600.7 = 180.66$.
    *   Total Profit $\approx 800 (Red) + 1429 (Yellow) + 180 (Blue) = 2409$.

The model is feasible.
