## Model Type Declaration
**MILP** (Mixed Integer Linear Programming)
Since the decision is to select specific discrete courses (binary choices), and the objective is to minimize the count of selected courses, this is a binary integer programming problem.

## Index Sets & Parameters

**Sets:**
*   $C$: Set of all available courses.
    *   $C = \{1, 2, 3, 4, 5, 6, 7\}$
    *   1: Calculus
    *   2: Operations Research
    *   3: Data Structures
    *   4: Managerial Statistics
    *   5: Computer Simulation
    *   6: Computer Programming
    *   7: Forecasting

**Parameters:**

*   $Req_{Math}$: Required number of Mathematics courses = 2
*   $Req_{OR}$: Required number of Operations Research courses = 2
*   $Req_{CS}$: Required number of Computer Science courses = 2

**Category Membership Matrix ($A_{c,k}$):**
Where $A_{c,k} = 1$ if course $c$ belongs to category $k$, else 0.
Categories $k \in \{M, OR, CS\}$.

*   **Course 1 (Calculus):** $A_{1,M}=1$, others 0.
*   **Course 2 (Operations Research):** $A_{2,M}=1$, $A_{2,OR}=1$, others 0.
*   **Course 3 (Data Structures):** $A_{3,CS}=1$, $A_{3,M}=1$, others 0.
*   **Course 4 (Managerial Statistics):** $A_{4,M}=1$, $A_{4,OR}=1$, others 0.
*   **Course 5 (Computer Simulation):** $A_{5,CS}=1$, $A_{5,OR}=1$, others 0.
*   **Course 6 (Computer Programming):** $A_{6,CS}=1$, others 0.
*   **Course 7 (Forecasting):** $A_{7,OR}=1$, $A_{7,M}=1$, others 0.

**Prerequisites ($P_{c,p}$):**
Where $P_{c,p}=1$ if course $c$ requires course $p$ as a prerequisite.
*   Course 5 (Computer Simulation) requires Course 6 (Computer Programming): $P_{5,6}=1$
*   Course 3 (Data Structures) requires Course 6 (Computer Programming): $P_{3,6}=1$
*   Course 4 (Managerial Statistics) requires Course 1 (Calculus): $P_{4,1}=1$
*   Course 7 (Forecasting) requires Course 4 (Managerial Statistics): $P_{7,4}=1$
*   All other $P_{c,p} = 0$.

## Decision Variables

Let $x_c$ be a binary variable for each course $c \in C$:
$$
x_c = \begin{cases} 
1 & \text{if course } c \text{ is selected} \\
0 & \text{otherwise}
\end{cases}
$$
Domain: $x_c \in \{0, 1\} \quad \forall c \in C$

## Objective Function

Minimize the total number of courses taken:

$$
\text{Minimize } Z = \sum_{c \in C} x_c
$$

## Operational Constraints

**1. Category Requirements**
The student must select exactly the required number of courses in each category. Note that a single course can satisfy multiple category requirements simultaneously.

*   **Mathematics Requirement:**
    $$
    \sum_{c \in C} A_{c,M} x_c = Req_{Math} \quad (\sum A_{c,M} x_c = 2)
    $$
    Expanded: $x_1 + x_2 + x_3 + x_4 + x_7 = 2$

*   **Operations Research Requirement:**
    $$
    \sum_{c \in C} A_{c,OR} x_c = Req_{OR} \quad (\sum A_{c,OR} x_c = 2)
    $$
    Expanded: $x_2 + x_4 + x_5 + x_7 = 2$

*   **Computer Science Requirement:**
    $$
    \sum_{c \in C} A_{c,CS} x_c = Req_{CS} \quad (\sum A_{c,CS} x_c = 2)
    $$
    Expanded: $x_3 + x_5 + x_6 = 2$

**2. Prerequisite Constraints**
If a course is selected, its prerequisite(s) must also be selected.
Constraint form: $x_c \leq \sum_{p} P_{c,p} x_p$ for all $c$.

*   **For Computer Simulation (5):** Requires Computer Programming (6).
    $$x_5 \leq x_6$$
*   **For Data Structures (3):** Requires Computer Programming (6).
    $$x_3 \leq x_6$$
*   **For Managerial Statistics (4):** Requires Calculus (1).
    $$x_4 \leq x_1$$
*   **For Forecasting (7):** Requires Managerial Statistics (4).
    $$x_7 \leq x_4$$

**3. Non-negativity / Integrality**
$$
x_c \in \{0, 1\} \quad \forall c \in \{1, 2, 3, 4, 5, 6, 7\}
$$

### Feasibility & Solution Analysis (Sanity Check)

Let's deduce the optimal solution to ensure the model captures the logic correctly.

1.  **CS Constraint:** $x_3 + x_5 + x_6 = 2$.
    *   Options for $\{x_3, x_5, x_6\}$ are $(1,1,0), (1,0,1), (0,1,1)$.
    *   Note: $x_6$ (Programming) is a prerequisite for both $x_3$ and $x_5$.
    *   If we pick $x_3=1$ or $x_5=1$, we *must* have $x_6=1$.
    *   Case A: $x_6=1$. Then we need one more from $\{x_3, x_5\}$. So either $(x_3=1, x_5=0, x_6=1)$ or $(x_3=0, x_5=1, x_6=1)$.
    *   Case B: $x_6=0$. Then $x_3=0$ and $x_5=0$. But sum must be 2. Impossible.
    *   Therefore, **$x_6$ (Computer Programming) MUST be selected.**

2.  **Implications of $x_6=1$:**
    *   From CS constraint: We need exactly one of $x_3$ or $x_5$ to be 1.
    
    *   **Scenario 1: Select Data Structures ($x_3=1, x_5=0$)**
        *   Current CS count: $1 (x_3) + 0 (x_5) + 1 (x_6) = 2$. (Satisfied)
        *   Current Math count: $x_3$ contributes 1. Need 1 more Math from $\{x_1, x_2, x_4, x_7\}$.
        *   Current OR count: 0. Need 2 OR from $\{x_2, x_4, x_5, x_7\}$. Since $x_5=0$, we need 2 from $\{x_2, x_4, x_7\}$.
        *   Prereqs:
            *   $x_4 \leq x_1$.
            *   $x_7 \leq x_4 \leq x_1$.
        *   We need to pick 2 OR courses from $\{2, 4, 7\}$.
            *   If we pick $x_7=1$, we need $x_4=1$ and $x_1=1$.
                *   This gives OR: $x_7=1, x_4=1$. Sum = 2. (Satisfied)
                *   Math check: $x_3=1, x_4=1, x_7=1, x_1=1$. Sum = 4. But we only need 2 Math.
                *   Wait, the constraint is Equality $=2$.
                *   In this sub-case: Math courses selected are $x_3, x_4, x_7, x_1$. That's 4 courses. This violates Math $=2$.
                *   So we cannot pick $x_7$ if it forces too many Math courses? No, we just can't pick the others.
                *   Let's re-evaluate: We need exactly 2 Math. We already have $x_3=1$ (Math). We need exactly 1 more Math from $\{x_1, x_2, x_4, x_7\}$.
                *   We need exactly 2 OR from $\{x_2, x_4, x_7\}$ (since $x_5=0$).
                *   If we pick $x_2$ (OR, Math):
                    *   Math count so far: $x_3(1) + x_2(1) = 2$. (Satisfied).
                    *   We need 1 more OR. Options: $x_4$ or $x_7$.
                    *   If we pick $x_4$: Math count becomes $2+1=3$ (Violation).
                    *   If we pick $x_7$: Math count becomes $2+1=3$ (Violation).
                    *   So $x_2$ cannot be part of the solution if we need another OR course that is also Math?
                    *   Wait, is there a non-Math OR course?
                    *   OR courses: $2(M,OR), 4(M,OR), 5(CS,OR), 7(OR,M)$.
                    *   All OR courses are ALSO Math courses!
                    *   Therefore, selecting 2 OR courses means selecting 2 Math courses (at least).
                    *   We already have $x_3$ (Math).
                    *   Total Math = (Math from OR choices) + (Math from non-OR choices).
                    *   Since all OR courses are Math, selecting 2 OR courses contributes 2 to the Math count.
                    *   The Math constraint is $Sum = 2$.
                    *   Therefore, the **only** Math courses selected can be the 2 OR courses.
                    *   This implies **no other Math courses** can be selected.
                    *   Math courses are $\{1, 2, 3, 4, 7\}$.
                    *   So $x_1=0, x_3=0$ (if not OR), etc.
                    *   But we established $x_3=1$ in Scenario 1. $x_3$ is a Math course.
                    *   So if $x_3=1$, we have 1 Math course. We need 1 more Math course.
                    *   We also need 2 OR courses. All OR courses are Math.
                    *   So the 2 OR courses will add 2 to the Math count.
                    *   Total Math = $1 (x_3) + 2 (OR courses) = 3$.
                    *   This violates Math $=2$.
                    *   **Conclusion: Scenario 1 ($x_3=1$) is INFEASIBLE.**

    *   **Scenario 2: Select Computer Simulation ($x_5=1, x_3=0$)**
        *   Current CS count: $0 (x_3) + 1 (x_5) + 1 (x_6) = 2$. (Satisfied)
        *   Current Math count: $x_5$ is NOT Math. $x_6$ is NOT Math.
        *   Current OR count: $x_5$ IS OR. So we have 1 OR. We need 1 more OR.
        *   Current Math count: 0. We need 2 Math.
        *   Available OR courses to pick the 2nd one from: $\{2, 4, 7\}$ (since $x_5$ is already picked).
        *   All these are also Math.
        *   Let the 2nd OR course be $Y \in \{2, 4, 7\}$.
        *   Picking $Y$ adds 1 to OR count (Total OR=2, Satisfied) and 1 to Math count.
        *   We need 1 more Math course to satisfy Math=2.
        *   This 1 more Math course must be a Math course that is **NOT** an OR course (otherwise OR count would exceed 2).
        *   Math courses: $\{1, 2, 3, 4, 7\}$.
        *   OR courses: $\{2, 4, 5, 7\}$.
        *   Math courses that are NOT OR: $\{1, 3\}$.
        *   So we must pick either $x_1=1$ or $x_3=1$ (but not both, as that would make Math=3).
        *   Let's check prerequisites.
        
        *   **Option 2a: Pick $Y=x_2$ (Operations Research course)**
            *   Selected so far: $x_5=1, x_6=1, x_2=1$.
            *   Need 1 more Math from $\{1, 3\}$.
            *   If pick $x_1=1$:
                *   Courses: $\{1, 2, 5, 6\}$.
                *   Math: $1, 2$ (Count 2). OK.
                *   OR: $2, 5$ (Count 2). OK.
                *   CS: $5, 6$ (Count 2). OK.
                *   Prereqs:
                    *   $x_5 \leq x_6$ ($1 \leq 1$). OK.
                    *   $x_2$ no prereqs. OK.
                    *   $x_1$ no prereqs. OK.
                *   Total courses: 4.
            *   If pick $x_3=1$:
                *   Courses: $\{2, 3, 5, 6\}$.
                *   Math: $2, 3$ (Count 2). OK.
                *   OR: $2, 5$ (Count 2). OK.
                *   CS: $3, 5, 6$ (Count 3). **Violation** (Need exactly 2).
        
        *   **Option 2b: Pick $Y=x_4$ (Managerial Statistics)**
            *   Selected so far: $x_5=1, x_6=1, x_4=1$.
            *   Need 1 more Math from $\{1, 3\}$.
            *   Prereq for $x_4$: $x_4 \leq x_1$. So if $x_4=1$, **$x_1$ MUST be 1**.
            *   So we are forced to pick $x_1=1$.
            *   Courses: $\{1, 4, 5, 6\}$.
            *   Math: $1, 4$ (Count 2). OK.
            *   OR: $4, 5$ (Count 2). OK.
            *   CS: $5, 6$ (Count 2). OK.
            *   Prereqs:
                *   $x_5 \leq x_6$ ($1 \leq 1$). OK.
                *   $x_4 \leq x_1$ ($1 \leq 1$). OK.
            *   Total courses: 4.

        *   **Option 2c: Pick $Y=x_7$ (Forecasting)**
            *   Selected so far: $x_5=1, x_6=1, x_7=1$.
            *   Need 1 more Math from $\{1, 3\}$.
            *   Prereq for $x_7$: $x_7 \leq x_4$. So if $x_7=1$, **$x_4$ MUST be 1**.
            *   Prereq for $x_4$: $x_4 \leq x_1$. So if $x_4=1$, **$x_1$ MUST be 1**.
            *   So we are forced to pick $x_4=1$ and $x_1=1$.
            *   Courses: $\{1, 4, 5, 6, 7\}$.
            *   Math: $1, 4, 7$ (Count 3). **Violation** (Need 2).
            *   So this option is infeasible.

    *   **Comparison of Feasible Solutions:**
        *   Solution A: $\{1, 2, 5, 6\}$ -> Calculus, Ops Research, Computer Simulation, Computer Programming. (4 courses)
        *   Solution B: $\{1, 4, 5, 6\}$ -> Calculus, Managerial Statistics, Computer Simulation, Computer Programming. (4 courses)

    *   Are there solutions with 3 courses?
        *   Sum $x_c = 3$.
        *   We know $x_6=1$ is required.
        *   CS requires 2 from $\{3, 5, 6\}$. With $x_6=1$, we need one of $x_3, x_5$.
        *   So we have at least $\{6, 3\}$ or $\{6, 5\}$.
        *   If $\{6, 3\}$: Math count 1 ($x_3$). OR count 0. Need 2 OR.
            *   Remaining slots: 1 course left (since total 3).
            *   Can 1 course provide 2 OR? No, each course provides at most 1 OR credit (even if multi-category, it counts as 1 per category).
            *   So we can get at most 1 OR from the 3rd course.
            *   Total OR would be 1. Violation.
        *   If $\{6, 5\}$: Math count 0. OR count 1 ($x_5$). Need 2 Math, 1 more OR.
            *   Remaining slots: 1 course left.
            *   Can 1 course provide 2 Math AND 1 OR?
            *   Courses that are Math AND OR: $\{2, 4, 7\}$.
            *   If we pick one of these, say $x_2$:
                *   Math count becomes 1. (Need 2). Violation.
            *   So 1 course cannot satisfy both remaining requirements (2 Math, 1 OR) because max Math contribution is 1 per course.
        
    *   Therefore, minimum is 4.

**Answer:** The minimum number of courses is **4**.
Possible sets:
1. Calculus, Operations Research, Computer Simulation, Computer Programming
2. Calculus, Managerial Statistics, Computer Simulation, Computer Programming
