To formulate the optimal job sequencing problem for minimizing the makespan (total processing time) on a two-machine flow shop, we use a Mixed Integer Linear Programming (MILP) model. This is a classic sequencing problem that can be solved exactly using binary variables to define the order of jobs.

### 1. Index Sets & Parameters

**Index Sets:**
*   $J = \{1, 2, 3, 4, 5, 6\}$: The set of jobs.

**Parameters (Processing Times in minutes):**
*   $A_j$: Processing time of job $j$ on Machine A.
    *   $A_1 = 30, A_2 = 60, A_3 = 60, A_4 = 20, A_5 = 80, A_6 = 90$
*   $B_j$: Processing time of job $j$ on Machine B.
    *   $B_1 = 70, B_2 = 70, B_3 = 50, B_4 = 60, B_5 = 30, B_6 = 40$
*   $M$: A large constant (Big-M) used in sequencing constraints. A safe upper bound is the sum of all processing times on both machines:
    *   $M = \sum_{j \in J} (A_j + B_j) = (30+70) + (60+70) + (60+50) + (20+60) + (80+30) + (90+40) = 100 + 130 + 110 + 80 + 110 + 130 = 660$

### 2. Decision Variables

*   $C_{A,j}$: Continuous variable representing the completion time of job $j$ on Machine A. ($C_{A,j} \ge 0$)
*   $C_{B,j}$: Continuous variable representing the completion time of job $j$ on Machine B. ($C_{B,j} \ge 0$)
*   $x_{ij}$: Binary variable where $x_{ij} = 1$ if job $i$ is processed before job $j$ on **both** machines (i.e., in the sequence), and 0 otherwise, for all distinct $i, j \in J$.
    *   Note: In a 2-machine flow shop with the same job order on both machines (permutation flow shop), the relative order is the same for both machines.

### 3. Objective Function

Minimize the makespan (total processing time), which is the maximum completion time among all jobs on the final machine (Machine B).

$$ \text{Minimize } Z = \max_{j \in J} C_{B,j} $$

To linearize this, we introduce an auxiliary variable $C_{max}$:
$$ \text{Minimize } C_{max} $$
Subject to:
$$ C_{max} \ge C_{B,j} \quad \forall j \in J $$

### 4. Operational Constraints

**A. Machine A Sequencing and Timing**
For any pair of distinct jobs $i, j$, either $i$ precedes $j$ or $j$ precedes $i$.
1.  **Precedence on Machine A:**
    $$ C_{A,j} \ge C_{A,i} + A_j - M(1 - x_{ij}) \quad \forall i, j \in J, i \neq j $$
    $$ C_{A,i} \ge C_{A,j} + A_i - M x_{ij} \quad \forall i, j \in J, i \neq j $$
    *(Simplification: We can just use one set of constraints if we define $x_{ij}$ strictly as "i before j". If $x_{ij}=1$, $C_{A,j} \ge C_{A,i} + A_j$. If $x_{ij}=0$, $C_{A,i} \ge C_{A,j} + A_i$. Note that $x_{ji} = 1 - x_{ij}$.)*

    Let's use the standard disjunctive formulation:
    $$ C_{A,j} \ge C_{A,i} + A_j - M(1 - x_{ij}) \quad \forall i, j \in J, i \neq j $$
    $$ x_{ij} + x_{ji} = 1 \quad \forall i, j \in J, i \neq j, i < j $$
    *(This ensures a total order.)*

    Actually, a more robust standard formulation uses the "before" logic explicitly for both machines to ensure the flow shop constraint. Let's refine the constraints to be precise.

    **Refined Timing Constraints:**

    1.  **Machine A Non-Overlap:**
        $$ C_{A,j} \ge C_{A,i} + A_j - M(1 - x_{ij}) \quad \forall i, j \in J, i \neq j $$
        Where $x_{ij}=1$ means job $i$ is before job $j$ in the sequence.

    2.  **Machine B Non-Overlap:**
        Since it is a permutation flow shop, the order on B is the same as on A.
        $$ C_{B,j} \ge C_{B,i} + B_j - M(1 - x_{ij}) \quad \forall i, j \in J, i \neq j $$

    3.  **Flow Shop Transition (A to B):**
        A job cannot start on Machine B until it has finished on Machine A.
        $$ C_{B,j} \ge C_{A,j} + B_j \quad \forall j \in J $$
        *(Wait, strictly $C_{B,j}$ is the completion time. The start time on B is $C_{B,j} - B_j$. The constraint is $C_{B,j} - B_j \ge C_{A,j}$, which simplifies to $C_{B,j} \ge C_{A,j} + B_j$.)*

    4.  **Binary Variable Consistency:**
        $$ x_{ij} + x_{ji} = 1 \quad \forall i, j \in J, i < j $$
        $$ x_{ij} \in \{0, 1\} \quad \forall i, j \in J, i \neq j $$

    5.  **Non-negativity:**
        $$ C_{A,j} \ge 0, \quad C_{B,j} \ge 0 \quad \forall j \in J $$

### Summary of the Model

**Model Type:** MILP

**Minimize:**
$$ C_{max} $$

**Subject to:**

1.  $$ C_{max} \ge C_{B,j} \quad \forall j \in J $$
2.  $$ C_{A,j} \ge C_{A,i} + A_j - M(1 - x_{ij}) \quad \forall i, j \in J, i \neq j $$
3.  $$ C_{B,j} \ge C_{B,i} + B_j - M(1 - x_{ij}) \quad \forall i, j \in J, i \neq j $$
4.  $$ C_{B,j} \ge C_{A,j} + B_j \quad \forall j \in J $$
5.  $$ x_{ij} + x_{ji} = 1 \quad \forall i, j \in J, i < j $$
6.  $$ x_{ij} \in \{0, 1\} \quad \forall i, j \in J, i \neq j $$
7.  $$ C_{A,j}, C_{B,j} \ge 0 \quad \forall j \in J $$

**Parameters:**
*   $A = [30, 60, 60, 20, 80, 90]$
*   $B = [70, 70, 50, 60, 30, 40]$
*   $M = 660$
