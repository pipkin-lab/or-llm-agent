### Decision Variables

| Variable | Domain | Description |
|----------|--------|-------------|
| $x_i$ | $x_i \geq 0$, **integer**, $\forall i \in I$ | Monthly production quantity of brand $i$ (units) |
| $y_i$ | $y_i \in \{0, 1\}$, $\forall i \in I$ | Binary indicator: $y_i = 1$ if brand $i$ is produced, $0$ otherwise |

**Domain justification:**
- $x_i$ is **INTEGER**: automobiles are discrete physical units (one cannot produce a fraction of a car).
- $y_i$ is **BINARY**: encodes the all-or-nothing batch constraint.
- The model is a **MILP** because it contains both integer and binary variables with a linear objective and linear constraints.

### Operational Constraints

**1. Steel resource constraint:**
$$1.5\,x_1 + 3.0\,x_2 + 5.0\,x_3 \;\leq\; 6{,}000$$

**2. Labor resource constraint:**
$$300\,x_1 + 250\,x_2 + 400\,x_3 \;\leq\; 600{,}000$$

**3. Minimum batch size constraints (all-or-nothing logic):**

For each brand $i$, if production occurs ($y_i=1$), output must be at least 1,000 units; if not produced ($y_i=0$), output must be zero.

$$x_i \;\geq\; 1{,}000\, y_i, \quad \forall\, i \in I$$

$$x_i \;\leq\; \bar{x}_i\, y_i, \quad \forall\, i \in I$$

where $\bar{x}_i$ is a valid upper bound on $x_i$ when $y_i = 1$. We derive tight bounds from the resource constraints:

- For $i=1$ (Zhujiang): from steel, $x_1 \leq 6000/1.5 = 4{,}000$; from labor, $x_1 \leq 600{,}000/300 = 2{,}000$. So $\bar{x}_1 = 2{,}000$.
- For $i=2$ (Songhuajiang): from steel, $x_2 \leq 6000/3.0 = 2{,}000$; from labor, $x_2 \leq 600{,}000/250 = 2{,}400$. So $\bar{x}_2 = 2{,}000$.
- For $i=3$ (Huanghe): from steel, $x_3 \leq 6000/5.0 = 1{,}200$; from labor, $x_3 \leq 600{,}000/400 = 1{,}500$. So $\bar{x}_3 = 1{,}200$.

Thus:
$$x_1 \leq 2{,}000\, y_1, \quad x_2 \leq 2{,}000\, y_2, \quad x_3 \leq 1{,}200\, y_3$$

**4. Non-negativity and integrality:**
$$x_i \geq 0, \quad x_i \in \mathbb{Z}, \quad \forall\, i \in I$$
$$y_i \in \{0, 1\}, \quad \forall\, i \in I$$

### Feasibility Sanity Check

- **All three brands at minimum batch (1,000 each):**
  - Steel: $1.5(1000) + 3.0(1000) + 5.0(1000) = 1{,}500 + 3{,}000 + 5{,}000 = 9{,}500 > 6{,}000$ ✗
  - So producing all three brands simultaneously is **infeasible** under the steel constraint.
- **Two-brand combinations at minimum batch:**
  - Brands 1 & 2: Steel $= 1{,}500 + 3{,}000 = 4{,}500 \leq 6{,}000$ ✓; Labor $= 300{,}000 + 250{,}000 = 550{,}000 \leq 600{,}000$ ✓
  - Brands 1 & 3: Steel $= 1{,}500 + 5{,}000 = 6{,}500 > 6{,}000$ ✗
  - Brands 2 & 3: Steel $= 3{,}000 + 5{,}000 = 8{,}000 > 6{,}000$ ✗
- **Single brand at minimum batch:** All feasible individually.

The feasible region is non-empty (e.g., produce only Zhujiang at 1,000 units, or Zhujiang + Songhuajiang at 1,000 each). The model is **feasible**. The integer nature of $x_i$ combined with the binary linking constraints makes this a proper MILP.
